5. `04_SOURCE_INDEX.md`：仓库文件、职责和审计定位。
6. `REPORT_FOR_EXPERTS.md`：用户原始工作报告（原样保留）。

## 最重要的总判断

当前代码可以作为“可复现的二维晶粒演化 + 简化液固分配工程模型”，但还不能作为“Ti64 晶界偏析/晶界扩散的定量真值生成器”。

在完成独立晶界偏析、晶界扩散、变分拖曳和收敛验证之前，禁止用生产输出训练声称接近真实物理的神经算子。

## 实施纪律

- 不启动全尺寸生产跑来证明问题已经解决；先跑 1D、局部 2D、smoke test。
- 每次只改变一个物理或数值因素，并保存输入 diff、日志、CSV 和诊断 JSON。
- 不把“某个固定网格上的 `k_eff` 接近平衡值”当成网格收敛证据。
- 不把 `wGB=12 µm`、AMR 或 GP 当成已验证修复；它们必须通过材料包中的测试矩阵。
- 任何文献缺失参数都必须标注为 calibration parameter，不得伪装成材料常数。
