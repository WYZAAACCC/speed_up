# 第一部分：研究目标与总体思路

## 1.1 目标

加速 Ti-6Al-4V（Ti64）激光粉末床熔融（LPBF）中**耦合的「晶粒结构演化 + 元素扩散」**计算。

手段：用 **MOOSE 相场仿真**生成训练数据，训练**神经算子**，替代仿真中最昂贵的部分。

## 1.2 核心思路：两条轨道 × 两个阶段

本工作的架构**不是**「一个端到端的算子替代整个仿真」，而是**分解**：

```
拓扑轨道 T:  T_n ──[传统相场 或 神经网络]──▶ T_{n+1}
溶质轨道 C:  C_n ──[逐面神经算子 或 传统求解器]──▶ C_{n+1}

交错耦合：
    上一步的拓扑结果 ──▶ 影响这一步的溶质变化
    这一步的溶质变化 ──▶ 影响下一步的拓扑变化
```

| | 阶段 1：熔化 → 凝固 | 阶段 2：凝固后粗化与偏析 |
|---|---|---|
| **拓扑轨道** | 形核 + 外延生长 + 竞争生长 | 粗化（晶粒长大/消失） |
| **溶质轨道** | 凝固前沿偏析 | 晶界偏析与扩散 |

**每一个格子都可以独立选择「传统求解器」或「神经网络」。**

**关键澄清（用户多轮确认，不得漂移）**：逐面算子学的是**晶界处的元素扩散**，
**不是**晶粒演化；晶粒拓扑演化用**传统求解器**；耦合是**离散/交错**的。

## 1.3 为什么这样分解（而不是端到端）

| 理由 | 说明 |
|---|---|
| **拓扑难学** | 晶粒的拓扑突变（形核、合并、消失）是离散事件。拆开后拓扑变成「晶粒网络 → 新晶粒网络」的干净映射，**可学** |
| **可替换** | 两条轨道可各自选用传统求解器或 NN。贵的用 NN，需要保证精度的用传统求解器 |
| **可归因** | 两条轨道可分别对真值验证，而不是耦在一起无法定位误差来源 |
| **误差隔离** | 1.4 节的尺度分离问题只存在于溶质轨道，不污染拓扑结果 |

## 1.4 最核心的物理矛盾：尺度分离

**这是全部技术选择的出发点。**

| 长度尺度 | 数值 |
|---|---|
| 计算域 | 430 µm × 150 µm |
| 网格 `dx` | **1 µm** |
| 相场弥散界面宽 `W` | 见下方【约定说明】 |
| **真实溶质边界层 `D/V`** | **4.2 nm**（`D_L = M·k_c = 2.52e-9 m²/s`，`V = 0.6 m/s`） |
| **真实晶界偏析区** | **≈ 1 nm** |

**【约定说明】本项目骨架参数是 `wGB = 4.0e-6 m`**（MOOSE 的 `GBEvolution` 关系
`κ = 0.75σw`、`μ₀ = 6σ/w`）。由此派生**两个**宽度，数值差 √2 倍：

```
w = sqrt(κ/μ₀)  = 0.354·wGB = 1.41 µm    ← 生产脚本的「界面分辨率」判据用这个
d = sqrt(2κ/μ₀) = 0.500·wGB = 2.00 µm    ← W/(D/V) 用这个
```

**本报告统一采用 `d` 与实测的 `D_L = 2.52e-9 m²/s`：**

```
W/(D/V) = d·V/D_L = 2.00e-6 × 0.6 / 2.52e-9 = 476
```

（2026-09-18 版写 `≈480`，用的是 `W = wGB = 4 µm` 与 `D = 5e-9`——两个约定各自自洽，
因两次改动恰好抵消而数值接近。）

**薄界面渐近理论要求 `W < D/V` 模型才定量。我们远离定量区 476 倍。**

**实测后果**（脚本 `verify_c1.sh`、`measure_trapping*.sh`）：

```
溶质在弥散界面内的特征时间   W²/D ≈ 6.3e-3 s
LPBF 凝固过程时间                  ≈ 6.5e-4 s
```

**⇒ 溶质在整个凝固过程里连界面宽度都扩散不过去，微观偏析几乎来不及发展**
（实测：完整过程只发展到平衡值的约 1/3；短时算例中 `c_max` 与 `c_min` 逐位相同）。

**⚠ 一个必须请专家澄清的点（Q10）**：通行判据「界面内应有 4–8 个单元」
在不同文献里对「界面」的定义不同——是 `w`、是 `d`、还是 `η` 从 0.9 到 0.1 的
**可见过渡区（约 4d）**？三种读法在 `dx = 1 µm` 下给出的结论相差 8 倍：

| 读法 | 有效单元数 | 判定 |
|---|---|---|
| `w = 1.41 µm` | 1.41 | ✗ 严重欠解析 |
| `d = 2.00 µm` | 2.00 | ✗ 欠解析 |
| 可见过渡区 `≈ 4d = 8 µm` | 8.0 | ✓ 达标 |

**⇒ 本项目的立场**：不靠约定判断，**用实测的越界-网格收敛曲线当裁判**
（§4.8 已实测：纯固相越界随网格收敛到 0）。但生产分辨率（`dx = 1 µm`）下
**这个曲线还没测过**，这正是 Q3 与 §7.3 要做的事。

### 2.4.3 2a：晶界能/迁移率的**取向差**加权

严格复刻 **Moelans 算法 1**（Phys. Rev. B 78, 024113 (2008)），
逐对 `(i,j)` 由取向差 `Δθ` 经 **Read–Shockley** 得到 `σ_ij`，
再解不动点得 `κ*_ij`、`γ*_ij`，最后按 `(η_i²+ε)(η_j²+ε)` 加权平均。
`θ_m = 15°`（Read–Shockley 阈值）。

**已数值验证**（脚本 `check_gb_energy.py`）：28 对晶界的实现界面能
与 Read–Shockley 目标值偏差 **≤ 8.96e-05**。

**关键约束**：不动点用的 `μ` 必须是算例真正使用的 **9e5**，
不能用 `GBAnisotropy` 的公式（那会给 763136）。**已用数值实验证明后者不自洽**
（`γ*` 冲到 1.926 > 1.5，界面本身不稳定）。

### 2.4.4 2b：迁移率的**热梯度对齐**因子

`<100>` 在 2D 中具有四重对称性，故用 `align4 = cos²(2(φ−θ))`。迁移率为

```
L = L2a · L2b,   L2b = 1 + A_ani·(2·align4 − 1),   A_ani = 0.7
```

**已证明**：`align4` 的分子分母中梯度模长 `G²` 精确抵消，
故它**只依赖梯度的方向，与大小无关**（「`G²` 跨 14 个数量级导致病态」的怀疑不成立）。

**已实测竞争生长机制有效**（脚本 `run_cg_test.sh`）：
`A_ani=0.7` 时 `gr0` 面积分数 0.4762 → 0.6515；`=0` 时恒为 0.5000。

**⚠ `A_ani = 0.7` 是唯象占位值**，文献中无此量。见 §6 P5。

### 2.4.5 【2026-09-19】熔化开关的物理修复（④）

**这是本版最重要的模型改动。**

#### 问题

`ACGrGrPoly.C:61` 的残差是

```cpp
return _mu[_qp] * (op*op*op - op + 2.0*_gamma[_qp]*op*SumOPj);   // SumOPj = Σ_{j≠i} η_j²
```

反推得体自由能

```
f_旧 = mu(T) · [ Σ_i (η_i⁴/4 − η_i²/2) + γ Σ_{i<j} η_i²η_j² ]
```

**`mu` 在 T = 1882.2 K 过零，液相里为负。**两处后果：

| | 机理 | 后果 |
|---|---|---|
| (a) | 四次项系数 `mu/4` 变**负** | `η → ∞` 时 `f → −∞` —— **自由能下无界** |
| (b) | 交叉项系数 `mu·γ` 变**负** | 由排斥变**吸引**：相邻序参量互相把对方往上拉 |

**（b）是越界的直接推手**：取 η₁=1、η₂=0.3、`mu<0`，

```
∂f/∂η₁ = mu·(1 − 1 + 2γ·0.09) = 0.27·mu < 0    ⇒ 把 η₁ 往上推
```

**（a）保证它一旦冲过 1 就停不下来。**
**⇒ 这是模型层面的缺陷，不是离散化误差。**

#### 修复方案：标准 Landau 形式

```
f_新 = mu0·Σ(η_i⁴/4)  −  mu_T(T)·Σ(η_i²)/2  +  mu0·γ Σ_{i<j} η_i²η_j²

∂f_新/∂η_i = mu0·η_i³ − mu_T·η_i + 2·mu0·γ·η_i·Σ_{j≠i}η_j²
```

**为什么这是物理的，不是补丁**：Landau 展开
`f = (a/2)Ση² + (b/4)Ση⁴ + bγΣη²η²` 里，**温度只进二次项系数 `a(T)`，
四次项系数 `b` 是常数**。原模型让 `mu(T)` 同时乘四次项与二次项——
**这才是那个非标准的选择**，而它正是「`mu<0` 时四次项变号」的根源。
修复不是「加一项把发散压住」，而是**把偏离标准的那一步改回标准**。

（说明：最初向用户提过一版 ad-hoc 修法——把四次项系数冻结、保留原 tanh 当驱动力。
**用户选择了标准形式，而不是那一版。**）

**可证的三个性质**：

1. **驻点有界**：`∂f_新/∂η_i = 0` ⇒ `η_i² = mu_T/mu0 − 2γ·Σ_{j≠i}η_j² ≤ s ≡ mu_T/mu0`。
   而 `mu_T ∈ [−2mu0, mu0]` ⇒ `s ≤ 1` ⇒ **`η ≤ 1` 恒成立**。
   **原模型的越界在数学上不可能再出现。**
2. **自由能有界**：四次项与交叉项系数恒正 ⇒ `η→∞` 时 `f→+∞`。
3. **固相不变**：`mu_T = mu0`（T 足够低）时 `f_新` 与 `f_旧` **逐项恒等**。

**熔化温度不变**：`mu_T` 过零仍在 T = 1882.2 K。

#### 实现方式（生产输入的最小改动）

利用一个恒等式，**不必重写核结构**：

```
ACGrGrPoly 取【常数】mu = mu0   →  mu0·(η³ − η + 2γηΣ)
再加 AllenCahn(f_drive)         →  (mu0 − mu_T)·η_i
两项相加 = mu0·η³ − mu_T·η + 2·mu0·γηΣ   ✓ 正是 ∂f_新/∂η_i
```

其中 `f_drive = (mu0 − mu_T)/2 · Ση_i²`，故 `∂f_drive/∂η_i = (mu0−mu_T)·η_i`。

**改动清单**：

| 文件 | 改动 |
|---|---|
| `stage1_meltpool_c.i` | `[barrier_mu]`→`[barrier_muT]`（属性名 `mu`→`mu_T`）；新增 `[mu_barrier_const]`（常数 `mu`=9.0e5）；新增 `[f_drive]`；`[Kernels]` 增 8 个 `AllenCahn`；`[f_grain]` 改 Landau 形式 |
| `run_nonad_prod.sh` | 断言块名同步；**新增**常数势垒与 `mu0` 的逐位一致性硬断言 |
| `gate0_report.py` | 同上 |
| `tests/verify_f_grain.i` + `.py` | 验证判据改为「ACGrGrPoly(mu0) + AllenCahn(f_drive) 之和」 |

**与生成器的兼容性**：`gen_aniso_nonad.py` 注入的各向异性 `kappa_op`/`gamma_asymm`
被原样使用；`splice_aniso_nonad.py` 把 8 组核追加在 `[Kernels]` **末尾**，
不碰新增的 AllenCahn（已实测生成的 `stage1_meltpool_d.i` 结构正确）。

#### 额外收益：各向异性标定在热区变得自洽

生成器按 **μ = 9e5** 解出 Moelans 不动点 `(a*, γ*)`。
**而原模型里 `μ(T)` 在热区偏离 9e5，且 `σ ∝ sqrt(μ)`**
——**即热区的各向异性晶界能本来就是错的。**

④ 把势垒系数变成常数 `μ0 = 9e5` 后，`(a*, γ*)` 与注入的 κ/γ 在**全域**自洽。

**⚠ 但这没有解锁 MOOSE 内置的 `GBAnisotropy`**：它仍然
`declareProperty<Real>("mu")`（`GBAnisotropyBase.C:53`）会与我们的 `mu` 双声明，
且 `_mu_qp = 6·sigma_init/wGB` 是**硬编码公式**不是参数（`GBAnisotropy.C:63`）。
严格成对取向差模型仍需写 C++ 材料。

#### 代价（列进 Gate 2 标定，不是自由参数）

`σ(T)` 仍然随温度下降，但**指数变了**：

| | `σ(T)/σ₀` | T = 1830 K 处 |
|---|---|---|
| 原模型 | `sqrt(s)` | 0.8706 → **0.5224 J/m²** |
| Landau | `s` | 0.7580 → **0.4548 J/m²**（−13%） |

界面**宽度**公式不变（`d = sqrt(2κ/mu_T)`）。
真实 `dσ/dT` 约 −1~−3×10⁻⁴ J/m²/K ⇒ 1530 K 内降 25~77%，
**Landau 的 24% 反而比原版的 13% 更接近实测**【推理，未核实】。
**⇒ 这是 Gate 2 的重新标定项**，且引出一个必须先查清的问题（见 §6 P6）。

# 第三部分：关键决策及其理由

## 3.1 为什么不用自动微分（AD）

MOOSE 支持 AD（用对偶数数组精确求雅可比）。我们**实现了完整的 AD 版本**
（`ADTimeDerivative`/`ADGrainGrowth`/`ADACInterface` + `ADDerivativeParsedMaterial` ×4），
并用 `-snes_test_jacobian` 验证 AD 的雅可比**确实更精确**
（`‖J−J_fd‖/‖J‖ = 3.2e-08`，非 AD 为 1.2e-3）。

**但 AD 版本实测有致命问题：牛顿迭代【线性爬行】。**

| 版本 | 牛顿行为 |
|---|---|
| 非 AD | **二次收敛**：`1.31e-4 → 4.01e-10`（9 次迭代） |
| AD | **线性爬行**：12 次迭代仅从 `1.58e-4` 降到 `5.85e-5`（每步约 4%） |

**⇒ 结论：AD 的雅可比更精确，却收敛更差，根因未查明**（§6 P8）。
因此**生产使用非 AD 版本**。

**⚠ 由此产生一个陷阱**：仓库根目录的 `gen_aniso.py`/`splice_aniso.py` 是 **AD 版**生成器，
非 AD 版已冻结在 `frozen/`。
**用错生成器会得到 AD 版算例，表现为牛顿爬行、`DIVERGED_MAX_IT`、
且砍 `dt` 无效——与「`dt` 过大」的症状极像，极易误判。** 本项目已因此误判过一次。

## 3.2 为什么用 ASM 而不是 MUMPS（直接求解器）

**缩小算例（215×75）上的结论与全尺寸相反，这是一个必须记录的教训**：

| 配置 | 215×75 | **全尺寸 430×150** |
|---|---|---|
| MUMPS（精确 LU） | 955 s | **2014 s** |
| ASM + ILU | 1522 s | **499 s** |

**全尺寸下 ASM 快 4 倍、内存减半（3182 MB vs 6418 MB）。**

**原因**：MUMPS 的 fill-in 是**超线性**的——内存从 486 MB（215×75）
涨到 6418 MB（全尺寸），**13 倍**，而单元数只涨 4 倍。

**⇒ 生产必须用全尺寸，所以必须用 ASM。缩小算例上的性能结论不可外推。**

**且不牺牲物理**：已证明**同容差下 ASM 与 MUMPS 给出同一个解**
（相对 L2 差异 `1e-13 ~ 1e-15`，且不随时间增长，脚本 `cmp3.py`）。

## 3.3 为什么 `nl_abs_tol` 必须 ≤ 1e-9

三路对照实验（A/B/C/D，脚本 `solver_compare*.sh`）：

| 对比 | 只变什么 | `gr0` 相对 L2 差异（t=4e-5） |
|---|---|---|
| C vs B | **只换求解器**（同容差 1e-6） | **1.4e-13** |
| A vs D | **只换求解器**（同容差 1e-9） | **~1e-15** |
| A vs C | **只换容差**（同 MUMPS） | **2.1e-03** |

**⇒ 精度完全由容差决定，与求解器无关。**

**逐变量残差**进一步定位（脚本 `diag_scaling.sh`）：

| 变量 | `nl_abs_tol=1e-6` 收敛时 | `1e-9` 收敛时 |
|---|---|---|
| `gr0`–`gr4` | **1.7e-7 ~ 7.4e-7**（主导） | 3.9e-13 ~ 2.1e-10 |
| `c` | 1.8e-12 | — |
| `w` | 4.6e-18 | — |

**⇒ 残差被序参量主导，且 `|R|_η = 3e-7` 对应约 `2e-3` 的解误差（比例约 10⁴）。**
**残差容差是本问题解精度的坏代理。** 用 `1e-6` 则溶质场「真值」只在 0.2% 精度上成立。

**另**：`l_max_its` 从 30 提到 300 的依据是——非 AD + 300 是零失败，
AD + 300 有 2 次 `DIVERGED_ITS`。

## 3.4 为什么起始 `dt` 必须给 1e-7

**现象**：`dt = 1e-6` 或 `4e-6` 起步时，**首步反复失败**——牛顿爬行十几到二十几次
迭代不收敛（`DIVERGED_MAX_IT`），然后砍步长重试。
某次全尺寸基准因此**白烧 2839 s（47 分钟）**。而把首步降到 **5e-7** 即正常收敛。

**⇒ 这不是物理问题，是配置问题。起始 `dt` 取 1e-7，让 `IterationAdaptiveDT`
（`growth_factor = 1.5`）自行爬升。**

## 3.5 其他被排除的方法及原因

| 方法 | 排除原因 |
|---|---|
| **AMR（自适应网格）** | **⚠ 结论已撤回，见 §6 P14。** 原记录为「实测会破坏溶质守恒」，但**查无任何可追溯的实测记录**。现降级为「**待复测**」 |
| **换填充排序**（`nd`/`metis`/`rcm`） | 三种**全部失败**：`nd` 导致 MUMPS 分解崩溃（`DIVERGED_PC_FAILED`，疑零主元）；`metis` 在该 PETSc 构建中**未注册**；`rcm` 同样失败 |
| **`-snes_lag_preconditioner 5`** | ✅ 有效（358 s vs 基线 405 s，**1.13×**），**已纳入方案** |
| **显式时间积分** | 相场方程刚性极强（界面弛豫时间 ~4.7e-6 s），显式积分步长会被压到不可接受 |
| **`GBAnisotropy` 材料** | **确认不可用**，三个独立死结：① 它硬编码声明 `mu` 属性，与我们的常数势垒冲突；② 它的 `σ` 是逐对**常数表**（无法表达 Read–Shockley），且**完全没有热梯度对齐机制**；③ **它不提供任何导数属性**，而 `ACInterface` 无条件索取 `dL/dop` 等——拿不到时 MOOSE **静默填零、不报错**（残差对、雅可比错，是个会让人误以为「跑通了」的陷阱） |
| **巨势相场法（GP）** | **暂缓**，见 §3.6 |

### 关于 `dtmax = 2e-6`（**限制提速的硬约束**）

代码注释写明「【关键】**界面弛豫时间 ~4.7e-6 s**；不加 dtmax 会发散」。
**⇒ 该值是为低于界面弛豫时间而设的物理约束，不是随手取的，不宜放宽。**

**后果**：步数（约 330 步）无法靠增大 `dtmax` 压缩，
**单条轨迹 12–22 小时的耗时无法通过时间步策略改善**。
（本项目在**测试脚本**中曾用 `dtmax = 4e-6` 跑通短算例，但那逼近弛豫时间，
**不宜据此建议放宽生产值**。）

## 3.6 为什么巨势相场法（GP）暂缓

GP 的设计目的是「界面宽度任意、仍然定量」——把溶质变量从浓度 `c` 换成化学势 `w`，
浓度成为代数导出量，从而消除 `W²/D` 这个时间尺度。**这正好针对 §1.4 的矛盾。**

经彻底调研（MOOSE 源码）后确认：

| 我们的需求 | GP 能否支持 |
|---|---|
| 8 个非守恒序参量（多晶） | ✅ 无上限（需加 1 个液相序参量，共 9 个） |
| 温度驱动的熔化开关 | ✅ 有现成范例（液相巨势加 `−S(T−T_m)` 偏置） |
| 2a 各向异性 | ✅ 近乎零改动 |
| 2b 热梯度对齐 | ✅ 零改动 |
| 溶质分配 | ✅ **精确映射**，非拟合 |
| 界面参数 | **κ = 0.75σW、m = 6σ/W —— 与我们现有参数完全相同** |

**代码层面无阻塞，工作量约 1–2 周（改输入文件，无 C++、无重编译）。**

**但暂缓，原因是一个未经验证的核心假设**：

> **MOOSE 代码库中没有任何一个 GP 算例运行在 `W/(D/V) ≫ 1` 的区间。**
> 全部测试与范例都落在 `W/(D/V) ~ O(1)`。

文档只承诺「界面厚度与能量可独立设置、允许粗网格」，
**没有承诺「任意界面宽度都定量」**。理论依据在文献
（Plapp, PRE 84, 031601；Aagesen et al., PRE 98, 023309），
但**不在 MOOSE 的测试覆盖里**。

**而我们是 `W/(D/V) ≈ 476`。若该假设不成立，整个改造收益为零。**

**更麻烦的是**：抗截留项 `AntitrappingCurrent` 本身的设计前提也是薄界面
（`W ≲ D/V`），在 476 处**没有任何证据表明它的 `O(W)` 展开仍收敛**。

**⇒ 因此规划了一个 1–2 天的「Phase 0」验证实验（Gate 1 步骤 3）**：
1D 平面前沿，扫描 `W/(D/V)` 从 1 到 500，分别接与不接抗截留，
**用 `k_eff` 偏差数据决定是否推进**。这是唯一可能让我们止损的地方。

**⇒ 步骤 0 已建成该基准并验证通过**（见 §4.7）。

## 3.7 【2026-09-19 新增】为什么 ④ 用 `AllenCahn` 而不是 `MatReaction`

`AllenCahn` 的雅可比是**符号完备**的——`AllenCahn.C:52` 对角 `∂²F/∂η²`、
`:65` 非对角 `∂²F/∂η∂η_j`（对全部耦合变量）、`ACBulk.h:105` 迁移率乘积法则项。

而 `MatReaction` 只对**已声明**的参数求导（`MatReaction.C:96-109`），
缺失的导数经 `getMaterialPropertyDerivative` **静默返回 0**。
**这与 D 版不收敛（雅可比少项、残差还在）是同一类缺陷。**

**⇒ 凡是「新增一个自由能项」的需求，一律优先用 `AllenCahn`。**

## 4.4 成本分解（回答「NN 替代什么才划算」）

**方法**：全尺寸 + ASM，串行跑四个变体，各 2 个时间步。

| 变体 | 墙钟 | 牛顿迭代 | 雅可比均值 |
|---|---|---|---|
| **V0 完整基线** | **482 s** | 14 | 22.5 s |
| **V1 去各向异性材料（2a+2b）** | **207 s** | **7** | 20.3 s |
| **V2 去溶质 `c`/`w`** | **419 s** | 14 | 19.9 s |
| **V3 去两者** | ~190 s | 7 | 18.5 s |

**两条结论**：

- **溶质只占约 13%**，且**不改变牛顿迭代数**（14→14）
- **各向异性材料占约 57%，但机制不是「装配变便宜」**（22.5→20.3 s，只省 10%），
  **而是「让牛顿迭代数翻倍」**（14→7）

**⚠ 该实验设计有一个缺陷**：V1 同时改变了「装配成本」与「收敛难度」两个变量，
因此 57% 不能直接读作「各向异性材料的装配成本」。

# 第六部分：当前遇到的问题

> P1–P13 沿用 2026-09-18 版（状态已更新）；**P14–P19 为本版新增**。

## P1【最严重】溶质尺度分离（原缺口 #3，编号 C4）

**问题**：真实溶质边界层 `D/V ≈ 4–8 nm`，模型弥散界面宽 2 µm，差约 500–1000 倍。
实测模型把溶质响应时间从物理的 `(D/V)²/D ≈ 7e-9 s` 拉长到 `W²/D ≈ 6.3e-3 s`，
**放慢约 10⁶ 倍**。

**后果**：微观偏析**幅度错约 3 倍**（完整过程只发展到平衡值约 1/3）、
**空间尺度错约 1000 倍**。

**候选解**：巨势相场法（§3.6）。**但有未验证的核心假设，需 Phase 0 实验（Gate 1 步骤 3）。**

**不确定性**：
- GP 在 `W/(D/V) ≈ 476` 处是否定量 —— **MOOSE 测试覆盖空白，文献无直接背书**
- 抗截留项在该区间是否仍有意义 —— **无证据**
- 若 GP 不成立，备选是「降低 `W` + 细化网格」（代价见 §7.3）或
  「用解析/半解析边界层模型旁路相场」

## P2【严重】溶质→拓扑反馈完全缺失（C8）

**问题**：自由能 `f_loc` **只进入 `c` 方程**（`SplitCHParsed`），
**不进入 `η` 方程**。⇒ **变分不一致，溶质拖曳（solute drag）完全缺失。**

**这不是疏漏**：源文件注释明确记录这是主动推迟的：
> 「所以这里**只在 c 方程里体现分凝，η 方程不反向耦合**。代价：**暂时没有溶质拖曳**。」

**修法（原则明确）**：让自由能成为单一泛函。拆成
`f = f_phase(η) + f_solute(c, η)`，η 方程加 `ACBulk(f_name = f_solute)`。
**溶质拖曳会自然涌现，不需手写拖曳项。**
**（注意：④ 的改动已经让「温度变号」这个旧顾虑不再成立——`mu` 现在是正常数。）**

**不确定性**：
- 加上后**晶粒动力学是否被破坏**（收敛性、2a/2b 验证）—— 未知
- 需要一个**受控实验证明拖曳真的存在**（同一条晶界，改变溶质浓度与扩散系数，
  比较迁移速度）—— 方案未定

## P3【中等】形核缺失（C3）

**问题**：核列表里没有任何形核机制 ⇒ 算不出等轴晶。

**严重性判定**：文献调研发现 Ti64 的**生长限制因子仅 0–10 K**
（比 Ti-4Fe 的 42 K 小一个数量级），文献共识是
「Ti64 在 LPBF 中通常假设熔池内无形核、全靠基底外延生长」。
**⇒ 我们的全柱状结果对 Ti64 定性上是对的**，此缺口严重性**下调**。

**但**：它是**算子 1（熔化→凝固）的核心内容**。

**机制已查清**（MOOSE 源码）：`GrainTracker` 的 `reserve_op` +
`DiscreteNucleationForce`/`Reaction` + `DiscreteNucleationFromFile`。
**并已实测澄清一个关键语义**：`reserve_op` 是**【永久槽位】**——
每个保留 op 承载 1 个形核晶粒、取向固定、永不被 remap
（最小实验 `b0a_nucleation.i`，`max_gr3: 0 → 1.17`）。
⇒ **`op_num` 必须 ≥ 基体晶粒数 + 期望形核次数**。

**⚠ 与 ④ 相关的新约束**：④ 之后若采用 `wGB = 12e-6`（见 §7.3），
界面宽 4.24 µm ⇒ **小于约 10–17 µm 的晶粒无法被表示**，形核产生的核会被直接抹掉。
**这是 P3 与 Q3 的交叉约束。**

## P4【中等】取向绑在序参量而非晶粒（C0）

**问题**：当前算例把每个序参量的取向 **θ_i 硬编码**展开在
`orient_cos`/`orient_sin`/`kappa_aniso`/`gamma_aniso`/`L2a`/`align4` 的解析式里。
而 MOOSE 的正规架构是取向绑定**晶粒 ID**。
**后果**：`GrainTracker` 的 remap（形核必需）会改变晶粒所占的序参量 ⇒
**取向被改掉**，物理错误。

**三条出路**（已用源码逐行核实）：
1. 保持 per-op 取向 + `reserve_op`（零物理改动，但形核次数上限 = 保留 op 个数）
2. AuxVariable 桥（`OutputEulerAngles`），约 1 天，但**丢掉逐对 Read-Shockley σ**
3. 写 per-grain 取向的 C++ Material（约 250 行 + 重编译），**唯一 100% 保真**

## P5【中等】`A_ani = 0.7` 无标定依据（C2）

**文献调研结论**：**β-Ti 体系中晶界迁移率各向异性强度从未被定量测量过。**
最接近的工作（Wu et al. 2012）用的是**开关参数（0 或 1）**，不是连续强度。
**⇒ 只能标定。** 做法：灵敏度扫描 `A_ani ∈ {0, 0.3, 0.7, 1.0}`，
量织构强度与晶粒长宽比，与 LPBF Ti64 实测织构比对。

| `k`（V 的 β/液） | 0.63 | 原出处（Lee 2025）**未核实**，但方向（k<1）由 LBM-CA 研究支持 |

**【2026-09-19 新增】σ 的参考温度问题**：④ 之后 `σ(T) = σ_anis·s(T)`。
**`0.6 J/m²` 是「工作温度下的值」还是「T→0 的参考值」？**
Ti64 的 β 相只存在于 1268 K 以上，所以它**很可能是一个高温测量值**。
若是，则**当前模型与修复都偏了**：应让 σ 在工作温度（~1830 K）等于 0.6，
而不是让 σ(300 K) = 0.6。
**⇒ 这是一个一参数重标定（生成器重跑一次），但决定 Gate 1 的判据拿什么当基准。
必须先查清 Gornakova & Prokofjev 2020 的测量温度。**

## P7【严重·方法论】NN 的「真值从哪来」问题

**这是整个方案成立与否的核心。**

用户要求算子学**接近真实的物理**。但真实晶界偏析区约 1 nm
⇒ 要解析它需要 **0.25 nm 量级网格**，是当前的 **4000 倍细化**，跑不动。

> **如果真值需要细网格仿真，而细网格算不起 —— 训练数据本身就没有。这是个循环。**

| 出路 | 做法 | 问题 |
|---|---|---|
| (a) 中间尺度真值 | `dx = 0.25 µm`（4× 细化）做少量高保真仿真 | 4× 细化仍差 1000 倍 |
| (b) 解析/半解析真值 | KGT 或溶质边界层解析解 | 额外建模，且只能给标量关系 |
| (c) **GP 改写后的模型当真值** | 若 GP 能在粗网格定量，它本身就是「便宜的真相」 | **尚未验证**（即 P1 的 Phase 0） |

## P14【严重·结论撤回】「AMR 破坏溶质守恒」这条结论没有可追溯的出处

**2026-09-18 版写的是**：「**实测会破坏溶质守恒**（本项目早期结论）」。

**本次逐条追查的结果**：这条结论在仓库里只以三种形式存在，**全部是转述**：

- `ROADMAP.md:739`：「AMR | ❌ 破坏守恒（**此前已实测**） | ❌ 放弃」
- `REPORT_FOR_EXPERTS.md:346`（旧版）：「**实测会破坏溶质守恒**（**本项目早期结论**）」
- `ROADMAP.md:755`：「（但注意 … 已实测 **AMR 会破坏守恒**）」

**没有量级、没有脚本、没有日期、没说是哪个算例。**
**这与已被推翻的「7.3e-07 残差地板」、被误判的「外部 SIGKILL」是同一类传承结论。**

### 机制分析（说明为什么「必然破坏」不成立）

| 操作 | 机制 | 是否守恒 |
|---|---|---|
| **加密** | `c` 是 Q1 Lagrange 场。细分网格上插值**精确复现原函数** | ✅ **积分精确不变** |
| **粗化** | 细网格解压回粗网格 | 取决于投影方式 |
| **L2 投影** | `∫P_H u = (P_H u, 1) = (u, P_H·1) = (u,1) = ∫u`（常数属于 Lagrange 空间） | ✅ **严格守恒** |

**⇒ 取决于 MOOSE/libMesh 换网格时究竟用插值还是 L2 投影。这个一测就知道。**

### 但真正可能的拦路虎在别处（⚠ 可能才是原结论的真实来源）

本算例有 **20 多个 `DerivativeParsedMaterial`**，且是一棵深树：

```
η → kappa_aniso / gamma_asymm / align4 → L2b → L
```

AMR 换网格时这些**有状态的**材料属性要重投影。**MOOSE 自己把它标成实验性的**：

```
FEProblemBase.C:8947 → "Using EXPERIMENTAL Stateful Material Property projection with Adaptivity!"
```

**重投影 `η` 没问题（它是解变量，有严格转移），但重投影 `L`、`align4`
这种由 η 层层派生的量就会掉精度**，而误差会回到残差和雅可比里。
**⇒ 原结论观察到的「守恒破坏」，可能不是 `c` 的守恒丢了，
而是材料属性重投影污染了整个解。**

### 为什么这条重要：AMR 可能省 9 倍算力

**方案**：`[Adaptivity]` + 标记 `0.05 < η < 0.95` 的单元 + refine 2 级。

| | 单元数 | 分辨率 | 内存 |
|---|---|---|---|
| 现状（`dx=1 µm`，全局） | 64,500 | `w/dx = 1.41` ✗ | 3.45 GB |
| 全局加密 2 级 | 1,032,000（16×） | 5.7 ✓ | **55 GB ✗** |
| **AMR 只加密晶界 2 级** | **~115,000（1.8×）** | **5.7 ✓** | **~6.2 GB ✓** |

（晶界单元占比按 3.5–7% 估算【推理】。）

## P15【中等·既有缺陷】溶质方程的雅可比缺一整块

**现象**：每次运行都打印

```
Missing coupled variables {gr0, gr1, ..., gr7}
(add them to coupled_variables parameter of coupled_parsed)
```

**根因**：溶质核 `SplitCHParsed` 从未声明过 `f_loc` 里的序参量，而

```
f_loc = k_c/2·(c−c₀)²  +  A_part·c²·(gr0² + … + gr7²)
```

**后果**：残差是对的，但**雅可比里缺了「经 `A_part·c²·Ση²` 传递到 η」那一整块**。
⇒ 解不会错，但**牛顿迭代数会偏多**。

**这与 D 版不收敛是同一类缺陷。已确认是改动前就存在的**，不是 ④ 引入的。
**修法是一行**：给 `[coupled_parsed]` 加 `coupled_variables = 'gr0 … gr7'`。

## P16【中等·物理输入】激光温度场在源点附近达到 14984 K

**现象**：`laser_T` 是 Rosenthal 型解析解，在 `R = 10 µm` 处给出 **T ≈ 13870 K**，
实测算例的 `T_max = 14984 K`。**Ti64 沸点约 3315 K。**

**评估**：

- **点源奇异性是 Rosenthal 解固有的**，不是笔误——正确公式在 `R→0` 同样发散
- **熔池形状大概率不受影响**：`T = 1882 K` 等值线在 `R ≈ 30 µm` 处
- **但深熔池区的材料属性在 1.4 万度上求值**，直接推高刚度
  （`L = 4/3·M₀·exp(−Q/k_bT)/wGB` 在该温度达 `5.3e6` 量级）

**⇒ 建议**：核对前因子 `28/(2π·20)` 是否为**单位笔误**；
若是有意为之，则在沸点处**截断 T**。**不要顺手改**——要单独记账。

## P17【方法论】相场界面宽 `ε` 从未做过收敛性研究

**我们的 κ、μ₀、L 关系（`κ = 0.75σw`、`μ₀ = 6σ/w`、`L = 4/3·M₀/w`）
正是保持 σ 与 M 不随 `wGB` 变的那组标准关系**（`check_wgb_invariance.py`
已验到 8.96e-05）。所以模型**对 `ε` 是正确参数化的**。

**但项目只在 `wGB = 4e-6` 这一个值上跑过全部算例。**
Gate 1 步骤 1 做的是**网格**收敛（`dx` 变、`ε` 固定），**那不是 `ε` 收敛**。
**已有的部分证据只覆盖**：平衡界面的 σ、一维平面前沿速度。
**没有覆盖**：曲率驱动长大、三叉晶界、拓扑事件、各向异性。

**⇒ 在拿到 `ε`-收敛曲线之前，「`wGB = 12e-6` 可以」或「不可以」都是没有证据的判断。**

### 关于「界面加厚到晶粒宽的 10.6%」会有什么影响

| 受影响？ | 项 | 说明 |
|---|---|---|
| ✅ 已验不变 | σ、一维速度、Moelans 不动点 | `check_wgb_invariance.py` |
| ⚠ 未验 | **曲率驱动长大（R² 斜率 = −2Mσ）** | **理论不变，未实测** |
| ⚠ 会变差 | **三叉晶界** | 弥散模型本有「伪第三相」效应，`ε` 越大越强 |
| ⚠ 硬约束 | **小于 ~2–4ε（约 10–17 µm）的晶粒无法表示** | **会卡住未来的形核（P3）** |
| ✅ 会变好 | 各向异性的角分辨率、网格诱导各向异性 | 单元数从 1.41 涨到 4.24 |

**关键判断**：`ε` **不是物理量**，是正则化参数。真实晶界约 1 nm，本项目用 1.41 µm
**已经比真实厚 1400 倍**。「4.24 µm 太厚」这个问法本身不成立。
**唯一的标准是：观测量在 ε 变化时是否稳定。**

## 7.3 【建议采纳】`--wgb 12e-6`，但先做 `ε`-收敛性验证（P17）

**理由**：它是**唯一一个不花算力就把欠解析修掉**的杠杆。

```
wGB = 4e-6  →  w = sqrt(κ/μ₀) = 1.41 µm  →  w/dx = 1.41  ✗
wGB = 12e-6 →  w = sqrt(κ/μ₀) = 4.24 µm  →  w/dx = 4.24  ✓（同一 dx = 1 µm 网格，成本不变）
```

（此处统一用 `w` 约定。若按 §1.4/Q10 的「可见过渡区」读法，现状可能已达标——
**这正是要先请专家澄清 Q10 的原因**。）

**对比加细网格**：要做到 `w/dx = 4` 需 `dx = 0.354 µm` ⇒ 515,000 单元 = 8×
⇒ **27.6 GB > 23 GB** ✗，且 33 min/步 ✗。**这条路是堵死的。**

**但必须先验证**。**建议先做 `ε`-扫描，四个观测量**：

1. 圆形晶粒的 `R²` 斜率（曲率驱动长大 ⇒ `σ` 的有效值）
2. 静止平界面的 `σ_eff`（工具已有）
3. 三叉晶界的结点角度与迁移率
4. 一个晶粒消失时的**临界半径**（拓扑事件）

对 `wGB = 2, 4, 8, 12 µm` 各跑一遍。**判据：这些量对 `ε` 的变化在容差内平坦。**

**顺带一个很便宜的诊断（半小时）**：把 `A_ani = 0` 且 κ/γ 各向同性化，跑同一算例。
**若越界明显下降 ⇒ 欠解析正被各向异性放大**；若不降 ⇒ 纯网格问题。

### 关于甲-8：本项目已自行推导的论证路径（**需专家确认严密性**）

已知 Fisher / Whipple / Suzuoka 的 **B 型动力学解只依赖乘积 `P = s·δ·D_GB`**，
**与 `δ` 单独取值无关**（这正是「三重积」之所以叫三重积的原因）。
因此若弥散晶界宽为 `w`，只要取

```
s · w · D_GB^模型  =  s · δ · D_GB^真实
```

就能**精确复现同一个 `P`**——这是**恒等式级论证**，不是近似。

**⚠ 但本项目实测发现一个前提不满足。**
B 型区要求 `√(D_体·t) ≫ w`，而我们（阶段 1，`t = end_time = 6.5e-4 s`）：

```
√(D_体·t) = √(2.52e-9 × 6.5e-4) ≈ 1.28 µm
```

而弥散晶界的厚度（三种约定下分别是 `w = 1.41 µm`、`d = 2.00 µm`、
可见过渡区 `≈ 4 µm`）**都大于或接近 1.28 µm**。

**⇒ 根本不在 B 型区，上述恒等式在此处用不上。**
（**这个结论对三种宽度约定都成立**，所以不依赖 §1.4 的约定争议。）

**这引出一个更深的问题（请专家评估，并入 Q1）**：是否存在另一个动力学区间
（例如 `√(D_体·t) ≪ w` 的 A 型或 C 型区）有类似的不变量，
使得弥散晶界的等效参数标定仍然成立？还是说**必须把晶界当作独立实体
（Gibbs 界面，见 `GB_SOLUTE_GOAL.md`）才能绕开这个问题**？

> 这一条与 §6 P1（尺度分离）、P7（NN 的真值从哪来）是**同一个问题的三个侧面**：
> 弥散晶界在 `W/(D/V) ≫ 1` 时到底还能不能定量地表示晶界扩散。
> **它也是「为什么必须做 Gate 1 步骤 3 的扫描」的根本理由。**

# 第十一部分：一句话总结

**本工作的实质进展是：把一个「自由能下无界」的模型缺陷按教科书形式修好了
（固相极限下与旧模型逐位相同），顺带发现「序参量越界」其实是两个独立问题叠在一起——
修好了其中一个，另一个（界面欠解析）才是生产分辨率下的主导项。**

**同时在 Gate 0 的执行中发现：一条被当作定论的旧结论（「AMR 破坏守恒」）
没有任何可追溯的实测记录，而它挡着一条可能省 9 倍算力的路。**

**当前最需要专家判断的四件事**（按「能省掉多少工作」排序）：

1. **Q10**：「界面内应有 4–8 个单元」的「界面」是哪个宽度？
   **成本最低、可能收益最大**——若按「可见过渡区」读法我们其实达标，
   则 P17 / §7.3 的整条工作线都可以省掉。
2. **Q1**：巨势相场在 `W/(D/V) ≈ 476` 处到底定量不定量（决定整个技术路线）
3. **Q3**：`ε`-收敛性研究该怎么设计（若 Q10 判定确实欠解析，这是主要修复手段）
4. **Q4**：AMR 的材料属性重投影在移动晶界下能不能用（可能省 9 倍算力）
