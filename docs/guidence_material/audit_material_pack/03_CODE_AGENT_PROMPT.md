# 可直接交给代码 agent 的任务说明

你正在维护 `WYZAAACCC/speed_up`。目标是在笔记本级 CPU/内存上建立可复现、尽可能物理正确的 Ti64 LPBF 相场与晶界溶质基准。不要直接启动全尺寸生产跑。

## 第一任务：只修确定性 bug

1. 在 `pipeline/stage1_meltpool_c.i` 的 `SplitCHParsed` 增加 `gr0...gr7` 的 `coupled_variables`。
2. 添加脚本检查日志中不存在 `Missing coupled variables`。
3. 添加/运行局部 Jacobian 测试。
4. 不改变 `kappa_c`、`M`、自由能、网格和时间步。
5. 提交前输出输入 diff、测试日志和基线对比。

## 第二任务：建立物理最小模型分支

不要直接改生产文件。复制到 `pipeline/validated/` 或使用参数化输入。

1. 先实现 `D_L,D_S,D_GB` 可分层的 1D 模型。
2. 再拆出液固分配自由能和固固晶界偏析自由能。
3. 让溶质自由能同时进入 `c` 和 `η` 方程，保持变分一致。
4. 每次只加一项，并运行对应测试矩阵。

## 第三任务：解析欠解析

1. 对 `kappa_c` 做极限扫描，不得把 0.105 µm 说成已解析。
2. 对 `wGB` 做 epsilon 扫描，保持 σ、M 物理不变量。
3. 记录平面界面、圆晶粒、三叉晶界、移动前沿的收敛曲线。
4. 只有收敛后才尝试 AMR。

## 第四任务：温度与求解器

1. 让温度截断可开关；比较原始 Rosenthal、3200 K、3500 K。
2. 所有材料属性都使用同一个有效温度。
3. 保留 ASM 路线；不要默认 MUMPS。
4. 默认 4–8 MPI 进程，记录峰值 RSS。

## 代码质量要求

- 所有新增参数都有单位、来源或 `calibration` 标记。
- 所有输入生成都可由单条命令重现。
- 所有测试失败都退出非零。
- 不吞掉 MOOSE warning。
- 不删除旧测试；新增测试必须说明它防止哪类回归。
- 每个阶段完成后更新 `VALIDATION_STATUS.md`。

## 完成定义

只有 T1–T9 通过，才能讨论正式模型；只有 T11–T13 通过，才能声称晶界溶质物理；只有 T16 通过，才能生成神经算子训练集。
