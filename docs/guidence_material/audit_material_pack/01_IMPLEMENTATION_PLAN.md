# 后续实施计划

## Phase 0：冻结基线（先做）

目标：在任何模型改动前，保存当前 HEAD 的可复现基线。

必须保存：

- 生成器 SHA256；
- 完整 `.i` 文件；
- `run.log`、CSV、诊断 JSON；
- MOOSE、PETSc、编译器版本；
- 网格、时间步、内存和 Newton/GMRES 统计。

不通过则停止后续工作。

## Phase 1：确定性代码修复

### 1.1 修复溶质雅可比

只增加 `coupled_variables=gr0...gr7`，不得同时改变 `M`、`kappa_c` 或自由能形式。

验收：Jacobian 差异、Newton 迭代、守恒和短时间解均通过。

### 1.2 温度截断实验

加入可开关的 `T_cap`，至少比较：原式、3200 K、3500 K。只比较短时间局部算例，不跑生产。

验收：熔池等温线、晶粒速度、残差、温度最大值变化有记录。

### 1.3 溶质迁移率分层

将 `D_L`、`D_S`、`D_GB` 解耦。先在 1D 静态相界面上验证守恒和化学势平衡，再验证移动前沿。

## Phase 2：解决欠解析与 `kappa_c`

### 2.1 `kappa_c` 极限

比较 `1e-11, 1e-13, 1e-14, 1e-15, 0`。对于每档至少使用两种 `dx`。

如果 `kappa_c=0` 可稳定工作，优先将溶质方程改为守恒二阶扩散形式，减少四阶刚性和一个变量 `w`。

### 2.2 epsilon 收敛

扫描 `wGB=2,4,8,12 µm`，并保持物理 `σ`、`M` 不变。每个 `wGB` 至少配两档网格。

必须测：平面界面、圆晶粒、三叉晶界、移动溶质前沿。

### 2.3 AMR

只在前两阶段通过后测试 AMR。分别测试只加密、加密+粗化、关闭状态材料重投影的情况。守恒、速度、晶界过剩和材料属性变化必须分开记录。

## Phase 3：重建晶界溶质模型

推荐结构：

```text
体相 c(x,t)                 -> 体扩散
晶界指示 h_gb(η)             -> 独立偏析和快速扩散
f_partition(c, phase)        -> 液固分配
f_segregation(c, h_gb)       -> 固固晶界偏析
δF/δc                        -> 溶质守恒方程
δF/δη                        -> 晶界迁移和溶质拖曳
```

先做固固晶界，不要同时加入液固相变、双组元和形核。每次只增加一项。

## Phase 4：GP/抗截留路线

只有在传统模型的 1D 基准稳定后，才建立 GP 分支。扫描 `W/(D/V)=1...500`，预先规定误差止损线。GP 通过前不能作为生产真值模型。

## Phase 5：训练数据和神经算子

只有以下条件全部通过才生成训练数据：

- 雅可比完整；
- `c` 守恒；
- `D_L/D_S/D_GB` 语义正确；
- `Γ_GB` 网格和 epsilon 收敛；
- 移动晶界拖曳通过；
- 训练/测试按时间和工况隔离；
- 面拓扑标签经过独立人工/脚本抽查。

## 禁止事项

- 禁止直接把 `wGB=12 µm` 合入生产。
- 禁止把 `kappa_c=1e-14` 称为“已解析”。
- 禁止用当前旧模型输出训练“物理真实”算子。
- 禁止同时修改自由能、网格、求解器和时间步后解释结果。
- 禁止在没有 Ti64 数据时把 `M0`、`A_ani`、`D_GB` 写成已验证材料常数。
