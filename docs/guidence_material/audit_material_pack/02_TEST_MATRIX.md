# 验收测试矩阵

| 编号 | 测试 | 最小算例 | 通过判据 |
|---|---|---|---|
| T0 | 输入可重复性 | 生成器 + hash | 同一 commit 输出逐字相同 |
| T1 | 溶质 Jacobian | 1D 平界面 | 有限差分相对误差 ≤ 1e-5；无 Missing coupled variables |
| T2 | 总溶质守恒 | 1D/2D 短跑 | 相对漂移 ≤ 1e-8 |
| T3 | 非负浓度 | 移动前沿 | `min(c) >= -1e-10` |
| T4 | 液固平衡分配 | 静止平界面 | `k_eff` 与理论值误差 ≤ 1% |
| T5 | `kappa_c` 极限 | 静止平界面 | `k_eff` 对继续减小 `kappa_c` 收敛；不得只看单档 |
| T6 | 迁移率分层 | 固相/液相扩散 | `D_L,D_S,D_GB` 与输入定义一致 |
| T7 | 平面前沿 | 1D 移动界面 | 速度和 `k_eff` 对 dx、dt 收敛 |
| T8 | epsilon 收敛 | 圆晶粒 | `R²` 斜率变化 ≤ 5% |
| T9 | 三叉晶界 | 三晶粒静态 | 三叉角误差 ≤ 5°；无伪第三相增长 |
| T10 | 温度截断 | 局部热区 | 熔池等温线变化有界；最高温度不超过 cap |
| T11 | 晶界过剩 | 1D 固固晶界 | `Γ_GB` 对 dx、wGB 收敛 |
| T12 | 晶界快速扩散 | 1D 示踪 | 有效扩散三重积与目标值误差 ≤ 5–10% |
| T13 | 溶质拖曳 | 移动固固晶界 | 随浓度/扩散率变化的速度趋势正确；与无溶质对照显著可分 |
| T14 | AMR 加密 | 平面/圆晶粒 | 守恒 ≤1e-8，速度和 Γ 变化 ≤5% |
| T15 | GP 扫描 | 1D 前沿 | s=1...500 的误差曲线完整；超过止损线即停止 |
| T16 | NN 数据质量 | 小型数据集 | 标签守恒、无 NaN、时间切分无泄漏 |

## 生产前硬门槛

T1–T9 必须通过；如果研究目标包含晶界溶质，则 T11–T13 也必须通过。T15 未通过时，GP 只能作为实验分支。T16 未通过时不得训练正式算子。
