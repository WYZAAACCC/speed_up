用户的目标是"做到物理正确、不被审稿人质疑"。2026-09-17 逐条自查后确认：
**当前状态不能过审。** 按严重程度：

## 硬伤（必须补）

1. **`A_ani = 0.7` 纯唯象，无任何标定依据。**
   2b 的全部物理内容都压在这一个数上。审稿人必问"这个数从哪来"。
   补法：用 LPBF 实测织构反标定，或引文献里的界面各向异性强度（金属表面能各向异性
   通常 ε ≈ 1~2%，但那是表面能不是迁移率；迁移率各向异性强度的文献值需查）。

2. **没有形核核 → 没有等轴晶。**
   核列表里只有 Cahn-Hilliard + AC，没有任何形核机制。真实 LPBF 熔池**顶部有等轴晶区**，
   这是 LPBF 显微组织最标志性的特征。没有它，预测出来"全是柱状晶"，与实验对不上。
   补法：加形核模型（MOOSE phase_field 有 `Nucleation` 类核，或自己按过冷度/冷却速率
   控制形核率）。注意：加形核会引入新晶粒 → **序参量会被回收 → op↔取向映射不再稳定**，
   那正是之前判定"不需要写 C++"的依据，届时需要重新评估（可能要接
   `RandomEulerAngleProvider` + `EulerAngleUpdater`，或将 op_num 设得足够大）。

3. **溶质边界层 δ_c ~ D_L/V ≈ 8 nm，比 1 µm 网格小两个数量级。**
   解出的是被网格展宽的剖面，不是真实边界层。LPBF 真实存在**溶质截留**
   （界面速度 ≫ 扩散速度 → 有效分配系数趋近 1）。定量预测必须换模型
   （如界面响应函数/Aziz 模型，或直接用有效分配系数）。

## 次要但会被问

4. **`Q` 无取向差依赖** —— 找不到文献依据，只能置常数。目前只有 σ（Read-Shockley）
   和 M（∝Δθ/θ_m）有取向差依赖。
5. **基体取向是散射分布，不是真实 LPBF 的强 `<100>` 纤维织构。**
   在 `gen_aniso.py:build_orientations()` 里改一行即可收窄。
6. **溶质单组元、`c0=0.35`、分配系数 `k=0.5` 是占位**，不是 Ti64 真实的 Al/V 与热力学。
7. **2a 在当前随机织构下效果本来就弱**：11 个互异取向差里只有 3 对低于 15° 的
   Read-Shockley 阈值，其余全取大角极限。强织构下才会显著。

## 可以辩护的部分（不必改）

- 2a 严格复刻 Moelans Algorithm 1（`GBAnisotropy` 的算法），各向同性极限精确退化为
  已发表基线 `kappa_op=1.8e-6 / gamma_asymm=1.5`，偏差 3.17e-05 已查明来源
  （教科书圆整值 0.75 vs 不动点精确解 0.74997626）
- 2b 的温度梯度用真实温度场的**解析导数**，已用数值微分独立核对（偏差 < 1e-6）
- 温度作为输入有硬依据：`L ∝ exp(−Q/kbT)`，固相内 T 从 373→992 K 迁移率差 27 个数量级
- 取向进入模型的通道可以严格论证（只有逐对 Δθ 与逐晶粒 align 两条）
