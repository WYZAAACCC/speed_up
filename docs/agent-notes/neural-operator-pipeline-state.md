2026-09-17 建立的 `F:\speed_up\pipeline\` 管线——把相场结果转成"晶粒图 + 逐面溶质"数据集，训练**逐面通量算子**（每个面单独调用、权重共享，类比有限体积在每个面求通量）。

**面的定义**：共享一条边(2D)/一个面(3D)的相邻单元晶粒 ID 不同 → 晶界单元；同一晶粒对 (i,j) 的连通晶界单元集合 = 一个面。于是拓扑变化退化成图的增删。

## 三个关键实测结论（都不在仓库里，务必记住）

1. **守恒已达标，且与网络精度无关**。转移规则对比（`tcmp.log`，用 tb.pt 回放 t=992..1376）：
   - `none`（丢弃）：总量丢 493.6，漂移 1e-4~1e-5
   - `volume`/`area`/`flux`：丢弃 0，漂移 **±1e-16（机器精度）**
   原因：预测的是"面↔晶粒交换通量 J"，同一 J 在一侧 −、另一侧 +，装配时精确抵消。

2. **但三条守恒规则的"面误差"几乎完全一样**（t=1376 时 0.2318/0.2319/0.2319）。
   → **转移规则的差异目前还看不到物理后果**。这正是 P1 核心实验（规划阶段2 ★）要证明的东西，**尚未成立**。怀疑是被算子自身 ~17-23% 的误差盖住了。

3. **27–35% 的方差未解释**，是"特征不足"还是"机制不足（需要邻面交互）"**未定论**。`ablation.py` / `noise_check.py` / `noise_vs_threshold.py` 已写好，但**结果只打在终端、没存盘**。

## rollout 训练发散的根因与修法（踩过的坑）

`train_rollout.py`（旧版）loss 冲到 1e15，两个原因：
- **`sd` 无下限**：第 12 列是时间步长 dt，固定步长下方差为 0 → 归一化除以近零 → 特征爆到 1e9，J 达 2.7e6
- **loss 未归一化**：面含量量级 ~78，平方 ~6000

修法（`train_rollout_batched.py`）：`sd` 加下限 `1e-3*max(|mean|,1)`；loss 用参考值均方归一化。修后成功产出 `tb.pt`（14:41，201985 参数）。
