**2026-09-20 定论。** 此前写在 `physics-gaps-for-reviewers.md` 里的
「溶质截留 +39%」「抗截留项不成立」「只能声明局限」**三条都作废**。

**根因是参数漏改**：`tests/front1d.i` 的 `kappa_c` 停在 `1.125e-11`，
而生产早在 **2026-09-18** 就改成 `1e-14`（`stage1_meltpool_c.i:542-562`）。
四个"溶质截留"实验全跑在旧值上。

**两个机制（都实测）**：
1. `ℓ_c = sqrt(κ_c/k_c)` 必须 ≪ `δ_c = D/V`。`κ_c: 1.125e-11→1e-13` 把 `k_eff`
   从 0.877 压到 0.800，**之后饱和**。
2. **主因是界面宽 `ξ`**：精确关系 `k_eff = 1/(1 + (2A/k_c)·δ_c/L_eff)` 反解出
   **`L_eff = δ_c + 1.5·ξ`**（4 个 `s` 档系数 1.29~1.36，跨 8 倍 `δ_c`），
   在生产工作点外推 476 倍仍成立（预测 3.00 µm，实测 3.17 µm）。
   物理含义：**溶质是在整个弥散界面 `ξ` 上被排出的，不是在锐前沿上**。
   **不是网格问题**：`δ_c/dx` 从 0.5 到 16 全部网格收敛到 <0.5%。

**实测生产工作点**（`validated/run_prod_1d.sh`，`V = 0.6 m/s` = 生产扫描速度）：
`k_eff = 0.999015`，物理（Aziz `a0=0.3nm`）`0.6549`
⇒ **界面排出的溶质被低估 350 倍 ⇒ 微偏析被低估 350 倍**（那正是本课题的目标量）。

**修复三条，缺一不可**：
* (a) `kappa_c = 1e-14` —— 生产已有，**但从未在移动前沿上验证过**
* (b) **抗截留项** `AntitrappingCurrent`（每个 η 一个核）+ `F_at` 材料。
      官方形式 `F = W·(c_β−c_α) = W·(1−k)·c`（读自 MOOSE 的
      `GrandPotentialAnisotropyAntitrap.i`）。1D 标定 **`ALPHA = 2`**（4 档 `s`）：
      基线误差 17~46% → **≤6.6%**（`k_eff` 逐档 +2.30 / −0.69 / −4.22 / −6.55%）。
      ⚠ **最优 `ALPHA` 随 `ξ/δ_c` 从 2.5 漂到 1.7** ⇒ 它是**领头阶**修正，
      不是精确的与宽度无关的重整化 —— 如实写，别夸大。
      **必须乘 `(1 − h_gb)`** —— 本模型的 η 兼表晶粒身份，晶粒长大时 `η̇ ≠ 0`
      会在晶界上产生伪溶质流。抗截留项是散度项 ⇒ 严格守恒、静止界面上恒为 0
      ⇒ T4/T11/Ω₀ 那套验证不受影响。
* (c) `D_L ≥ 2V·dx`（生产 ≈ `1.2e-6`）。理由：`L_eff = δ_c` 一旦成立，精确关系给出
      `c_max − c0 = 2Ac0/k_c` —— **与 `D_L` 和网格都无关**，放大只是把亚网格的
      边界层变成可解析的。副作用：熔池混合 `D_L t/L² = 0.02 ≪ 1` ✓；
      `D_S`/`D_GB` 逐点精确不变 ⇒ 不影响 `s·δ·D_GB` ✓。

**仍未做**：`D_L` 闭合**未改生产**（但其核心论断已被 8 倍 `D_L` 扫描检验：
散布 17~46% → ≤6.6%）、2D 端到端验证。

**已澄清的两项**：
* 生产 `F_at` 的 `W` —— 两个模型的 η 剖面**尾部衰减长相同**
  （`front1d.i` 的 `√(2κ/Wg)` 与生产的 `√(κ_op/(2μ₀))` 都是 **1.0 µm**，
  tanh 等效标度都是 2 µm）⇒ `ALPHA=2 / W=2 µm` 可直接搬。
  ⚠ 生产的 `λ_tail` 要由 `∂f/∂η₁` 在 `(1,0)` 附近线性化得到；
  **不能用 `η₂=1−η₁` 约束归约**（沿它 `f` 在 0.5 处是极大，无 kink 解）。
* 打补丁的生产输入**端到端跑通**：86×30 上跑完一步，`total_solute` 逐位不变；
  生产链存活检查 17 项全过。
* ⚠ 跑生产输入**必须用自建 `gb_jac-opt`**，用 MOOSE 自带 `phase_field-opt` 会报
  `'ACGrGrPolyJ' is not a registered object`。
