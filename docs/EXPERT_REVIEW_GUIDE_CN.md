# Ti-6Al-4V LPBF 相场—神经算子项目专家审核与执行指南

## 结论先行

当前工作在**代码核对、离散方程实现、求解器对比和数值诊断**方面做得很好；手写核等价性、ASM/MUMPS 对照、温度梯度核对和分配系数代数验证是可信的工程成果。但它还不能宣称“接近真实物理”：4 μm 弥散界面相对于约 4–8 nm 溶质边界层相差约 480 倍，现有分裂 Cahn–Hilliard 模型的动态偏析与截留不具备已证明的定量性。神经网络不能修复该系统误差，必须先建立高保真参考模型。

最重要的科学风险是： (i) GP/抗截留项在 W/(D/V)=480 是否仍定量，文献没有直接保证；(ii) V 在 β-Ti 晶界的偏析方向未定，α/α 晶界富集不能直接外推到 β/β；(iii) 溶质自由能对 η 的导数必须进入晶粒方程，否则溶质拖曳不是变分一致的；(iv) σ_H=0.6 J m⁻²、M0=232 m⁴(J s)⁻¹、A_ani=0.7 是占位/待标定参数；(v) 4 μm 晶界下用 Fisher 三重积等效的论证不成立，因为 √(D_bulk t)≈1.3 μm<w，未进入 B 型区。

## 必须按顺序完成的路线

### Phase 0：一维物理闸门（先做，1–2 天）

做等温 1D 平面凝固前沿，固定速度和液相浓度，扫描 `W/(D/V)=1, 2, 5, 10, 50, 100, 500`，每点比较抗截留开/关。记录 `k_eff=c_s/c_l`、界面速度、总溶质量、界面位置和自由能。用 Stefan/薄界面定量相场结果作基准；门槛建议：质量误差 <10⁻⁶，相速度误差 <2%，k_eff误差 <5%（论文若声称定量，收紧到 1–2%）。若 100–500 不收敛，停止把 GP 称为“定量”，改用局部细网格/薄界面校正或独立 Gibbs 晶界模型。

### Phase 1：使相场物理闭合

1. 采用 `f=f_phase+f_solute` 时，将 `∂f_solute/∂η_i` 同时加入 AC 方程；做单晶界速度—浓度对照，检查溶质拖曳方向和自由能耗散。
2. 重新用 CALPHAD（PanTi/Thermo-Calc 或公开数据库）在实际温度、成分和相态计算 `k_V(T,c)`、液/β化学势和液相线/固相线；`k=0.63` 只能作为待验证初值。
3. 对 V/Al 的 β/β 晶界偏析能采用 DFT 或文献数据；在证据不足时把偏析焓设为带符号区间参数（例如 `E_seg∈[-0.2,0.2] eV/atom` 的敏感性扫描），不得固定为富集。
4. σ_H、M0、A_ani 逐一标记为“文献值/反演值/占位值”。M0 用 Semiatin 晶粒长大数据反演；A_ani 做 0、0.3、0.7、1.0 扫描并用 EBSD 纹理或晶粒长宽比校准；σ_H 用直接测量、MD/DFT 或明确的不确定度区间。
5. 明确适用范围：Ti64 LPBF 的外延柱状生长可作为默认场景；若研究等轴晶，必须加入可验证的形核率/密度模型。`reserve_op` 只提供槽位，不能替代每晶粒取向和形核物理。

### Phase 2：数值生产设置

保留非 AD + ASM/ILU；全尺寸实测 ASM 优于 MUMPS。生产输入应同步为 `nl_abs_tol≤1e-9`、首步 `dt=1e-7 s`、`dtmax=2e-6 s`（不要因短算例把它放宽到 4e-6）；线性迭代上限按实际收敛日志设置。每个算例输出质量守恒、自由能、界面速度、晶粒面积分数和求解器日志。先用小域/短时做回归，再跑全尺寸。源文件必须与已实测设置一致，并固定生成器版本（避免 AD/非 AD 混用）。

### Phase 3：神经算子只替代已验证的推进器

不要训练当前粗网格 CH 去宣称真实物理。高保真参考通过 Phase 0 后，再生成数据。建议两阶段：先用 128²–256×128 的参数扰动数据预训练，再用 10–20 条全尺寸高保真轨迹微调。参数用 Latin hypercube 扰动激光速度/功率、Q、M0、k、扩散系数和 σ；留出整组参数外推测试集。

RTX 4060（通常 8 GB）建议 FNO/UNO 或带边界 mask 的 U-Net：宽度 32–48、4 层、Fourier modes 16–24、参数量 <5M、batch 1–4、FP16 训练、FP32 验证；边界不是周期边界，不能直接套无 padding 的 FNO。输入至少包含当前场、BDF2 历史场、dt、温度/梯度和材料参数。每次只推进 1 步，使用 10–50 步 rollout、scheduled sampling。损失必须包含场误差、总溶质守恒、自由能耗散/非增、相场范围约束和界面速度误差。报告单步误差之外的长时 rollout、质量漂移和 OOD 参数误差。

笔记本上全尺寸 ASM 约 3.18 GB/条、单步约 135–240 s、约 330 步为 12–22 h；MPI-8 只有约 2.75×扩展，建议并发 2–4 条并监控内存/温度。当前模型中溶质约占 13% 成本，因此在粗网格上替换它没有充分加速论证；真正的价值来自“高保真细尺度参考”或经 Phase 0 证明的 GP 模型。

## 对当前假设的判定

| 假设/做法 | 判定 | 必要修改 |
|---|---|---|
| 两条轨道拆分 | 工程上合理，可解释 | 必须验证交错耦合的总自由能与守恒；不能把拆分当作物理解耦证明 |
| Rosenthal 温度作为外场 | 作为第一版可接受 | 与热传导/潜热耦合的差异需做敏感性和实验温度场对照 |
| 4 μm CH 界面给出真实偏析 | **不成立/未证明** | Phase 0；失败则细界面或 Gibbs 界面 |
| GP 在任意大 W 下定量 | **不能直接假设** | 只有扫描误差达标后才可采用 |
| V 在 β 晶界富集 | **未定** | DFT/文献核实；符号敏感性扫描 |
| `k=0.63` | 可作初值，非最终事实 | CALPHAD 自算并随温度/成分变化 |
| `σ=0.6, M0=232, Aani=.7` | 待标定 | 反演/MD/DFT/EBSD 校准，报告区间 |
| 非 AD 生产 | 当前合理 | 查明 AD 线性爬行后再考虑；不影响当前非 AD 结果 |
| NN 可直接学粗网格真值 | **不成立** | 先建立高保真标签，再训练受守恒约束的局部推进器 |

## 数值与验收指标

- 几何：430×150，dx=1 μm；W=4 μm；计算时长 6.5×10⁻⁴ s；激光速度 0.6 m s⁻¹。
- 温度：`T_mid=1903 K`、液相线/固相线约 1928/1878 K 仅作为当前工况参数，须由所用成分数据库重算。
- 求解：非 AD、ASM/ILU、`nl_abs_tol≤1e−9`、首步 `1e−7 s`、`dtmax=2e−6 s`。
- GP 闸门：`W/(D/V)` 扫描 1–500；k_eff 误差目标 <5%（理想 <2%）、质量误差 <10⁻⁶、速度误差 <2%。
- NN 闸门：留出参数集 rollout 50 步；质量漂移 <0.1%；自由能不应系统性上升；晶粒面积分数、界面速度和 k_eff 分别报告误差及置信区间。

## 可发表性边界

在 Phase 0 通过前，论文应把结果表述为“经验证的数值模型/加速器”，不能表述为定量预测真实 LPBF 偏析。若 Phase 0 失败，最稳妥的论文贡献是：提出并验证守恒的高保真细界面/Gibbs 参考模型，再展示神经算子加速；不要用 NN 掩盖界面宽度造成的系统误差。
