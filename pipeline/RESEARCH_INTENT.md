## 二、研究路线 v2（三个窗口）【用户 2026-09-22 确认】

> 用户原话（2026-09-22）：
> 「就按照原来的 **Window A -> CA，使用滑动窗口，产出冻结的晶粒骨架 + 晶界网络几何（不学）**；
> **Window B -> 局部 PF，晶内 alpha-prime 与晶界 alpha（要学）**；
> **Window C -> Gibbs 面上的 @@\Gamma_i@@ 演化（要学，且是原创点）**」

| 窗口 | 物理内容 | 求解器 | 是否学习 | 产出 |
|---|---|---|---|---|
| **Window A** | 固液前沿 L->beta：形核、外延生长、竞争、柱状/等轴形貌 | **CA（滑动窗口）** | ❌ **不学** | **冻结的 prior-beta 晶粒骨架 + 晶界网络几何** + 凝固化学初值 |
| **Window B** | 凝固后晶内组织：beta->alpha-prime、alpha-prime->alpha+beta、V/Al 重分配、**晶界 alpha 膜** | **局部精细 PF** | ✅ **要学** | 晶内相分数 / 板条 / 变体 / 成分场 |
| **Window C** | 界面（晶界 / 相界）化学：@@\Gamma_i@@、沿界面的扩散与分配、界面能 | **Gibbs 面** | ✅ **要学（原创点）** | @@\Gamma_i(t)@@、面通量、界面能 |

### 2.1 Window A：滑动窗口 CA —— 术语必须说准

- 窗口 **跟着固液界面 @@\Sigma_{sl}(t)@@ 走**，不跟着晶界走。
- CA 推进的是**固液界面**；**晶界是涌现的**：晶界 = grain ID 场 @@g(\mathbf x)@@ 的间断集合。
  **CA 里没有任何一条方程是写晶界的。**
- 所以准确说法：**Window A 里被推进的是固液界面，晶界是被它「画」出来的，不是被它「推」的。**
- **不学 Window A 的理由**【推导，有实测支撑】：
  1. 它的化学在 LPBF 区制下**可严格退化为 Scheil 解析式**（见 §三），学一个已知解析式没有价值；
  2. 拓扑变化本身不适合神经算子（用户 v1 原话：「神经算子并不好学到拓扑变化」）。

### 2.2 Window B：局部精细 PF

- 对象：**晶内** alpha-prime / alpha / beta 与 **晶界 alpha 膜**。
- **要学**：这是贵、局部、且有明确 teacher 的部分。
- 必须拆成**两个物理机制不同的子模型**（详见 `MATH_FRAMEWORK.md` §5.5）：
  - **B1: beta -> alpha-prime** 位移型 / 无扩散：V **不分配**，athermal；
  - **B2: alpha-prime -> alpha+beta** 扩散型：守恒场 CH，V 进 beta、Al 留 alpha。
- 【实测】B2 需要 @@t\sim L_{\mathrm{lath}}^2/D_V^{\alpha}@@：1073 K 时 0.33 h、973 K 时 5.3 h、900 K 时 59 h
  ⇒ **LPBF 建造期内 B2 不发生**，它由**后处理热处理**或长时高温停留触发。

### 2.3 Window C：Gibbs 面上的 @@\Gamma_i@@ 演化

- 零厚度面 + **面过剩量** @@\Gamma_i@@（把真实 ~1 nm 的偏析层折成面积量）。
- **要学**，且是本方案的**原创点**（本轮文献检索未发现 Ti64 动态 Gibbs surface 算子的公开先例）。
- 这也是 v1 里「逐面算子」这一想法的**正确落点**：
  当年想学的「晶界上的元素扩散与分配」不属于 Window A（那里是 Scheil），属于**这里**。

### 2.4 时间线上谁先谁后

@@
\text{Window A（凝固，ms 级）}\;\to\;\text{Window B（固态，s~h 级，需重热/热处理）}\;\to\;\text{Window C（界面，全程活跃）}
@@

三者由**事件驱动调度**串起来（混合自动机，见 `MATH_FRAMEWORK.md` §2），
通过**统一的全局材料状态**读写，不允许各自维护一份材料。

## 三、数学框架（摘要）

> **完整版见 `pipeline/ca_pf_framework/MATH_FRAMEWORK.md`**（850+ 行，含全部方程、边界条件、接口量、守恒律、验证状态）。
> 本节只列骨架与已定结论，便于自查是否跑偏。

### 3.1 四层结构

| 层 | 内容 | 关键方程 |
|---|---|---|
| **L0** 状态与调度 | 全局状态 @@\mathfrak{S}@@、活动窗口、混合自动机 @@(Q,\mathfrak{S},F,Inv,E,G,R)@@ | 事件函数 @@\psi@@、迟滞 + 最短驻留（排除 Zeno） |
| **L1-T** 热层 | 焓式能量方程 + 潜热 | @@\partial_t h=\nabla\cdot(k\nabla T)+q@@，@@h=\rho\!\int c_p\mathrm dT+\rho L_ff_l@@ |
| **L1-G** Window A (CA) | 形核 + 界面响应函数 @@V(\Delta T)@@ + 捕获规则 + Scheil | @@V=a_2\Delta T^2+a_3\Delta T^3@@ 或**插值表**；decentered octahedron 捕获 |
| **L1-P** Window B (PF) | 多相场 + Cahn-Hilliard + 微弹性 | @@\partial_t\varphi_\alpha=-\frac1{\tilde N}\sum_\beta M_{\alpha\beta}(\delta F/\delta\varphi_\alpha-\delta F/\delta\varphi_\beta)@@；@@\partial_t c_i=\nabla\!\cdot\!(\sum_j M^c_{ij}\nabla\mu_j)@@ |
| **L1-C** Window C (Gibbs) | 吸附方程 + 面内扩散 + 面-体交换 | @@\mathrm d\gamma=-\sum_i\Gamma_i\mathrm d\mu_i-S^\sigma\mathrm dT@@；@@\partial_t\Gamma_i+\nabla_s\!\cdot(\Gamma_i v_s)=\nabla_s\!\cdot(D^s\nabla_s\Gamma)+\ J^{\mathrm{bulk}}_i@@ |
| **L2** 接口层 | 投影算子 @@\Pi@@、halo、一致性条件 | @@\int_{\Omega_i}c\,\mathrm dV=\bar c_i|\Omega_i|@@（**逐胞精确守恒**） |
| **L3** 学习层 | 算子定义 + 守恒约束 | @@\mathcal G_{\mathrm{PF},\Delta t}:u_\Omega|_{B_r}\to u_\Omega|_{B_{r_0}}@@（Halo-in / Core-out） |

### 3.2 已经验证过的关键结论（有数值证据）

| 结论 | 数值 |
|---|---|
| **Window A 的化学可严格退化为 Scheil** | @@Fo_L=D_Lt_f/\lambda_1^2=7.74\gg1@@；反扩散 @@\alpha_{bd}=1.6\times10^{-3}\ll1@@；守恒恒等式误差 @@<10^{-4}@@ |
| Scheil 预测的末期液相浓度与仓库实测吻合 | @@c_l(f_s{=}0.99)=0.198@@，实测 @@c_{\max}\in[0.12,0.24]@@ |
| **prior-beta 骨架在 LPBF 中冻结** | 单道热循环晶粒长大 **1.4 nm**，100 层累计 **2.8 nm**（反例：超转熔点退火 600 s ⇒ 1.3 mm） |
| **halo 判据有闭式解** | 泄漏 @@e^{-N}@@；Dirichlet 截断误差 @@\frac{1-k}{k}e^{-N}=0.587e^{-N}@@；@@N=5\Rightarrow0.39\%@@ |
| **拖曳必须隐式** | @@v=M_{GB}[\Delta G-P_{\mathrm{drag}}(v)]@@；线性闭式在 @@v=v^\ast@@ 时误差 100%，@@2v^\ast@@ 时给负压强 |
| **Gibbs 面的规范不变性** | 平移 3 nm 漂移 @@3.7\times10^{-16}@@（两相 Gibbs-Duhem 精确相消） |
| **潜热不可忽略** | @@Ste=1.74@@；凝固区间内 @@L_f/(c_p\Delta T_0)=18.6@@；热层实现 11/11 判据通过 |
| **PF 必须复现 CA 的 @@V(\Delta T)@@** | 薄界面极限 @@W\to0@@ 且 @@W/V@@ 固定（Karma-Rappel）+ 抗截留通量。**强制项** |

### 3.3 六条必须处理的 FAIL（当前框架/参数不一致或不足）

| # | 内容 | 定量 |
|---|---|---|
| F1 | 凝固区间参数不自洽 | 本项目 @@(k,c_0)@@ -> @@\Delta T_0=17.9@@ K；文档写 45 K（另一套 @@k,c_0@@） |
| F2 | 同上另一种表述 | 要凑 45 K 需 @@\Delta H_f=5434@@ J/mol（真实 14150） |
| F3 | 潜热不可忽略 | 已补上并验证（热层） |
| F4-F6 | 全域 PF 要可信需 @@\Delta x\le48@@ nm；生产 @@\Delta x=2@@ µm 欠解析 **42 倍** | 这是「为什么要局部 PF」的论据本身 |

@@F4\sim F6@@ 的意义：**全域精细在熔池尺度上不可能**，所以「CA + 局部 PF」不是权宜之计，而是**唯一可行解**。
同时它也说明**CA 为什么不需要这个分辨率**：CA 用 LKT 解析解**内置**了溶质边界层，不靠网格解析它。
