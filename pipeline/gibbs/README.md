## §0 一句话

生产模型把晶界当成「一块 4 µm 宽的弥散板」，偏析强度由一个**无量纲常数 `Ω₀`** 定；
本支线把 Γ **升格为独立的低维状态量**，其平衡由 **McLean 等温线**（材料量 `ΔG_seg(T)`）给出。

**⇒ 这是弥散表示在数学上做不到的事**：生产里 `Γ ∝ wGB`，要让 Γ 对上文献就必须 `s → 1`
（实测 `s = 1.0015`）。两者不可能同时对。1D 验证显示本支线的 **`Γ` 与 `wGB` 逐位无关**（见 §3）。

## §2 物理闭合：模型与参数台账

### 2.1 方程

```
体相自由能（无量纲化形式，物理精确）
  f_loc/f_ref = τ·[c·ln c + (1−c)·ln(1−c)]  −  (−ln k)·c·(1−h_solid)
  其中 τ = T/T_ref，f_ref = R·T_ref/v_m，k = 液固分配系数

迁移率
  M = D_eff / f_cc,   D_eff = D_L + (D_S−D_L)·h_solid + (D_GB−D_S)·h_gb
  ⇒ **D = M·f_cc 逐点精确** ⇒ 审计 P0-4（固相扩散反比液相快 1.59 倍）由构造消除

低维晶界 Γ（mol/m²）
  dΓ/dt = h_gb · k_att · ( Γ_eq(c,T) − Γ )
  Γ_eq  = Γ_0 · exp(−ΔG_seg(T)/(R·T)) · c          （Henry 极限）
  ΔG_seg(T) = ΔH_seg − T·ΔS_seg
  体相源： ∂c/∂t = ∇·(D∇c) − shape(x)·∂Γ/∂t
  shape(x) = h_gb / ∫h_gb dx = h_gb / ((4/3)·wGB),   ∫shape dx = 1
```

**⇒ 关键**：`Γ` 的量级由 `shape` 的归一化保证，**与 `wGB` 无关**；而局域富集比
`s = exp(−ΔG_seg/(RT))` 也**与 `wGB` 无关**。两者同时对上了。

### 2.2 为什么必须是理想溶液（`ln`）而不是二次型

生产的 `k_c/2(c−c₀)²` 是**线性响应（Henry）**形式，偏析势引起的位移落在 `c` 上
⇒ `Δc ∝ 1/wGB` ⇒ `s ∝ 1/wGB`。
换成理想溶液的 `τ·c·ln c` 后，偏析势引起的位移落在 **`ln` 活度**上
⇒ `ln[c_GB/(1−c_GB)] − ln[c_far/(1−c_far)] = −ΔG_seg·h_gb/(RT)`
⇒ **精确 McLean（Cahn 1962），与 `wGB` 无关**。

同一段物理在弥散表示里 `Γ = ρ_mol·wGB·A(s) ∝ wGB` —— 两个不能兼得，这就是必须做低维 Γ 的原因。

### 7.2 ⚠ 新物理解论：**在 `wGB = 4 µm` 下，fix A 的效应可以忽略**

fix A 的方程是 `(1 + shape·Γ_eq'(c))·∂c/∂t = ∇·(M∇w)`。**我原先漏了一个 `ρ_mol`**：

```
守恒量必须是 ρ_mol·c + shape·Γ   [mol/m^3]
⇒ (1 + shape·As/ρ_mol)·∂c/∂t = ∇·(D∇c)        ← 除的是 ρ_mol，不是 1
```

代入生产数：

```
shape·As/ρ_mol = [1/((4/3)·4µm)] · Γ_0·K(T) / ρ_mol
              = 1.875e5 · 4.47e-5 / 1.0129e5
              = 8.3e-5          ← **0.008%，可忽略**
```

**⇒ 在 `wGB = 4 µm` 下，晶界的"储存（capacity）"效应对体相溶质平衡的影响是 1e-4 量级。**

同一件事换个说法：真实晶界单位面积过剩 `Γ = 1.6e-6 mol/m²`；把它摊到 4 µm 厚的带里
= `0.3 mol/m³`，而带内的体相溶质是 `c·ρ_mol = 3646 mol/m³` ⇒ 比值 8e-5。
**若晶界宽是物理的 0.5 nm，同样摊开会得到 ~3200 mol/m³ —— 与体相同级（~90%）。**
⇒ **容量效应的量级完全由 `wGB` 决定，`wGB` 错 8000 倍，它就被稀释 8000 倍。**

**沿晶界扩散通道同样被稀释**：真实线电导 `δ·D_GB = 2.5e-19 m³/s`；
要在这个 4 µm 带里表达它需要的等效体积扩散系数是
`δ·D_GB/((4/3)wGB) = 4.7e-14 m²/s` —— **低于固相体扩散 `D_S = 4e-13`**。
⇒ **在 4 µm 带里，晶界的"快速扩散优势"也被几何稀释掉了。**

**⇒ 结论（从 Gibbs 一侧独立得到，与前面几轮一致）**：
**`dx = 1 µm` / `wGB = 4 µm` 的 2D 熔池，无论怎么改方程的动力学，都无法正确表示晶界的溶质物理。**
原因不是动力学写错了，是**表示**（8000 倍过厚的带）把两个效应都稀释掉了。

**⇒ 物理上正确的做法只有一条：把晶界作为**真正的低维实体**表示 —— 它有自己的面积状态量 `Γ`
与自己的线电导 `δ·D_GB`，体相通过归一化的 `shape` 与它交换。
这正是 `RESEARCH_INTENT.md` §二 说的"算子作用在每一条晶界上"的那个对象，
也是 1D Gibbs 验证（§3.2）已经证明可行的那一套。**

### 7.3 一条附带的重要物理认识（可能改变 Stage 2 的定位）

`δ·D_GB` 相对体扩散的贡献 ≈ `(1/d_晶粒)·δ·D_GB / D_bulk`。
代入 Ti64：晶粒 ~40 µm、`D_GB/D_S ~ 1e3`（生产中用的标定值）、`δ = 0.5 nm`
⇒ 晶界网络对宏观输运的贡献 ≈ 1.6% —— **在 `T/T_m ≈ 0.9` 的凝固温度下，晶界扩散是二阶效应。**

**但 `T/T_m < 0.5`（~900–1200 K，即 APT 测量的温区、也是"凝固后粗化与偏析"阶段的温区）时，
`D_GB/D_bulk` 可以到 1e4–1e5 ⇒ 晶界通道变成主导。**

**⇒ 含义**：晶界溶质物理真正重要的地方是**阶段 2（凝固后）**，不是阶段 1（熔化→凝固）。
这与 `GB_SEGREGATION_LITERATURE.md` 甲类空白（Ti64 的 `D_GB` 数据不存在）叠加，
说明**阶段 2 既是价值所在、也是数据最缺的地方**。
