生成器一共动 **12 处**，每处都在输出里打印命中的块名与被替换的文本：

| # | 改什么 | 为什么 |

| 4 | 每条晶界一个独立低维状态量 **`Gam_k` ≡ Γ_k/A_s** | **「逐面算子」的那个「面」**；每条晶界自己的 Γ |
| 5 | 面方程的**时间导数项**：`ScaledTimeDerivative`，`scale = A_s/ρ_mol` | 与体相的通量守恒严格配对（p3c 已验证的写法） |
| 6 | 体相 ↔ 面 的交换：**mortar 约束 `GBFluxExchange`**，`kex = A_s·k_att/ρ_mol` | 守恒通量交换（3D 原型已验证：面测度/守恒到 1e-12） |
| 7 | 面上的材料 `AsRho_k`/`kex_k`：**随 T 变**（`A_s = Γ₀·exp(−ΔH_seg/(RT))`） | 生产完全没有温度依赖；Gibbs 版把它补上 |
| 8 | **删掉生产的晶界偏析项**：`A_part*c²*min(1,2S)` 与 `(Omega0/wgb)(c−c0)h_gb` | 偏析改由面上的 McLean 承担 ⇒ 避免**双计**。自检断言这两项在**代码行**里出现 0 次 |
| 9 | 自由能 → **物理量纲理想溶液**：`FREF·[τ(c ln c+(1−c)ln(1−c)) − (−ln k)c(1−h_solid)]` | 精确 McLean、自带温度依赖；同时消除审计 P0-4 |

| 11 | **所有体相对象加 `block` 限制**；`coupled_res`/`coupled_parsed` 的耦合变量改成与材料**逐字同序** | 见 §4.1/§4.2（两条都是实测踩出来的） |
| 12 | 关 AMR（`max_h_level = 0`） | mortar + AMR 未验证，先隔离出来 |

## §3 算例选择与参数（每一条都有实测依据）

| 量 | 取值 | 依据 |
|---|---|---|
| 窗口 | x ∈ [−262, −176] µm，y ∈ [0, 48] µm，z ∈ [0, 10] µm | 柱状晶界在 −236.87 / −195.96 µm（两条都在窗口内）；Rosenthal 池深（T>1628 K）在 −262→−176 µm 上是 31.7→46.4 µm ⇒ **域深必须 ≥47 µm，否则窗口里一点固相都没有** |
| `dx` | **2 µm** | `wGB/dx = 4`（生产同款比例） |
| `wGB` | **8 µm**（生产 4 µm） | 见下 |
| `dtmax` | 1e-7（生产 2e-6） | 按 dx 缩 |
| 预条件子 | `lu + mumps`（生产是 asm/ilu） | **mortar 约束从来没在 asm/ilu 下测过**；实测 asm/ilu 直接 `DIVERGED_PC_FAILED (SUBPC_ERROR)` |
| `nl_abs_tol` | 1e-7（生产 1e-9） | 见 §4.3（实测残差地板） |

### 为什么可以把 `wGB` 从 4 µm 放大到 8 µm（**这是本工作最关键的判断**）

1. **Gibbs 把偏析从弥散带上搬到了面上** ⇒ `wGB` 现在**只是数值界面宽**，放大它
   **不再改变偏析物理**（弥散表示下放大 `wGB` 会直接改 `Γ`，见 `AGENTS.md` §3.5）。
2. 放大必须**同步重标定**：`mu0 = 6σ/wGB`、`κ = 0.75σwGB`、`L = 4/3·M₀/wGB`、Voronoi `int_width`。
3. **重标定已用项目自己的工具数值验证**（`_wgb_check.sh` → `results_wgbchk/log_wgbchk.txt`）：

```
wGB(µm)   κ_iso        μ0      w(µm)    最大相对误差
   4     1.8e-06     900000   1.4142   8.959e-05
   8     3.6e-06     450000   2.8284   8.959e-05     <- 逐位相同的误差
=> 两个 wGB 下真实晶界能都等于目标值 ⇒ 改 wGB 只换分辨率，不换物理
```

## §4 三个必须记账的诊断

### 4.1 低维块会被**无 block 限制的对象**污染（实测）

`probe_lowdim.i`：一个 2×2 的 2D 网格 + 中间一条低维块，变量/核**故意不加 block**：

```
u_all = 9.7666 = u_bulk(8.2197) + u_on_gbb(1.5469)
u_on_gbb_max = 0.77345 = 1 + 0.3*sin(4)      <- u 真的在低维块上被求解了
```

⇒ **MOOSE 会把无限制的变量/核/材料也装到低维块上**。所以本工作把
`[Kernels]/[Materials]/[AuxKernels]/[Postprocessors]` 与所有体相变量都加了 block 限制
（只有 `T` 故意不加 —— 面上的 `A_s(T)` 要用它）。

### 4.2 核与材料的 `coupled_variables` **必须逐字同序**

`SplitCHParsed`/`SplitCHWRes` 的非对角雅可比是
`cvar = mapJvarToCvar(jvar); (*_dXdarg[cvar])[_qp]`（`SplitCHWResBase.h`），
而 `_dXdarg` 是按**材料**的 `coupled_variables` 顺序索引的。
Gibbs 版把 `M` 的依赖扩到了 `c`、把 `f_loc` 的依赖扩到了 `T`
⇒ 核也必须声明 `'c T gr0 … gr7'`，否则 `∂M/∂c` **整块静默丢失**（P0-1 同类）。

> ⚠ 同一条也解释了历史隐患：生产材料的顺序是 `'c gr0 … gr7'` 而核写的是 `'gr0 … gr7'`
> —— 顺序不一致。本工作在 3D 副本里把它们**统一**了（**没有动生产原件**）。

### 4.3 残差地板：与 dt 无关的**空间**离散地板

用 `Debug/show_var_residual_norms` 打变量级残差：

```
|R|_2 of individual variables:   gr0 1.19e-9  gr1 1.11e-9  gr2 4.7e-10
                                 gr3..gr7 = 0
                                 c   3.45e-9   w 5.5e-12
                                 Gam0 2.2e-30  Gam1 6.5e-31     <- 面完全没问题
最大残差节点：(x,y,z) ≈ (-240.5 µm, 30~32 µm, ...)   <- 糊状区（固相线~液相线之间）
```

把 `dt` 从 5e-8 一路砍到 1e-12，残差**逐位不变** ⇒ 纯空间离散不一致，不是时间步问题。
`Gam` 的残差是 **1e-30** ⇒ **Gibbs 面不是地板来源**。
⇒ 3D 算例的 `nl_abs_tol` 设在实测地板之上（1e-7）。

### 4.4 `c` 会冲到负值（−0.035）—— 理想溶液版**把这个老问题暴露出来了**

生产自由能是二次型 `k_c/2(c−c0)²`，**没有 `c=0` 的势垒** ⇒ 负浓度不会报错，
只是悄悄错。Gibbs 版是理想溶液 `c ln c` ⇒ `c≤0` 直接 NaN。
所以本工作加了**数值下限** `CFLOOR = 1e-6`（比任何物理浓度低 3~4 个量级）：

```
expression = 'FREF*( (T/TREF)*(max(c,CFLOOR)*log(max(c,CFLOOR)) + (1-c)*log(1-c)) - ... )'
M 的分母同样加下限（否则 c<0 ⇒ f_cc<0 ⇒ M<0 负迁移率 = 不稳定）
```

**这是记账，不是修复。** 真正的缺口是：固液前沿在 `dx = 2 µm` 上没有解析
（`κ_c = 1e-14` ⇒ 溶质界面 ~20 nm ≪ dx），前沿过冲把 `c` 打到负值。

## §5 实测结果

（数字全部来自 `results_*/case_out.csv` 与 `run.log`，可用 `analyze_run.py` 复算。）

### 5.1d 【2026-09-21 收官】守恒已闭合 —— 交错耦合的显式扣账 `GBSoluteSink`

**做法**：不再指望"同一个牛顿解出那个 1e-17 的汇"，而是**按构造成立**：
每步（`timestep_begin`）量出面上 Γ 的增量 `dM`，把 `dc = -dM/(ρ_mol*V_int)` 直接加到
**全部 300 个界面节点的 c** 上 ⇒ 体相库存的变化 = −dM **是代数恒等式**。

**实测（等温非平衡算例，Γ 从 0 开始，t = 1e-6 s，10 步）**：

```text
UO 自己记的扣账总额          9.716972e-16 mol
体相实测少掉的 ρ_mol*Δ∫c dV  9.716977e-16 mol     ← 逐位一致
面上 Γ 的增量 A_s*ΔΣ∫Gam dA  1.035787e-15 mol
面/体相比值                  1.066   （修之前是 2.0e7）
界面贫化 depletion          +9.29e-5  （修之前是 -3.94e-5，负的）
```

**那 6.6% 的差额 = 正好最后一步的交换量**（最后一步 dM = 7.086e-17 = 总额的 6.8%）
⇒ 这是**交错耦合固有的一步滞后**（第 n 步的交换在第 n+1 步开局才扣），**不是缺陷**；
继续跑下去它不会累积。**⇒ 守恒已成立。**

**实现里踩到的四个坑（都是"不报错就错"或直接段错误）**：

| # | 坑 | 现象 | 修法 |
|---|---|---|---|
| 1 | `T` 住在**辅助系统**，我却用**非线性系统**的 `dof_map` 查它的 dof | **段错误**（rc=139），日志停在第一步雅可比处 | 用 `aux.system().get_dof_map()` |
| 2 | `V_int` 把**低维面元**也当体元（它的 `volume()` 是面积） | `V_int = 1.92e-9`（应为 2.4e-15，差 1e6） | 跳过 `e->dim() < mesh_dimension()` |
| 3 | 在 `timestep_end` 改解 | 被 MOOSE 的 advance/同步丢掉，只生效 ~1/1000 | 改到 **`timestep_begin`** |
| 4 | BDF2 的**第三个**解向量 `solutionOlder()` 没一起平移 | `u_dot` 被伪造，体相多丢 48% | u/u_old/u_older **三个一起平移**（1.5−2+0.5=0） |

另外两条（都在本次实测中排除）：
· `compute_primal_residuals = false` ⇒ **段错误**（MOOSE 后面仍会 cacheResidualNeighbor，而没人填）——所以那条 1e-17 的 primal 残差**留着**，双计可忽略（小 11 个量级）；
· UO 被 MOOSE 在 `EXEC_INITIAL` 就调用，那时解向量还没建好 ⇒ 必须在最前面挡掉 `initial`。

**⚠ 仍然存在的限制**：跨晶界**剖面**里的局部贫化**看不清** ——
局部信号 ~1e-4 相对量级，而被体相那个 **2Δx 棋盘振荡（~1e-2）** 盖住了（§5.1c-0 / §6-S9）。
积分量（depletion、守恒账）是干净的；要看清剖面必须先洗掉那个振荡。

### 5.1f 【2026-09-21 深夜】**双向显式交错成型：熔池通了、守恒精确**

**做法**（`GBStaggeredUpdate`，**整个替代 mortar 方案**）：砍掉 `[Constraints]`，面↔体相两条腿都在
一个 UserObject 里、在 `timestep_begin` 显式推一步：

```text
面： Γ_eq = A_s(T)·c（McLean）， Γ ← Γ_eq + (Γ_old − Γ_eq)·exp(−k_att·dt)   ← 精确解，任意 dt 稳定
体： ΔM = Σ_面元 Σ_节点 A_s(T_n)·ΔΓ_n·(A_e/4)，   Δc = −ΔM/(ρ_mol·V_int)  ← 加在全部界面节点
⇒ ρ_mol·Δ∫c dV + ΔM ≡ 0 是**恒等式**（同一对象里同时扣两边），与非线性容差无关
```

**实测（等温非平衡算例，t = 1e-6 s，10 步）**：

```text
面拿到   A_s·ΔΣ∫Gam dA = 9.749332e-16 mol
体相少了 ρ_mol·Δ∫c dV  = −9.749332e-16 mol      ← 逐位相同
比值 = 1.000e+00   界面贫化 depletion = +1.265e-4
```

**实测（三维真熔池，t = 3e-7 s，3 步，GB 在 1705–1746 K）**：

```text
Converged = 3   DidNOT = 0     第 1 步 |R| = 3.541741e-06（与不开耦合的参考完全相同）
GBStagger：面↔体相在交换（dM = −1.57e-19 mol ⇒ 面在**释放**溶质，因为局部 c < 0.036）
读回 Gam ∈ [0.0354, 0.0366]（随局部 c 变化）    depletion = +0.7223（0.72%）
```

**⇒ 三维熔池 + Gibbs 面 + 交错耦合：能收敛、在交换、守恒按构造成立。**

**这一夜踩掉的四个坑（都记账）**：

| # | 坑 | 症状 | 修法 |
|---|---|---|---|
| 1 | 同一节点在 4 个面元上各写一次 ΔΓ | 读回 Gam ∈ [0.0034, 0.0137] = **4 倍**（节点属于 4 个面元） | 节点值**只写一次**；面积权重只用于记账 |
| 2 | `T` 在**辅助系统**，却用非线性系统的 dof_map 查 | **段错误** | 用 `aux.system().get_dof_map()` |
| 3 | `V_int` 把低维面元当体元（其 volume() 是面积） | 差 1e6 倍 | 跳过 `e->dim() < mesh_dimension()` |
| 4 | `timestep_end` 改解 / BDF2 第三个向量没平移 | 修正被丢掉 / u_dot 被伪造 | 改 `timestep_begin`；u/u_old/u_older 一起平移 |

### 5.1e ⚠（**已更正**）曾经以为的"新回归"：真熔池第 1 步 `|R| = 1.924032e+01`

> **更正**：这个 `|R| = 19.24` **不是耦合造成的**，是我早先做实验时把
> `automatic_scaling = true` 设成了**默认开**、忘了改回来（日志里那行
> "Performing automatic scaling calculation" 就是它）。把它改回默认关之后，
> 熔池第 1 步残差 **3.541741e-06**、直接收敛（见 §5.1f）。
> ⇒ 教训：**改默认值做实验，必须当场改回来**（否则后面每一个失败都被误归因）。

把 `kex` 修对之后，熔池算例**第一次有了真实的耦合**，于是它的第 1 步不再收敛。
**已排除的（逐个单因素切除，每次只关一个）**：

| 关掉什么 | 结果 |
|---|---|
| `SINK=0`（不加 GBSoluteSink） | 仍 `\|R\| = 1.924032e+01` ⇒ **与 UO 无关** |
| `TWOSIDE=0`（改回单侧低维块） | 同样 ⇒ 与两侧块无关 |
| `DISP=0`（去掉零位移系统） | 同样 ⇒ 与它无关 |
| `GAMSCALE=`（去掉 Gam 的 scaling） | 同样 ⇒ 与它无关 |

**⇒ 剩下的解释只有一个，而且很合理**：以前熔池算例能跑，是因为 `kex=0` ——
**耦合是死的**；现在 `kex` 修对了（熔池的晶界面在 1705–1747 K，`kex ≈ 4.96e-4`），
晶界与体相**真的开始交换**，而熔池体相本身很刚（糊状区 + 2Δx 振荡 + c 负值），
**第一步的强瞬变就把它顶崩了**。
⇒ 这与 §5.1d 的结论是同一件事的两面：**显式扣账解决了"体相那一步"，
但 LM（面）方程仍然靠 mortar 在同一牛顿里解** —— 熔池上这一步的源太强。

**下一步（很明确）**：把 LM 也改成显式/交错更新（每步用上一步的 c 推 Γ，
再把 Γ 的增量扣给体相），这样两边都不在同一个牛顿里强耦合。

```text

   ⇒ 面/体相 = 2.0e7（这一跑更极端，因为体相的变化被数值噪声主导）
② 界面： depletion = 1 - c(界面)/c(体相平均) = **-3.94e-5**   ← 负的
   ⇒ 界面处不但没贫化，反而略浓 ⇒ **晶界没有从体相抽走任何东西**
③ 剖面： 远场(>5µm) 0.035990  界面附近(±2µm) 0.036053
   ⇒ 剖面贫化 = -1.75e-3（同样是负的）
```

**同一个剖面还暴露了第二个（体相自己的）缺陷**：c(x) 有明显的**网格尺度振荡**
（周期 ≈ 2Δx = 4 µm，幅度 ~1%）。这是界面远小于网格时 Cahn–Hilliard 的典型棋盘振荡
（`κ_c = 1e-14` ⇒ 溶质界面 ~20 nm ≪ dx = 2 µm）。**这条与 Gibbs 面无关**，
是 §6-S9「固液前沿欠解析」的同一个根。

守恒失衡的机制（三条独立证据指向同一处）：

```text
① 面拿到     A_s*Σ∫Gam dA = 4.7542e-5 * 3.2455e-11 = 1.543e-15 mol
② 体相少了   ρ_mol*Δ∫c dV  = 101292.88 * (-8.57e-26) = -8.68e-21 mol
③ 比值 1.8e5  ⇒ 体相几乎没丢
④ 逐类型诊断：约束给体相的汇 = (K/2)(c-Gam) ≈ 8.4e-6 /面积，落到每个节点 ≈ 1e-17
   而体相自身的 |R| ≈ 1e-7  ⇒ 相差 1e10 倍
```

⇒ 这是**收敛判据的行缩放问题**，不是公式错、也不是接线错。
公式本身是守恒的（Lower: −K(c−λ)；Sec/Pri 各 +K/2(c−λ)；基函数和 = 1 ⇒ 积分意义上严格抵消）。
但只要用**一个标量范数**判收敛，体相就不会去响应那 1e-17 的汇。

**已试过并排除的解法**：

| 试法 | 结果 |
|---|---|
| 显式写 `compute_primal_residuals = true` | 无变化（本来就是 true） |
| 每侧各一个低维块（MOOSE 文档里"两侧界面"的写法） | 无变化 |
| 加零位移系统（p3c 有，我最初删了） | 无变化 |
| 把 `c` 也定义到低维块上 | 无变化 |
| `Executioner/automatic_scaling = true` | **更糟**：第 1 步就 `\|R\| = 2.58e1` 发散、dt 砍到 3e-12 |
| 给 LM（Gam）单独 `scaling = 1e9` | ✅ **有效**（Γ 活了），但没有解决体相侧 |

**① `kex` 不能加 `block` 限制。**

```text
[GBDBG] n=1 type=0 sec=0.036 pri=0.036 lam=0 kex=0        <- 修前：驱动力对、kex=0
[GBDBG] n=1 type=0 sec=0.036 pri=0.036 lam=0 kex=0.000469338  <- 修后：与解析逐位一致
```

原因：`GBFluxExchange` 的积分点在 **mortar segment 网格**的元素上，它们不属于 `gbb0` 这个子域；
带 `block` 限制的材料在那里**求不出来、静默取 0**。p3c 用的是**无 block 限制**的
`GenericConstantMaterial`，所以它一直好。
⚠ 反面教训：`AsRho` 带 `block = gbb0` 是**对的**（读它的是 `ScaledTimeDerivative`，就装在同名低维块上）
⇒ **"材料要不要加 block"取决于谁读它、在哪里读**，不能一刀切。
⚠ 修法上还有一层：`kex` **只能有一份**（无 block）。两个同名材料都不限制时 MOOSE 直接报
`declared on block 0 by multiple materials`（实测）。

**② 面上方程必须给 `scaling`，否则被体相残差淹没。**

```text
不加：[Variables] Gam0 无 scaling  -> 每步 n_nonlin = 0（一次牛顿都不做）⇒ Γ 永远停在初值
加 ：Gam0  scaling = 1e9           -> 19 步全收敛，Gam_avg 0 -> 0.03385
```

这不是调参：SNES 用**一个标量范数**判收敛，而面上方程的节点残差量级（~1e-16）
比体相（~1e-6）小 10 个量级 ⇒ 不抬它就等于**没解**。MOOSE 的 `[Variables] scaling`
正是为此设计的，且**不改变解**。

### 9.4 ✅ 【S9】诊断结论：`c<0` 与 2Δx 振荡**完全来自体相（熔池固液前沿）**

| 实验 | 结果 |
|---|---|

### 9.8 ✅【A5】dt 收敛性判据：**观测阶数 p ≈ 1.05（一阶）**

| `results_p3c_rerun`（3D 原型 p3c） | 13 | 21 | 12 | 大部分步骤假收敛 |

**⇒ 报告 §5.2 / §5.3 / §5.4 / §5.5 / §5.7 / §9.x 里所有"3D 上验证通过"的结论，
   都只说明"求解器在被冻结的状态上宣布收敛"，不构成任何物理证据。**
（同时作废：§9.4 里"`k_att=0` 与开着逐位相同 ⇒ 与晶界层无关"—— 它比较的是**两个冻结值**。）

**2D 不受影响**：2D 的残差尺度 ~1e-4（单元面积 4e-12 ⇒ 比 3D 的单元体积 8e-18 大 5~6 个量级），
`nl_abs_tol=1e-7` 是**紧**的。本轮全部 2D 算例（`n3c1e2`/`n4nopart`/`n6iso`/`k4base`）
**没有任何一步的 `n_nonlin = 0`** ✓ ⇒ 2D 结论（§12）成立。

### 13.2 为什么会这样（机理，可算）

残差是**体积/面积分**：3D 单元体积 `(2e-6)^3 = 8e-18`，2D 单元面积 `(2e-6)^2 = 4e-12`。
同样大小的**局域**不平衡，3D 的节点残差比 2D 小 **~4e-6 倍**。
实测比例：3D `|R| ≈ 2.3e-9` vs 2D `|R| ≈ 1e-4` ⇒ **4e-5**，与量纲分析同量级 ✓。

### 13.3 正确做法（**必须改**）

`nl_abs_tol` **不能跨维度照搬**。两条可用的规则（任选，须在输入里写明依据）：

1. **让相对判据说了算**：把 `nl_abs_tol` 设到远低于 `|R0|`（3D 用 `1e-14` 量级，或更小），
   由 `nl_rel_tol = 1e-8` 主控；`nl_abs_tol` 只作为"本步本来就不需要动"的保护。
2. **按网格度量缩放**：`nl_abs_tol ∝ dx^dim`。2D/`dx=2 µm` 用 `1e-7` ⇒ 3D 同 `dx` 应取 `~1e-13`。

⚠ **任何 3D 结果在采用新 atol 之前都不得引用。** 复跑方法：
```bash
q1_3dfix  : 3D 修正版 + dtmax=1e-8 + nl_abs_tol=1e-7    <- 冻结（作废）
r1_3dfix_a14: 同上，只把 nl_abs_tol 改成 1e-14            <- 真正的 3D 检验
r2_3dold_a14: 旧版 3D + dtmax=1e-8 + nl_abs_tol=1e-14
```

### 13.4 `nl_abs_tol` 的正确设定规则（**可直接照用**）

实测到的规律：**残差是 `dx^dim` 量级的积分**，所以

```
|R|_典型  ∝  dx^dim        （同一局域不平衡下）
```

| 维度 | `dx` | 单元度量 | `|R0|`_典型（实测） | 应取的 `nl_abs_tol` |
|---|---|---|---|---|
| 2D | 2 µm | 4e-12 | **~1e-4** | `1e-7`（现在用的，**紧**，正常） |
| 3D | 2 µm | 8e-18 | **~2.3e-9** | 应取 **~1e-12**（= 1e-3·`|R0|`），而不是 1e-7 |

**规则**：先跑 1~2 步，从日志读第 0 次迭代的 `|R|`，然后取
`nl_abs_tol ≈ 1e-3 × |R0|`（或直接用 `nl_rel_tol=1e-8` 主控，把 `nl_abs_tol` 设到
比 `|R0|` 低 3 个量级）。**不可以把 2D/1D 的值抄到 3D**。
（实测：3D 取 `1e-14` 也偏严——第 1 步要 17~20 次牛顿迭代才压到 2.5e-12，
随后仍达不到 rel 目标；取 `1e-12` 才是"几步就收敛"的量级。）

### 13.6 ⭐ 定量对账：为什么可以断定 3D 的"收敛"是 atol 假象（不是"状态本来就稳态"）

同一个物理状态、同一步（step 2，2D 与 3D 用同一套初值与温度场）：

```
2D（n3c1e2, dx=2 µm）  step 2 :  |R0| = 3.130377e-04
                                  3.1e-4 → 2.2e-4 → 2.1e-4 → 2.4e-5 → 2.1e-6 → 4.3e-09   （5 次迭代）
                      step 3 :  3.4e-4 → ... → 5.8e-13
3D（q3_3dold_dt8, dx=2 µm）step 2 :  |R0| = 2.288422e-09   → 直接 "Solve Converged!"（0 次迭代）
```

**对账**：残差是体积/面积分，单元度量 2D = `dx²` = 4e-12、3D = `dx³` = 8e-18 ⇒ 同局域不平衡下
`|R|` 之比应 ≈ `1/dx / sqrt(N3/N2)` ≈ `5e5 / 2.4` ≈ **2.1e5**。
**实测比值 = 3.13e-4 / 2.29e-9 = 1.4e5** —— 与预测同量级（差 1.5 倍，来自 2D/3D 熔池几何与节点数差异）✓

⇒ **3D 的 2.3e-9 不是"物理上已经平衡"，而是同一个局域不平衡被 `dx³` 缩小了 5~6 个量级。**
   用 2D 的标尺（`atol/|R0| = 1e-7/3.1e-4 = 3.2e-4`）折算到 3D ⇒ 正确 `atol ≈ 3.2e-4 × 2.3e-9 ≈ **7e-13**`
   —— 与我新起的 `t1/t2` 用 `1e-12` 一致 ✓

**顺带的加分证据**：修复后的 2D 算例，残差在一步内能压到 **5.8e-13**；
   而修复前的旧版在 t\*=1.268e-7 处**冻结在 2.375e-5**（高 7 个量级）。
   ⇒ 这条同时证明**旧版那个"非零残差地板"确实被 C1 正则化消掉了**。
