## 三、本轮新暴露的问题（部分已修 / 部分待修）

### 已加固（10 倍改善）；根因已重新认识（**不完全是 bug**）

**1. @B@sussman_reinit@B@ 对"大范围单调线性场"会移动界面** —— 比初版报的更严重，但**性质要说准**：

对 @B@d = 2z + const@B@（@B@|grad d| = 2@B@）做重初始化，@B@iters@B@ 越大越糟：
@B@d=0@B@ 从 0.012um -> **-0.82um(iters=100) -> -71um(iters=3000)**，带内 @B@|grad d|@B@ 变 nan。

**已加的三处加固**（EXPERT-#3c）：
  ① 自适应步长 @B@dtau_eff = min(dtau, 0.5*dx/3/max(gm))@B@（CFL 对 @B@gm@B@ 也成立）
  ② 单步更新 clip 到 @B@+-0.5*dx@B@
  ③ **发散守卫**：@B@max|phi|@B@ 超初值量级 10 倍 => **拒绝本次 reinit**（返回原场，不静默生效）
效果：3000 迭代下从 -71um 改善到 **-6.3um（约 10 倍）**，但**仍未收敛到解析值**。

**根因的重新认识（重要）**：Sussman 重初始化的不动点是 @B@|grad phi| = 1@B@ 的场；
而 @B@d = 2z + c@B@ 是**线性场**（斜率 2），它**本来就不在不动点上** =>
迭代把斜率推向 1 的**同时必然改变零等值面位置**。所以"界面被移动"**不一定是 bug**，
而是"输入不是 SDF"的必然后果。
=> 正确结论：**@B@sussman_reinit@B@ 只应在界面附近的窄带内、且输入已近似 SDF 时使用**。
这正是 @B@reinitialize(mode='pair')@B@ 的做法（@B@near = |d| <= 6dx@B@ 掩模 + 前置归一化），
所以**实际路径的结果是对的**（0.01200um，多次验证），但**底层的窄带假设必须保持**。

**仍待办**：把"窄带 + 近似 SDF"这个前置条件写成**运行期断言**（例如带内 @B@|grad d|@B@ 偏离 1 超过 50% 就告警），
以免将来在别处误用。
