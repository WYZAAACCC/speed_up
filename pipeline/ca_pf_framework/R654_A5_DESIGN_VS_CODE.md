## §1 两个口径的原文

### 1.1 设计（`BLOCK_SELFAC.md:852-860`，逐字）
> **每 `N_proj` 步**，对每个场 `k`：
> 1. **取支撑函数**：该变体的三个已知轴 `{a_k, w_k, n*_k}` 及其反向共 6 个法向；
>    对**界面点云**（`|phi_k| <= 0.5*Delta_x`）算 `h_j = max(x·n_j)`（6 个数）；
> 2. **构造多面体** `K_k = {x : x·n_j <= h_j, j=1..6}`；
> 3. **保体积标定**：把 6 个 `h_j` 统一缩放，使 `vol(K_k)` = 当前该场体积；
> 4. **替换** `phi_k <- SDF(K_k)`

### 1.2 实现（`_r68_facet_op.py`，docstring `:1-13` + 代码 `:33-72`）
> 1. 界面点 = `|phi_k| <= 0.5*dx`；
> 2. 三个轴的**支撑半宽**：`h_j = (max(x·n_j) - min(x·n_j))/2`，中心 `c_j = 中点`；
> 3. **保体积标定**：`s = (V_target / V_proj)^(1/3)`，`h_j ← s·h_j`；
> 4. 新 `phi_k = max_j (| (x - c0) · n_j | - s·h_j)`

**⚠ 而实际代码用的是**（`:33`、`:64-65`）：
```python
body = np.isfinite(phi_k) & (phi_k < 0)        # ← 体内胞，不是界面点云
lo.append(float(np.quantile(pr, q_lo)))        # ← 分位数，不是 max
hi.append(float(np.quantile(pr, q_hi)))
```
`q_lo=0.005`、`q_hi=0.995`（**为抗"长指棘轮"从 min/max 改的**，见 `:52-58`）。

### 1.3 ⇒ 出入有两处（**实现自己的 docstring 也与代码不符**）

| # | 设计 | 实现（代码） | 是否有记账 |
|---|---|---|---|
| **①** | 点云 = **界面点** `\|φ\|≤0.5Δx` | 点云 = **体内胞** `φ<0` | ⚠ **`_r68_facet_op.py:27-32` 有记账**（解释为何必须取自"体"），但 `BLOCK_SELFAC §8.C` **未同步** |
| **②** | `h_j = max` | `h_j = quantile(0.995)` | ⚠ **`:52-58` 有记账**（抗长指棘轮），`§8.C` **未同步** |
| **③** | `h_j = (max−min)/2`（半宽） | 用 `lo/hi` 两边界 + `max(lo−x·n, x·n−hi)` | ✅ **数学等价**（差一个中心平移），**不是出入** |

**而它自己的代码用的是另一套**（体内胞 + 分位数）⇒ **该文件内部 docstring 与代码不一致**。

## §2 定量判定（`_t11_A5_geom.py`）

对同一快照、同一场、同一目标体积 `V0 = #(φ<0)`，分别按两口径算盒子：

| 臂 | 场数 | **半宽相对差（三轴）** | **`a/w` 相对差** |
|---|---:|---|---|
| **`B40`**（`proj=1`，盒子） | 7 | `+2.8% … +17.5%` | **`+8.4% … +16.1%`**（**全部同向：实现更大**） |
| **`L0`**（`proj=0`，自由形状） | 10 | `+0.4% … +65%` | **`−49% … +10%`**（**方向都变**） |

### 2.1 ⇒ 三条结论

**① ✅ 实现口径系统性地给出**更大**的长厚比**（`B40` 上 `+8% … +16%`）
机理：**体内胞点云比界面点云"更宽"**（体内延伸到界面之外）
⇒ 按体积标定后**长厚比被抬高** ⇒ **与 `R70` 记载的"棘轮"同源**。

**② ⛔ 在 `L0`（非盒子形状）上两口径能差 49%**
⇒ **"出入很小"这个判断是错的**（我先前在对话里说过"很小"，此处更正）。
⇒ **在外形非盒子时，这个出入是**一阶**的。**

**③ ⚠ 该出入在 `BLOCK_SELFAC.md §8.C` 里从未记账**
（该文件最后一次改动是 **2026-10-02**，此后未再同步）
⇒ **若上游按 `§8.C` 的设计文档来判断"这个机制会造出什么几何"，
得到的几何与代码实际造的**不同** ⇒ **会影响上游判断。**
