### 一、`§95` 当时写了什么

> 「**首次偏离在 step 240**，而两块初始相距 **2.5 µm**、`t=0` 异变体接触面 = 0

### 五、顺带核实的两件事

1. **`V0` 的单位**：`_r112` 把它读成 `0.0000` 是因为它在 CSV 里是 **m³**
   （N=96 盒：`2.14e-16 m³ = 214 µm³`，盒 216 µm³ ✓ 是**母相体积**）。
   ⇒ **β 分数 = `V0/盒体积`**：step 0 时单块 **0.9906**、两块 **0.9810**；
   step 560 时 **0.979** 与 **0.959**。
   ⇒ 母相消耗只有 **1–4%**（因为转变分数本来就小）⇒ **"母相竞争"这条通道量级太小**，
   不足以解释 7.6% 的几何差异。**（此句为【推理】：从量级估计，未做隔离实验。）**
2. **`_r111_vtctrl.py` 作废**：我拿 `Vt` 当"同 Vt 比较"的横轴，但
   **单块臂 `Vt` ≈ 块 0 的体积，两块臂 `Vt` = 块 0 + 块 1**
   ⇒ 同一个 `Vt` 在两臂里对应**块 0 只有一半大**
   ⇒ 表里出现"两块 span 随 `Vt` **下降**（1901→639）"这种**非物理**读法。
   ⇒ **`_r111` 的"+1704 nm / +60.9%"作废**；正确做法见 `_r112`（同 step + 切"未接触"窗口）。
