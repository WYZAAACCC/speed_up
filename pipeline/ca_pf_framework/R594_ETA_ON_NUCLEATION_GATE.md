# R594 —— ★★★ 修法 A 的**另一半**：η 此前只接在长大律，没接在**形核闸门**上

> 日期：**2026-10-04** ｜ 发现路径：**s295 把引擎的形核分诊计数接出来之后才看得见**
> 意义：**「一场多板条」+「块数恒 1」+「burst 首档被拒」三个症状同一个根因**，
> 且它同时解释了为什么修法 A（η）在前几轮**只改善了一半**。

## 1. 怎么发现的（**先补量具，再谈物理**）

s293/s294 让「块数 = B」的规则正确工作后，实测 `fresh` 通道**仍然每次都被拒**：

```
t5FIX  事件=6  fresh 被拒=6
t5BKMo 事件=5  fresh 被拒=5
t5ETAo 事件=2  fresh 被拒=2
```

而引擎**自己就有分诊计数、却一个都没打印**（`dbg['fresh_exc']` `:2183`、
`dbg['fresh_blocked']` `:2188`、`dbg['sites_resampled']` `:2219`、`dbg['sc_*']` `:2154-2157`）。
⇒ **s295 把它接出来（纯记账，不改数值）**，一行就给出了答案：

```
fresh_cand=12   fresh_blocked=12   sites_resampled=12   sc_try=11   supercrit=11
sc_last_df    = +1.2273e8      ← 化学驱动力 ✓（理论 ΔG(Ms)=1.2275e8，4 位吻合）
sc_last_ed    = -2.1342e8      ← ★ 弹性罚能 = 驱动力的 **1.74 倍**
sc_last_fcrit =  1.6e6         ← 2γ/t
```

**关键读法**：`sites_resampled=12` ⇒ 引擎的**解卡机制正常工作**（位点被重抽了 12 个），
但重抽的位点**全部卡在同一条判据**上
⇒ **阻塞是「判据」，不是「几何」** —— 这一步排除了"位点池/有界盒"两个候选假设。

## 2. 判据（`windowB_surface.py`，逐行读过）

```python
fcrit = 2.0 * float(gamma) / max(float(t), 1e-30)          # :1872
return bool(float(df) + med > fcrit), med, fcrit, nc       # :1884（修前）
```
代入实测：`1.2273e8 + (−2.1342e8) = −9.07e7`，**远不大于** `1.6e6` ⇒ **拒绝** ✓ 与实测一致。

## 3. 根因：**η 只接了一半**

| 律 | 位置 | 修前是否含 η |
|---|---|---|
| **长大律** `dG_cell = Δdf + η·Δed − γκ` | `:4366` | ✅ 含（前几轮已接） |
| **形核闸门** `df + η·ed > 2γ/t` | `:1884` | ❌ **不含** |

而「弹性罚能高估 ~3 倍」（**纯线弹性、无塑性弛豫/TRIP**）这条物理理由
**对形核闸门同样成立** —— 储存能里同样有约 2/3 应被塑性耗散掉。
⇒ **两条律口径不一致，等于一半修、一半没修。**

**后果链**：核**根本放不下**（`fresh` 全拒）⇒ 只有 `attach`/`stack`（**不经**该判据）能放核
⇒ 而那些核放下去又被长大律**溶解**（前几轮的实测：体积 −40–87%、板条被啃成多块）
⇒ **「一场多板条」+「块数恒 1」+「burst 首档 20 上限」全部由此而来。**

## 4. 修法（`_t5_patch_sceta.py`，一处）

```python
_eta_sc = float(getattr(self, 'ed_eta', 1.0) or 1.0)
return bool(float(df) + _eta_sc * med > fcrit), med, fcrit, nc
```

* `η = 0.375`：`1.2273e8 + 0.375·(−2.1342e8) = **+4.270e7** > 1.6e6` ⇒ **通过** ✓
* **与 `:4366` 用同一个 `self.ed_eta`** ⇒ 两条律口径一致（不再一半一半）
* `η = 1.0`（**默认**）⇒ **与原文逐字等价** ⇒ 归档臂**逐位不变** ✓

## 5. ★ 验收：**单变量、同引擎对照**（不是外部解析模型）

三臂**只差 `--ed-eta`** 一个开关，同一份代码、同一时刻重启：

| 臂 | `--ed-eta` | `sc_try → sc_pass` | `fresh` 被拒 | 形核事件 |
|---|---|---|---|---|
| `t5ETAo` | **0.375** | **2 → 2（全通过）** | **0** | 2 |
| `t5FIX` | **0.375** | — | **0** | **38**（修前卡在 20 + 25 次被拒） |
| `t5BKMo` | **无（η=1.0）** | — | **5 / 5 仍全拒** | 5 |

**⇒ `η=1.0` 的臂仍然 100% 失败、`η=0.375` 的臂 100% 通过** ——
这正是 s296 所预测的，且**唯一差异就是 η** ⇒ **判据成立，不是巧合**。

`t5FIX` 的 `dbg`：`sc_last_df=+1.2273e8`、`sc_last_ed=−2.1029e8`、`sc_last_fcrit=1.6e6`、
