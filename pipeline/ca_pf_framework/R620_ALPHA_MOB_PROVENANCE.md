# R620 —— ③ 文献矫正（第一批）：`alpha_KM` 与 `MOB` 的真实出处，以及一个必须裁定的张力

日期：2026-10-05（第 11 轮）

---

## 0. 摘要（三句话）

1. **`alpha_KM = 0.041739` 是启动器有意钉的值**（`_t5_short.py:274` `default=0.041739  # ★ abA 的原值`，且 `:104` 显式透传），
   引擎自身的默认是 `ALPHA_KM_REF = 0.011`。
2. 而框架在 `R507_SHAPE_CLOSURE.md` 里**由两个约束联立导出** `α_KM ∈ [0.0089, 0.0205]`
   （C3「块内 ≥2 根」下界 ∩「块厚文献带 (1.0, 6.0) µm」上界），**推荐 0.011**。
   ⇒ **生产值 0.041739 = 该带上界的 2.04 倍。**
3. **由此暴露一个硬张力**：要把总板条数做到用户要求的「两百多」，
   在 `α = 0.011` 下需要 `B ≈ 34`（9 块只有 54 根）；而 `α = 0.0417` 虽然给出 `9×23 = 207` 根，
   却把块厚推到 `W_block = n·t ≈ 11.7 µm`（远超文献带）。
   **两条路不能同时满足——需要用户裁定。**

## 1. `alpha_KM` 的文献链（本次逐条核实）

| 环节 | 内容 | 出处 / 置信度 |
|---|---|---|
| 律的形式 | `f = 1 − exp[−α(M_s − T)]`；**T 为自变量、与时间无关**（athermal） | Koistinen & Marburger 1959, DOI `10.1016/0001-6160(59)90170-1`【DOI 已复核；原文未取到】 |
| Fe–C 的 α 值 | **`α = 0.011 K⁻¹`**（四组不同碳含量碳钢拟合） | Geng et al. 2024, DOI `10.1007/s12613-023-2780-9`【**全文**，二手】 |
| 组分式 | `α_BS = 0.0224 − 0.0107x_C − 0.0007x_Mn − 0.00005x_Ni − 0.00012x_Cr − 0.0001x_Mo`（wt%） | van Bohemen–Sietsma，经 Geng 2024 转述 |
| 物理内核 | **`α = V̄·φ·(dΔG/dT)`**（Magee 1970）；`V̄` = 每个新单元平均体积 | Magee 1970（ASM *Phase Transformations* p.115，**书章无 DOI**）；经 Geng 2024 / Khan 1990 §5.2 转述【全文】 |
| 钢的 `V̄` | **20 µm³**（"a typical plate … 0.2 × 10 × 10 µm"） | Khan 1990 剑桥博士论文 §5.2【全文】 |
| **Ti-64 确实用 KM 律** | `X_αm,0^eq(T) = 1 − exp[−k_αm^eq (T_αm,sta − T)]` for T ≤ M_s，**"depends on temperature only, not time"** | Nitzler et al. 2021, arXiv:2101.05787 eq.(5)（仓库 `lit/part_E_kinetics.md:84`【实测/原文】） |
| 同上（另一独立模型） | "combining diffusion-driven JMAK kinetics with **diffusionless Koistinen–Marburger** transformations"（Ti-6Al-4V） | van der Linde et al. 2026, arXiv:2604.24669（仓库 `lit/part_E_kinetics.md:85`） |

⇒ **律的形式对 Ti-64 有出处；数值 α 只有 Fe–C 的。**

## 2. 我用 Magee 律做的推导（`_t11_alpha_derive.py`，可复算）

```
反标定（用 Khan 的钢数消掉 φ 与 DS_steel 的乘积）：
    φ·DS_steel = α_FeC / V_steel = 0.011 / 20 µm³ = 5.5e14  (K⁻¹ m⁻³)
    校验 a = V·(φDS) = 0.011000  PASS

本体系板条体积（框架 recommend() 的口径）：
    V_ti = t·L·W = 510 nm × 4.59 µm × 1.224 µm = 2.8653 µm³  （钢的 0.1433 倍）

则 α_Ti = V_ti · φ · DS_Ti
```

⚠ **φ 与 `DS_steel` 在上述反标定里不可分离**（只得到乘积）⇒ 两种口径都报：

| 口径（`DS_steel` 取值） | `α_Ti` | `n(T_end=298)` |
|---|---|---|
| 若 `DS_steel ≈ 1.0e6 J/(m³K)`（Fe-C 量级，**未核实**） | **0.000654** K⁻¹ | 0 |
| 若 `DS_steel = DS_REF = 4.147e5`（**借用 Ti 的值**） | **0.001576** K⁻¹ | 0 |
| 敏感度带（`V_ti` ×0.5–1.5、`DS` ×0.8–1.2） | `6.3e-4 … 2.8e-3` | 0–1 |

**负对照**（量具有分辨力）：用钢的 `V̄ = 20 µm³` 代入同一 `φ, DS` ⇒ `α = 0.011`，
与 `V_ti` 口径差 **6.98 倍** = `V_steel/V_ti` ✅ PASS。
⇒ **`V̄` 的选择确实改变 α，推导不是恒等式。**

### 2.1 结论（**必须分清两件事**）

* **(a) 我的推导给出 `α_Ti ≈ 1.6e-3`，比生产的 0.0417 小 26 倍。**
  这**不一定**说明生产值错 —— 因为 `φ` 是把"每个新单元按驱动力增量计的数目比例"
  这个**唯象常数**从 Fe–C 反标定来的，而 Ti-64 的形核位点密度/自催化强度与钢不同，
  `φ` 未必可搬。**Magee 律在这里只能给量级与方向，不能给数值。**
* **(b) 但框架自己的闭式给了独立约束**：`R507_SHAPE_CLOSURE.md:38-39`
  由「C3 块内 ≥2 根」∩「块厚文献带 (1.0, 6.0) µm」导出 **`α_KM ∈ [0.0089, 0.0205]`**，
  推荐 0.011。**生产值 0.041739 超出上界 2.04 倍。**

## 3. ★ 由此暴露的硬张力（**需要用户裁定**）

### 3.1 事实

| 项 | `α = 0.011`（框架推荐 / R507 带内） | `α = 0.041739`（生产生效） |
|---|---|---|
| `n(T_end) = floor(α·(M_s − T_end))` | **6** 根/块 | **23** 根/块 |
| `B = 9` 时总根数 `B·n` | **54** 根 | **207 根** ✅ 满足"两百多" |
| `W_block = n·t`（`t = 510 nm`） | **3.06 µm** ✅ 在 (1.0, 6.0) 带内 | **11.7 µm** ❌ 超带 1.95 倍 |
| 板条长 / 块厚 = `L/W_block` | 1.50 | 0.39 |

### 3.2 为什么不能同时满足

* 用户要求 **最终 200+ 根板条**（且 ≤ nv）；
* 文献带要求 **块厚 1.0–6.0 µm**；
* 而 `总根数 = B·n`、`n ∝ α`、`W_block = n·t` 三者由同一套几何绑死
  ⇒ **`总根数 = B·W_block/t`**。
  取带中心 `W_block = 3.5 µm`、`t = 0.51 µm` ⇒ `B = 200/6.9 = 29 块`。

### 3.3 三条可选路径（**我不自己定，请用户裁**）

| 路径 | 做法 | 代价 / 风险 |
|---|---|---|
| **P1 增块数**（我倾向） | 保持 `α ≈ 0.011`（带内），把 `B` 从 9 提到 **~34** | 几何上界 `B_max = L_box²/A_f = 100/1.536 = 65` ⇒ **装得下**；但每块 6 根 ⇒ 需要 34 个独立形核位点，`--laths` 要 220 个场（已是）；`vmap` 手写分组要从 10 组改成 34 组 |
| **P2 放宽块厚带** | 保持 `α = 0.0417`、`B = 9` | 块厚 11.7 µm > 盒子 10 µm ⇒ **单块绕盒/装不下**；须写明"块厚不是文献值" |
| **P3 承认两者不可兼得** | 明确记录取舍并只报一个 | 用户目标（"两百多"）或文献一致性**必舍其一** |

⚠ **P1 与 ④(b)（natural 模式让块数涌现）天然契合**：若块数由驱动力涌现而不是输入，
`B` 就不再是旋钮，而 `α` 可以取文献带内的值 —— **两条问题一次解决**。
但 P1 需要先解决 ②-6 的停机（否则块建多了一定会再撞上同一条位点表死锁）。

## 4. `MOB` 的文献链（本次核实到两个独立值）

| 源 | 值 | 量纲 | 换算 `m³/(J·s)`（÷Ω_V = 1.064e-5 m³/mol） | 与引擎 `1e-9` 之比 |
|---|---|---|---|---|
| **Salama et al. 2024**, *Comput. Mater. Sci.* **241** 113033, DOI `10.1016/j.commatsci.2024.113033` | `1×10⁻¹³` | **`m⁴/(J·s)`** | `9.4×10⁻⁹` | 引擎大 **~106×** |
| **Boccardo et al. 2024**, arXiv:2404.09806（LPBF Ti-6Al-4V 马氏体分解体相场） | `L = 0.00125·exp{−9500/T}` | **`m³/(J·s)`** | 800 K → `8.8e-7`；1200 K → `4.6e-4` | 引擎小 **~880×**（800 K） |
| 引擎生效 | `MOB = 1e-9` | `m³/(J·s)` | `1e-9` | — |

**同文 `arxiv_2404` 还给**：`σ = 0.1 J/m²`（界面能）、`δ = 10Δx`（弥散界面宽）、
`L_interface` 用上式。**Salama 同文给**：`γ = 0.24 J/m²`、`δ = 4.5Δx`、`Δx = 0.1 µm`、`Δt = 1e-3 s`。

⇒ **两个独立文献值彼此差约 2 个数量级，引擎夹在中间。**
⇒ 之前那句「引擎比真实小 10⁴ 倍」（`_bk_exp.py:2049` 的注释）**与文献不符，已撤回**（见 `R619` §11）。
⇒ 真结论：**该值没有任何本体系锚点**，且**两个文献值本身就矛盾** ⇒
   按「文献 → 推导 → 标定」的次序，下一步应是**用 C-3 有序性约束反解 MOB 的允许带**
   （框架已有 `v_min_ordered`/`q_max_ordered`），而不是二选一硬取。
