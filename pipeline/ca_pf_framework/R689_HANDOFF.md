## §1 ⇒ 一句话结论（**本 goal 最终收敛判断**）

> **`B2` 是唯一值得做的下一步；阶段 C 可以不做。**
>
> **理由（6 条独立证据）**：
> 1. `mob_dip` 在 `c≈4` **饱和**（`R677` + `R687` 的两个新臂独立确认）；
> 2. **`f_flat` 完全由 `facet_proj` 决定**（`R687`/`R688` 独立确认）；
> 3. **现成开关已达 8.03**（文献带下端 9.0 的 **89%**），`G4`/`C4`/`F8` 均为**零代码改动**；
> 4. 阶段 C 的收益**大部分被 `G4` 提前实现**（7.17 + `f_flat` 0.113 达标）；
> 5. 阶段 C **必须配 `D1`**（`soft` 与多面体的平面冲突，`R683 §4.2`）；
> 6. **`B2` 更便宜**，且是 `C` 的**必要配套**（`R674`/`R683`）。

**⇒ 且 `F8` 是**最稳的生产候选**（`dip=8` + `facet_proj`，`mob_wulff=0`）：
形状比 **7.91**、`f_flat` **0.101**（达标）、**全程零撞盒**。**

## §4 启动一个 A8 臂（**完整命令**）

`_t11_facet_arm.py` 的**位置参数顺序**（`argv[1..14]`）：
```
tag  wulff  band  beta_h  dip  iform  rmode  beta_w  nuc_nm  fproj  steps  N  nuc_mode  eng_cadence
```
**例**（`F8` = `dip=8` + `facet_proj`，6 µm 盒）：
```bash
$PY -u _t11_facet_arm.py F8 1 40 6.477 8.0 exp2 none 2.3 125.0 1 400 96 auto 30
```
**⚠ 三个已知陷阱**：
1. **`--mob-dip` 只在 `mob_wulff=1` 时被消费**（`R663`）⇒ **`wulff=0` 时传 `dip` 无效**；
   （⚠ 但 `F8` 是 `wulff=0` **且** `dip=8` ⇒ **它的 `dip` 也未生效**！
   **⇒ `F8` 实际等价于"`facet_proj` + 大 `band`"** ⇒ **见 §6 未解问题**）
2. **`--nuc-mode driver` 会连带关掉生长**（`R662`）；
3. **`--eng-cadence -1` 也会**（`R662`）⇒ **单板条隔离做不到**。

## §6 ★ 本 goal 的**未解问题**（诚实登记，**含一个刚发现的严重问题**）

### ★★ 刚发现：**`F8` 的 `dip` 很可能根本没生效**
`F8` 用 `wulff=0` + `dip=8` ⇒ **按 `R663`，`dip` 只在 `mob_wulff=1` 时被消费**
⇒ **`F8` 实际是"`facet_proj` + `band=40` + 6 µm 盒"，`dip` 被忽略。**

**⇒ ⇒ 这**动摇了 `F8` 作为"最佳候选"的结论**：
`F8`（7.91）≈ `C4`（8.03）的相似性，**可能不是"`mob_wulff` 不必要"**，
而是**"`F8` 的 `dip` 没生效"**！

**⚠ 我必须记账**：**`R688 §3①` 的结论（"`mob_wulff` 在 `facet_proj` 在场时几乎不必要"）
建立在"`F8` 的 `dip=8` 生效"的假设上** —— 而该假设**与 `R663` 矛盾**。
**⇒ 该结论**撤回**，标为【待重测】。**

**⇒ 修法**：重跑 `F8` 时应传 `wulff=1`（像 `C4`/`F6` 那样），或**先查 `meta.json` 确认**。
