## §4' ★★★ **实测：完整 φ 的检查点成本（**好消息**）**

### 4'.1 实验（`_r581_ckpt_measure.sh`）
**跑了一条**短臂**：`N=64`、`nv=240`、30 步、**`--phi-every 1`**（每步存**完整** φ）
（其它开关按生产档：`--pf-phi onfly --qs-clock 1 --nuc-overlap-nm 62.5` 等）**
```
snap_00000.npz   2.05 MB      ← 只有 1 个场（种子）
snap_00010.npz   5.87 MB      ← 已有多个场
snap_00020.npz   5.88 MB
snap_00030.npz   5.89 MB
目录总计         24 MB
```
**⇒ ⇒ **★★★★★ ∴ 完整 φ 在 N=64/nv=240 上只要 **≈4.9 MB/帧**（5.9 MB 减去 `region`+带+元信息约 1 MB）** ✓
**★ 与 `_sparse_band` 注释里的「164.7 MB @N=192/7 场（f32）」**不矛盾**：
那个是 **f32 + 未压缩** 的原始字节（7×7.08M×4 = 198 MB）；**这里压到 4.9 MB ⇒ 压缩比 ~40×**
（**因为大量**未活跃**的场是常数 `1e3` ⇒ 压成几乎 0**）** ✓✓✓

### 4'.2 ⇒ **外推到 N=160（生产规模）—— ★ 我先前给的 80–200 MB 是**乐观端****

**★ 先算"每个活跃场要多少"（这是关键）**：
`seed_plate` 逐字（`:2850-2855`）：**`φ_k = min(φ_k, sdf)`**，而 `sdf` 是**到该板的距离**（**全域有定义**），
且 `np.full(…, 1e3)` 的 `1e3` **远大于盒内任何距离**（盒对角线才 ~1.7e-5 m ≪ 1e3）
**⇒ **★★ ∴ `φ_k = sdf` **在全盒都有不同取值** ⇒ **每个活跃场的 φ 是**稠密**的 N³ 数组**（不是"只在附近"）** ⚠

| 项 | N=64（**实测**） | **N=160（推算）** |
|---|---|---|
| 活跃场数 | **~18**（`--phi-every 1` 那条短臂） | **18 → 240**（**取决于形核推进**） |
| 每活跃场原始字节 | 262144 × 8 = **2.10 MB** | 4.096 M × 8 = **32.8 MB** |
| **实测压缩比** | **4.9 MB / (18×2.10 MB) = **≈7.7×** | 同量级（φ 是光滑距离场）【推理】 |
| **★ 每活跃场落盘** | **0.27 MB** | **★ ≈4.3 MB** |
| **★ 每帧合计（f64）** | **4.9 MB** | **★ 48 场 ⇒ ~205 MB；240 场 ⇒ ~1.0 GB** |

**⇒ ⇒ **★★★★★ ∴ **诚实的区间是 **200 MB – 1 GB / 帧（N=160、f64）****，
**我先前写的 "80–200 MB" 是**乐观端**（假设活跃场数只涨到 48）** ⚠
**★ 而"活跃场数"这一项**必须实测**（它是**唯一**的不确定量）⇒ 见 §4'.5。**

## §2 ★ 为什么**不需要**存整场 φ（论证 —— 这是本方案能成立的关键）

### 2.1 `region()` 的语义（`windowB_surface.py:1513-1537` 逐字）
```python
def region(self):
    _p = getattr(self, 'par', None)
    if _p is not None:
        return _p.argmin(self.phi).astype(np.int16)
    return np.argmin(self.phi, axis=0).astype(np.int16)
```
**⇒ 纯 `argmin(φ, axis=0)`，**无掩模、无阈值** ⇒ 全盒划分。**

### 2.2 ★ 但母相是**派生**的（`:2888-2890` 逐字）
```python
"""★ 多区域 VDF 的标准初始化：母相 = 变体并集的补集 ⇒ φ_0 = −min_{k≥1} φ_k。
   （本轮修的 bug：把 φ_0 初始化成常数 1e3 ⇒ argmin 永远选变体 ⇒ 母相初始体积 0 ✗）"""
self.phi[0] = -np.min(self.phi[1:], axis=0)
```
**⇒ 于是：**
| 胞的位置 | 判据 | 胜者 |
|---|---|---|
| **在某场内** | 该场 `φ_k < 0` ⇒ `min_{k≥1} φ_k < 0` ⇒ `φ_0 > 0` | **该场** ✓ |
| **在母相里（远离所有场）** | 所有 `φ_k > 0` ⇒ `φ_0 < 0` | **母相** ✓ |
| **两场交界** | 两个负值取更负者 | **更"深"的那个** |

**⇒ ★★★ ∴ `region` 只取决于两件事：**
1. **各 `φ_k` 的**符号**（谁在里面）**
2. **负值之间的 **argmin 次序**（谁更深）**

**⇒ **★ 而这两件事**都在界面带内决定**** —— 因为**符号翻转**只发生在 `|φ| ≈ 0`，
**"谁更深"的次序翻转也只发生在两场 φ 接近处** ⇒ **都在带内**** ✓

### 2.3 逐场演化**是否读带外 φ**
| 算子 | 是否读带外 | 依据 |
|---|---|---|
| **`region()`** | 只读**符号 + 负值 argmin** | §2.2 ⇒ 带内够 |
| **平流 `phi[k] -= dt·upwind_flux_vec(phi[k], Vvec, …)`** | **★ 会读到带外 **2 胞**（二阶 stencil）** | **`:5003`**；而 `Vvec` 由 `karr/larr` 构造（`:4995`）⇒ 只在界面附近非零 |
| **`reinit`** | **★ 不读** | **`:5267-5271`**：`near = \|φ\| ≤ band_cells·dx`；`phi[k] = np.where(near, newp, phi[k])` ⇒ **带外原样保留** |
| **`np.gradient(phi[k])`**（`sgn`/`gmag`） | 会读 ±1 胞 | `:5007` |
| **`facet_project`** | 局部 | `:3499` |
| **`curvature`/法向** | 界面附近 | `:610-618` |

**⇒ ⇒ **★★★★★ 结论（【推理】，**必须由门 1 实测确认**）**：
**逐场更新**只需要 `|φ| ≲ band_cells·Δx` 的区域**（`band_cells=6` vs stencil 的 2 胞 ⇒ **3× 余量**）
⇒ **远场 φ 的**具体数值**对下一步**没有影响**** ⇒ **稀疏带足够**。

### 2.4 ★ 但要**诚实标注**两处风险
1. **`band_cells=6` 的余量是【推理】，不是实测** ⇒ **门 1 必须给出判定**；
2. **若某个算子（例如未来的刻面/接触项）读了更远**，稀疏带就会漏 ⇒ **门 1 的负对照必须能**故意**把带改窄（如 2 胞）并**确认**它**会**失配** ⇒ **证明判据有分辨力**（P12）。
