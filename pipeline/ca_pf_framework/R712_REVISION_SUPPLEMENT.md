## 2. 【补 §5.1-A】几何类必须显式声明；面级运动学 = `ḣ_f = v_f`

### 2.1 为什么必须补

R712 §5.1 同时要求「半空间交集 `Ω_i = {x | n_if·x ≤ h_if}`」（⇒ **是凸体**）
与「板条允许共享面、相交、截断和形成奇异边/角」（⇒ **需要非凸/多体**）。
两者在数学上不相容，而原文没有选边，也没有给运动学 —— 实施者无法写出第一行代码。

### 2.2 补齐文本（建议直接插入 §5.1 末）

```
【补 §5.1-A】几何类与运动学（先写死，不得事后挪动）

A. 几何类声明（三选一，必须显式）
   (i)  每个板条 = **一个凸多面体**（H-表示：面法向 + 面距）；
        ⇒ 依据 [验] V-A1：半空间交集恒为凸；这是 H-表示的**适用边界**。
        ⇒ 代价：板条不能有凹面；真实马氏体板条的透镜状/被邻片咬出的凹口**表示不了**。
   (ii) 每个板条 = **一个 V-表示多面体**（顶点 + 半边/面邻接），允许非凸；
        ⇒ 代价：运动学要解顶点速度，不能只写面距方程（见 B 段）。
   (iii) **逐板条一个凸多面体 + 板条之间不断开**（本方案的推荐默认）：
        凹陷由"相邻板条 + 它们之间的母相/晶界区域"共同表达，而不是由单个多面体的凹面表达。
        ⇒ 这与本项目"界面 = 零厚度 Gibbs 面"的表示层选择一致（RESEARCH_INTENT §2.2）。

B. 运动学（**面法向不旋转时是精确等式，不是近似**）
   若界面由面族 {n_f, h_f} 描述且 **ṅ_f = 0**，则
        v_n(f) = ḣ_f                                       … (K1)
   推导：面是隐式方程 n_f·x = h_f 的水平集，沿法向走 δ 使左端增加 δ
        ⇒ 法向位移 = Δh_f ⇒ 两边除以 dt 即 (K1)。
   依据 [验] V-A3：三档 δ（1e-3/1e-2/1e-1）残差 ≤ 1.1e-16。
   ⇒ **面级推进就是推进 h_f**；顶点是**导出量**，不需要单独积分。

C. 体积-面积账（用于守恒自检与"是否吞掉板条"的判据）
        V̇ = Σ_f A_f v_f                                     … (K2)
        dV = Σ_f A_f v_f dt + O(dt²)
   依据 [验] V-A2（本机实测）：
        · 恒等式 Σ_f A_f n_f = 0：单位立方体相对残差 **0.000e+00**、
          随机 60 点凸包 **3.98e-17**（散度定理的必然结果）；
        · 中心差分速率 (V(+δ)−V(−δ))/2δ：δ=1e-3 时立方体给 **6.000008** vs ΣA_f=**6.000000**
          （相对差 **1.33e-06**）、随机凸包给 **56.106246** vs **56.106240**（**9.69e-08**）；
        · 立方体有**解析**展开 ΔV = 6δ + 12δ² + 8δ³（逐位核对 ≤1e-15）
          ⇒ **一阶系数恰是 ΣA_f**；大 δ 下的偏差是 δ² 项，**不是公式错**。

D. 何时允许"取凸包"（**这是本方案最容易静默出错的一步**）
   · H-表示下，面平移不保证交仍是非空/非退化 ⇒ 需要**面激活/失活**规则：
     若某半空间变的冗余（可由其余半空间推出）⇒ 该面**消失**并从面表移除。
   · **禁止对整个体系取凸包**。依据 [验] V-A5：哑铃形（两个单位立方体 + 细颈）
     `conv(·)` 体积 = **4.0000**，并集体积 ≈ **2.0200** ⇒ 凸包**多填 49.5% 的母相**。
     ⇒ 取凸包会把"两根板条 + 中间母相"变成"一根粗板条"，且**吞掉后来形核的小板条**。
   · 允许取凸包的唯一场合：**单个板条自身**在 H-表示下做"面冗余清扫"。
```

## 3. 【补 §5.3-A】「共享面」的正确形式：两个**不相交**的凸体**不能**共享非退化的面

### 3.1 为什么必须补

R712 §5.1 写「板条允许**共享面**、相交、截断」，§5.3 写「板条交叠体积、**共享面面积**」，
§5.4 的验收标准写「两个不同取向多面体能够**共享面**、形成交线并保持各自身份」。
**这三处都需要澄清一个数学事实**，否则实施者会去写一个不可能的实现。

### 3.2 补齐文本（建议插入 §5.3 末）

```
【补 §5.3-A】"共享面"的可实现形式（先写死）

事实：两个**凸体**若共享一个**二维测度非零**的面，则它们在内部相交
      （共享面同时属于两者的边界，而边界点可由体内部的极限点逼近）
      ⇒ "两个不相交的凸板条共享一张面"**在几何上不成立**。
依据 [验] V-A2 的恒等式 Σ A_f n_f = 0 的一个直接推论：
      若面 F 同时是 Ω₁ 与 Ω₂ 的边界且 A_F > 0，则 A_F 在两次求和中各出现一次
      ⇒ Ω₁ ∪ Ω₂ 的边界在该处的**外法向不唯一** ⇒ 该处必是并集的内点或非流形集。
      [引] 这是凸集分离定理的标准推论（Rockafellar, Convex Analysis, §11），我未另做证明。

⇒ 因此本节把"共享面"实现为**三种可实现的替代表达**，并规定各自的判据：

  (a) **相向接触（零厚度共同界面）**：两板条**相邻但不相交**，
      中间由一条**零厚度的 Gibbs 面**连接（本项目的表示层本来就允许它）。
      这是与 RESEARCH_INTENT §2.2 一致的那一支，**推荐默认**。
      判据：存在一张面 F 与一个零厚度面集合 S，使 F₁ 与 F₂ 在 S 上共面；
            共面判据 = |n₁·n₂| > 1−ε 且 |h₁−h₂| < ε_h（ε 由 Δx 定）。

  (b) **相消接触（合并为同一面）**：两板条的接触面**在物理上是同一张面**
      （同一变体、错配角 < θ_th），此时它们**共用一条面记录**，
      由 `Block` 持有（见 §8.1 的补齐 B4）。
      判据（同取向成块）：|Δθ| ≤ θ_th 且合并后界面能下降。

  (c) **相交/截断（真重叠）**：仅在**同一板条的历史**中出现
      （例如两面推进到相撞），用 H-表示的面激活/失活规则处理（见 §5.1-A D 段）。
      **不同板条之间禁止真重叠**：一旦检测到重叠 ⇒ 按 §5.3 的"并合/截断"规则处理，
      并**记入拓扑事件日志**（否则体积账会静默错）。

  ⇒ 与 §5.4 验收标准的对应修正（原文"共享面"改读为 (a)/(b)）：
     · "两个不同取向多面体能够共享面" ⇒ **(a) 零厚度共同界面**（不相交、共面）；
     · "并保持各自身份" ⇒ 两体的 `id/variant` 不变，界面记录归 `Block`。
```

| 断言 | 依据 |
|---|---|
| 凸体共享非退化面 ⇒ 内部相交 | `[代]` 凸集分离定理的推论；`[验]` V-A2 的 `Σ A_f n_f = 0` 恒等式给出同一结论的离散形式 |

## 4. 【补 §7.1-A】棱/顶点为什么不能用曲率项；替代式是 Herring 平衡

### 4.1 为什么必须补

R712 §7.1 只说「对于棱边/顶点，使用明确的非光滑几何规则，而不是把面硬化成平滑曲率」，
**没有给原因、也没有给替代式**。实施者会以为"加个规则就行"，
而实际现状是：**现有引擎在棱上有一个不收敛的惩罚项**（见下），照抄它做面级运动学会把病带过去。

### 4.2 补齐文本（建议插入 §7.1 末）

```
【补 §7.1-A】平面/棱/顶点的三段式规则

(1) 平面（facet 内部）：κ_f ≡ 0 ⇒ v_f = M_f [ΔG_chem + ΔG_el]。
    ⇒ **Gibbs–Thomson 的曲率项在平面上恒为零**，这正是要换成多面体表示的理由。
    依据 [验] V-A2/V-A4：本机实测"平面上离散曲率**中位 ≡ 0.000**"
        （`_auditR708_facetproj.py`，解析长方体，N=48/96/128 三档）。

(2) 棱与顶点：**`−γκ` 这一项在那里无定义**，必须换规则。
    [码] 现状（这是本条的动机，不是假想）：
        · 速度律 `windowB_surface.py:4873-4875`：`dG_cell = Δdf + η·Δed − stk·κ`；
        · `κ` 由 `div(∇d/|∇d|)` 逐胞算出（`:3792-3795`）；
        · 实测 `max|κ|·Δx ≡ 1.789` 在 Δx = 125 / 93.8 / 62.5 / 46.9 nm
          **四档上逐位不变** ⇒ `κ ~ 1/Δx` **不收敛**
          （`_auditR708_facetproj.py`，本机实测）。
    ⇒ 若照抄，棱上的罚强**由网格决定**，换网格就换物理。
    替代式（2D 棱 / 3D 棱与顶点统一形式）：
        Σ_f ( γ_f · t_f + ∂γ/∂t_f ) = 0                        … (K3)
      其中 t_f = 该棱上、切于面 f 且指向外的单位矢量。
    依据 [验] V-A6（本机实测）：
        · 各向同性 γ、三面互成 120° ⇒ |Σ t_f| = **4.97e-16**（PASS，即等角 120°）；
        · 非等角 0°/80°/200° ⇒ |Σ t_f| = **0.6840** ≠ 0
          ⇒ **必须靠 γ 项才可能平衡**，所以 (K3) 不能省 ∂γ/∂t_f。
    [引] (K3) 是界面热力学的 **Herring 关系**（Herring 1951, *The Physics of Metal Interfaces*；
       亦见 Sutton & Balluffi, *Interfaces in Crystalline Materials*, §5）。
        ⚠ **我未读原文核对该式的符号约定与 ∂γ/∂t 的定义域**（它是"切向梯度"在棱上的取值，
        对分片光滑 γ 需要在面内取极限）。**这一条标 [引]，采纳前请让专家确认。**

(3) 界面能 γ(n) 的形式约束：必须是**分片光滑**的（允许在面族交界处有尖点），
    且必须使 `γ + γ_θθ`（Herring 刚度）**不出现光滑曲率型的发散**。
    [引] 满足这一条的规范构造是 **Cahn–Hoffman ξ-vector**：γ(n) = min_{ξ: ξ·n=1}(ξ·(ξ)) 的对偶，
        ξ = ∇(γ)，多面体由支撑函数 h(n) = max_f (ξ_f·n) 给出
        （Cahn & Hoffman 1974, *Acta Metall.* 22, 1205）。
        ⚠ **我只用了它的两条可验证推论**（凸性、以及"面法向集 ⇔ ξ 集"的对应），
        **未独立验证其一般形式**；标 [引]。
    [决] 若不自建 ξ-vector 形式，则必须指定一个**分片光滑**的 γ(n)（例如按面族给出常数 γ_f
         + 面族交界处的显式尖点），并接受"只在所给面族上成立"这一限制。**请拍板走哪条。**
```
