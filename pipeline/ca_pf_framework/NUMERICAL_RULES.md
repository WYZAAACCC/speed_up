# 数值规则（必须落到算例上的那几条）—— 2026-09-25 实测口径

> 每一条都写明**判据**与**实测代价**。凡未在算例里落实的，就是**未收口**。
> 出处：`pf1d_moose/README.md` §9（T1.1/T1.2）、`_chk_profile3.py`、`_t41_profile.py`。

## R1（时间步） `dt ≲ 0.05 · l_D²/D_L`，并且**必须做 dt 减半复核**

- 依据：溶质边界层的弛豫时间 `τ = l_D²/D_L`。生产 `l_D = D_L/V = 1.2e-6/0.6 = 2 µm`，
  `τ = 3.33e-6 s`。
- **实测**（同一算例只改 dt）：`dt = 4.17e-8`（= 0.013·τ）⇒ `c_int` 偏差 **−14.0%**；
  `dt ≈ 1e-6`（自适应 dt 的结果，≈0.3·τ）⇒ 偏差 **−49.1%**。
- ⚠ **`IterationAdaptiveDT` 不能用**：它按"牛顿迭代数≈8"放 dt，与时间精度无关，
  实测把 `c_int` 挪了 35 个百分点。要用就配 `max_increase` / `time_integration` 限制，
  否则退回固定 dt。
- 判据：`dt` 与 `dt/4` 给出的目标量之差 < 判据容差。

## R2（网格）`l_D/dx ≥ 4–8`（生产 V=0.6 ⇒ `dx ≤ 0.25–0.5 µm`）

- 依据：`l_D/dx` 就是"边界层里有几个胞"。生产 `dx = 1 µm ⇒ l_D/dx = 2`。
- **实测（dx=1 µm，同一 dx 上的两种取法）**："界面成分"取**交界前一个节点** = 0.049101（−14.0%）；
  在 `gr0=0.5` 处**插值** = 0.059686（+4.5%）。差 = 1 个胞 = 0.5·l_D ≈ **目标值的 22%**
  ⇒ **这个 dx 上"界面成分"本身没有定义**，因此**不能在这里标定 `ALPHA`**。
- **dx 收敛实测**（固定 dt、固定行程 90 µm、生产 `F_at`、`ALPHA=2`）：
  `dx` = 2.0 / 1.0 / 0.5 / 0.25 µm ⇒ `c_int` 偏差 = −25.1% / −14.0% / **−3.5%** / **+2.0%**
  ⇒ 单调收敛并穿过目标值 ⇒ **`dx ≤ 0.5 µm` 就够标定（`ALPHA*` 从 2.58 掉到 2.14）**。
- ⚠ 但 `c_min` 随 `dx` 加密**持续下降**（0.0133 → 0.0030 → **−0.0067**）⇒ 界面附近的伪振荡
  **不随 `dx` 收敛** ⇒ 加密只解决了积分量，**没解决界面本身**（见 `README.md` §9.4/§9.6）。

## R3（求解器容差）`nl_abs_tol ≈ 1e-3·|R₀|`，并**逐条检查"0 次牛顿迭代"**

- 依据：`nl_abs_tol` 若大于残差本身的量级，MOOSE 会打印 `0 Nonlinear |R| = ...` 紧接
  `Solve Converged!` ⇒ **零次迭代的"假收敛"**（本项目踩过：3D 曾全部是假收敛）。
- 检查法：`grep -c 'Solve Converged' run.log` 与 `grep 'Nonlinear |R|' run.log` 联合看；
  某一步的迭代数必须 ≥1 且有实质下降。
- 反例（**好**的）：本仪器 ALPHA=4 末几步 `|R| = 5.26e-3 → 3.12e-3 → 1.48e-3 → 1.8e-17`，
  2–5 次迭代 ⇒ 真收敛 ✓。

## R4（抗截留系数）**只有 `ALPHA·W_F` 是物理量**；且尺度随区制变

- **实测**：`ALPHA=2, W_F=4 µm` 与 `ALPHA=4, W_F=2 µm` 的 `c_int` 与 `c` 范围**逐位相同**
  ⇒ `F_at = ALPHA·W_F·(1−k)·c·(1−h_gb)` 里两个参数不可分辨。
- 生产现值 `2 × 2 µm = 4 µm` = `int_width` ⇒ 已等价于"**系数 1 × η 界面宽**"的标准归一化。
- **但所需尺度不是普适的**：薄仪器（`W/l_D = 0.105`）上正确尺度 ~ `w_c ≈ l_D ≈ 100 nm`；
  生产（`W/l_D = 2`）上 `W_F = w_c = 0.105 µm` **更差**（−36.8%）。
  ⇒ 只能"按区制标定"，**不许写成普适常数**。
- 另：判据只对 `c_int` 是不健全的（`c_int` 对上时液相侧有 +143% 尖峰）。
- ★★ **实测判决（2026-09-25）**：`dx` 从 1.0 → 0.5 µm 让 `c_int` 偏差从 −14.0% 掉到 −3.5%，
  同时 `ALPHA*` 从 2.58 掉到 2.14 ⇒ **生产现值 `ALPHA=2` 只差约 7%，不需要改**；
  「生产 `ALPHA` 欠修正」是 `dx=1 µm` 太粗的伪影（已撤回）。
  ⇒ **修法 = 加密网格，不是改 `F_at`。**

## R5（工程纪律）**输出目录不得复用**；每次跑完必须核对"实际用到的 dt/网格"

- **实测事故**：同一目录先跑 nx=150、后跑 nx=300，`profile_line_<步号>.csv` 混在一起，
  `max(步号)` 读到**旧行程**的剖面 ⇒ 一度得出"行程已收敛、逐位相同"的**假结论**。
- 纪律：(i) 每次跑前清 `profile_line_*` / `*_out.csv`；(ii) 输出目录带唯一后缀；
  (iii) 从日志回读 `dt`、`nx`、`dx` 与判据目标值（`p1c_prod1d.py` 现在会打印
  `dt = ...  dt/(l_D²/D_L) = ...`）。
- 读 CSV 一律用 `pipeline/validated/robust_csv.py`（`/mnt/f` 的 9p 会**静默返回过期数据**）。
