## §1 ① 双向转换算法

### 1.1 **多面体 → 网格场**（**现实现已在做，逐字核实**）
`_r68_facet_op.py:81-92`：
```python
_U  = np.stack([u/|u| for u in ax], 0)          # 三轴（n*, a, w）单位化
_pr = P @ _U.T                                   # 胞心在三轴坐标下的投影 (…,3)
phi_proj = np.max(np.maximum(lo - _pr, _pr - hi), -1)   # ★ 多面体的 SDF
```
**⇒ 该公式对**任意法向集**都成立**（把 `ax` 从 3 轴换成 `K` 个面法向 `F`）：
```
phi(x) = max_{j=1..K} ( |(x − c)·F_j| − h_j )        # 若面成对（±F_j）
```
**⚠ 注意**：现实现用的是 `max(lo_j − x·u_j, x·u_j − hi_j)` ⇒
**它是"成对"写法**（`lo_j`/`hi_j` 对应 `−u_j`/`+u_j`）
⇒ **对一般多面体**（面不成对）应写成：
```
phi(x) = max_{j=1..K} ( x·F_j − h_j )                # ★ 一般形式（K 个面各自独立）
```
**⇒ ⇒ 从 `K=6`（盒子）到 `K` 任意（Wulff 多面体）的推广是**一行代码的差别**。**

### 1.2 **网格场 → 多面体**（**现实现的"提取"步骤**）
`_r68_facet_op.py:33-72` 的做法（**逐条**）：
| 步 | 做法 | 行号 |
|---|---|---|
| 1 | 取**体内胞**（`φ < 0`）的点云 | `:33` |
| 2 | 三轴投影 `_pr = P @ _U.T` | `:64-66` |
| 3 | `lo_j = quantile(_pr_j, 0.005)`、`hi_j = quantile(_pr_j, 0.995)` | `:64-65` |
| 4 | 外扩 `0.5·dx` | `:71-72` |

**⇒ ⚠ 两处与设计文档的出入**（`R654` 已定量：`a/w` 差 **+8.4…16.1%**（`B40`）/ **−49%**（`L0`））：
| # | 设计（`BLOCK_SELFAC §8.C`） | 实现 |
|---|---|---|
| **①** | 点云 = **界面点** `\|φ\|≤0.5Δx` | 点云 = **体内胞** `φ<0` |
| **②** | `h_j = max` | `h_j = quantile(0.995)`（`R70` 抗棘轮改的） |

**⇒ ⇒ C3 必须**明确选哪个**（不能两个都留）**：
**建议**：**保持实现（体内胞 + 分位数）**，理由：
* `R70` 的棘轮是**已实测**的问题（`d(a)` 被抬高一倍）；
* 且 `R654` 已量化差异 ⇒ **可选"两种都算、取更稳的那个"**（并记账）。

### 1.3 ⇒ **推广到 Wulff 面法向集**（C3 的核心增量）
```python
# 提取：从体内胞点云到 (F, h)
body = (phi < 0)
pts  = P[body]
# ★ 方案 A（保守，保持现实现）：按三轴投影取分位数 ⇒ 仍只得 6 面
# ★ 方案 B（C 的目标）：按 Wulff 面法向集 F（C1 §1）逐个取分位数
for j in range(K):
    proj = pts @ F[j]
    h_j  = quantile(proj, 0.995)          # 或 max
    c_j  = ...                            # 面的中心偏移（需统一定义）
```
**⚠ 方案 B 的**未解决问题**：`h_j` 是**有符号**的（相对原点）⇒
若原点不在多面体内，`max_j(x·F_j − h_j)` **不是 SDF**
⇒ **必须先把原点移到体的中心**（现实现用的是"绕中点缩放"，`:88`）。

**【推理】**：方案 B 可行，但**原点约定必须显式**（建议：用体的**质心**，
而不是"分位数的中点"——后者在多面体非对称时会偏）。

## §2 ② 体积/面积守恒：显式校验与修正

### 2.1 ★ 现实现的修正（**逐字核实** `_r68_facet_op.py:85-96`）
```python
vp = max(int((phi_proj < 0).sum()), 1)      # 投影后的胞数
s  = (tgt / float(vp)) ** (1.0/3.0)         # ★ 立方根标定
mid = 0.5*(lo + hi);  hw = 0.5*(hi - lo)
lo2, hi2 = mid - hw*s, mid + hw*s           # 绕中点缩放
phi_new = np.max(np.maximum(lo2 - _pr, _pr - hi2), -1)
v1  = int((phi_new < 0).sum())
rel = (v1 - tgt)/max(tgt, 1)                # ★ 显式残差
```
**⇒ ⇒ 修正机制 = 单一标量 `s` 的立方根缩放（体积守恒）**
**⇒ 残差 `rel` 已被显式算出并返回**（`dict` 里）⇒ **可用于判据。**

## §4 ④ 与 `soft=True` 的关系 —— **是否仍需涂抹？**

### 4.1 `soft` 是什么（**逐字核实**）
`windowB_surface.py:1249-1251`：
> ⚠ 严格说 `soft` 是"**把 `ε⁰` 抹宽 1.5 胞**"的**弥散界面**近似，而本模型是
> **零厚度 Gibbs 面** ⇒ 若将来要走严格锐界面，正确做法是换**锐界面弹性求解器**

**⇒ ⇒ 所以 `soft` 与"锐界面"是**同一件事的两端**：**
| | `ε⁰` 的处理 | 与多面体的关系 |
|---|---|---|
| **`soft=True`（现默认）** | 抹宽 **1.5 胞** | **多面体的平面被打磨掉** ⇒ 与 C 的表示**冲突** |
| **`soft=False`** | 硬 `region` 指示 | 产生 **Gibbs 振荡**（`:1243`）⇒ **`ΔL/ΔW` 反而更差**（2.18 vs 4.38） |
| **锐界面求解器（目标）** | **显式界面几何**（= 多面体） | **与 C 的表示天然一致** |

### 4.2 ⇒ **C3 的建议**
| 问题 | 答案 |
|---|---|
| 多面体表示下**是否仍需涂抹**？ | ⛔ **不应涂抹** —— 涂抹会把 C 刚建立起来的**平面**再磨圆 |
| 那不就会**Gibbs 振荡**吗？ | ✅ **是** ⇒ **所以 C 必须与 `D1`/`D4` 的锐界面求解器**一起做**，不能单独做** |
| 若不换求解器呢？ | ⚠ **那就必须保留 `soft=True`** ⇒ **C 的平面与 `soft` 的涂抹直接冲突** ⇒ **C 的收益会被抵消一部分** |

**⇒ ⇒ ★ 这是一个**结构性的耦合结论**：**
**`C3` 把 `C` 与 `D1/D4` **绑成一件工作**：
**要么"多面体 + 锐界面求解器"一起上，要么 C 单独做的收益有限。**
**⚠ 这是【推理】，依据是 `soft` 的定义（`:1249-1251`）与 `soft=False` 更差的实测 —— 但"冲突有多大"**未实测**。**
