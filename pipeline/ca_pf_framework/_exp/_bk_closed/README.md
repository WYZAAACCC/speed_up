## ⚠ 为什么 `cl1` 系列被废弃（**不要拿它们当结论**）

`_bk_closed.py` 第一版把闭式给的**物理板条厚** `t = 510 nm` 直接当**播种厚**。
但共享界面（`attach`）把重叠区 `o = 125 nm` 从**两片各吃 `o/2`**：

* 内部片（两张界面）共被吃 `o` ⇒ 播种必须是 `t_phys + o`
* 末片（一张界面）被吃 `o/2` ⇒ 走 `t_last_reduce = o/2`

不补的后果（`dry_cl1`，跑到 step 1000，由 `_bk_thick.py` 量**剔孤儿**厚度）：

   场 1（被咬两次）  391.8 nm   vs 510 ⇒ **−23.2%**   ← 510 − 2×62.5 = 385 ✓
   场 2（尚未被咬）  503.5 nm   −1.3%
   场 3（尚未被咬）  508.0 nm   −0.4%

⇒ 若跑满 2853 步，V-8b 与 A-8 都会 FAIL，而原因是**配置错、不是物理**。
修正版是 `cl1b` 系列（`--plate-T 635 --plate-t-physical 510`）。

**`dry_cl1` 的三个快照仍然有用**：它是这条修正的 **A/B 证据**（同一配置只差播种厚），
`_bk_closed_verdict.sh` 的 D 段会把它与补偿后的读数并排打印。

## 复现

```bash
PY=/root/miniconda3/envs/ml/bin/python
$PY _bk_closed.py --gamma 0.25 --tag cl1b --run      # 主配置
$PY _bk_closed.py --gamma 0.15 --tag cl1gb --run     # 隔离 γ
$PY _bk_closed.py --arm gpos --gamma 0.25 --tag clctrlb --run   # 配对正对照
$PY _bk_closed.py --alpha-km 0.005 --gamma 0.25 --tag cln2 --run  # α 敏感度
bash _bk_closed_verdict.sh cl1b clctrlb              # 完整证据包
```
