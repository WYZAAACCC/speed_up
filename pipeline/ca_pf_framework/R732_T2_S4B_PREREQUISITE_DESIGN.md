## §1 问题的准确表述（**三层，逐层收窄**）

### 1.1 `R725` 的实测（三轮，两轮是我的设计错）
`[验]` 第 3 轮（`--laths 1,1,…,6,6`（M=12、6 变体）＋ **`--nuc-init 6`**，λ ∈ {0,.5,1}）：
```
n_var_sig = 3      ← 确实有 3 个不同变体在场

f2_area   = 0.0
blk_laths = 1/1/1/1  ← 4 个块各只有 1 根板条
```
⇒ **变体存在，但它们彼此不相邻。**

### 1.2 根因（`[码]`，读 `_bk_exp.py:4412-4414`）
> `--var-rule` = 新核的**变体选择规则**：ed / random / doublet
> **`fresh`（独立形核）通道需要待机位点**（`_nuc_place_initial`）；
> **`>0` 才会走 `fresh`**，而**只有 `fresh` 才按 `--var-rule` 选变体**
> （**`stack` 是"同变体、新场"**）。

⇒ **`stack`/`attach` 两个通道在生产里是"同变体"的** ⇒ 只有 `fresh` 能造新变体。
⇒ 而 `fresh` 的**源场选择**（`R712 §7.2 :476`）是：
```
block 级竞争评分 | 现状 = **全局随机源**（`_bk_exp.py:2454  ks[rng.integers(...)]`）
                  | 修法 = §5.4 的 (S1) + BlockRef 的局部评分
```
⇒ **源场是"全局均匀随机抽一个"，不是"贴着已有块选"** ⇒ 新变体落在**远离**已有场的地方 ⇒ `nf2 = 0`。

### 1.3 ⇒ 这就是 `R712 §7.2` 那三件的**共同前置**
`§7.2` 的"缺三件"里，**第一件（block 间成对界面能 `γ_ij`）与第三件（block 级竞争评分）
是相互依赖的**：
* 要测 `γ_ij`（S4-B），**必须先有 F2 界面**；
* 要有 F2 界面，**必须先有"让异变体板条相邻"的机制** —— 那就是第三件的**局部评分**。

⇒ **`R712 §10.2` 把 S4-B 记为"小（机时）"是错的**；它依赖一件**主代码改动**。
⇒ 已回写 `R712 §0.7` 与 `§10.2`（见 `R725`）。

## §2 最小设计（**让异变体界面能出现**，只改源场选择）

### 2.1 为什么"最小"
**不动**任何物理：不改 `γ`、不改 `M(n)`、不改形核律、不改弹性。
**只改一件事**：`fresh` 通道**选哪个源场 / 落在哪里**。

### 2.2 现状（`[码]`）与目标
| | 现状 | 目标 |
|---|---|---|
| 源场 | **全局均匀随机**（`:2454 ks[rng.integers(...)]`） | **局部**：只看与候选位点**几何相邻**的场 |
| 变体 | 按 `--var-rule`（`ed`/`random`/`doublet`） | 不变（仍按 `--var-rule`），但**在"相邻场之外"的变体里选** |
| 落位 | 待机位点（t=0 随机撒） | **优先落在已有场的边缘**（`R712 §4.7` 的"edge-to-edge 顺序形核"） |

★ **物理依据（`[文]`，`R712 §4.7` 已引）**：Shi & Wang 2013（R-A）`:983` 逐字
> "The nucleation rate is determined by both **the abundance of available nucleation sites**
> and **their nucleation barrier**."

⇒ **位点丰度**（§4.4 的 `N(T)`）与**势垒**（`E_int`）**两者都要**。
而"edge-to-edge 顺序形核"正是文献里**异变体相邻**的形成机制。

### 2.3 记分式（`R712 §5.4` 的 (S1)，**已给，不重新设计**）
```
score(p;x) = w1·Ê_int(p;x) + w2·(γ̄_F2(p) 的降低量) + w3·r(p)      … (S1)
接受：同位置所有候选中 score 最小者；w 由 §8 标定（初值 (1,0,0)）
```
### 2.4 ⇒ 最小改动 = **把 `score` 接进 `fresh` 的源场/变体选择**
| 步 | 改动 | 判据 |
|---|---|---|
| **①** | 新增**开关**（默认关，环境变量，与 `SEED_CLEAN_EVERY`/`NDIR_LSQ` 同套） | 默认档 `_r30_regress.sh` 逐位一致 |
| **②** | `fresh` 的源场从"全局随机"改为"**按 (S1) 在局部候选里取最小**" | `nf2 > 0` 且**只在开关开时** |
| **③** | 权重初值 `(w1,w2,w3) = (1,0,0)`（= **只用 `E_int`**，`R712 §11.1` 的 D-4） | 不引入新自由参数 |
| **④** | **前置判据**：`nf2 ≥ 1`（`R725` 的 F11-0） | 这是 S4-B 能开测的**唯一条件** |

### 2.5 ⚠ 三个必须先说清的风险
| # | 风险 | 说明 |
|---|---|---|
| **1** | **`E_int` 用的量必须是"本变体 vs 母相"还是"本变体 vs 邻块"？** | `R712 §4.7` 说 `E_int = −σ:ε⁰` **与引擎的 `ed = +ε⁰:σ` 代数等价**，且 `ed` 在速度律里取**差值** ⇒ **"把 `σ:ε0` 接到形核"不是新增机制**。⇒ **用 `ed` 即可，无需新量** |
| **2** | **会不会把 `nf2` 造出来但让物理更假？** | (S1) 的 `w2/w3` 项**没有物理取值依据** ⇒ `R712 §11.1` 只冻结了**初值 `(1,0,0)`**。⇒ **先只用 `w1`**，`w2/w3` 留 `[待标定]` |
