### 2.3 ★ 硬错误 E1：弹性驱动力符号反了

**代码位置**：`windowB_surface.py:1193-1195`
```python

    out[v + 1] = (-np.einsum('p,p...->...', self.e0v_eng[v], sig)   # = -eps0_v : sigma
```

它被当作**驱动力**加进 `dG_cell`（`advance` 里 `+ (edk - edl)`），与 `df` 同一量纲、同一符号约定

### 2.4 ★ 硬错误 E2：β 的标定公式错（漏了 Wulff 凸化）—— 这才是"长不出来"的主因

`LATH_FACET_PLAN §9.3/§10.2` 用
```
长/厚 = e^{β_h},  长/宽 = e^{β_w},  宽/厚 = e^{β_h − β_w}
```
反推并"互校"，取 β_h = 3.5、β_w = 2.3，声称"两条独立路径给 3.0 与 3.8，自洽"。

**这条公式是错的。** level-set 的 `∂φ/∂t + v(n)|∇φ| = 0` 是 Hamilton–Jacobi 方程，
其黏性解是 **Huygens 包络**，渐近形状是 `v(n)` 极图的 **Wulff 形（凸包）**，不是极图本身。
对 `v(n)=C·exp[−β_h(n·n_hab)²−β_w(n·w)²]`：

* 极图在 `n_hab` 附近**非凸**（2D 凸性判据 `r²+2r'²−rr'' = r²[1+β²sin²2θ−2βcos2θ]`，
  在 θ=0 处 = `r²(1−2β)`，**β>0.5 即为负**）；
* Wulff 凸化把它换成**平面刻面**，支持函数由"肩部"决定：
  `h(n_hab) = max_u e^{−β_h u²}·u = e^{−1/2}/√(2β_h)`（在 `u=1/√(2β_h)` 处取到）；
  `h(ŵ)` 同理（最优方向朝**便宜方向 a** 倾斜）。

**闭式**：`h(a)=1`, `h(ŵ)=e^{−1/2}/√(2β_w)`, `h(n_hab)=e^{−1/2}/√(2β_h)`

```
长/厚 = √(2β_h)·e^{1/2} = 2.3316·√β_h          （而不是 e^{β_h}）
```

**3D 凸包数值验证**（`_audit_wulff.py`，40 万方向 + `scipy.spatial.ConvexHull`）【实测】：

| β_h, β_w | Wulff 凸包半宽 [a,w,n] | 长/厚 | 长/宽 | 宽/厚 | 朴素 e^{β_h} |
|---|---|---|---|---|---|
| **3.5, 2.3（现生产）** | 0.9999, 0.2828, **0.2292** | **4.36** | **3.54** | 1.23 | 33.1 |
| 3.5, 0.0 | 1.000, 1.000, 0.2292 | 4.36 | 1.00 | — | 33.1 |

| 115, 18 | 0.9996, 0.1010, 0.0400 | **25.00** | 9.89 | 2.53 | 8.8e49 |

闭式与 3D 凸包**逐位吻合**（≤1e−3）。

### 2.6 ★ 硬错误 E3：`reinitialize(mode='pair')` 把 `|∇φ_k|` 往 1 的**一半**以下推

`reinitialize(mode='pair')`（EXPERT-#3 之后成为**默认**）对差分场 `d = φ_k − φ_l` 做 Sussman，
目标是 `|∇d| → 1`，然后对称回写。**问题**：对一个正常的 VDF，
`∇d = ∇φ_k − ∇φ_l`，而界面两侧 `∇φ_l ≈ −∇φ_k`（两个 SDF 的法向相反）
⇒ **`|∇d| ≈ 2`**，不是 1。把 `|∇d|` 驱到 1 ⇒ **`|∇φ_k| → 0.5`**，并在反复 reinit 中越推越小。

**单因素实测**（`_audit_faces2.py`，同一算例、只改 `reinit_every`）【实测】：

| step | `median|∇φ_winner|`（带内），reinit=0 | reinit=25 |
|---|---|---|
| 20 | 0.867 | 0.867 |
| 40 | 0.826 | **0.455** |
| 60 | 0.813 | **0.279** |
| 80 | 0.807 | **0.208** |
| 120 | 0.853 | **0.189** |
| 160 | **0.958** | **0.157** |
| 带胞数（`|φ|≤2dx`）@160 | 7824 | **20871** |

代码自己就在报警：`windowB_surface.py:1524: pair reinit: band |grad d| median=1.975 → …`
（`_audit_faces2.log`），而 `_BUN_N1/N3/N5.log` 里它一路降到 **0.134–0.16**
⇒ 换算回 `|∇φ| ≈ 0.07–0.08`，即**几何界面带被虚增 ~13 倍**。

**后果**（都是静默的）：
* 所有以 `|∇φ|` 计的**几何量**（`cell_area_geom` 的 `A_c = |∇φ|dx²/3`、`S_v`、板片厚 `t=2f/S_v`、

* `iface = |φ_winner| ≤ 2dx` 选中的物理带厚从 2 胞膨胀到 ~13 胞 ⇒ EDT 延拓的
  "最近界面胞"语义被改变；
* `band_health` 的 `median|∇φ| < 5` 判据根本挡不住（0.15 ≪ 5）；
* 与 §2.4 的 Wulff 结论叠加时，**真实的界面速度被非均匀地缩放**。

> 注意区分：level-set 的**零等值面速度**本身对 `|∇φ|` 的**均匀**缩放不敏感
> （`Δφ/|∇φ| = dt·v`），所以这不是"速度被砍半"这么简单；
> 但**非均匀**的 `|∇φ|` 会让剖面不再纯平移、并让一切几何测度失真。这条与
> `LATH_CODE_AUDIT §C` 里"仍未定位"的那几项高度相关。
>
> 正解方向【推理】：差分类场的重初始化目标应是 `|∇d| = |∇φ_k| + |∇φ_l|`（VDF 下 = 2），
> 或者回到"逐 φ_k 重初始化 + 约束 k–l 零等值面"的方案。

### 2.6b 尚未定位：同一算例里各向异性**随时间退化**

同一个"干净"算例继续跑下去（`_audit_faces.log` 前 150 步 / `_audit_faces2.log` 前 160 步）【实测】：

| step | Δr_n (nm/步) | Δr_w | Δr_a |
|---|---|---|---|
| 10–90 | 0.10 ~ 0.12 | 0.30 | 2.8 → 0.9 |
| 100–160 | **0.26 → 1.6** | 0.31 | **0.6 → 0.9** |

149 步累计：Δr_n = 61.3 nm、Δr_w = 46.4 nm、Δr_a = 223 nm
⇒ **实测比 0.275 : 0.208 : 1（设计 0.030 : 0.100 : 1）**。
`_audit_faces2` 同时给出：主轴与 a 的夹角全程 0.1°~1.2°（**形状没有转动**）、
带内 `median|∇φ|` 从 0.87 漂到 0.81 再回到 0.96（**不是全局塌缩**）。

**当前最自洽的解释【推理，待判】**：
Wulff 形在 n_hab 方向是**平面刻面**，刻面边界是一条**尖边**；而 EDT 延拓的速度场在尖边上
必然被抹平（最近界面胞在刻面/侧面之间跳变）。尖边一旦被抹圆，快速的侧向/端面就会
**从两侧"吃掉"刻面**，于是射线沿 n 打到的已不再是"法向为 n_hab 的平面"，而是
坡度介于 a 与 n 之间的**斜帽面** ⇒ r_n 增速、r_a 减速。w 方向因为 β_w 较小（刻面浅）
不受影响，所以**始终精确**。
⇒ 这解释了"只有被压制最强的方向漏得最多"这个反常，也是 §2.4 那条"光滑指数给不出刻面"的
数值侧同一件事。**这一条我尚未做隔离实验，标【未核实】。**

### 3.2 结果分析错误（4 条）

#### (a) ★ 周期盒绕卷：9 档实验的"长"读数全部超过盒子边长

`_chk_single_lath.py`（第 162-168 行）与 `_chk_lath_final.py`（第 25 行）都用
**未解绕的胞坐标**（`np.argwhere(region==k) * dx` ∈ [0, L)）算 extent，而域是**周期**的。
区域一旦绕盒，该"extent"就退化为投影跨度，上限为 `L·Σ|u_i|`（u = 该方向单位向量）。

`_audit_geom.py` 的独立计算【实测】：

| 档 | L (µm) | 实测"长"/"side2" (µm) | 该方向投影上限 (µm) | 占上限 |
|---|---|---|---|---|
| **C1** | 3.2 | **5.262** | 5.491 | **95.8%** |
| **A1** | 2.4 | **3.784** | 4.118 | **91.9%** |
| N1 | 1.6 | 2.450 | 2.746 | 89.2% |
| **A0** | 2.4 | **3.568** | 4.118 | **86.6%** |
| W23 | 1.6 | 2.297 | 2.746 | 83.7% |
| D20 | 2.4 | 3.406 | 4.118 | 82.7% |
| X10 | 1.6 | 2.191 | 2.746 | 79.8% |
| **C0** | 3.2 | **4.175** | 5.491 | **76.0%** |
| D03 | 2.4 | 2.885 | 4.118 | 70.0% |

**9/9 档的"长"都 > L**。⇒ 这些区域**已绕穿周期盒**，"长/宽""长/厚"读数不可用。
**其中 C0/C1/A0/A1 正是 `EXPERT_REVIEW_RESPONSE.md §5` 标题为
"第一批**干净**的板条数据"的那四档**，而该节据它们下的两条结论
（"圆盘种子也能长成长条 ⇒ M(n) 确在驱动面内各向异性"、"弹性驱动是显著的等轴化因素"）
**都建立在不可用的读数上**。

> 附带的双重失真：`_chk_lath_final.py` 用 `scipy.ndimage.label`（**默认非周期连通**）
> ⇒ 绕盒的板条会被**切成多块**，再对"块"算 extent。切块与绕卷两个效应方向相反，
> 使读数既不可靠也不可解释。`_chk_m6_route.py` 的 M4（`np.cov` 于整数下标）
> 与 `_chk_morph_full.py` 的 M4 有同样问题。

#### (b) `_3face.log` 的"大面 1.2–2.8×"我复现不出来

`_dbg_3face.py` **明确设了 `g.pf = None`（关弹性）与 `gamma=0`**，
按代码逐行推演，界面胞上的 `vnk` 应**恰好**等于 `M·Δf·Mfac(self)`（`ind` 指向自己、`sigma²=1`、
无曲率项）⇒ 判据比值应为 1.000。实测却是 1.219 / 1.230 / **2.770** / 1.442 / 1.376。
而我的独立干净算例（§2.5）给的是 1.00–1.18。
⇒ **该诊断的"大面偏快"目前无法归因**：可能是诊断自身的口径问题，也可能是某种
我未复现的构型相关泄漏（它的种子是 `elong=6` 的**椭圆端**，我的是矩形棱柱）。
**在查清之前，不应把"大面偏快"当作模型的结论引用。**【未核实】

#### (c) NE0 vs NE1 的 dt 差 12 倍

`_chk_single_lath.py` / `_chk_m6_route.py` 的初值 dt 用 `max|ed|` 估：
NE0（开弹性）`dt0 = 1.269e-9 s`、NE1（关弹性）`dt0 = 1.5e-8 s` **【实测：读日志】**。
700 步对应的物理时间差 **12 倍**。以 f 为钟（0.727 vs 0.898）勉强可比，
但**形状比不是 f 的单值函数** ⇒ 该对照不成立。

#### (d) M6 ≈ 随机是"形态的推论"，不是独立判据

我做了 **M6 判据本身的正/负对照**（`_audit_m6.py`，人为平面界面，法向偏离 ncmp 0/10/30/60/90°）【实测】：

```

偏离 10 deg                     10.0
偏离 30 deg                     28.9
偏离 60 deg                     61.2
偏离 90 deg                     89.1
随机方向 1/2/3                  61.8 / 75.9 / 44.7
球（各向同性）                   60.9
```
⇒ **M6 判据有效（线性、准确），"M6≈随机"不是判据失灵。**
但要注意读法：M6 在"12 变体互相挤满、母相只剩 10%"的构型里
**是块状形态的必然推论**，不是独立的"晶格择优缺失"证据。
把它写成"硬缺陷：没有惯习面择优"在因果上容易误导；正确的读法是
"组织是块状的（= M4 的结论）⇒ 界面取向必然随机"。

## 4 "条状马氏体长不出来" —— 分层根因（按重要性排序）

| # | 层 | 根因 | 证据 | 可修性 |
|---|---|---|---|---|
| **1** | **标定公式** | `长/厚 = e^{β_h}` 是错的；Wulff 凸化给 `长/厚 = √(2β_h)·e^{1/2}`。β_h=3.5 ⇒ **上限 4.36**，与实测 4.17–4.87 吻合 ⇒ **已经长到极限** | §2.4【实测】 | 换 M(n) 的**函数形式**（近奇异/尖点），或把 β 提到 ~10²（但那已无物理依据） |
| **2** | **弹性符号** | `ed = −ε⁰:σ`，应为 `+ε⁰:σ` ⇒ 正反馈 | §2.3【实测】 | **一行**（`+`变`−`），但要全量重跑 |
| **3** | **重初始化** | `mode='pair'` 把 `|∇d|` 驱到 1 ⇒ `|∇φ_k| → 0.5` 并持续下降（实测 0.87→0.16）；几何测度静默失真 | §2.6【实测：单因素对照】 | 改目标/改方案；把 `|∇d|` 断言升级为硬失败 |
| **4** | **量测口径** | 单核实验的 extent 用未解绕的周期坐标；9/9 档"长">L | §3.2(a)【实测】 | 加"是否绕盒"硬守卫 + 解绕/惯性张量口径 |
| **5** | **初始条件** | 种子 1.8 µm 放进 1.6 µm 盒；且只撤回了 E6 | §3.1(a)【实测】 | 已加硬检查（旧算例不可重跑） |
| **6** | **推进格式** | 尖边（刻面边界）被 EDT 延拓抹圆 ⇒ 快面吃掉刻面 ⇒ n 方向漏、a 方向慢 | §2.6b【推理/未核实】 | 需"按配对"或"尖点 M(n)"或 Wulff 包络式推进 |
| **7** | **尺度配置** | 要 长/厚=25 的板条（长 10–30 µm）就得 ≥30–60 µm 的盒子；同时 dx ≤20 nm 才能解析 0.25–0.9 µm 的板条 ⇒ N≈1500–3000³ | 算术 | **不可行** ⇒ 回到"面表示/介观口径"（`HYBRID_FRAMEWORK §0` 的原始判断是对的） |

**一句话**：**不是"仿真跑不出板条"，而是"这套 M(n) 在设计上就给不出比 4.4:1 更长的板条"** ——
β 的标定用错了公式，掩盖了这个事实；弹性符号错误又让"加弹性"这条诊断路线失效；
量测口径与种子越界则让"实测 1.4–2.6:1"这一类数字全部不可用。
