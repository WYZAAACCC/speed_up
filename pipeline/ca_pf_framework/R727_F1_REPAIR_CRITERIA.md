## §2 本方案的设计（**与 `norm_smooth` 的本质区别**）

### 2.1 数学依据（`[代]`，我推的，**可机械验证**）

在以 `x₀` 为**中心**的对称窗上做一阶平面拟合，法向方程 `AᵀA g = Aᵀb` 中
`A = rᵀ`（相对坐标）满足 `Σr = 0`、`Σ r_i r_j = (n/3)δ_ij`
⇒ **`g` 恰好等于窗内的均值梯度**：
```
g(x₀) = (1/n) Σ_{x∈N(x₀)} ∇φ(x)
```
取 **3×3×3 箱**（`n = 27`）⇒ **`g = (1/6)·[S(φ_{i+1}) − S(φ_{i−1})]`**
其中 `S` = **3×3×3 周期箱和**（`_sep_conv3`，`np.pad(mode='wrap')`，**边界精确**）。

### 2.2 ⇒ 与 `norm_smooth` 的三点区别（**为什么这不是重复劳动**）

| | `norm_smooth=m`（既有） | **本方案（LSQ/box-sum）** |
|---|---|---|
| 平滑对象 | `∇d` **的分量**（`gd_`）再归一化 | **`φ` 本身**先箱和、**再做一次差分** |
| 数学含义 | 梯度的**盒式平均** | **一阶平面拟合的法向**（严格意义上"最小二乘平面"） |
| 尺度 | 用户给的 `m`（胞） | **固定 3×3×3**（可扩展） |
| 与解析 SDF 的关系 | 会**软化真法向**（把平面抹弯） | 对**线性场精确**；对曲面给"窗内平均法向" |
| 上游判决 | ⛔ **会产生离群碎片**（`R12-a`） | ✅ **本方案由 `R723` 在解析场上验证到 0.037°** |

★ **关键区别**：本方案**不引入新的插值/拟合自由度** —— 它就是"用箱和把 `∇φ` 的离散噪声按坐标精确积掉"，
**在平面附近是恒等的**（不会像盒式平滑那样把棱角磨圆）。

### 2.3 边界处理（**必须周期**）
`par.gradient`（`windowB_par.py:354-359`）用**盒边界截断**的单边差分 —— 而物理是**周期**的。
⇒ 本方案用 `_sep_conv3`（**严格周期**，已对 `scipy` 逐位校验）⇒ **边界更自洽**。
