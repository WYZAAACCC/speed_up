### 4.1 (★) 液相线恒等式：把两个溶质绑在一起

    G(T; c^liq) := sum_i k_i(T) c_i^liq + k_Ti(T) X^liq = 1,   k_j = exp[-dg_j/(R T)]

物理含义一句话：**「按 `k` 逐组分把液相成分放大后，固相的总和必须恰好是 1」**。

* 纯 Ti 检验：`c^liq = 0 => G = k_Ti = 1` 只在 `T = T_m` 成立 ✓（判据 T-A4）

### 4.4 §7.7「溶质到底是谁」的**结构性回答**（用户已裁决：走三元）

## 5. 与 Gibbs 面（Window C）的关系：R6 —— 位点竞争

**不兼容点（A6）**：`gibbs_physics.py` 的 McLean 等温线

    c_GB/(1-c_GB) = c_far/(1-c_far) * exp[-Delta G_seg/(R T)]

是**单物种**的。两个溶质时，吸附**不能**各自独立用 McLean —— 它们争同一批晶界位点。
正确的闭合是 **Langmuir 竞争吸附**（多元 McLean）：

    Gamma_i / (Gamma_0 - sum_j Gamma_j) = a_i * exp(-Delta G_seg,i / (R T))

（`a_i` = 体相活度；理想溶液下 `a_i ~= c_i`）。单物种极限立刻退化为 McLean ✓。

**该式同时解释了为什么单物种 McLean 会系统性高估偏析**：忽略 `sum_j Gamma_j` 时，
每个物种都以为自己独占全部位点。`Gamma_0 = 12.9 at/nm^2` [T] 是**总**位点数，

**每个溶质一套**，并且必须显式声明「另一物种占了多少位点」。
