## §4 ★★ 更关键的定性差异：**无投影时长厚比会"停住"**

| 臂 | 长厚比轨迹（随 `Vt` 增大） |
|---|---|
| **`L0`**（proj=0） | 1.00 → 1.48 → 2.06 → **1.66 → 1.52 → 1.46 → 1.39 → 1.36 → 1.32 → 1.29 → 1.26** |
| **`L1`**（proj=1） | 1.00 → 1.84 → 2.43 → 3.02 → 3.50 → 3.89 → 4.31 → **4.80 → 5.08 → 5.68** |

**⇒ `L0` 的长厚比在 `Vt ≈ 6e-19` 之后**不升反降**（2.06 → 1.26），即**形状在"变圆"**；
⇒ `L1` 则**持续单调上升**（未撞盒区间内到 **5.68**，仍未见饱和）。
**⇒ 这是两者最本质的差别：`--facet-proj` 把"长不起来"变成了"持续伸长"。**
