## 2. 理论框架（**要加入的物理**）

### 2.1 运动学与自由能
小应变分解：
```
ε = ε^e + ε⁰(φ) + ε^p ,      ε⁰(φ) = Σ_k φ_k ε⁰_k
F = ∫ [ f_chem(φ,T) + f_grad(∇φ) + ½ (ε − ε⁰ − ε^p) : C : (ε − ε⁰ − ε^p) ] dV
```
力学平衡（准静态、无体力）：`∇·σ = 0`，`σ = C : (ε − ε⁰ − ε^p)`。
相场驱动力：`∂F/∂φ_k ∋ −σ : ε⁰_k` —— **这就是引擎里 `ed_k` 的物理出处**。

### 2.2 塑性（率无关 J2、关联流动、理想塑性）
```
f_y = σ_eq − σ_y ≤ 0 ,        σ_eq = √(3/2 ‖dev σ‖)
ε̇^p = λ̇ (3/2) dev σ / σ_eq ,   λ̇ ≥ 0 ,  f_y λ̇ = 0
```
**关键假设（有依据）**：塑性弛豫的时间尺度（ns 级）≪ 相场演化尺度
⇒ 力学问题**始终处于已松弛态** ⇒ 每步做**径向回退**
```
σ_plast = σ_el · min(1, σ_y / σ_eq(σ_el))
```
### 2.3 ⇒ 第一版结论（**看起来对，但被 V5 否掉**）
> 「相场驱动力由 `−σ_el:ε⁰_k` 换成 `−σ_plast:ε⁰_k`，无需新增求解。」

## 3. 自检（**预登记判据，可以 FAIL**）

### 3.1 `_t10_trip_derive.py`：V1–V4 全 PASS
| 判据 | 结果 |
|---|---|
| **V1** `σ_y→∞` 必须回到纯弹性 | ✅ **逐位相同** |
| **V2** 一维单轴 `σ = min(Eε, σ_y)` | ✅ 两档精确 |
| **V3** 纯静水不得屈服（J2 是偏量判据） | ✅ `σ_eq = 0.000e+00` |
| **V4** `σ_eq(σ_plast) ≤ σ_y` 逐胞硬不变量 | ✅ 2000 个随机张量全满足 |

### 3.2 **V5 FAIL —— 第一版被否掉**
```
V5 σ_y=0.3 GPa: η_eff ∈ [0.0450, 0.0450]，跨度 0.0000   ❌ FAIL
V5 σ_y=1.0 GPa: η_eff ∈ [0.1500, 0.1500]，跨度 0.0000   ❌ FAIL
```
**根因（立方对称）**：`ε⁰_k = R ε⁰_1 Rᵀ` ⇒ `σ_eq(C:ε⁰_k)` **与 k 无关**
（实测 **6.669 GPa**，12 个变体全同）⇒
**对单变体做径向回退 ≡ 整体乘常数 ⇒ 与现有 η 方案零增量。**

> 顺带解释一个长期困惑：**均匀 η 在数学上无法改变变体间的相对能量**（只能整体缩放）
> ⇒ 它能改「形核门槛」（为何它有效），但**结构上不可能**修掉局部掐断（为何它无效）。

### 3.3 **V5′ —— 修正版（对总应力场回退），仍然基本被否掉**
做法：`σ_el(x) = Σ_k φ_k(x) C:ε⁰_k`（多变体叠加）⇒ `σ_eq(x)` 随空间变化 ⇒ 回退。
```
同变体相邻:         最优常数 η 残差 = 0.00%
异变体相邻 (A≠B):   残差 = **0.26%**     ← 几乎为零
异变体相邻 (另一对): 残差 = 5.65%
```
**⇒ 仍然近似等价于常数 η**：因为叠加只让 `σ_eq` 从 6.669 变到 6.570 GPa（**1.5%**）
⇒ 折减因子在空间上几乎不变 ⇒ **该路也不做。**

## 4. ★★ V5′-d 给出的**真正的物理结论**（框架的落点）

```
自协调组态（12 变体等分）：
    σ_eq = **0.0000 GPa**            ← 偏量应力**恰好抵消**（C4：Σ dev(ε⁰_k) = 0）
    w_el = **7.4742e7 J/m³**         ← 但**不是 0**：残留 **10.0%**（= 单变体 7.4674e8 的 0.100）
```

**⇒ 分解**：
| 分量 | 自协调下 | 能否被 J2 塑性弛豫 |
|---|---|---|
| **偏量** | **恰好抵消** | 是（本来也不需要） |
| **静水** | **残留**（相变体积变化引起） | **不能**（J2 判据是偏量的） |

**⇒ 由此得到一个可推导的 η：**
```
w_el^物理 = w_静水(ε⁰) + min( w_偏量(ε⁰), σ_y²/(6μ) )
Ti64:  w_静水 = 7.47e7 J/m³                 （全约束的 10.0%）
       w_偏量弛豫后 ≈ 5.7e5 J/m³            （σ_y = 300 MPa 时；可忽略）
⇒  w_el^物理 ≈ **7.47e7 J/m³**
```

| 口径 | 值 | 占比 |
|---|---|---|
| 全约束（无几何、无塑性） | 7.467e8 J/m³ | 100% |
| **几何弛豫后（引擎实测单板条 `\|ed\|`）** | **2.96e8** | 40% |
| **+ 塑性弛豫偏量（本轮推导的物理值）** | **7.47e7** | **10%** |
| ⇒ **η_物理（相对引擎 `\|ed\|`）** | **7.47e7 / 2.96e8 = 0.253** | |

**⇒ 推导值 η = 0.253；当前用的是唯象标定的 0.375**（当初按"让形核判据配平"定，
不是推导出来的）。推导值小 33% ⇒ 弹性罚能还能再降三分之一 ⇒ 掐断应进一步减轻。

### ★ 健壮性（很重要）
结果**对 `σ_y` 不敏感**：只要 `σ_y²/(6μ) ≪ w_偏量`，`η_物理` 就只由**静水占比**决定；
σ_y 高到约 **2 GPa** 该不等式仍成立 ⇒ **唯一缺的文献量不影响结论**（见 §5）。

### ⚠ 必须标明的近似
把引擎实测 `|ed| = 2.96e8` 当作"几何弛豫后、塑性弛豫前"的值是**近似**
（真实塑性还会改几何）⇒ 由判据 1 检验。
