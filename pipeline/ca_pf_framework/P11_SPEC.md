## 1. ⚠ 第一次尝试为什么失败（必须记住，否则会重犯）

**做法**：1D 稳态、界面系、混合浓度式
@@
-V\,c_m+D_{\mathrm{eff}}(\xi)\,\partial_\xi c_l+j_{\mathrm{at}}=-V\,c_\infty,\qquad c_m=f_sc_s+(1-f_s)c_l
@@
然后取 @@k_{\mathrm{eff}}=c_s(-\infty)/c_l(0)@@。

**失败原因（两条，都是定义层面的）**：

1. **稳态质量平衡强制 @@c_m(-\infty)=c_\infty@@**。深固相区 @@D_{\mathrm{eff}}\to0@@ ⇒ 通量只剩 @@-Vc_m@@ ⇒ 它必须等于 @@-Vc_\infty@@。
   这是**物理上正确的**：一根无限长柱子的稳态凝固，进来多少出去多少，固相远处必然回到名义成分。
2. 于是 @@k_{\mathrm{eff}}\equiv c_s(0^-)/c_l(0^+)\equiv k@@ **恒成立**（局部平衡直接给出），**测不出任何弥散界面偏差**。
   实测：k_eff 随 W 从 +6e4 涨到 -8e10 —— 那是**病态求解**（@@D_{\mathrm{eff}}=0@@ 的行让矩阵近奇异），不是物理。

**⇒ 正确的可测量不是 @@c_s(-\infty)/c_l(0)@@，而是【界面处液相 / 远场液相】：**

@@
R\;\equiv\;\frac{c_l(0^+)}{c_\infty}\;\overset{!}{=}\;\frac{1}{k_e}=1.5865
@@

锐界面稳态解析解给出 @@c_l(0^+)=c_\infty/k_e@@，所以 @@R=1/k_e@@；
**弥散界面会把 R 推离 1/k_e，且偏离随 @@W V/D_L@@ 增长**；抗截留通量的作用就是把它拉回来。

## 3. 正确的方程（耦合 PF，@@W\to0@@ 且 @@W/V@@ 固定）

变量：@@\varphi@@（非守恒，@@\varphi=1@@ 为固相）、@@c@@（守恒）。

@@
\frac{\partial\varphi}{\partial t}=M_\varphi\Big[\sigma\big(\nabla^2\varphi-\tfrac{\partial g}{\partial\varphi}\big)-h_\varphi(\varphi)\,\Delta G_{\mathrm{chem}}\Big]
@@
@@
\frac{\partial c}{\partial t}+\nabla\!\cdot\!\big(\mathbf j_{\mathrm{at}}\big)=\nabla\!\cdot\!\Big[M_c(\varphi)\,\nabla\mu\Big],\qquad
\mu=h(\varphi)\mu_S(c)+(1-h(\varphi))\mu_L(c)
@@
@@
\mathbf j_{\mathrm{at}}=-\frac{W}{\sqrt2}\,\frac{\partial_t\varphi}{|\nabla\varphi|}\,\big(c_l^0-c_s^0\big)
@@

要点（**全部是必须项，缺一条这个极限就不存在**）：
1. @@\mu@@ 的**插值形式**（不是 @@c@@ 的插值）—— 这是 partition 的来源；
2. @@h(\varphi)=3\varphi^2-2\varphi^3@@（或 @@\varphi^3@@ 族），必须与 @@g(\varphi)@@ 的双阱**配套**；
3. @@M_c(\varphi)=M_S+(M_L-M_S)h(\varphi)@@，且 **@@M_c\,\partial^2f/\partial c^2\to D@@ 恒等式必须成立**（不能在 @@D@@ 与 @@M@@ 之间混用）；
4. 界面动力学项与曲率项的**系数必须由同一个 @@\sigma@@、@@M_\varphi@@ 推出**（否则 V(ΔT) 会多一个自由参数）。

边界与初始：1D，方向凝固，@@T(z)=T_0+Gz@@（@@G@@ 取框架的 @@10^6@@ K/m），拉速 @@V@@；
远场 @@c\to c_\infty@@，无通量出口；初值用 §5.2 的 @@T_{\mathrm{pair}}@@ 定出的平衡对。

## 7. 重大发现（2026-09-22 第六轮）：抗截留在生产代码里已经实现，且带一个自由前置因子

### 7.1 现有实现（逐行核对 `pipeline/stage1_meltpool_c.i`）

| 项 | 值 |
|---|---|
| 核 | **AntitrappingCurrent**（MOOSE phase_field 内置），生产输入里对 gr0..gr7 各挂一个，共 8 个 |
| 作用变量 | w（**分裂化学势变量**）—— 这正是 SplitCHParsed 的 w 参数要的东西 |
| 材料 | F_at，DerivativeParsedMaterial，coupled_variables = c w，material_property_names = h_gb |
| 表达式 | F_at = ALPHA * W * (1 - k_eq) * c * (1 - h_gb) |
| 常数 | **ALPHA = 2**，**W = 2e-06 m**，k_eq = 0.6303 |

### 7.2 这份实现给出两条必须记的结论

**(a) 前置因子 ALPHA = 2 是 A 档指派值。**
Karma-Rappel 原式（PRL 87, 115701 (2001)）的前置因子是 1/sqrt(2) = 0.707，这里取 **2**（差 2.83 倍）。
=> **ALPHA 就是本规格第 2 节判据 P1-c 里那个必须【数值定出】的 A\*。**
**现在它是个自由参数，没有人验证过它的正确值。** 这是 P1.1 最有价值、也最容易出错的落点。

**(b) 注意 F_at 里的 W = 2e-06 可能与真实界面宽不一致。**
仓库里界面宽用过 wGB（生产 4 um、Gibbs 版 8 um）与 int_width；F_at 里硬编码成 2e-06 m。
**抗截留的幅值正比于 W**，所以 W 取错 4 倍 => 抗截留错 4 倍。
**这条必须先对齐**【未核实】：需要核对 F_at 的 W 应当等于哪一个界面宽度。

### 7.3 因这条发现而缩小的 P1.1 工作量

原以为要新建 mu_interp / CHBulkCustomMu / AntiTrappingFlux 三个核。核对后：

| 原计划新核 | 现状 |
|---|---|
| mu_interp | **不需要**：把自由能写成 f = RT/Vm*[(1-c)ln(1-c)+c*ln c] + h(phi)/Vm*(dgB + dHf*(1-T/Tm))*c，则 df/dc 自动就是插值化学势（见 pf1d_moose/README.md） |
| AntiTrappingFlux | **已存在**：MOOSE 内置 AntitrappingCurrent，生产里已用 |
| CHBulkCustomMu | 视 SplitCHParsed + w 的分裂写法能否直接承载而定；**先用现有写法** |
| ACBulkChemDrive | 可复用 ACBulk / AllenCahn |

=> **P1.1 从【要写三个新核】降级为【用现有对象搭 1D 算例 + 定出 ALPHA\* + 对齐 W】**。

### 7.4 修正后的下一步（顺序）

1. **对齐 F_at 里的 W**：查它应等于哪个界面宽度（int_width? wGB?）。若不一致，那是生产代码里的一个真实 bug（抗截留幅值错），要单独立项；
2. 照抄 stage1_meltpool_c.i 的 [w] + AntitrappingCurrent + F_at 写法搭 1D 算例；
3. 冻结 phi + 均匀 T：验证两相共存给 c_s/c_l = k_e；
4. 加梯度与拉速，测 R = c_l(0+)/c_inf，验证锐界面极限 R -> 1/k_e（P1-a）；
5. 扫 ALPHA 定出 ALPHA\*（P1-c）—— **这是 P1.1 最有价值的产出**。

## 8. 真实 bug（2026-09-22 第六轮）：抗截留幅值用错了界面宽，小 2~4 倍

### 8.1 证据（逐行核对）

| 文件 | 界面宽 | `F_at` 里的 W | 比值 |
|---|---|---|---|
| `pipeline/stage1_meltpool_c.i`（生产原件） | `int_width = 4.0e-6` | `2e-06` | **W/wGB = 0.5** |
| `pipeline/gibbs/prod3d/stage1_meltpool_gibbs3d.i`（3D 副本） | `int_width = 8e-06` | `2e-06` | **W/wGB = 0.25** |

抗截留电流的幅度 **正比于界面宽 W**（Karma-Rappel）。W 取成真实界面宽的 1/4，
=> **抗截留补偿只有该有的 1/4** => 弥散界面吞掉/吐出的溶质没有被补回来。

### 8.2 生成器其实早就知道，但默认值留在了错的一侧

`make_gibbs3d.py` 第 114-120 行原文：

    ⚠ 生产的 W = 2e-6 m 是硬编码的界面宽度，而本模型的 eta 界面宽是 wGB
      （生产 4 um、本 2D 副本 8 um）=> W 与 wGB 不一致（差 2~4 倍）。
    => 用错 W 会让被界面吞掉/吐出的溶质补偿不完整。

却有 `AT_W = float(os.environ.get("AT_W", "2.0e-6"))` —— **默认值就是那个错的 2e-6**。
这与仓库自己总结的教训 3.24（同一参数在多文件重复时，改一半比不改更危险）是同一类。

### 8.3 已做的修改（只改副本的生成器，不碰生产原件）

    AT_W = float(os.environ.get("AT_W", "%.10g" % WGB))

- 默认改为**跟随本模型真实界面宽 WGB**；仍可用 `AT_W` 环境变量覆盖；
- 备份： `make_gibbs3d.py.bak_atw`；
- 验证： WGB=8e-6 时 AT_W 现在等于 8e-06（原来恒为 2e-06）。
- `pipeline/stage1_meltpool_c.i` **未动**（SHA256 仍为 775f9487...6669）。

### 8.4 ⚠ 必须记账的后果（**这一条会改变已有结论**）

凡是**让抗截留起作用**的 2D/3D 副本算例，此前都是在**抗截留弱 4 倍**的条件下跑的。
特别是仓库报告里记的：

    T5->C4（Gibbs 吸附）：实现了、接线正确、但效应为零 -> 未解决

**这很可能就是原因**：补偿只有 1/4，剩下的 3/4 伪影把真实效应盖掉了。
=> 这些结论需要用修正后的生成器**重跑**才能确认。**这是一项会改变物理结果的重跑，属需用户知情的范围，已登记。**

### 8.5 仍然要定的事

- `ALPHA = 2` 仍是 A 档指派值（Karma-Rappel 原式是 1/sqrt(2) = 0.707，差 2.83 倍）。
  修好 W 之后，`ALPHA` 才有意义去标定 —— 两者必须在同一个 A/B 里一起定。

## 9. P1-a 已验证通过（2026-09-22 第六轮）

### 9.1 算例

文件 `pf1d_moose/p1a_1d.i`：1D、x in [-200, 200] nm、nx=400；
冻结 phi = 0.5(1-tanh(x/(sqrt2*20nm)))；均匀 T = T_L = 1911.1 K；
分裂 CH 结构**照抄生产输入**（`CoupledTimeDerivative(w,v=c)` + `SplitCHWRes(w,mob_name=M)` + `SplitCHParsed(variable=c,w=w)`）。
自由能 `f = R*T/Vm*[(1-c)ln(1-c)+c*ln c] + h(phi)*(dgB+dHf*(1-T/Tm))*c/Vm`，
**dgB = 7334 J/mol**（见 9.3 的纠正）。

### 9.2 结果

| 配置 | c_liquid | c_solid | 比值 c_s/c_l |
|---|---|---|---|
| atol=1e-14, t=3e-4 s | 0.044208447762884 | 0.027951820625156 | 0.6322755 |
| atol=1e-10, t=3e-3 s（时间 x10） | 0.044208440706925 | 0.02795182763321 | 0.6322762 |

目标 `k_e = 0.6303` => **偏差 +0.31%**。

### 9.3 两件必须记账的事

**(a) 假收敛已排除。** 506 步里 505 步是 `0 Nonlinear`（atol=1e-14 太松），
这是仓库记录过的假收敛特征。按框架规则 `nl_abs_tol ~ 1e-3*|R0|`（|R0|=85.6 => ~0.086）重设 atol=1e-10 并把时间延长 10 倍后，
结果**逐位一致到第 8 位有效数字** => 不是假收敛。物理上也一致：sqrt(D*dt)=97 nm 与 400 nm 域同量级，1~4 步即到稳态。

**(b) 纠正我上一轮的一个错误：dgB = 7334，不是 7515.9。**
上一轮我混用了两套参考成分对（液相线对 vs 固相线对）。自洽做法是在 **T = T_L 用液相线对**
（c_l = c0 = 0.036、c_s = k_e*c0 = 0.022691）：

    Delta = -R*TL*ln[ c_s(1-c_l) / (c_l(1-c_s)) ] = 7552.4 J/mol
    而 Delta = dgB + dHf*(1 - TL/Tm)  =>  dgB = 7552.4 - 217.96 = 7334.4 J/mol

**7334 正好等于框架 TH9 的 -R*TL*ln(k_e)** => 两处独立算出的值一致，互相印证。
反代验证：c_l = 0.036 => c_s = 0.022690 = 0.6303*0.036，精确。

### 9.4 这一步意味着什么

**插值化学势不用新核、用生产同款的分裂 CH 写法就能精确复现平衡分配系数。**
=> P1.1 的下一步（P1-b/P1-c）现在有了一个**已验证的物理基底**：可以去扫 W 与 ALPHA，
定出那个现在被指派成 2 的 Karma-Rappel 抗截留前置因子。

1. 把 phi 换成真正的 Variable（加一个把 phi 钉到目标剖面的核），看抗截留是否开始起作用；

## 11. 抗截留为零的根因：**已由源码 + 官方文档钉死**（2026-09-22）

### 11.1 源码（/root/moose/modules/phase_field/src/kernels/AntitrappingCurrent.C）

    Real AntitrappingCurrent::computeQpResidual()
    {
      const Real norm_sq = _grad_v[_qp].norm_sq();
      if (norm_sq < libMesh::TOLERANCE)
        return 0.0;
      return _F[_qp] * _v_dot[_qp] * _grad_v[_qp] * _grad_test[_i][_qp] / std::sqrt(norm_sq);
    }

### 11.2 官方文档（.md 原文）

    弱形式:  ( F(u,v,a,b,...) * (grad v / |grad v|) * (dv/dt) , grad psi )
    其中 v (v) 是【取时间导数的那个耦合变量】。

### 11.3 结论：核的贡献【严格正比于 dv/dt】

1. 残差 = F * _v_dot * (grad v 的方向) * grad(test)。**dv/dt = 0 时贡献恒为 0。**
2. 另外：`|grad v|^2 < TOLERANCE` 时也直接返回 0（即只在界面内非零）。

我的 1D 复现算例里 `phi` 是 **AuxVariable**（FunctionAux 赋值）：
MOOSE 的 AuxVariable 默认**不提供 _u_dot** => `dv/dt` 被当作 0
=> **与实测的 ALPHA=0 与 ALPHA=2 逐位相同（15 位）完全一致。根因确认。**

### 11.4 顺带发现的两条（**推翻我第 7 节的假设**，必须更正）

**(a) 参考文献不是 Karma-Rappel，而是 Plapp 2011。**
官方文档的引用是 `plapp_unified_2011`。
所以【前置因子 1/sqrt(2) = 0.707 不能从 Karma-Rappel 直接搬过来】——
第 7.2(a) 节里我拿 1/sqrt(2) 去比对 `ALPHA=2` 的那段**不成立**，
正确的做法是从 Plapp 2011 的推导里定出该前置因子（或数值定出，即 P1-c 的本意）。

**(b) MOOSE 的形式是 +F(grad v/|grad v|)(dv/dt)，符号为正。**
而 Karma-Rappel 的抗截留电流是 -(W/sqrt2)(dphi/dt)(grad phi/|grad phi|)(c_l - c_s)，符号为负。
仓库的 `F_at` 表达式是**正的**（`ALPHA*W*(1-k_eq)*c*(1-h_gb)`）。
=> **符号必须对着 Plapp 2011 核一遍**；在 dv/dt 还被当成 0 之前，这个问题被完全掩盖了。

4. 然后才谈把结论搬到 3D 副本 —— 且要注意**生产的 ALPHA=+2 落在符号错的一侧**，
   但在 W/delta_c ~ 0.17 的区制里这个错只值 ~0.2%，所以此前没人发现。

## 17. 在 W/dc >= 1 区制下定 ALPHA：**符号确定、数量级确定、仍有 W 依赖**（2026-09-23）

|---|---|---|

### 17.3 三条结论

**(a) 符号确定：ALPHA* < 0。** 两个 W 上 dev 都在 ALPHA in (-1, 0) 之间**变号**：

    W = 200 nm : ALPHA* ~ -0.51   （-1.0 -> +2.02e-4 ; 0 -> -2.14e-4）
    W = 400 nm : ALPHA* ~ -0.26   （-0.5 -> +2.50e-4 ; 0 -> -2.78e-4）

=> **生产取 ALPHA = +2（正值）在符号上是错的**，而且数量级偏大约 4~8 倍。

**(b) 修正量确实随 W 成比例**（强一致性检查）：ALPHA 引起的斜率

**(c) 但 ALPHA* 仍有 W 依赖（-0.51 vs -0.26）=> 判据里混进了别的项。**
   注意 ALPHA=0 的残余偏置：W=400 是 -2.78e-4、W=200 是 -2.14e-4，
   比值只有 1.30，**不随 W 成比例** —— 说明存在一个**与界面宽无关、与 ALPHA 无关的偏置**
   （约 -2e-4，疑为瞬态/其它离散化效应）。它把零交叉点按 W 不同程度地拉偏。

=> **结论：`ALPHA* < 0` 与 `|ALPHA*| ~ O(0.3~0.5)` 是可靠的；精确值需要更干净的判据。**

### 17.4 更干净的判据（下一步）

不用"固相成分 = c_inf"，改用**直接对账界面处的溶质通量**：
在界面位置量 J_diff = D_L * dc/dx|_界面两侧 与 V*(c_l - c_s)，两者之差就是抗截留应当补的量。
这个量**直接就是抗截留的定义**，不受远场/瞬态偏置影响。做法：

1. 从已有算例的 CSV 导出界面附近的 c(x)（需要加 LineValueSampler 或用 exodus 输出）；
2. 在界面位置数值求 dc/dx，与 V*(c_l-c_s) 对比；
3. 扫 ALPHA 找使残差为零的值 —— 这个残差与 W 无关（因为它是局部的通量账）。

### 19.5 ⭐ 为什么 `dev` 是**错的**观测量：移动坐标系的第一积分把它钉死了

稳态、以 `V` 平移的坐标系里，无论是 CH 还是抗截留，第一积分都是

```text
M(phi) * d(mu)/d(xi) - j_at(xi) = -V * c + const
```

（由 `d/dxi[...] = dc/dt|_lab` 得）。深处固相 `j_at -> 0`、`M mu_xi -> 0`；
远场液相 `j_at -> 0`、`M mu_xi -> 0`、`c -> c_inf`。于是

```text
-V * c_s = -V * c_inf   =>   c_s = c_inf    （严格恒等式，与 ALPHA、W 无关）
```

**实测完全证实**：`drive_ak.py` 里 ALPHA = 0/-1/-2/-3 四档的深处固相成分**都是 0.036000**。
⇒ **`dev = c_s - c_inf` 是恒等式钉死的量，原理上定不出 ALPHA。** 这解释了 §17/§18 的
「符号能定、幅值定不了、还有 W 依赖」——那些都是瞬态在作祟，不是判据分辨率问题。

### 20.3 ⭐ 根因候选：`F_at` 的形状

MOOSE 侧的**权威事实**：

| 项 | 内容 |
|---|---|
| 核 | `AntitrappingCurrent` = `CoupledSusceptibilityTimeDerivative` × `(grad v/\|grad v\|)` |
| 弱形式 | `( F (grad v/\|grad v\|) dv/dt, grad psi )`（官方 .md 原文） |
| 推论 | `j_at = F dv/dt (grad v/\|grad v\|)`，故 **`\|j_at\| = F \|dv/dt\|`** |
| 稳态移动系 | `dv/dt = -V dv/dxi` ⇒ **`\|j_at\| = F V \|grad v\|`** |
| 引用 | Plapp, PRE **84**, 031601 (2011)，DOI 10.1103/PhysRevE.84.031601 |

而 Plapp 的抗截留电流形如 `-(W/√2) Δc (dv/dt) grad v/|grad v|^2`，**含 `1/|grad v|`**：

| 形式 | `F` | 稳态 `\|j_at\|` | 形状 |
|---|---|---|---|
| Plapp/KR | `(W/√2) Δc / \|grad phi\|` | `(W/√2) Δc V` | **跨界面均匀** |
| 生产/本算例 | `ALPHA W (1-k) c (1-phi)` | `ALPHA W Δc V \|grad phi\|` | 峰值在界面中心、液相侧偏重 |

⇒ 两者的**形状因子不同**（一个是 `1/|grad phi|`，一个是 `(1-phi)`），
所以「ALPHA 是普适常数」在这个形式下**本来就该失效**——与 §20.1 的实测一致。

**修复方向（需用户拍板，因为这是改物理核）**：
把 `F_at` 换成与 `1/|grad phi|` 成正比的形状（或直接等价地实现 Plapp 的电流），
再重新标定 ALPHA。注意 MOOSE 的 `DerivativeParsedMaterial` 拿不到 `|grad phi|`，
可选路线：
(a) 用 `AuxVariable` 存 `|grad phi|` 再喂进 `F_at` —— ⚠ **会静默丢掉 F 对该量的导数（雅可比少项）**，

### 22.1 文献原式（已取到全文，不再靠自己猜形状）

| 来源 | 内容 |
|---|---|
| **Plapp, PRE 84, 031601 (2011)**，arXiv:**1105.1670**，式 (102) | `j_at = a·W·[ρ_l(μ) − ρ_s(μ)]·n̂·∂_tφ`，`n̂ = −∇φ/\|∇φ\|`，`a>0` 由匹配渐近分析定 |
| **Echebarria, Folch, Karma, Plapp, PRE 70, 061604 (2004)**，arXiv:**cond-mat/0404164** | `j_at = −a W (1−k) c_l⁰ e^u (∂_tφ) ∇φ/\|∇φ\|`；`a = 1/(2√2)`（其插值对的定值） |
| 同上，一般形式 | `a(φ) = [h(φ)−1][1−q(φ)] / [√2(φ²−1)]` |

**关键**：**没有 `1/|∇φ|`**。MOOSE 的 `AntitrappingCurrent` 弱形式是
`( F (∇v/|∇v|) ∂v/∂t, ∇ψ )`（源码 `AntitrappingCurrent.C` + 官方 .md），
即 `j_at = F·∂_tφ·(∇φ/|∇φ|)`，所以

```text
F = a · W · [ c_l(μ) − c_s(μ) ]        （正号）
```

⇒ 我们之前用的 `(1−φ)` 权重（1D）/「`h_gb` 门」（生产）**都不是形状因子的正确来源**；
`Δc` 必须由**局部化学势**解出两相平衡成分之差。

### 22.2 `Δc` 的闭式（两个模型都有，可直接写进 `DerivativeParsedMaterial`）

**(a) 1D 同构算例**（`p1c_alpha2.i` 的 `f_loc`：理想溶液 + `h(φ)Δg(T)c`）：

```text
mu = RT/Vm·ln(c/(1-c)) + h(phi)·dg(T)/Vm,   h = 3phi^2-2phi^3,  dg = dgB+dHf(1-T/Tm)
c_l = 1/(1 + ((1-c)/c)·exp(-h·dg/(RT)))
c_s = 1/(1 + ((1-c)/c)·exp((1-h)·dg/(RT)))
```

**(b) Gibbs 分支**（`make_gibbs3d.py` 的 `f_loc = FREF[(T/TREF)g(c) − (−ln k)c(1−h_solid)]`）：

```text
a_s = (c/(1-c))·exp( ln(KPART)·(1-h_solid)·TREF/T )      ->  c_s = a_s/(1+a_s)
a_l = a_s·exp( -ln(KPART)·TREF/T )                       ->  c_l = a_l/(1+a_l)
Delta c = c_l - c_s
```

两个模型**结构相同**（理想溶液 + `(1−h)` 插值），且无量纲驱动力几乎相同
（1D 的 `dg/(RT) = 0.4753` vs Gibbs 的 `−ln k = 0.4615`，差 3%）
⇒ **1D 标定可直接迁移到 Gibbs 分支**。

## 23. ⭐ 本轮独立发现：**生产自由能缺一个能量标度 ⇒ 非线性绝对容差整体失效**

> 这是在给「生产式二次型 `f_loc`」建 1D 同构算例时撞出来的，**与抗截留系数无关**，
> 但影响面更大（它可能就是仓库里一长串「假收敛 / 停滞 / 残差冻在非零地板」的**共同根因**）。

### 23.1 现象（实测，`pf1d_moose/quad_*/`）

生产 `f_loc = k_c/2·(c−c0)² + A_part·c²·h_solid` 用的是 `k_c=0.9`、`A_part=0.264`
—— 即**自由能是 O(1) 的数**（没有 J/mol、没有 R·T/v_m 这类物理标度）。
把这套原样搬进 1D 同构算例后（其余与已验证的算例逐字相同）：

```
 0 Nonlinear |R| = 6.003361e-10
 1 Nonlinear |R| = 6.002881e-10
 2 Nonlinear |R| = 6.002480e-10
 ...
 9 Nonlinear |R| = 6.000305e-10
```

- `|R0| ≈ 6e-10`，而算例沿用 `nl_abs_tol = 1e-9` ⇒ **0 次牛顿迭代就"收敛"**（假收敛）
- 把 `nl_abs_tol` 收紧到 `1e-13`（交接文档 §13 的规则）**也没用**：
  牛顿停在 `6e-10` 不动，每次迭代只降 `~5e-14`（≈ 1e-4 的相对量）
- 再收紧到 `1e-18`：**同样停住**，最终 `Solve failed and timestep already at or below dtmin`
- 收紧前那版（`nl_abs_tol=1e-9`）跑了 17 步后崩；探针读到 `c = 0.000000`

### 23.2 根因：**整套线性/非线性系统被"自由能标度"缩放了 ~1e-10**

`f_cc` 与 `f_c` 都正比于自由能的整体标度；`M = D/f_cc` 又把它除掉 ⇒
**物理完全不变**（`D = M·f_cc` 是构造恒等式），但

| 量 | 随标度 S 的变化 |
|---|---|
| 残差 `\|R\|` | `∝ S` |
| 雅可比 `J` | `∝ S` |
| 线性系统右端 `−R` | `∝ S` |
| **`nl_abs_tol` / `l_tol` / `nl_rel_tol`** | **不变**（是人写死的绝对数） |

⇒ `S ~ 1` 时容差是"相对 1e-9"，`S ~ 1e-10` 时容差变成"相对 1e-1"甚至更松。
而且**线性求解也一起失配**：右端 `~1e-10`，`l_tol` 的相对判据下解出的 `δ ≈ 0`
⇒ 牛顿步几乎为零 ⇒ **收紧 `nl_abs_tol` 只会把"假收敛"换成"卡死"**。

### 23.3 正确修法（实测有效）：把自由能归一化到物理标度

只做一次等价变换（物理不变）：

```text
f_loc  ->  S · f_loc          （S = 1.0e9）
M      ->  M / S              （即分母 f_cc 乘 S）
Delta c 的闭式不变（S 在 mu_L = mu_S 里两边约掉）
```

实测同一算例（`end_time = 2e-6`，40 步）：

| 版本 | `\|R0\|` | 牛顿行为 |
|---|---|---|
| 未归一化 | 6.003361e-10 | 停在 6e-10，每次只降 5e-14 ❌ |
| **归一化 `S=1e9`** | **4.771491e-01** | **4.77e-1 -> 1.29e-4 -> 3.85e-16（3 次迭代，二次收敛）✅** |

40 步全部 `Solve Converged`，`1 Nonlinear` 计数 = 40（步数）✅。

## 24. ⭐⭐ 统一诊断：`|R0| ∝ dx^dim` + **一行 `automatic_scaling = true` 解决**（2026-09-23）

> 本轮为了做 3D A/B，先撞上「3D 里 φ 完全不演化」，一路查到**最小可复现算例**，
> 发现它与 §23 是**同一个病**，并找到了与维度无关的正解。

### 24.1 最小可复现算例（`pf1d_moose/min_{1d,2d,3d}.i`，20 行）

只保留 `φ` + `CoefTimeDerivative(1e-9)` + `Reaction` + `BodyForce(f=0.1t)`，
`dt = 5e-8`、`end_time = 5e-7`（真解 `φ = 0.1 t = 5e-8`）：

| 维度 | `φ(t=5e-7)` | 每步 `0 Nonlinear` 后的 `\|R0\|` |
|---|---|---|
| 1D | **4.48e-8** ✅ | 4.99e-15 -> 9.97e-15 -> 1.50e-14 |
| 2D（ny=2） | **0**（完全不动）❌ | 3.05e-21 -> 6.11e-21 -> 9.16e-21 |
| 3D（ny=nz=2） | **0** ❌ | **1.87e-27** -> 3.74e-27 -> 5.61e-27 |
| 3D（ny=nz=1，单层） | **0** ❌ | — |

**`|R0|` 正比于单元测度 `dx^dim`**（1D `~1e-7`、2D `~5e-14`、3D `~2.5e-20` 的面积/体积因子），
逐档与解析估计吻合到 ~1 位有效数字。

### 24.2 机理

MOOSE 的收敛判据是 `|R| < max(nl_abs_tol, nl_rel_tol·|R0|)`。
我写死的 `nl_abs_tol = 1e-14`：

- 1D：`|R0| = 5e-15` ⇒ 目标 `1e-14` 与 `|R0|` 同量级 ⇒ **勉强真迭代**（所以"1D 看起来没问题"）
- 2D/3D：`|R0| = 1e-21 / 1e-27` ⇒ **`|R0| << nl_abs_tol` ⇒ 第 0 次迭代就"收敛"** ⇒ 解逐位不动 ❌

**把 `nl_abs_tol` 收紧到 `1e-30` 也不行**（实测）：目标落到 `1e-30`、而残差的舍入地板
`~|R0|·1e-16 ~ 1e-43`… 实际行为是**时间步被砍到 1.5e-12**、`φ` 仍是 0。
⇒ **和 §23 一样：盲调绝对容差无效，必须让残差本身回到 O(1)。**

### 24.3 ✅ 正解：`automatic_scaling = true`（一行，且与维度无关）

在最小 3D 算例的 `[Executioner]` 里加一行：

```text
[Executioner]
  ...
  nl_abs_tol = 1e-14
  automatic_scaling = true      # <-- 就这一行
  nl_rel_tol = 1e-9
  l_tol     = 1e-12
[]
```

实测：**`φ(t=5e-7) = 4.99e-8`（= `0.1 t`，精确）**，10 步全部有真迭代（`1 Nonlinear` 计数 = 10）。✅

MOOSE 自动缩放会按变量从雅可比里估计缩放因子，把残差/雅可比归一到 O(1)
⇒ `nl_abs_tol` / `nl_rel_tol` 重新变得有意义，**且自动适应 `dx^dim`**。

### 24.4 与 §23 的统一表述

| 版本 | 现象 | 根因 | 修法 |
|---|---|---|---|
| §23 | 残差 ~1e-10（生产任意能量标度）⇒ 假收敛；收紧容差 ⇒ 卡死 | 残差尺度 ≪ 绝对容差 | 归一化自由能标度（`×1e9`，物理不变）**或** `automatic_scaling` |
| §24 | 2D/3D 残差 `~dx^dim` ⇒ 假收敛；收紧容差 ⇒ 时间步崩 | 同上 | **`automatic_scaling = true`** |

**⇒ 两者是同一条规则**：
> **回归测试里必须要求 `|R0|` 与所用绝对容差同量级；最省事且稳健的做法是永远开 `automatic_scaling`。**
