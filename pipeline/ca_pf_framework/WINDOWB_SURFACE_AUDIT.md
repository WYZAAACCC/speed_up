## 0. 总体判定

**模型层不是 CA** ✅：状态量是**连续 level-set 函数** `φ_k(x)` + **连续体相场**（成分 `c`、弹性），
演化律是 **PDE**（`∂φ_k/∂t + v_n^k|∇φ_k| = 0`）与**界面条件**（Gibbs–Thomson / Stefan / McLean），
**没有"离散状态 + 局部规则同步更新"**（CA 的定义特征）✗。

**但"格点味"集中在 5 个离散化位置上**（下表 P1–P5）：它们不是模型，而是我**图省事**沿用格点原型的写法，
其中一条（界面面积）已量化出 **+52%** 的系统误差 ✗ ⇒ 必须换成几何（partial-volume / coarea）形式。

### P6 ★★ 速度扩展被我误删 —— 界面速度只有理论的 **13.8%**

上一轮我把 `extend_velocity()`（把界面速度沿法向复制到带上）删了，理由写成
"`v_n` 由带上的局部 κ 直接给出（处处光滑）；nearest-point 扩展是 O(dx) 近似 ⇒ 无必要"。
**这个理由错了。** 后果（孤球收缩，用**射线交点**量半径）：

| 配置 | `d(R²)/dt` / 理论 |
|---|---|
| **不扩展 + 1.5dx 窄带**（上一轮的默认）| **0.138** ✗✗ |
| 不扩展 + 8dx 宽带 | 1.014 ✓ 但带内 `|∇φ|` 爆到 4–5 ✗ |
| **扩展 + 6dx 带**（本轮默认）| **1.005** ✓ |

**机理**（两条都要懂）：
 - **窄带不扩展**：带外的 φ "不动" ⇒ 带边出折点且随时间累积 ⇒ 界面速度塌掉；
 - **宽带不扩展**：`v_n = −Mγκ ∝ 1/r` 在带内变化 ⇒ 剖面被**非均匀拉伸** ⇒ `|∇φ|` 爆炸；
 - ⇒ 只有"速度**沿法向为常数**（扩展）+ 足够宽的带"才让剖面更新成为**纯平移**
   ⇒ 保 SDF、保界面速度。这是 level-set 的标准做法，上一轮删错了。

实现与成本：`extend='edt'`（nearest-interface-point，默认）。EDT 在 96³ 上 ~100 ms/次 ×2
⇒ 每步 +330 ms；加 **`ext_refresh=5` 步索引缓存**（界面每步只走 0.02 dx）⇒ 步时 ~40 ms。
`extend='pde'`（沿法向延拓 PDE，局部）实测 0.916（延拓未完全传播）⇒ **不用**。
**多畴**同一处也要扩展（`LevelSetMulti.advance`），额外要求"只在本区域内传播"，
用 `karr == karr[最近界面胞]` 约束。

使 `iface` 覆盖全场 ⇒ 返回垃圾索引 ⇒ `karr==kat` 切掉一半更新 ⇒ 速度 0.25× ✗；
加 `not iface.all()` 守卫后 W2 恢复 **1.0000** ✓。

Herring 的 `a2` 比从 0.926（上风口径）升到 **1.002** ✓ —— 说明上一轮归因的
"一阶迎风 |∇φ| 的取向误差"其实**主要就是"不扩展"的带边效应**。

## 7. H6（三叉线 ΣJ_s = 0）与 H7（层间 Π 守恒）—— 2026-09-25

### 7.1 H6 查出的**真 bug**：面扩散用的是微分算子 ⇒ **根本不守恒**

`LevelSetMulti.update_Gamma` 里的面扩散原为 **Laplace–Beltrami 微分算子**（中心差分）：
它没有**通量结构** ⇒ `Σ A_c·ΔΓ ≠ 0`，"三叉线通量平衡 ΣJ_s = 0"在那种写法下**结构上不可能成立**。
（旧实现只在 A3 里验过"切向性"，**没验守恒** —— 这是漏掉的一条。）

**改法（保守边通量形式）**：
- 边通量 `J_ij = -D_s·A_e·sinθ_ij·(Γ_j-Γ_i)/dx²`，
  `A_e = ½(A_c(i)+A_c(j))`，`sinθ` = 边方向在切平面上的投影（由 winner 法向算）；
- 每条边只在 i、j 各记一次、符号相反 ⇒ **逐位守恒**；
- `sinθ→0`（纯法向相连）⇒ `J→0` ⇒ 不跨界面扩散 ✓；
- 三叉线处三支通量自然相加 ⇒ **ΣJ_s = 0 结构性成立**；
- 面积、交换、扩散**用同一个掩模** `m = (cell_area_geom>0)`（连通审计 §5.2 的老账）。
- ⚠ 量纲记账：第一版写成 `D_s·A_e/ℓ`（把**面积**当**边长**用）⇒ 有效 D 变成 `D_s·dx`，
  实测有效 `D_s/D_s = 1e-8 = dx` ✗；正确是 `D_s·A_e·sinθ/dx²`（修后 **0.9959** ✓）。
