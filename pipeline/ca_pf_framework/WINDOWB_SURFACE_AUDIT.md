## 0. 总体判定

**模型层不是 CA** ✅：状态量是**连续 level-set 函数** `φ_k(x)` + **连续体相场**（成分 `c`、弹性），
演化律是 **PDE**（`∂φ_k/∂t + v_n^k|∇φ_k| = 0`）与**界面条件**（Gibbs–Thomson / Stefan / McLean），
**没有"离散状态 + 局部规则同步更新"**（CA 的定义特征）✗。

**但"格点味"集中在 5 个离散化位置上**（下表 P1–P5）：它们不是模型，而是我**图省事**沿用格点原型的写法，
其中一条（界面面积）已量化出 **+52%** 的系统误差 ✗ ⇒ 必须换成几何（partial-volume / coarea）形式。

### P6 ★★ 速度扩展被我误删 —— 界面速度只有理论的 **13.8%**

上一轮我把 `extend_velocity()`（把界面速度沿法向复制到带上）删了，理由写成
"`v_n` 由带上的局部 κ 直接给出（处处光滑）；nearest-point 扩展是 O(dx) 近似 ⇒ 无必要"。
**这个理由错了。** 后果（孤球收缩，用**射线交点**量半径）：

| 配置 | `d(R²)/dt` / 理论 |
|---|---|
| **不扩展 + 1.5dx 窄带**（上一轮的默认）| **0.138** ✗✗ |
| 不扩展 + 8dx 宽带 | 1.014 ✓ 但带内 `|∇φ|` 爆到 4–5 ✗ |
| **扩展 + 6dx 带**（本轮默认）| **1.005** ✓ |

**机理**（两条都要懂）：
 - **窄带不扩展**：带外的 φ "不动" ⇒ 带边出折点且随时间累积 ⇒ 界面速度塌掉；
 - **宽带不扩展**：`v_n = −Mγκ ∝ 1/r` 在带内变化 ⇒ 剖面被**非均匀拉伸** ⇒ `|∇φ|` 爆炸；
 - ⇒ 只有"速度**沿法向为常数**（扩展）+ 足够宽的带"才让剖面更新成为**纯平移**
   ⇒ 保 SDF、保界面速度。这是 level-set 的标准做法，上一轮删错了。

实现与成本：`extend='edt'`（nearest-interface-point，默认）。EDT 在 96³ 上 ~100 ms/次 ×2
⇒ 每步 +330 ms；加 **`ext_refresh=5` 步索引缓存**（界面每步只走 0.02 dx）⇒ 步时 ~40 ms。
`extend='pde'`（沿法向延拓 PDE，局部）实测 0.916（延拓未完全传播）⇒ **不用**。
**多畴**同一处也要扩展（`LevelSetMulti.advance`），额外要求"只在本区域内传播"，
用 `karr == karr[最近界面胞]` 约束。

使 `iface` 覆盖全场 ⇒ 返回垃圾索引 ⇒ `karr==kat` 切掉一半更新 ⇒ 速度 0.25× ✗；
加 `not iface.all()` 守卫后 W2 恢复 **1.0000** ✓。

Herring 的 `a2` 比从 0.926（上风口径）升到 **1.002** ✓ —— 说明上一轮归因的
"一阶迎风 |∇φ| 的取向误差"其实**主要就是"不扩展"的带边效应**。

## 7. H6（三叉线 ΣJ_s = 0）与 H7（层间 Π 守恒）—— 2026-09-25

### 7.1 H6 查出的**真 bug**：面扩散用的是微分算子 ⇒ **根本不守恒**

`LevelSetMulti.update_Gamma` 里的面扩散原为 **Laplace–Beltrami 微分算子**（中心差分）：
它没有**通量结构** ⇒ `Σ A_c·ΔΓ ≠ 0`，"三叉线通量平衡 ΣJ_s = 0"在那种写法下**结构上不可能成立**。
（旧实现只在 A3 里验过"切向性"，**没验守恒** —— 这是漏掉的一条。）

**改法（保守边通量形式）**：
- 边通量 `J_ij = -D_s·A_e·sinθ_ij·(Γ_j-Γ_i)/dx²`，
  `A_e = ½(A_c(i)+A_c(j))`，`sinθ` = 边方向在切平面上的投影（由 winner 法向算）；
- 每条边只在 i、j 各记一次、符号相反 ⇒ **逐位守恒**；
- `sinθ→0`（纯法向相连）⇒ `J→0` ⇒ 不跨界面扩散 ✓；
- 三叉线处三支通量自然相加 ⇒ **ΣJ_s = 0 结构性成立**；
- 面积、交换、扩散**用同一个掩模** `m = (cell_area_geom>0)`（连通审计 §5.2 的老账）。
- ⚠ 量纲记账：第一版写成 `D_s·A_e/ℓ`（把**面积**当**边长**用）⇒ 有效 D 变成 `D_s·dx`，
  实测有效 `D_s/D_s = 1e-8 = dx` ✗；正确是 `D_s·A_e·sinθ/dx²`（修后 **0.9959** ✓）。

### 11.7 ★★ 更重要的结构性发现：**B1 的 f(T) 不能由"预置晶核 + 生长"给出**

长时刻扫描（`t_end = 4e-6` s，N=32）——`_t21b_scan3.csv`：

|---|---|---|---|---|---|---|
| `f`（`t = 4e-6` s）| 0.9610 | 0.9601 | 0.9618 | 0.9592 | 0.9780 |

给 0.9618 / 0.9674，仍在缓升但已近平）。

**为什么**（物理，不是数值）：12 个 Burgers 变体在自协调构型下 `sum_v dev(eps0_v) = 0`（已验，C4 = 3.3e-16）
⇒ **净本征应变相消 ⇒ 弹性能几乎不随 f 增长 ⇒ 驱动力不随 f 消失** ⇒ 任何正驱动都会把组织推到**几何饱和**
（12 个预置板条把域填满 ≈ 96%）。

⇒ **结论（改变 B1 的路线）**：
1. **`f_eq(T)` 不能从"预置晶核 + 生长"的 RVE 里测出来** —— 那测到的是**几何饱和**，不是热力学平衡。
2. 因此 **`alpha'_prime` 的分数 vs T 只能由"athermal 形核"给出**；而形核在 HYBRID_FRAMEWORK §8 item 4 里
   明确是**输入**。两条可走的路：
   (a) **把 KM/Koistinen 当输入模型**（`alpha_KM` 取文献值），模型只负责"给定 T 历史 -> 形核数密度"；
   (b) 显式建 **`N_v(T)`**（Greer 判据或自催化），再由 PF/level-set 长大到该数密度对应的分数。
3. `windowB_km.py` 的解析部分（`dG_chem` / KM / `fit_alpha` / DS 带）对两条路都直接可用；
   缺的是"**形核**"这一层（也是 T2.1b 真正该补的东西）。

### 11.12 ★ 根因（量级论证）：**相容板条没有"生长停止"机制，而生长又慢于冷却**

1. 每个晶核的法向取的是**弹性最省能法向**（`npref`，与 M2 同一做法）⇒ 板条与母相近似**rank-1 相容**
   ⇒ 自身弹性能 ~= 0 ⇒ **没有背应力**；12 变体自协调又让**净本征应变相消**（C4 = 3.3e-16）
   ⇒ 也没有宏观背应力 ⇒ **驱动力不随 f 减小** ⇒ 生长不停。
2. 更本质的一条**区制**问题：**生长时间 vs 冷却时间**
   `t_g ~= v_0/(v A)`（A = 界面面积）；取 `v = M|dG| = 1e-9 x 7e8 = 0.7` m/s、
   `A ~= 1e-14` m^2、`v_0 ~= 1e-20` m^3 ⇒ **`t_g ~= 1.4e-5` s**，
   而本轮 `t_cool = 3e-7` s ⇒ **生长比冷却慢 50 倍** ⇒ 处在该"慢生长"区制里，f 是**动力学**量。
   真实马氏体板条长大是**无扩散、声速量级**（~ns），远快于冷却（~ms）⇒ 真实材料在"**快生长/athermal**"区制，
   f(T) 只由**形核**定（这正是 KM 的物理前提）。
3. 要进"快生长"区制，需要 `M|dG| t_cool/dx >> 1` ⇒ 在本 RVE 的 CFL 步数下要
   **~1e4–1e6 步**（当前 ~300–2200 步）⇒ **当前算力下不可达**（如实记账）。

### 11.13 结论（B1 的分数该怎么处理）—— **路线改定**

1. **`alpha'` 的分数 vs T 在本模型里是纯动力学的**：对**给定热循环**它是确定的、可复现的
   （scan2 的"同一时刻 f 随驱动单调增"✓），但**不退化成一个只依赖 T 的定律**（KM），
   除非满足 11.12 的"快生长"区制。
2. ⇒ **走 KM-as-input**（这正是 HYBRID_FRAMEWORK §8 item 4「形核/分数是输入」的落地）：
   `f(T) = 1 - exp[-alpha_KM (M_s - T)]`，`alpha_KM` 取 **[A] 占位 + 敏感度带**
   （`5e-3 / 1.1e-2 / 2e-2` K^-1，【未核实】，需检索 Ti64 值）。
   **PF/level-set 的职责**改为：给定分数下的**形貌**（板条/集束/变体选择）+ **T 依赖驱动力**。
3. ⇒ 已实现并验证的部件**保留可用**：`windowB_km.py`（`dG_chem(T)` / KM / `fit_alpha` /
   `T0_from_Ms` / DS 带 / `N_target`）、`windowB_b1.py`（athermal 形核驱动、
   `f_target='KM'` 控制模式、autocatalytic 变体选择）、判据 T2.1b-7（符号约定）与 T2.1b-8a/8e（指纹）。
4. **仍然是真的（可以引用）的结论**：`M2` 改符号前的 `f_trans` 作废；athermal 指纹成立
   （保温不新增晶核）；`df > 0` = 变体有利；f(T) 是动力学量（不是热力学平衡量）。
