而 `C4`/`G4` 的 `step 0` 是 **`Vt=1.95e-21`、`nf3=0`、`nslab=1`**（**几乎空**）

### 1.2 根因
我第一版长程命令**直接调 `_bk_exp.py`**，只写了 ~14 个参数，
而 `_t11_facet_arm.py:86-105`（`C4`/`G4` 用的启动器）传了**一整套**，

```
--nuc-shape disc --grow-stack                      # 播种形态 + 堆叠生长

--qs-clock 1 --qs-max-relax 100 --ed-eta 0.253
--gamma0 0.25 --gamma-film 0.6 --alpha-km 0.041739 --T-end 298 --cool-rate 2352400
--rank1-swap none --var-rule ed --nuc-sites-refill 1
--every 25 --snap-every 25 --pair-every 200
```
**⇒ 播种行为完全不同** ⇒ 两臂的动力学不可比 ⇒ **该轮（`B2L_pre`/`B2L_post`）作废**。

### 1.3 处置

**⇒ 教训（`P8`/`P18` 的又一次实例）**：**跨臂比较前必须先核"第 0 行是不是同一个意思"。**

## §2 ✅ 一个**撤回的担心**：`C4` 的 `F3` 面片**没有**坍缩

### 2.1 我担心什么
`B2L_pre` 的日志显示 `nf3` **3036 → 13**、`nslab` **6 → 1**
⇒ 我担心**此前所有 `Λ` 读数（含 `C4 = 8.03`）测的是"一整块 vs 腔"而不是"单根板条"**。

### 2.2 实测（`_b2_f3chk.py`，**逐臂核实**）

| 臂 | `nf3_col` 轨迹（step 0→末） | `F3` 面积（µm²） | `nslab` | 判定 |
|---|---|---|---|---|
| **`C4`** | 0 → 1 → 2 → **3** | 0 → 0.41 → 0.72 → **2.88**（@300） | 1 → **4** | ✅ **生长、面片增加** |
| **`G4`** | 0 → 0 → 1 → 2 → **3** | 0 → 0 → 0.40 → **1.39**（@300） | 1 → **4** | ✅ **生长** |
| `B2L_pre` | 5 → 2 → 1 → **0** | 7.18 → 4.71 → **0.02** | 6 → **1** | ⛔ **坍缩（作废臂）** |

**⇒ ✅ `C4`/`G4` 的 `nslab` 从 1 **增长到 4**、`F3` 面片数 **增长到 3**、面积 **增长到 2.9 µm²**
⇒ **它们是**健康生长**的，没有坍缩**
⇒ **我上一条的担心**撤回**：`Λ = 8.03` 的读数解释（PCA 主轴比）**仍然有效**。**
**⇒ 且坍缩只出现在**作废的那个臂**上** ⇒ 更说明它是配置错误造成的。

### 2.3 ⚠ 但仍要记一条口径提醒
`B2L_pre` 的坍缩说明：**在某些配置下 `F3` 面片会整体消失** ⇒
**任何 `f_flat` / `Λ` 读数都必须**先报当时的 `nf3` 与 `F3` 面积****，
否则无法判断"读数是在有面可测的时候取的"。**⇒ 建议加入口径清单。**
