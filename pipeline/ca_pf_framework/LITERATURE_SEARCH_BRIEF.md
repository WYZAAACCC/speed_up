## §0 三条纪律（请务必遵守，否则数据不可用）

1. **每一个数必须带五件套**：`材料` + `工艺` + `状态` + `测量方法` + `口径`。
   例：「Ti-6Al-4V / LPBF / as-built α′ / 2D BSE 金相 / 线性截距法（平均弦长）」。
2. **凡原文用词含糊的，请照抄原句，不要替它解释。** 我们已经被坑过两次：
   同一篇 Shuai 2026 对**同一次测量**先叫 `lath width` 后叫 `lath thickness`。
3. **2D 截面上量到的"宽/厚"必须标注是 2D 表观值。** 一个 2D 截面物理上
   **无法分开「宽」与「厚」**（随机截面采到的是弦长）——这是本项目的硬结论。

> **如果您有高校/研究所的图书馆权限**（Elsevier ScienceDirect、Springer、Wiley 全文），

## §3 ★★★ 物理前提：决定 `β_h` 该加在哪根轴上（**本项目最大的未决项**）

> 背景（一句话）：我们把 β→α′ 的形状应变做 rank-1 分解，得到**两个**数学上等价的解，
> 分别给出「惯习面法向」与「长轴」。代码必须二选一。实测**两个解的弹性自能只差 8.6%**
> ⇒ **能量判据没有分辨力**，所以只能靠**晶体学**定。这件事**不能由仿真自证**。

### 3.1 β→α′ 的**惯习面**（在 β 母相坐标系里的 Miller 指数）

- **要什么**：
  1. Ti-6Al-4V（或纯 Ti）β→α′ 马氏体的**惯习面**实验报道值，**必须明确是在哪个坐标系**：
     **β(bcc) 母相坐标系** 还是 **α′(hcp) 子相坐标系**。两者不能混。
     （常见报道形如 `{3 3 4}_β` 或 `{10 5 5 3}_α′`，请把原文写的那个抄下来。）
  2. **方法**：TEM 迹线分析 / 双表面迹线 / PTMC 计算 —— 请注明。
  3. **bcc→hcp 的 Burgers 取向关系**下，惯习面与母相 `{110}` 的关系。
- **检索词**：`habit plane` AND (`Ti-6Al-4V` OR `titanium`) AND (`martensite` OR `alpha prime`) AND (`beta` OR `bcc`)；
  `{334} habit plane titanium martensite`；`crystallographic theory martensite titanium habit plane`；
  `马氏体 惯习面 TC4 钛合金 β 相`。
- **为什么**：这是我们判定「两个 rank-1 解，哪个是宽面法向」的**唯一可用判据**。

### 3.2 β→α′ 的 **PTMC / 不变平面理论计算**

- **要什么**：任何一篇对 **Ti-6Al-4V 或纯 Ti 的 β→α′** 做**现象学晶体学理论（PTMC/WLR/BM）**
  计算的论文，需要它给出的：**惯习面法向**、**切变方向**、**切变量**、**形状应变张量**。
- **为什么**：如果有现成的 PTMC 结果，我们可以**直接与我们的两个 rank-1 解对比**，
  一次定案；并且可以把「`a·n = trace(ε) = 0.127` 是否合理」也一起校核。

### 3.3 α′/α 板条**横截面**的宽:厚比（有没有人真的量过？）

- **要什么**：任何证据表明板条的**横截面不是方形**（即 `宽 ≠ 厚`）。可接受的证据形式：
  - 同一批试样**两个正交截面**分别测量（如沿/⊥ 建造方向）；
  - TEM 箔面已知时，同一板条在**箔面内**与**投影方向**的表观尺寸；
  - 任何形如「板条是**带状/矩形截面**」的定量陈述。
- **状态**：我们的结论是「**在已检索范围内不存在**」，但**没有找到反例 ≠ 不存在**。
  已知唯一真正的三维测量是 DeMott 2020（plasma-FIB 3D-EBSD，**E-PBF/EBM**，非 LPBF），
  而它**没有报告任何定量三维板条宽度**。
- **⛔ 请不要给**：钢的板条马氏体（如 Rezazadeh / Morito）、EBM/DED/锻造/热处理态、
  TA15 或其他钛合金。**跨材料/跨工艺的数我们一律不能用。**

### 3.4 `M(n)` 各向异性指数 β 的**同材料同工艺**锚点

- **背景**：模型用 `M(n) = M0 · exp[−β_h (n·n*)² − β_w (n·w)²]`，取 `β_h = 3.5`、`β_w = 2.3`。
  其中 `β_h` 是「Ti-64 位错环能量 ⇒ 3.8」与「无出处的 10–30 ⇒ 3.0」的混合；
  `β_w = 2.3` **完全建立在无归属输入上**。
- **要什么**：任何**独立的、有出处的**量，能约束
  「板条**厚向**长大速率 / **面内**长大速率」之比，或
  「界面位错迁移率随界面取向的**各向异性指数**」。可以是：
  - 板条**长:厚**与**长:宽**的同工艺实测（**同篇！**）；
  - 分子动力学/位错动力学给出的界面迁移率随取向的比值；
  - 马氏体长大动力学的理论式里形如 `exp(−β cos²θ)` 的指数取值。

## §4 ★ 初始条件与盒子尺度（回答"盒子要多大"）

### 4.1 **block / packet / colony 的尺寸**（LPBF Ti-64 as-built α′）

- **要什么**：prior-β 晶粒内 **block / packet / colony** 的**特征尺寸**（µm）或**分数**。
- **为什么**：我们目前的单板条隔离算例里，**板条长度由盒子决定，而真实材料里由"碰头"决定**。
  不知道 block/packet 有多大，就**无法决定 RVE 盒子该多大**，也无法判断
  「板条长 8 µm」这个靶在单板条算例里到底有没有意义。
- **状态**：已知检索**只找到定性描述**（"basket-weave structure"，无尺寸）。
  这是本项目一个**明确的空白**。

### 4.2 马氏体板条形核胚的**特征尺寸**

- **要什么**：Ti-64 α′ 形核的**临界核 / 操作核**尺寸的证据（实验或理论）。
- **为什么**：我们现在的种子是 `R = 500 nm, t = 700 nm`，
  而临界半径 `r* = 2γ/Δf ≈ 0.86 nm` ⇒ **种子比临界核大约 583 倍**，
  这个取值**目前没有任何出处**，是人为选的。需要文献支撑或明确记为假设。

### 4.3 β→α′ 的**驱动力 ΔG(T)**

- **要什么**：Ti-6Al-4V β→α′ 的**化学驱动力**随温度（尤其 298 K 与 M_s 附近）的
  可靠热力学值（J/m³ 或 J/mol）。我们现用 `Δf = 3.5e8 J/m³`（= 室温值）。
- **为什么**：它是长大速率的**线性**因子，直接决定"多快长到 8 µm"。
