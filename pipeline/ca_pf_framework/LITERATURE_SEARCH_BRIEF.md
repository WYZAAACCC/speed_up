## §1 背景（为什么需要这些数据）

我们在做一项**介观尺度的数值模拟**：模拟 **Ti-6Al-4V 经激光粉末床熔融（LPBF，亦称 SLM）
成形后，在打印态（as-built）下发生的 β → α′ 马氏体相变**。

要点如下：

1. **α′ 马氏体以「板条（lath）」的形式出现**——一种**又长又薄又窄的片状**组织。
   一根板条有**三个特征尺寸**：**长度（最长）、宽度（次之）、厚度（最薄）**。
   三者大致呈「细长薄片」的比例。

2. 我们的模型里，**界面推进速度取决于界面朝向**：沿板条**长度**方向推进最快，
   沿**宽度**方向较慢，穿过**厚度**方向最慢。这个"各向异性"由两个模型参数控制。
   ⇒ 因此我们**需要知道真实板条的三个尺寸之比**，用来标定和检验这两个参数。

3. 板条的**厚度方向**在晶体学上不是任意的：它等于相变的**惯习面法向**
   （即马氏体片与母相 β 之间那个平直界面的法向，通常写作某个晶面指数，例如 {3 3 4}_β）。
   ⇒ 我们**需要 β→α′ 惯习面的实验测定值**，而且必须知道它是在**母相 β 的坐标系**里
   还是在**子相 α′ 的坐标系**里给出的（这两个坐标系不能混用）。

4. **一个关键困难**：目前我们看到的文献，板条尺寸**几乎全部来自 2D 抛光截面的金相/SEM/EBSD 测量**。
   一个 2D 截面**物理上无法把「宽度」和「厚度」分开**——截面切过去得到的是**弦长**，
   既不是真宽度也不是真厚度。所以文献通常只报**两个**表观尺寸（一个长的、一个短的），
   而我们的模型有**两个**待定参数 ⇒ **约束不足**。
   ⇒ 因此我们特别需要：**A 组**（能同时给长与短的**同一篇**研究、以及任何**真正三维**的测量）、
   以及**B 组**（能证明板条横截面不是方形的证据）。

5. 另外，真实材料里板条的**长度**并不是自由长出来的，而是被同一区域内相邻板条**互相碰头**截断的。
   这个"碰头"的尺度由 **block / packet / colony（马氏体变体集团）的尺寸**决定。
   ⇒ 我们需要 **C 组**：变体集团的尺寸，用来判断我们的计算区域该取多大。

#### A-1 ★  Xie et al. 2026 的**补充材料（Supplementary）Table S1**

- **出处**：*Materials* **19**, 1945 (2026)，doi **10.3390/ma19101945**（PMC13208675）
- **要找什么**：
  1. **补充材料 Table S1 的原始逐条数据**：该文对 10 个试样各随机测了 50 条 α′ 板条
     （共 500 条）。正文 Table 2 只给了 10 个**平均值**；
     **我们需要每条板条的 length（长）与 width（宽）的原始数值列表**（有分布才能做统计检验）。
  2. **该文对 "length" 与 "width" 的测量定义**：是"单条板条的最小外接矩形"？
     是"沿长轴的截距"？是手工在 ImageJ 上画的？**正文里没有写**，请查正文方法节、
     图注、以及补充材料。**若确实没有定义，请明确回一句「论文未给定义」**——
     这本身对我们是有效结论。
  3. **顺便核对一个可疑参数**：该文写的扫描速度是 **90 mm/s**（190 W、层厚 30 µm、扫描间距 140 µm）。
     按此计算能量密度约 503 J/mm³，比 LPBF Ti-6Al-4V 的常见值高 6–10 倍。
     **请核对 PDF 原文到底是 90 还是 900 mm/s。**
- **为什么需要**：这是我们找到的**唯一一篇**同材料、同工艺、打印态、**未做长度预筛**、
  且**同时给出长与短两个尺寸**的研究。它给出 2D 长:短 = 16.7–23.8（均值 20.9）；
  而 Wang et al. 2026（见 A-2）给 9.0。**两篇相差 2.3 倍。**
  没有原始分布与测量定义，我们无法判断该采信哪一个，也无法复现这个测量。

#### A-5 ★★★  任何**真正三维**的板条尺寸测量

- **要找什么**：对 **LPBF/SLM Ti-6Al-4V 打印态 α′（或 α）板条**做过**真三维**测量的研究。

### B 组 ★★  横截面形状：板条截面是不是方形？（宽度 ≠ 厚度？）

- **要找什么**：任何能表明板条**横截面不是方形**（即**宽度 ≠ 厚度**）的**定量**证据。
  可接受的形式：
  1. **同一批试样做两个正交截面**分别测量（例如平行于建造方向 / 垂直于建造方向切取）；
  2. **TEM 观察**，且明确说明观察面相对于板条取向，能区分面内尺寸与投影尺寸；
  3. 任何形如「板条呈**带状 / 矩形截面**，宽厚比约 X」的**定量**陈述。
- **需要的数据**：宽 : 厚 的比值，或两个正交截面各自测得的短尺寸，**含单位、样本数、方法**。
- **为什么需要**：如果板条截面是方形，那么我们模型里的两个各向异性参数就退化成同一个，
  文献只需约束一个量；如果不是方形，就必须有两个独立的约束。
  **这决定了我们的模型参数可不可以被文献唯一确定。**
- ⛔ **请不要给钢的板条马氏体数据**（如 Rezazadeh、Morito 的工作）、
  也不要给 EBM/DED/锻造/热处理态的数据——**跨材料、跨工艺的数据我们一律不能用**。

### C 组 ★★  板条长度的"截断尺度"：block / packet / colony 的尺寸

- **要找什么**：在 **LPBF/SLM Ti-6Al-4V 打印态**的单个 prior-β 晶粒内，
  **block（同变体集团）/ packet（同惯习面族集团）/ colony** 的**特征尺寸（µm）**或**体积分数**。
- **需要的数据**：尺寸数值（均值/范围/分布）+ 统计方法 + 样本数 + 测量面（2D 还是 3D）。
- **为什么需要**：真实材料里板条的长度是由相邻板条**互相碰头**截断的，
  这个尺度就由 block/packet 的大小决定。我们需要它来判断：
  **我们的计算区域（目前边长几微米）是否小到无法容纳一根完整板条。**
  （我们已检索到该材料"形成 basket-weave 结构"的**定性**描述，
  但**没有找到任何 block/packet/colony 的尺寸数值**。）

### D 组 ★  相变晶体学与热力学（决定模型里"哪个方向是厚度方向"）

#### D-1 ★★★  β→α′ 的**惯习面**（在明确的坐标系下）

- **要找什么**：
  1. Ti-6Al-4V（或纯 Ti）β→α′ 马氏体**惯习面**的**实验测定值**，
     **必须明确标注是 β(bcc) 母相坐标系还是 α′(hcp) 子相坐标系**。
     常见写法如 `{3 3 4}_β` 或 `{10 5 5 3}_α′`——**请照抄原文的写法与坐标系**。
  2. **测定方法**：TEM 迹线分析 / 双表面迹线法 / 理论计算。
  3. 若同一篇里还给了 **Burgers 取向关系**下惯习面与母相 {110} 面的关系，也请一并抄下。
- **为什么需要**：我们的模型必须确定"厚度方向 = 哪个晶向"。
  我们在数学上有**两个等价的候选解**，而它们的能量只差 8.6%，
  **无法用能量判据区分**，只能靠晶体学实验数据来定。
  **这是我们目前最大的一个未决问题。**（检索词建议：`habit plane` + `Ti-6Al-4V` +
  `martensite` / `alpha prime` + `beta`；中文：`马氏体 惯习面 TC4 钛合金 β 相`。）

#### D-2 ★★  β→α′ 的**现象学晶体学理论（PTMC）计算**

- **要找什么**：任何对 **Ti-6Al-4V 或纯 Ti 的 β→α′** 做过 **PTMC / WLR / BM 理论计算**的论文，
  需要它给出的：**惯习面法向**、**切变方向**、**切变量**、**形状应变张量**。
- **为什么需要**：若有现成的理论结果，我们可以直接与自己的两个候选解逐一对照，一次定案。

#### D-3 ★  马氏体板条**形核胚**的特征尺寸

- **要找什么**：Ti-6Al-4V α′ 马氏体**形核的临界核或操作核尺寸**的证据（实验观测或理论估算）。
- **为什么需要**：我们模拟时放了一个初始晶核（半径 500 nm、厚 700 nm），
  而按我们的参数估算临界半径只有约 **0.9 nm** ⇒ 我们的核比临界核大约 **580 倍**，
  **这个取值目前没有任何文献依据，是人为设定的**。需要文献支撑，或明确记为假设。

#### D-4 ★  β→α′ 的**化学驱动力**（热力学）

- **要找什么**：Ti-6Al-4V β→α′ 相变的**化学自由能差**随温度的关系，
  尤其需要 **室温（约 298 K）**与 **M_s（马氏体开始转变温度）附近**的数值。
- **需要的数据**：数值（J/m³ 或 J/mol）+ 温度 + 计算方法（CALPHAD / 文献评估 / 实验反演）。
- **为什么需要**：它是板条长大速度的**线性因子**，直接决定"多快能长到 8 µm"。
