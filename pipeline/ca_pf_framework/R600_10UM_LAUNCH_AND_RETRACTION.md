## 1. ❗ **撤回**：那个「10 倍疑点」是我自己的读数错误

我曾报「同一行里 `Vt = 2.4005 µm³` 而 `Σvols = 24.0047 µm³`，恰好差 10 倍」。

**物理恒等式当场否掉了它**：`V0`(母相) + `Vt`(马氏体) 必须 = 盒体积。

```
step 2260:  V0 = 1.00995e-16 m³ = 101.00 µm³
            Vt = 2.40046e-17 m³ =  24.00 µm³
            V0 + Vt = 1.25e-16 m³ = **125.00 µm³**  ← 与 5 µm 盒体积**逐位吻合** ✓
            Σvols / Vt = **1e+18**（两列刻度一致）✓
```

**错因（我的量具用错，不是引擎错）**：打印时写了 `(Vt or "")[:9]`，
把字符串 `2.400463867187501e-17` 截成 `"2.4004638"` —— **把指数 `e-17` 切掉了**
⇒ 把 m³ 当成了 µm³ ⇒ 凭空造出一个 10 倍差。

**⇒ 反向收获（强验证）**：`V0 + Vt = L³` 在末态**逐位成立** ⇒ **体积量具可信**；
我先前用它算的成熟板条体积（`Σvols` 口径）**站得住**，不需要重算。

**教训（与 `AGENTS.md` §3.1/§7.5 P28 同源）**：**截断字符串当读数**是新的量具陷阱一类。
规则：**凡数值列，一律 `float()` 后按物理恒等式自检，不做字符串截断显示**。
