## P0-1 —— 弹性驱动力符号反了

### 现象

`LevelSetMulti.elastic_driving()` 返回 **`ed = −ε⁰_v : σ`**，却被当成**驱动力**
（与 `df` 同一符号约定：正 = 该变体有利）加进

```python
# windowB_surface.py:1343
dG_cell = (self.df[karr] - self.df[larr]) + (edk - edl) - stk * kap_cell
```

### 正确值（变分法）

对 `F_el = ½∫(ε−ε⁰):C:(ε−ε⁰)`，机械平衡下 `δF_el/δφ_v = −ε⁰_v:σ`；
演化 `∂φ/∂t = −L δF/δφ` ⇒ **驱动力 = `+ε⁰_v:σ`**。
（同族的 `PF3D.dfdphi()+step()` 合成出来的正是 `+ε⁰:σ` —— **对的**；
`PF3D.forces()` 与 `LevelSetMulti.elastic_driving()` 是 `−ε⁰:σ` —— **反的**。
外载项 `sext_e0 = +σ_ext:ε⁰` **符号是对的** ⇒ 这是内部弹性项**单独**写错。）

### 证据【实测】

`_audit_edsign2.py`（有限差分能量释放率，与代码约定无关）：

| 单变体球 R=120 nm | free | **−9.7581e+07** | **+1.6024e+08** | **−1.64** |
| 平板（法向 ẑ） | clamped/free | **精确 0**（加厚不改变 `E_el`，6 位有效数字） | **+1.5e8** | — |

> 比值 1.6 而非 1 可解释：面积用格点键测度，审计已实测对球 **+51.9%** ⇒

## P0-2 —— `M(n)` 的 β 标定公式错（漏了 Wulff 凸化）

### 现象

`LATH_FACET_PLAN §9.3/§10.2` 用

```
长/厚 = e^{β_h},   长/宽 = e^{β_w},   宽/厚 = e^{β_h − β_w}
```

反推 β，并声称"两条独立路径（位错环形成能 3.8 / 观测长径比反推 3.0）互校自洽"，
取 **β_h = 3.5、β_w = 2.3**。

### 为什么错

level-set 的 `∂φ/∂t + v(n)|∇φ| = 0` 是 Hamilton–Jacobi 方程，
其黏性解是 **Huygens 包络**，渐近形状是 `v(n)` 极图的 **Wulff 形（凸包）**，**不是极图本身**。
对 `v(n)=C·exp[−β_h(n·n_hab)²−β_w(n·w)²]`：

* 极图在 `n_hab` 附近**非凸**（2D 凸性判据 `r²+2r'²−rr'' = r²[1+β²sin²2θ−2βcos2θ]`，
  在 θ=0 处 = `r²(1−2β)`，**β>0.5 即为负**）；
* Wulff 凸化把它换成**平面刻面**，支持函数由"肩部"决定：
  `h(n_hab) = max_u e^{−β_h u²}·u = e^{−1/2}/√(2β_h)`（在 `u=1/√(2β_h)` 处取到）。
  `h(ŵ)` 同理（最优方向朝**便宜方向 a** 倾斜）。

**闭式**：`h(a)=1`，`h(ŵ)=e^{−1/2}/√(2β_w)`，`h(n_hab)=e^{−1/2}/√(2β_h)`

```
长/厚 = √(2β_h)·e^{1/2} = 2.3316·√β_h          （而不是 e^{β_h}）
```

### 证据【实测】

`_audit_wulff.py`（40 万方向 + `scipy.spatial.ConvexHull`；闭式与 3D 凸包**逐位吻合** ≤1e−3）：

| β_h, β_w | Wulff 半宽 [a,w,n] | **长/厚** | 长/宽 | 宽/厚 | 朴素 e^{β_h} |
|---|---|---|---|---|---|
| **3.5, 2.3（现生产）** | 0.9999, 0.2828, **0.2292** | **4.36** | **3.54** | 1.23 | 33.1 |
| 6.0, 2.3 | 0.9999, 0.2828, 0.1751 | **5.71** | 3.54 | 1.62 | 403.4 |
| 20, 10 | 0.9998, 0.1356, 0.0959 | 10.43 | 7.37 | 1.41 | 4.9e8 |
| 115, 18 | 0.9996, 0.1010, 0.0400 | **25.00** | 9.89 | 2.53 | 8.8e49 |

**与实测对照**（这才是关键）：

| 量 | Wulff 渐近（β=3.5） | `_chk_single_lath` 实测 | 出处 |
|---|---|---|---|
| 长/厚 | **4.36** | **4.19 / 4.17 / 4.87 / 5.51**（β_w=5） | `LATH_FACET_PLAN §10.1/§10.4` |
| β 3.5→6.0 增益 | 4.36→5.71（**+31%**） | 3.99→5.01（**+25%**） | §10.1 |

⇒ **§10.4 的"长/厚 卡在 ~4-5 是时间不够还是内在饱和"有确定答案：内在饱和，
且饱和值可解析预测、与仿真参数无关。**

### 影响面

* **β 的标定依据作废**：§9.3 的"两条独立路径互校自洽"是错公式造成的**假象**。
  （位错环给 β≈3.8；用正确公式反推观测长径比 10–30 需要 β≈18–165。二者**不再自洽**。）
* **"M(n) 能把板条做到 10–30"这个期望作废**（在 β~10⁰ 量级下**不可能**）。
  ⚠ 但 **"M(n) 实现正确且确实生效"这条结论仍然成立** —— 已由 `_audit_faces.py` 独立证实
  （干净盒子里三面推进速度 n:w:a 实测 1:3.0:28 vs 设计 1:3.31:33）。
* **所有以"长/宽/长/厚"判定 M(n) 效果的归档结论**需重读（D8/D9/D11、G0/G5/G9/Gx/GF、
  V0/V35/V60、§10.4 双轴表、§13 LR1/LR2、`_prodmob_*` 的 M4/M6p）。

### 修法（**需要用户拍板**，见 `WINDOWB_FRAMEWORK_REVIEW.md` §8）

M(n) 的光滑指数形式**在框架上给不出板条**（要 β~10² 才够，已远离任何物理推导）。
正解方向：**近奇异/尖点的界面本构**（在一个小角窗内 M→0 或 γ 有尖点 + Wulff 构造），
即"平面刻面 + 尖边" —— 与 §7.4/§1-①b 当年对 `γ(n)` 的直觉一致，
只是当年把它换成 `M(n)` 时没把凸化的账一起搬过来。

## P0-3 —— `reinitialize(mode='pair')` 把 `|∇φ_k|` 往 0.5 以下推

### 现象

`reinitialize(mode='pair')`（**EXPERT-#3 之后是默认**）对差分场 `d = φ_k − φ_l` 做 Sussman，
目标是 `|∇d| → 1`，再对称回写：

```python
# windowB_surface.py:1747-1754
dn = self.sussman_reinit(d)
corr = np.where(near, dn - d, 0.0)
...
delta[k] += 0.5 * corr
delta[l] -= 0.5 * corr
```

### 为什么错

对一个正常的 VDF，界面两侧 `∇φ_l ≈ −∇φ_k` ⇒ **`|∇d| ≈ 2`**，不是 1。
把 `|∇d|` 驱到 1 ⇒ **`|∇φ_k| → 0.5`**，并在反复 reinit 中越推越小。

### 证据【实测】

`_audit_faces2.py`，**单因素对照**（同算例、只改 `reinit_every`）：

| step | `median|∇φ_winner|`（带内），reinit=0 | **reinit=25** |
|---|---|---|---|
| 20 | 0.867 | 0.867 |
| 40 | 0.826 | **0.455** |
| 80 | 0.807 | **0.208** |
| 120 | 0.853 | **0.189** |
| 160 | **0.958** | **0.157** |
| 带胞数（`|φ|≤2dx`）@160 | 7824 | **20871** |

代码自己就在报警：`windowB_surface.py:1524: pair reinit: band |grad d| median=1.975 …`；
`_BUN_N1/N3/N5.log` 里一路降到 **0.134–0.16**（⇒ `|∇φ| ≈ 0.07–0.08`，几何带**虚增 ~13 倍**）。

### 后果（都是静默的）

* 一切以 `|∇φ|` 计的**几何量**（`cell_area_geom` 的 `A_c=|∇φ|dx²/3`、`S_v`、
  板片厚 `t=2f/S_v`、面 Γ 的摩尔↔面积换算）**系统性偏小**；
* `iface = |φ_winner| ≤ 2dx` 选中的**物理带厚**从 2 胞膨胀到 ~13 胞
  ⇒ EDT 延拓的"最近界面胞"语义被改变；
* `band_health` 的 `median|∇φ| < 5` 判据**挡不住**（0.15 ≪ 5）。

> 注意区分：level-set 的**零等值面速度**对 `|∇φ|` 的**均匀**缩放不敏感
> （`Δφ/|∇φ| = dt·v`），所以这不是"速度被砍半"这么简单；
> 但**非均匀**的 `|∇φ|` 会让剖面不再纯平移、并让**一切几何测度**失真。

### 影响面

* **所有 `reinit_every > 0` 的算例的几何量**：`S_v`、板片厚、`f` 的绝对值判读，
  以及 `M3/M4/M6/M6p` 的**绝对**读数。
* 需逐个确认的算子级判据（它们多数把 reinit 关掉或用固定界面）：
  `_chk_h6`、`_chk_w6`、`M3`、`M4`、`_chk_a3`、`_chk_w2`、`_chk_p1` —— **【未核实】**。
* **不受影响**：`_audit_faces.py`（`reinit_every=0`）得出的"三面速度比 = 设计值"这条。

### 修法

1. **最小修**：差分场的重初始化目标应为 `|∇d| = |∇φ_k| + |∇φ_l|`（VDF 下 = 2），而不是 1。
2. **或**回到"逐 `φ_k` 重初始化 + 约束 `k–l` 零等值面"的方案。
3. **无论选哪个**：把 `|∇d|` 偏离断言从 `mooseWarning` 式告警升级为**硬失败**。

|---|---|---|

| D3b | `median|∇d|` 稳定在 **2 ± 0.1** | 每步 |
