# R595 —— 量具修正 s297 + **撤回**「新的形核不是板条状的」

> 日期：**2026-10-04** ｜ 触发：s296 之后 `t5ETAo` 打印出一族「厚度 ≈ 4.2 µm」的场
> 结论：**那是量具伪影，不是物理**。视觉反证已给出。**按纪律撤回，不抹掉。**

---

## 1. 缺陷（**标签错，而 `_bk_measure.py` 早已写明**）

`_bk_exp.py:3193/3199` 打印：

```python
'厚度(在位的场) %s nm | ...'
% (..., ' '.join('%d:%.0f' % (k, mm['n_%d' % k] * 1e9) ...), ...)
```

而 `_bk_measure.py:176` 白纸黑字写着：

> `n_%d`（= `ths`，板条胞沿 `n*` 的**包围盒跨度**）**不是板条厚度**：
> 实测 `mb1s` 场 1 的包围跨度 624 → **2631 nm**（1500 步），
> 而由 φ 量出的**两张宽面之间的距离**只有 780 → **732 nm**（−48 nm）。
> ⇒ 包围跨度被**碎片**与 **`n*` 与真实板条法向的夹角**撑大。

⇒ **标签错**，而**碎片化会把包围盒撑满整个盒子**。

## 2. 我上过当（**撤回**）

s296 之后实测：

```
厚度(在位的场) 1:510 162:5944 185:3913 nm
```

**`5944 nm` 比 5.0 µm 的盒子还大 ⇒ 物理不可能值** ⇒ 当场可判是量具问题（这是最快的判据）。
我上一轮据此报了「**新的形核不是板条状的**」。

### ⇒ **撤回该结论。** 证据两条：

**① 视觉反证**（`_t5_split3d2.py t5ETAo 162 40` → `_w2_t5_split3d_t5ETAo_f162_en.png`）：
场 162 的**主体是一张干净的薄板**（2488 胞，`pieces=3`，主体 74%）
⇒ **形核是板条状的** ✓

**② 物理不可能值**：`n_k > L_box` ⇒ 不可能是"厚度"，只能是"包围跨度"。

### 改判
`n_k` 大 ⟺ 该场**碎片化严重**（或 `n*` 与真实法向夹角大）
⇒ 它其实是一个**对碎片化很敏感的代理量**，**只是标签必须改**。

## 3. 修法（`_t5_patch_thlabel.py`，**纯标签、零数值改动**）

```python
'厚度(在位的场) %s nm | 壁=%d | %.2fs/步'
→ '包围跨度(沿n*,≠厚度) %s nm | 壁=%d | %.2fs/步'
```
加长注释说明口径与陷阱。**CSV 列名 `ths`/`n_lath` 不动**（改列名会破坏全部分析脚本），
但在注释里点名「`ths`/`n_lath` 是同一个量」。

自检：锚点唯一 ✓ / 语法编译 ✓ / 备份 `_bk_exp.py.bak_s297thlabel` ✓ / 写后复验 3 项 ✓
（含"取值表达式未动（2 处）"这条**零数值改动**的守卫）；
sha256 `372e848df1a2 → 747e3914661c`（220947 → 222112 B）。

⚠ **没有为这个标签重启三臂** —— 纯装饰性改动，重启要付 ~15 min 构造代价，不值。

## 4. ★ 连带核查：宽比/长厚量具**没有**被污染

必须查（否则前面所有长宽比结论都要作废）：

| 量具 | 用什么量 | 判定 |
|---|---|---|
| `_t5_aralign.py` | `band_val < 0`（**带符号距离 φ**）+ **逐连通分量的 PCA 跨度**（`:33`、`:58`） | ✅ **不是 `n_k`** ⇒ 宽比/长厚读数**有效** |
| `_t5_seven.py` | `blk_laths`/`n_var_sig`/`nf2`（CSV 列）+ `band_val`（`:67`） | ✅ 不受影响 |
| `_bk_exp.py` 打印 | **`n_k`** | ❌ 已修标签 |

⇒ **宽比 6.76/6.40/6.54、长厚 12.85/11.59/11.61 这些数站得住**，不需要撤回。

## 5. 顺带得到的一个**有用**推论

`n_k` 既然对碎片化敏感，那它就是一个**便宜的碎片化告警**：
`n_k ≈ L_box` ⟺ 该场已被啃成散块。这可以当作「一场一板条」监控的**辅助哨兵**
（但**必须**与逐分量的量具交叉验证，不得单用 —— 正是本轮踩的坑）。
