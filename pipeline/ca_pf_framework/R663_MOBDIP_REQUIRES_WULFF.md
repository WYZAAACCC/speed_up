# R663 —— ⛔ 实验设计错误：`--mob-dip` **只在 `--mob-wulff 1` 时才被消费**

> **症状**：`E0/E2/E4`（`mob_dip` = 0.0/2.0/4.0）的 `Λ` 读数**逐位完全相同**
>（中位 3.73；各场 `4.1 4.0 3.7 3.6 3.4` 一字不差）。
> 按仓库 `P7`/`R635` 教训（`--beta-w 0.0` 曾让七臂作废）⇒ **先查参数是否生效**。

---

## §1 排查（三步，全部取证）

| 步 | 查什么 | 结果 |
|---|---|---|
| 1 | `meta.json` 里有没有 `mob_*` | ❌ **没有这些键** ⇒ 换个途径 |
| 2 | 我的启动器有没有把 `--mob-dip` 传对 | ✅ **对**（`dip = sys.argv[5]`，`:39`；我传的就是 0.0/2.0/4.0；`:98` 拼进 argv） |
| 3 | **引擎有没有消费它** | ⛔ **没有** —— 见 §2 |

## §2 ★★ 根因（`windowB_surface.py:5159`，逐字）

```python
if mob_wulff and npref is not None:      # ★★★ 入口条件
    _wt = getattr(self, 'wtab', None)
    ...
    else:
        _ck = (mob_beta, mob_beta_w, float(mob_dip))
        if _ck != getattr(self, '_wulff_key', None):
            import windowB_wulff as _WL
            _vf, _Vc, _ = _WL.fast_support_factory(
                _nh, _av, _wv,
                beta_h=float(mob_beta), beta_w=float(mob_beta_w),
                dip_c=float(mob_dip))            # ← mob_dip 唯一的使用点
```

**⇒ `mob_dip` 只在 `--mob-wulff 1` 打开时才会被用到。**
**⇒ 我启动 `E0/E2/E4`（以及 `D0/D2/D4`）时用的是 `wulff=0`** ⇒ **`dip` 被完全忽略**
⇒ 三臂当然**逐位相同**。

**⇒ 且这条与仓库 `R30 §46` 的记账一致**（我在 `:39` 的注释里就写着
"`dip` …**与凸化配套**" —— **我自己的注释写了，却没照它做**）。

## §3 ⇒ 两个后果

**① 我此前所有 `mob_dip` 实验都没测到 `mob_dip`**
（包括更早的 `fDip4` 等臂，若当时 `wulff=0` ⇒ 同样无效）⇒ **需要重新审那些结论**。

**② 正确设计是 2×2 因子**：
| | `mob_wulff=0` | `mob_wulff=1` |
|---|---|---|
| **`dip=0`** | ✅ 已有（`L0`/`E0` 等） | **`B0`（新）** |
| **`dip>0`** | ⛔ **无意义**（`dip` 被忽略；`E2/E4` 已证逐位相同） | **`B2`（dip=2）/ `B4`（dip=4）（新）** |

## §4 已启动的正确臂（`R630` 合规）

| 臂 | `mob_wulff` | `mob_dip` | 核段 | Wulff 预测 `v_a/v_w` |
|---|---:|---:|---|---:|
| `B0` | 1 | 0.0 | 0–3 | **3.45** |
| `B2` | 1 | 2.0 | 4–7 | **7.29** |
| `B4` | 1 | 4.0 | 8–11 | **8.98** |

**判据不变**（`R661 §2` 的 J1–J4），**但 J1 的对照基准改为 `B0`（而不是 `E0`）**，
因为 `B0` 才是"凸化开、无凹陷"的正确对照。
