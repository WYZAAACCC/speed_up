## §3 ⇒ 阶段 C 与 D1 的关系（**本轮的一个新判断**）

**⇒ 因此 D1（锐界面弹性）的优先级需要重新评估**：

| 问题 | 答案 |
|---|---|
| **D1 解决的是什么？** | 弹性求解在**界面处的精度**（现在是 `soft=True` 把 `ε⁰` 抹宽 1.5 胞） |
| **它影响形状比吗？** | ✅ **影响**：仓库实测 `soft` 开关把 `ΔL/ΔW` 从 **2.18 → 4.38**（`:1236-1241`） |
| **但它是"缺机制"还是"机制不够精确"？** | ⚠ **后者**（`R669 §6`：D5 是"缺机制"，D1–D4 是"机制不够精确"） |
| **⇒ 优先级** | **低于 D5 的 (c)**（`R669` 已排 (c) 第一） |

**⇒ 但 D1 有一个 D5 没有的优点**：**它不改物理、只改求解器**
