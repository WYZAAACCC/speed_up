## §1 主线核对：**没有偏离**

Window B 的定义（`RESEARCH_INTENT.md`）：**体相场 + Gibbs 零厚度面**，
在**单个 prior-β 晶粒内部的一个三维区域盒子**里做 **β→α′ 板条马氏体**的局部精细仿真；
板条自发按 Burgers 取向分组 → **block/colony → packet → variant cluster**。

| 主线要求 | 本轮实验怎么做的 | 是否偏离 |
|---|---|---|
| 三维盒、**单个 prior-β 晶粒内** | 24 µm 立方（`R24`），12 个 Burgers 变体 + 母相，单一母相取向 | ✅ 一致 |
| **零厚度 Gibbs 面** | 引擎的 level-set 变体场（`argmin` 定区域），界面无厚度 | ✅ 一致 |
| 板条按 Burgers 分组 | 用 `NPF`（惯习面）× `atab`（长轴）× `wtab`（宽向）；**block/packet 用 c 轴分组** | ✅ 一致 |
| **不是**弥散界面 PF | 未引入任何弥散界面 | ✅ 一致 |
| Window C（`Γ_i`）暂缓 | 全部算例 `surface_chem` 保持默认关闭 | ✅ 一致 |
| 学到的是**局部、可搬运**的算子 | 单核/多核算例都是同一个引擎、同一套参数 | ✅ 一致 |

**⚠ 一处必须持续标注的东西**：`norm_smooth = 4` 是**离散化正则化**（对 `∇d` 做 9³ 盒式平滑
再归一化），**不是物理参数**。它修正的是"逐胞法向噪声把 `M(n)` 的谷底抬起来"这个**数值**缺陷。
判据是**Δx 无关性**：Δx=250 nm 给 `ΔL:ΔW` = 0.115，Δx=125 nm 给 0.098/0.137。
⚠ **只有 2 个 Δx 点、1.15 倍之差** ⇒ 这条证据**偏弱**，报告时必须连同"只有两点"一起说。

## §2 本会话我犯过并已修的错误（全部留痕）

| # | 错误 | 怎么抓到的 | 性质 |
|---|---|---|---|
| 1 | 以为 `dG_max` 有并发竞态、**凭空加了一行赋值** | 逐行核对发现那个循环里**根本没有**该赋值 | 凭想象的改动，已撤 |
| 2 | 子盒 reinit 路径**原地改了调用者的 `d2`** ⇒ `corr2 ≡ 0` | `_r1_reinit_bbox.py` 的逐位判据 | **别名 bug，静默失效** |
| 3 | `reinit_iters` 可降到 20–40 | 子代理补做的"真退化场"扫描 | **判据本身错了**（见 #4） |
| 4 | 用"带内 `median\|∇d2\|`"当 reinit 的收敛判据 | 实测该量在真退化场上**单调降**而 `max\|Δ−REF\|` 已到 0 | 判据无效，已改口径 |
| 5 | `--shuffle-variants` 返回 `np.int64` ⇒ `meta.json` 崩 | **dry-run** | 序列化 bug |
| 6 | CSV 的 `row.update({k: mm.get(k) for k in COLS})` **把 `step/t_s/dt` 覆盖成 NaN** | 分析器解析失败 | 数据记录 bug |
| 7 | 逐分量 `gap_w_nm` 忘乘 `dx`（报 1.2e10 nm） | `e5` 报出 **1490 nm** 才对上 1500 nm 间距 | 单位 bug |
| 8 | 分析器里 `Wc`（米）当 nm 打，得 0 | 肉眼看输出 | 单位 bug（同一类，**一轮内犯两次**）|
| 9 | 「多个核合并了没有」用 `nc`（分量数）判 | 快照解剖：24 = **6 大 + 18 碎屑** | 判据被数值产物污染 |
| 10 | 改用 `big_frac`（最大分量占比）判 | 快照解剖：6 根**等大**独立板条给 0.167，看着像"83% 碎屑" | **第二次判据错** |
| 11 | `components.csv` 一律用 `+dx` 口径 | 与 `_r1_calib.py` 对照：`n*` 斜交时 `+dx` **高读 48%** ⇒ `LT` 低读 18–28% | **真偏差**，已加现场定标 |
| 12 | 「尖端被弹性驱动抵消 71%」是长不出板条的元凶 | 运行态分面 `Δed` 实测：尖端 −7.9e7 vs 侧面 −8.2e7（比 **1.015**）；关掉弹性的臂**没有变好** | **假说被自己否证** |

⇒ 12 条里 **7 条是"我的判据/量具错了"而不是引擎错了**。这与 `AGENTS.md §3.3` 的教训一致：
**最贵的错误不是代码写错，是量错了还以为在量对的。**

## §4 结论口径（防止过度声称）

* 单核：**"速率比与设计一致（1:0.098:0.033 vs 1:0.10:0.03）"** ✅；
  **不能**说"长出了标准板条"（C-5 未达标、尖端是圆的）。
* 多核：**"N 个平行核保持平行并合并成一个沿 `a` 拉长的板状区域"** ✅；
  **不能**说"形成了块"（块内板条不可分辨）。
* `norm_smooth=4`：**"离散化正则化，使 `M(n)` 的各向异性得以正确实现"**；
  **不能**当物理参数写进论文；报告必须同时给 m=0 与 m=4。
