audit(R141): 文献/初始条件/最终结果三线复核 + n* 从未收敛

文献
- MEASUREMENT_SPEC 同时存在两个互相矛盾的靶②: :513 的「≈9-16」(把 Wang 的长除以
  Shuai 的短, 跨篇拼接) 与 §12 R18 的「≈9-24」(Wang/Xie 各自同篇比值)。
- 「9-24」是 2D 截面表观值, 而模型报的是 3D 生长增量比 —— 不是同一个量。
  R18 说应与 L/T 比, ROADMAP:2393 说要把 L/W 推向 9-24, 两句不可能同时成立。

初始条件
- 种子 R=500/t=700nm => L:W:T = 1:1:0.70, 而设计速率比 1:0.100:0.030 => 厚 23 倍。
  (种子本身按设计正确构造, dxf3 实测 997.0/990.1/699.9)
- 种子 R=500nm 对临界核 r*=2*gamma/df=0.857nm => 大 583 倍 => 本算例只测长大, 不测形核。
- dt = 0.15*dx/(M0*df) => 每步标称位移 = 0.15*dx => 同步数 = 不同物理时间。
- _probe_shape 的 reinit_every=0(关 A-1) 而 T16 默认开 => 两族算例数值路径不同。

最终结果
- R3 的 max-min 系统性偏低整整 1 胞: 解析长方体 3000x1500x800 在 dx=166.7 报成
  2833.9x1166.9x500.1(偏 -5.5/-22.2/-37.5%); 亚胞系综下 -50%(2胞)..-6.9%(16胞);
  +dx 才是无偏的。R3 写的理由(加 dx 会抬高 25%)方向是反的。
  但斜的晶体学轴下所有口径都偏低 5-24%, 没有一个是准的 => 必须双口径+量化带。
- fill_n 对长方体恒等于 1.000(恒等式), 不是验证。
- 共同物理区间 [1250,3750]nm 内 dT 只有 0.33-1.27 胞, dW 只有 2.83-9.90 胞
  => dL/dT 有因子 8.5 的不确定度, dL/dW 分母 ±35%
  => R15 指定的靶② 第一观测量在现行窗口下量不准。
- 「soft 已消除网格依赖(166.7 与 83.35 都给 3.16)」被第三个网格点推翻:
  3.16 / 3.16 / 2.67 / 2.43 随加密单调下降, 极差 23-26% => 未收敛。

引擎级(本轮最重要)
- M(n) 的 beta_h 用调用方 npref(=NPF), beta_w 用引擎自己的 wtab —— 两套轴来源不同。
  实测 <NPF, n_eng> = 7.3-9.8 度(6 个变体) / 88.6-89.7 度(另 6 个变体)。
- 两者都来自「400 个随机法向取能量最小」, 但随机序列不同 => 不可复现。
- E(NPF)/E_min = 21-654(12/12); 40000 点 Fibonacci 仍高 3-9 倍 => 该 argmin 从未收敛。
- 两个 rank-1 解的弹性自能只差 8.6%(6.757e3 vs 7.342e3) => 能量判据对选支几乎无分辨力。
- 严重性边界: w = n x a 在 (n,a) 交换下只变号, 而 beta_w 是 (n.w)^2
  => beta_w 轴稳健(实测 |NPF.w| <= 0.086); beta_h 轴暴露。

  正确协变关系是 E(Qn;eps) = E(n; Q^T eps Q); 改正后相对差 3.25e-15。
