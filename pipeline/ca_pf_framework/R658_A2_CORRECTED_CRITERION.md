## §1 引擎的 `Mfac` 公式（**逐字照抄** `windowB_surface.py:5236-5255`）

```python
c2b_ = np.clip((ndir_ · nd_ref_)**2, 0.0, 1.0)          # (n̂·n*)²
_expo = -mob_beta * (c2b_ if pin_min else (1.0 - c2b_)) # pin_min 决定钉扎哪一端
if mob_beta_w > 0.0 and wtab is not None:                # ★ 第二钉扎轴 w
    c2w_ = ...                                           # (n̂·w)²
    _expo = _expo - mob_beta_w * np.where(_use_w, c2w_, 0.0)
_mfac_dt = np.exp(_expo)
v_cell = v_cell * _mfac_dt
```

### 1.1 ★ `pin_min` 的语义（`windowB_surface.py:5133-5141`，逐字）
> 形式： `M(n) = M0 * [1 - a*(n.n*)^2]`  (**`pin_min=True`, 默认**)
> …`M(n) = M0 * [1 - a*(1-(n.n*)^2)]` (`pin_min=False`)
> ⚠ 记账：D8 的 a00..a100 用的是 `pin_min=False`（当时 `mref` = **快生长方向**）…
> **板条要用 `pin_min=True` + `n*`=惯习面法向。**

**⇒ 正确语义**：`Mfac = exp(−β_h(n̂·n*)² − β_w(n̂·w)²)`
⇒ **`n̂ = n*`（惯习面法向）被**压制**（慢生长）**；`n̂ ⊥ n*` 生长快。

## §2 三个特征方向的 `Mfac`（本配置：`β_h=6.477`、`β_w=2.3`）

| 方向 | `(n̂·n*)²` | `(n̂·w)²` | **`Mfac`** |
|---|---:|---:|---:|
| `n̂ = n*`（惯习面法向） | 1.000000 | 0.0000 | **1.538e-3**（**慢**，钉扎） |
| `n̂ = a`（长轴） | 0.016156 | 0.0000 | **0.9006**（**快**） |
| `n̂ = w`（宽度） | 0.000000 | 0.9679 | **0.1079**（被 `β_w` 压制） |

（`|n*·a| = 0.127107`，取自 `_bk_exp.py:1814` 的 12 变体实测区间 `[0.126917, 0.127107]`。）

### 2.1 ⇒ **设计各向异性极比 = 585.4**

| 量 | 值 |
|---|---:|
| **设计极比** `Mfac(a)/Mfac(n*)` | **585.4** |
| **实测 `Λ`**（`L0` `proj=0`） | **3.25** |
| **实测 `Λ`**（`B40` `proj=1`） | **5.62** |
| ⇒ **兑现率**（`(Λ−1)/(585.4−1)`） | **0.43%** / **0.79%** |

**⇒ 这是"各向异性 → 形状"传递效率的**第一次定量指认**：
**设计给了 585 倍，形状只拿到 3–6 倍。**

## §3 ★★ 修正后的核心判据：极图非凸性

**做法**：在三个平面内扫 `n̂`，算 `Mfac(n̂)` 极图；
比较**极图面积**与**其凸包面积** —— 凸包严格更大 ⇔ **极图非凸** ⇔ **存在 missing orientations**
⇔ 按 `LATH_FACET_PLAN:45-48`，**该平面内可出现平直刻面**。

| 平面 | 极值 | 极比 | **凸包面积/极图面积 − 1** | 判定 |
|---|---|---:|---:|---|
| `(n*, a)` | [1.538e-3, 1] | 650.0 | **+18.29%** | ⛔ **非凸 ⇒ 可出刻面** |
| `(n*, w)` | [1.538e-3, 0.1041] | 67.6 | **+16.89%** | ⛔ **非凸 ⇒ 可出刻面** |
| `(a, w)` | [0.1041, 0.9006] | 8.7 | **+12.06%** | ⛔ **非凸 ⇒ 可出刻面** |

**对照**：把 `β_h` 从 6.477 提到 20/50/100，非凸度只从 **18.29% → 19.8/20.2/20.4%**（饱和）
⇒ **`β_h=6.477` 已经足够非凸** ⇒ **再加 `β_h` 不会带来新的刻面能力**（只是把极比推到无意义的大数）。

## §5 ⚠ 本工具的口径限制（**我第一版把判据说过头了，此处更正**）

* `凸包(极图)` 是 **γ-plot 的凸包**（Legendre 二次共轭的几何形式），
  与 **Wulff 平衡形状 `r(n)`** 是**对偶**关系，**不是同一个对象**；
* ⇒ **本工具只判"极图是否非凸"（= 是否存在 missing orientations）**，
  **不给出刻面的条数与朝向** —— 那需要另做 Wulff 构造（留给**阶段 C1**）；
* ⇒ 且"非凸"只是**必要条件之一**，**不保证刻面会被兑现**（§4.1 正是这个缺口）。

**另**：`LATH_FACET_PLAN:45-48` 的判据针对的是**界面能 `γ(n)`**；
本工具算的是 **`Mfac(n)`（生长动力学各向异性）**。
**两者的 Wulff 构造在形式上同构**（都走"极图 → 凸化 → 面法向"），
但**物理含义不同**（前者是能量极小，后者是法向速度各向异性）。
⚠ **该同构性我未从文档中核到**，标为 **【推理】**，**须在 C1 里核实**。
