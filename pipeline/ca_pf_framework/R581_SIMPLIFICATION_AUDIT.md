## §2 ★★ S4 `--nuc-overlap-nm`：本轮最重要的 §(16) 发现

### 2.1 它**直接接在引擎的 `attach_overlap` 上**
```python
# _bk_exp.py:1403
attach_overlap=a.nuc_overlap_nm * 1e-9,
```
而本长跑走的**正是引擎的 `attach` 通道**（日志：`模式 **attach**`）
⇒ **CLI 默认 0.0 会直接影响块内界面的完整性**。

**★★ 机理已在代码里逐行确认**（`windowB_surface.py:2540-2542`）：
```python
cc = c0 + ((_edge - float(c0 @ nrm))
           + _side * (_t_use / 2.0 - c.get('attach_overlap', 0.0))) * nrm
```
⇒ 新片的中心沿法向放在 `_edge + _side·(t/2 − o)`。
**`o = 0` ⇒ 新片的近端面恰好落在旧片边界上（相切）；`o > 0` ⇒ 咬进去 `o`。**
这与上面那条剂量–响应完全对上。**⇒ S4 成立，且机理清楚（不是推测）。**

### 2.2 代码自带的**剂量–响应实测**（`windowB_surface.py:1658-1662`）
> `attach_overlap` 的经验值（同分辨率 Δx=62.5 nm、同 n*、N=96、200 步的剂量–响应实测）：
> * `o = 1Δx = 62.5 nm` ⇒ 界面完整（β 夹层占比 **0.13–0.15** = 预摆对照底噪）
> * **`o = 0` ⇒ 只有 `0.29–0.62`（阶梯错位）**
> * `o = 1.5Δx` **过大**，会把先形成的板条撕碎
> ⚠ **这是模型选择，不是从自由能推出来的**（记账红线）

**机理解释**（同处注释）：`seed_plate` 用真 SDF、`argmin` 把界面定在两个零水平集的**中面**；
**恰好相切**时中面退化成旧片的零水平集，**台阶对不上的地方就留 1 胞 β**
⇒ **是阶梯错位伪影，不是物理**。

### 2.3 ⇒ **我的两个长跑臂用了 `o = 0`**，所以 C3 的证据需要打折扣
* **好消息（已实测）**：`col_cover_min` **恒 = 1**（79 行）⇒ 柱剖面法**没有静默丢层**
  ⇒ `nslab_n`/`nf3_col` 的**计数**是可信的；
  且 `nf3_col == nslab_n − 1` 在 **77/77 与 81/81 行**成立。
* **但**：那是**剖面**判据，不是**面积**判据 —— 界面可以在 38% 的面积上夹着 β 膜，
  而每条柱剖面仍然穿过一张 F3。
* ⚠ **我一开始想用 `f3_area_m2 / f3_area_stair` 当覆盖率 —— 那是错的**：
  自检（`_bk_measure.py:1125`）写明这个比值是**阶梯/几何因子**
  （45° 平面应给 √2 ≈ 1.414；我实测 1.742，说明界面有倾斜），**不是覆盖率**。
  **⇒ 本轮没有从 `series.csv` 直接量到 S4 影响的列**（如实登记：未核实）。

### 2.4 处置（按 goal §(16)④「代价 ≫ 收益 ⇒ 按物理正确的方式实现」）
* 代价 = **一个 CLI 参数**；收益 = **块内界面从"29–62% 是 β 膜"变成完整** ⇒ **必须修**。
* **已排队**：`_r581_p2q.sh` 会在 `p2_b3` 跑完后自动起 **`p2_b5ov`**：
  `--N 160 --m 4 --B 5 --overlap-nm 62.5`（取**引擎路实测的最优** `1Δx`）。

  「建议值 **≥ 1.5Δx**（Δx=62.5 nm ⇒ 94 nm）」，而引擎路的实测说 **1.5Δx 过大（会撕碎板条）**。

## §4 S9 `γ₀`：**文献带有值了**（这是 S9 从"占位"走向"可修"的关键）

`_bk_exp.py:3098-3104` 的注释自己写着：
> 闭环要求把 `γ_α′β` 从 **[占位] 0.15** 换成文献值
> （**Murzinova 2017 给 0.201–0.337 @975 °C、0.298–0.429 @600 °C**）
> ⇒ 必须能**单变量**地扫它。默认 0.15 ⇒ 全部归档读数逐位不变。

**⇒ 结论**：
* **`0.15` 落在文献带之外**（低于 975 °C 带的下界 0.201）；
* **`0.25`（归档 A/B 臂与本轮长跑显式传的值）落在 975 °C 带内**（0.201–0.337）；
* 而且代码里**已经有一条启动告警**：`--gamma0` 与闭环主情景
  `CL.GAMMA_F1_MAIN` 不等时会打印提示（`_bk_exp.py:3352-3356`）。
⇒ **判定：S9 的"真缺陷"成立（默认仍是占位），但本轮长跑用的 0.25 是有依据的。**
**修法（代价极小）**：把默认改成文献带内的值，并在 banner 里打印用的是哪一档温度。
⚠ 但**改默认会改变所有"不传 `--gamma0`"的算例**（含归档复现臂）

### ② 它是什么（`_bk_exp.py:1116-1118` 逐字）
```python
o = a.nuc_overlap_nm * 1e-9
_fr = float(a.nuc_compensate_frac)
Tj = (T + _fr * (o if j < nv else 0.5 * o)) if (o > 0 and a.nuc_compensate) else T
```
**代码自己的记账（`:1103-1115` 逐字）**：
> **补厚度**（`--nuc-compensate`）。张力：界面要落在共享平面上 ⇒ 重叠 `o` 必须 ≥ 1 胞；
> 但界面落在重叠区**中面** ⇒ 每张被重叠的面被吃 `o/2`，
> 而**内层片两张宽面都是 F3、`Δf = Δe_el ≡ 0`，没有任何体驱动力**去补回来
> ⇒ 被削薄就只会继续缩、碎裂（`gs3` 实测：板条 1 被撕成 **20 个碎片**、
> `f3_area` 被刷到 **7.95 µm²**，比预摆对照的 6.77 还大 —— **那是污染不是成绩**）。
> ⇒ 出路不是调 `o`，而是**把会被咬掉的预先补上**：
> **片 1..M−1 ⇒ 播 `T + o`；片 M ⇒ 播 `T + o/2`** ⇒ 每片稳态厚度回到 `T`，块总厚仍是 `M·T`。

### ③ 物理上"应该"是什么
* **真实块厚就是 `M·T`** ⇒ **不需要"补偿"**；补偿存在是因为**数值重叠 `o` 吃掉了材料**。
* **⚠ 但底下有一个**真**的物理问题**：模型里**同变体 α′/α′ 界面**（F3）**`Δf = Δe_el ≡ 0`**
  ⇒ **没有体驱动力**把被吃的厚度长回来。
  **⇒ "补偿"实际上在替一个**建模选择**买单**：同变体板条之间的厚度**无热力学偏好**（同相）。
* **⇒ 判定：它不是"把物理省掉"，而是"修正一个离散化伪影"** —— **前提是 `nuc_compensate_frac` 恰好对。**
