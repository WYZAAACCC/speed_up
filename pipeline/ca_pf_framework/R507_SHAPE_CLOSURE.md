## §1 补上的那一环：**每块真正放得下几根**

`R506` 只联立了 C-2 / 块厚带 / 块数上界 / C5 总根数 / 内存，**漏了超临界门槛**。补上之后多出一个决定性量：

```
每块放得下的核数 = n(T_end) − n(T_阈) = α_KM · (T_阈 − T_end)
```

而 **`T_阈` 取决于核的形状** —— 因为判据里的弹性罚 `|ed|` 取决于形状。
两个值都在**引擎同一条路径**（`_supercrit_probe`）、**同一核几何**（R=320 nm、t=510 nm）下实测：

| 核形状 | `|med_ed|` | `T_阈` | **每块放得下** |
|---|---:|---:|---|
| **带尖边圆盘**（`sdf = max(\|d\|−t/2, rperp−R)`，**现默认**） | **3.1720e8** | **380.1 K** | `α_KM × 82.1` |
| **光滑椭球**（`--nuc-shape ellipsoid`） | **2.5760e8** | **523.8 K** | `α_KM × 225.8` |

⇒ **椭球的弹性罚比圆盘低 18.8%**，形核窗口从 **82 K** 放宽到 **226 K**（**2.75 倍**）。

## §2 ★ 三个要求互相夹住 ⇒ **圆盘口径下是空集**

| 要求 | 出处 | 圆盘口径 | 椭球口径 |
|---|---|---|---|
| **① C3**（块内 ≥2 根堆叠） | 成功判据 C3 | `α_KM ≥ 2/82.1 = **0.0244**` | `α_KM ≥ 2/225.8 = **0.0089**` |
| **② 块厚带** `(1.0, 6.0) µm` | `W_BLOCK_BAND_UM` | `α_KM ≤ **0.0205**` | `α_KM ≤ **0.0205**` |
| **⇒ 交集** | | **空集 ❌** | **`[0.0089, 0.0205]`** ✅ |

**⇒ 框架参考值 `ALPHA_KM_REF = 0.011` **正落在椭球口径的交集里**。**
（而归档用的 `0.041739` 在两个口径下都**超出块厚带**。）

**⇒ ⇒ 所以：卡住全局的**不是** `α_KM`，是 `seed_plate` 造出来的核的**形状**。**

## §3 为什么说"尖边圆柱"是**数值产物**（这是判断的依据）

`seed_plate` 里那一行是：

```python
sdf = np.maximum(np.abs(d) - t / 2, rperp - R)
```

**`max()` 是 L∞ 范数** ⇒ 它给出的零等值面是**圆柱**，而 **`max` 的折点就是尖边**。
真实马氏体片是**透镜状（lenticular）**的；板条确实有**棱边（ledge）**，
但那不是"整条周界都是数学意义上的尖角"。
⇒ **这一行带来 18.8% 的额外弹性罚，而这个数字没有任何物理来源。**

## §4 实现与验收

**新开关**：`--nuc-shape {disc,ellipsoid}`（**默认 `disc` = 归档行为**，逐位不变）。
椭球用 `sqrt((d/(t/2))² + (rperp/R)²) − 1` 缩放 ⇒ 零等值面是半轴 `(R, R, t/2)` 的旋转椭球。

### 4.1 可证伪预测的检验（`_r509`）

**预测**（写死在 `R507` 里）：椭球罚 = 圆盘罚 × **0.656**（来自 `_r470`/`_r474`）。

| # | 判据 | 结果 |
|---|---|---|
| **S1** | 椭球罚 < 圆盘罚 | ✅ **PASS**（2.576e8 < 3.172e8） |
| **S2** | 比值 ∈ [0.55, 0.80]（预测 0.656） | ❌ **FAIL** —— 实测 **0.8121** |
| **S3** | 翻转点同幅下降 | ❌ **FAIL**（0.8127） |
| **S4** | **负对照**：disc 必须复现 `_r479` 的 3.1818e8 | ✅ **PASS**（相对差 0.31%） |
| **S5** | 只差形状（`cover` 胞数相同） | ✅ **PASS**（668 vs 668） |
| **S6** | 两形状的净效果都为零（回滚干净） | ✅ **PASS** |

### 4.2 ⚠ 我的判据错了（**自查错误 #98/#99，留痕**）

**S2/S3 的 FAIL 是我的判据设计错，不是实现错**：

* 我把 `_r470`/`_r474` 给的 **2.0873e8** 当成了"椭球的罚" ——
  但那是 **`PF3D` 求解器 + 1000×500×510 nm 的大椭球**；
* 而本处的核是 **R=320 nm、t=510 nm**（半轴 320/320/255）⇒ **几何不同**，**苹果比橘子**。
* 更早（#98）我还在 `R507` 的结论里把"高 52%"写死了 —— 那是同一个错的传播。

**⇒ 已改用引擎同几何实测的一对（3.1720e8 / 2.5760e8）。**
**⇒ 关键结论不变**（圆盘空集 / 椭球有解），但**幅度必须按实测报**：是 **18.8%**，不是 52%。
