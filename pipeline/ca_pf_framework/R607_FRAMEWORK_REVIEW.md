### ⚠️⚠️⚠️ [①(c)] **超临界探针的回滚不覆盖变体指派** —— 【已核实】
**代码事实**（`windowB_surface.py:2760-2795`，本会话逐行读过）：
```python
def _seed_undo_note(self, k, sdf, undo):
    pk = self.phi[k];  mk = sdf < pk
    if mk.any(): undo.append((k, ii, pk.ravel()[ii].copy()))
    for j in range(self.nreg):        # 只记 phi[j]
        ...
def _seed_undo_apply(self, undo):
    for (j, ii, vals) in undo: self.phi[j].reshape(-1)[ii] = vals     # 只还原 phi
```
**⇒ 回滚只覆盖 `phi`，不覆盖 `eps0` / `npref` / 任何取向量。**

**现状为什么没炸**：`seed_plate` 目前**只写 `phi`**（`eps0/npref` 在构造时定死）⇒ 无残迹。
**⚠ 但 natural 模式必须把变体指派（`eps0[p]`、`npref[p]`）写进槽位 `p`** ⇒ 探针若"试放→回滚"，
**被拒的候选会静默留下变体指派** ⇒ 该场取向被污染、且**没有任何报错**。
**⇒ 结论：natural 模式的实现**必须**同步扩展 `_seed_undo_note`/`_seed_undo_apply` 覆盖变体指派；**
**并且必须打独有成功串**（如 `[NUCASSIGN] slot=.. variant=.. undo=1`）以证明回滚真的执行到。
