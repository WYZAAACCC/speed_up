## 1. 背景：我在建的模型（读懂这节才能判断数据是否对得上）

### 1.1 物理图像

* 材料：**Ti-6Al-4V**，**LPBF 增材制造**，冷却速率极快（10⁴–10⁶ K/s 量级）。
* 相变：高温 **β（bcc）** → **α′（hcp，马氏体）**，**位移型（无扩散）**，
  在 **M_s 以下**发生。板条以 **Burgers 取向关系**从母相 β 中**形核 + 长大**。
* 层级（钢里的叫法，Ti-64 是否同样适用**正是我要问的**）：
  **prior-β 晶粒 → packet（同一惯习面族）→ block/colony（同一变体）→ lath（单根板条）**。
* 我关心的**最小结构单元是"块"**：**若干根同变体板条平行堆叠，板条之间是低角晶界**。
* 文献锚（我目前引用的）：
  * **Furuhara 2008**："a block is formed by **repeated nucleation of the same variant** of laths adjacent to each other" —— 块的成因是**同变体的反复形核**。
  * **Morito 2005**：板条宽度 ~0.2 µm，在 prior-γ 晶粒从 2.3 µm 长到 370 µm（160×）时"**does not change**" ⇒ **板条厚是形核属性，不是长大属性**。
  * **Chakraborty 2022**："the **transverse (width) growth of laths within blocks essentially depends on the nucleation of adjacent hierarchical units**"。
  * **Morito 2022**：三阶段形核规则（① 起点 = prior-β 晶界；② 主通道 = 已有板条周围、优先**同变体**；③ 母相硬化到阈值 ⇒ 改形核**其它变体**）。

### 1.2 我的模型做了什么（**这是判断"数据能不能用"的关键**）

* **界面是零厚度的"Gibbs 面"**，不是弥散界面 ⇒ 我需要的是**界面能 γ**（J/m²），
  而不是界面宽度、也不是扩散界面模型里的梯度系数。
* 模型里同时存在**三类界面**，它们的能量是三个不同的量，**不要混**：

  | 代号 | 界面 | 能量符号 | 我现在用的值 |
  |---|---|---|---|
  | **F1** | α′ / 母相 β | `γ_α′β` | 若借用文献 α/β 值；**缺**位移型专属值 |
  | **F2** | 不同变体的 α′ / α′ | 未单独取 | —— |
  | **F3** | **同一变体的 α′ / α′（= 块内的低角晶界）** | `γ_RS(θ)`（Read–Shockley） | 由 θ 与 `γ_m` 算出，θ = 1°–5°（**输入**） |

* **Read–Shockley 形式**（我用的）：`γ_RS(θ) = γ_m·(θ/θ_m)·(1 − ln(θ/θ_m))`，
  `θ_m = 15°`，`γ_m = E0·θ_m`，`E0 = G·b/(4π(1−ν))`，`b = a_α = 0.295 nm`。
  ⇒ **我需要 `G`（剪切模量）、`ν`（泊松比）、`b`（Burgers 矢量）的可靠取值**（见 P2-4）。
* **判据 C-1（决定 Q-B）**：**Cahn 润湿判据** ——
  低角晶界**是否**会被母相 β 润湿（即分裂成两张 α′/β 界面 + 一层 β 膜），
  取决于 `γ_低角晶界  vs  2·γ_α′β`。
  我算的结果是 **`γ_RS(θ≤5°) ≤ 0.277 J/m²` < `2γ_α′β`（我取 0.727 J/m²）⇒ 不润湿 ⇒ 干晶界**。
  ⚠ **这条结论的余量完全取决于 `γ_α′β` 取多少**：若取下限 `0.201`，则 `2γ ≈ 0.40`，
  仍大于 0.277，**结论不变但余量小得多**。⇒ 见 P0-5。

### P0-2 ★★★ **板条之间到底是干的低角晶界，还是夹着残余 β 膜？**

* **这是决定我主结论对错的那一条。**
* **我要的证据**：

     还是中间有一层**残余 β**？如果有 β 膜，**厚度是多少 nm**？
  2. **成分线扫（EDS/EELS）** 跨板条交界：V（β 稳定元素）**有没有富集峰**？

| **F-5** | "Ti-64 的 α/β 界面能**远低于 0.20 J/m²**"（比如 0.05–0.15） | 让 `2γ_α′β < γ_RS` ⇒ 变成**润湿** ⇒ 我的结论**翻转** |

## 7. **什么样的数据不能用**（红线，请先筛掉）

1. **钢的数据**（Fe-C、Fe-Ni、Fe-Mn、IF 钢……）。本项目曾把 **"block:lath ≈ 26"（Morito 2009）**
   当作标定靶，**后来撤回了** —— 理由正是"**那是钢（IF 钢 Fe-0.0049C-3.14Mn，1473 K 水淬），
   与 Ti-6Al-4V 跨材料**"。钢只能作**机制**参考，**不能作数值靶**。
2. **锻态/退火态 Ti-64 的片层 α+β 组织**。那是**扩散型**相变 + 平衡组织，
   与 LPBF 的**位移型 α′** 不是一回事。界面能尤其不能混（见 P0-4）。
3. **只有均值、没有离散度与样本数**的测量。
4. **不注明状态**（as-built / HIP / 退火 / 固溶时效）与**不注明成分**的数据。
5. **只给 EBSD 的 "block size" 却不给取向差阈值**的数据 —— 阈值变了，块的大小就变，
   这种数我无法用。
6. **综述里转述的二手数字**。若可能，请给**原始文献**；若只能给综述，请标明是转述。
