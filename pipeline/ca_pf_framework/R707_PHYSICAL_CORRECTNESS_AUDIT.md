```python
laths = [int(x) for x in a.laths.split(',') if x.strip()]   # M = 逗号个数

```

⇒ **`--laths` 的语义是"变体列表"，不是"根数整数"。**
⇒ **`--laths 3` 给的是 `[3]` ⇒ `M=1`**（只播 **1** 个场，且**变体号 = 3**），**不是 3 个场**。
⇒ ⚠ **这正是"单变量"纪律的反面教材**：我以为只改了 `M`，实际同时改了**场数**与**变体号**。

**处置**：
1. `_b2_Mtest.py` 已修：`LATHS = ",".join(["1"] * M)` ⇒ 传 **M 个逗号项**（与基线 `1,1,1,1,1,1` 同为变体 1，**真单变量**）；
