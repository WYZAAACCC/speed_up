## §3 ★ C6（涌现的自协调）—— **重写：按新判据 FAIL**

### 3.1 判据要写对：`r_selfac` 的下降**本身不是证据**
`_bk_measure.py:492-504`：
```
E[i] = ε⁰[i] − tr(ε⁰[i])/3·I          # 偏量部分
r_selfac = ‖Σ_v (V_v/V)·E[v]‖ / mean‖E[i]‖
```
⇒ **`r_selfac` 是"偏量应变和的模"。** 当**只有一个变体**时它 ≈ 1；
一旦出现**第二个不同的变体**，加权和必然抵消一部分 ⇒ 它会掉下来。
**⇒ "1 → 0.52" 只说明"多了一个变体"，不是"弹性能挑出了自协调的组合"。**
证伪它的办法：**随机**给同样多的场配变体，也应当掉下来。

### 3.2 实测（`_r581_c6judge.py`，快照 step 400；两个臂独立）

| 量 | `p2_b5` | `p2_b3` |
|---|---|---|
| 出现的变体集合 | **[1, 5]** | **[1, 5]** |
| `r_selfac`（按实测体积加权） | 0.5230 | 0.5287 |
| `r_selfac`（**等权**，与权重无关） | **0.5222043558** | **0.5222043558** |

**零模型（从全部 12 个变体里抽，检验"选择"）：**
| 零模型 | `p2_b5` | `p2_b3` |
|---|---|---|
| `all12` 中位 | **0.3674** | **0.3886** |
| p = P(随机 ≤ 实测) | **0.8542** ❌ | **0.8045** ❌ |

⇒ **实测比随机的中位数还差**（随机选 8 个变体更容易抵消）。

**枚举判据（等权，`C(12,2)=66` 种组合，**并列已处理**）：**
```
实测集合 [1,5] 的 r_selfac = 0.5222043558 = **全局最小**
达到全局最小的组合数 = **12 / 66**
⇒ 不比实测差的组合数 = **12 / 66** ⇒ 分位 = **0.182**
⇒ 判据（预先写死：分位 ≤ 0.05）：❌ **FAIL**（0.182 > 0.05）
```

### 3.3 C6 的**诚实结论**（分三层说，不混为一谈）
1. ✅ **正面**：实测变体对 **[1,5] 确实落在全局最自协调的那一档**
   （`r_selfac = 0.5222` **等于全局最小**）。
2. ❌ **不能据此判"涌现"**：**66 种配对里有 12 种并列达到同一个最小值（18%）**
   ⇒ "落在最小档"**没有选择性** ⇒ 按预先写死的 ≤5% 分位判据 **FAIL**。
   **不放宽阈值，照实记 FAIL。**
3. ⏳ **但有一条值得记的正面观察**：**两个臂（B=5 与 B=3）独立地选出了同一个变体对 [1,5]**。
   这提示选择是**确定性**的（由 `--nuc-*` 的 `var_rule='ed'`＝**弹性能驱动**的规则决定）
   ⇒ **可复现**。但这仍然**不是**"多体自协调涌现"（判据要的是后者）。

**⇒ C6 判定：❌ FAIL（分位 0.182 > 0.05）。**
**排除人为来源的论证**：变体由 `var_rule='ed'`（弹性能最大降低）选，**不是**人为规定取向 ——
这一点成立；但**"自协调"的强度没有超过"随机选一对"能达到的水平**。
⇒ 结论是「**选择是弹性驱动的、可复现的，但尚未证明它带来了超出随机的自协调**」。
