### 4.6.3 ⚠⚠ **两处口径更正**（写读数工具时当场发现，必须先于任何块厚结论）

**① `blk_span_nm` 是"包围盒跨度"，不是板条/块厚度**
`_bk_measure.py:176` 原文：
> `n_%d`（= `ths`，板条胞沿 `n*` 的**包围盒跨度**）**不是板条厚度**：
> 实测 `mb1s` 场 1 的包围跨度 624 → **2631 nm**（1500 步），
> 而由 φ 量出的**两张宽面之间的距离**只有 780 → **732 nm**（−48 nm）。
> ⇒ 包围跨度被**碎片**（`nc` 12–36）与 **`n*` 与真实板条法向的 7.3° 夹角**
>   （`n*·a = −0.127`）撑大 ⇒ R29 那批 `V-8b` FAIL **至少部分是口径伪影**。

**② 厚度约定有两套，且差 2 倍**（`--eng-t-nm 250` 是**全厚**，但 `seed_plate` 用 `|d| ≤ t/2`）
* 实测佐证：step 0 的 `blk_span_nm` = **507 nm**；
  `507 / 62.5 nm = **8.11 胞**`，而 `2 × 250 + 1 胞(62.5) = 562.5`、
  `250 + 1 胞 = 312.5` —— **8.11 胞 ≈ 2×(2×250)/62.5 = 16 胞的一半**……
  ⚠ **精确核对应读 `seed_plate` 的调用点**；本条**只登记"存在 2× 歧义"**，
  **不在未读全调用点前下定量结论**。
* ⚠ 因此**`plate_T = 510 nm` 与 `--eng-t-nm 250` 不是同一个量** ——
  前者是**声明值**（用于 `V_lath = plate_T·plate_L·plate_W` 的体积律），
  后者是**引擎几何值**。**两者不要混用**（`P30`）。

**②′ ✅ 已核清调用点（同轮内），并且发现一处真实不一致**（`_bk_exp.py`）
```
:1679/:1713/:1881/:1905/:1912   g.seed_plate(<k>, <c>, <n>, a.plate_W*0.5e-9, Tj, …)
:1879  c = c0 + ((edge − cproj) + side·(Tj/2 − o))·nj     ← 这里用 Tj/2 当**厚度**
```
而 `seed_plate` 内部（`windowB_surface.py:2643` 一带）用的是 `|d| ≤ t/2`
⇒ **同一个 `Tj` 在"偏移计算"与"距离判据"里各被除以 2 一次**。
* ⇒ 二者必有一处多除了一次（**要么**偏移里应是 `Tj − o`，**要么**判据里应是 `|d| ≤ t`）；
* ⚠ **我不判"哪个对"**：实测 `blk_span_nm = 507` 与两种解释
  （`2Tj=500`→8 胞；`Tj=250`→4 胞）**都不严格吻合**，且**只差 1–4 胞**
  ⇒ **分辨力不足**（`R581 P43`：判据先证有分辨力）
  ⇒ **登记为待判定项**，需一个**专门探针**（量"两层零水平集的中面间距" vs `Tj`）。
* ✅ **但 `seed_plate` 的面内几何是自洽的**（顺带核清）：
  `R = plate_W/2 = 250 nm`、`elong = plate_L/plate_W = 2.0`
  ⇒ 长半轴 `R·elong = 500 nm` ⇒ **全长 1000 nm = `plate_L`** ✅、**全宽 500 nm = `plate_W`** ✅
  ⇒ ⚠ 这条**修正了 `R624 §11.4` 的一半**：那里的"引擎椭球半长轴 `R·elong = 2.240 µm`"
  用的是 **`--eng-r-nm 320` × `--eng-elong 7.0`**（`eng_*` 组），
  而**驱动层播种**用的是 **`plate_W/2 × plate_L/plate_W`**（`plate_*` 组）
  ⇒ **两组参数给出不同的核几何**（`2.240 µm` vs `0.500 µm`）⇒
  **这也是一处**"同名异量"**，须一并纳入 `R624 §11.4` 的待裁定项**。

**⇒ 判据更正（`R624 §6.5` 判据 B 作废，用下面这条）**
| 原判据（**作废**） | 新判据 |
|---|---|
| `blk_span_nm ≈ blk_laths × 250 nm` | **相邻层间距** = `blk_span_nm / (blk_laths − 1)` ≈ **250 nm**（`blk_laths ≥ 2` 时才适用；容差 ±40%，因 `blk_span_nm` 会被碎片/偏角撑大） |

**⇒ 读数工具已按新判据实现**（`_t11_p8_readout.py`）：
* `blk_laths = 1` 时**明确报"层间距判据不适用"**（不硬算比值）；
