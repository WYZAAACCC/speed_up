## §1 ① 解析多面体**幂等**

### 1.1 现实现的自检（**逐字核实**）
`_r68_facet_op.py:99-101`（`selftest()`）：
> 自检：对一个**已知长方体**的 `φ` 做投影 ⇒ 应**几乎不变**（幂等）。

### 1.2 ★ C4 的**升级要求**：**不能用长方体，要用一般多面体**
**理由**：长方体只有 6 面且**轴对齐** ⇒ 它**测不到** C 的新增能力（Wulff 面法向集）。
**⇒ C4-① 必须用**任意多面体**（建议 `K = 8–24` 面，法向取自 `C1` 的 Wulff 构造）。

### 1.3 判据（**可 FAIL，先登记**）
| # | 判据 | 解析答案 | 阈值 | 依据 |
|---|---|---|---|---|
| **C4-J1a** | 缩放因子 `s` | **恰好 1.000** | `\|s−1\| ≤ 1e-6` | 仓库已过（长方体 `s=1.000`） |
| **C4-J1b** | 体积变化 | **恰好 0.0%** | `\|rel\| ≤ 1e-9` | 仓库已过（`体积变化 0.0%`） |
| **C4-J1c** | **零集形状不变** | 逐胞 `sign(φ)` 不变 | **差异胞数 = 0** | ★ **新增**（长方体自检没查这个） |
| **C4-J1d** | **面数保持** | `K → K` | **面数不变** | ★ **新增**（防"投影把多面体降级成盒子"） |

**⚠ `C4-J1c`/`C4-J1d` 的阈值是我定的** ⇒ 标【未核实】。
**⚠ 但 `C4-J1d` 是关键**：若 `(F,h)` 提取侧只取 3 轴分位数（`C3 §1.2`），
**则任何多面体投影后都会变成盒子** ⇒ **`K` 会掉到 6** ⇒ **这是必测的"降级"风险**。

## §3 ③ 常驱动力下的**界面速度**

### 3.1 已有判据（**goal 原文**）
> 对照 `_chk_w2.py` 的 **`|v/MΔf − 1| < 0.02`**

### 3.2 ★ 但**仓库实测的兑现率是 0.818**（**不是 1.0**）
`windowB_surface.py:4365-4368`（**逐字**）：
> **实测 `v/(MΔf)` 在 `Δx=40/50/62.5 nm` 上分别为 0.923/0.843/0.818**

**⇒ ⇒ ⚠ 这是一个**判据冲突**：
goal 写"`|v/MΔf − 1| < 0.02`"，而**仓库自己的实测**在 `Δx=62.5` 上是 **0.818**
⇒ **`|0.818 − 1| = 0.18 ≫ 0.02`** ⇒ **按 goal 的判据，现引擎**已经 FAIL**。**

**⇒ ⇒ C4-③ 必须先解决这个冲突**（三种可能）：
| 可能 | 解释 | 应对 |
|---|---|---|
| **(a)** goal 的 `<0.02` 是**对某个特定算例**（如 `band_len` 给足时） | 那 `band_len` 是前提 | **必须写明用哪个 `band_len`** |
| **(b)** `<0.02` 是**相对库的参照值**（不是 1.0） | 即 `\|v/(MΔf) − 0.818\| < 0.02` | **须核实** |
| **(c)** goal 的判据**本身有误** | — | **报上游** |

**⇒ ⛔ 我**不在未核实前选**。C4-③ **标为"待解决判据冲突"**【未核实】。**

### 3.3 可加的判据（**不受该冲突影响**）
| # | 判据 | 靶 |
|---|---|---|
| **C4-J3a** | **`v/(MΔf)` 与 `Δx` 的标度** | 应复现 `0.923/0.843/0.818` 的趋势（随 `Δx` **减小**而减小） |
| **C4-J3b** | **多面体 vs level-set 的 `v`** | 多面体应**更接近 1.0**（因 `C2 §1.3`：`κ=0` ⇒ 无曲率惩罚）★ **这是 C 的核心预言** |

**★ `C4-J3b` 是 C 的**核心可证伪预言**：**
**若多面体表示的 `v/(MΔf)` 不比 level-set 更接近 1 ⇒ C 的物理收益不存在。**
