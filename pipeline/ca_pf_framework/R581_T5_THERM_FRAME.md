## §2 物理：真实 LPBF 热史的分段结构

### §2.1 为什么不是线性（三条独立的物理理由）
1. **相变潜热**：凝固平台（`T_L → T_S`）期间温度**不按线性下降**；
2. **逐层再热**：一个材料点被**后续道次/层重复加热**，形成**热循环序列**（文献实测 **5 次**，`gla_thesis.txt:2899-2909`），
   而线性降温**只降不升** ⇒ **完全缺这一半物理**；
3. **自回火（auto-tempering）**：逐循环峰值**递减**，决定二次/三次 α′ 的生成
   （`gla_thesis.txt:3409-3411`：`Cycle2` 在 `T_L` 上、`Cycle3` 在 `T_S–T_β`、`Cycle4` 在 `T_β–M_s`、`Cycle5` 在 `M_s` 下）
   ⇒ **判据⑥「涌现自协调」的物理驱动源就在这个序列里**。

### §2.2 分段定义（**待实现的形状**）
```
阶段 0  初始        T = T0                                    （t < 0）
阶段 1  激光接近    Rosenthal 点源解析式（升温）              t ∈ [0, t_appr)
阶段 2  峰值平台    T = T_L（**截断**，因点源无上界）           t ∈ [t_appr, t_appr+t_melt)
阶段 3  凝固        T_L → T_S，冷速 CR_sol                    t ∈ …
阶段 4  固态快冷    T_S → …，冷速 CR_ss(T)（过 T_β 后衰减）    t ∈ …
阶段 5  再热循环×4  峰值 T_peak,n 递减的自回火序列             t ∈ …
阶段 6  自然冷却    回到 T0
```

### §2.3 阶段 1 的数学形式（**唯一有解析式的一段**）
Rosenthal 移动点源（`gla_thesis.txt:2604-2609`、`:2651-2656`）：
```
T(t) − T0 = λP / (2πkR) · exp( −V(ξ + R) / (2α) )
   ξ = x0 − V·t        （移动坐标，`:2665`）
   R = √(ξ² + z0²)      （材料点距扫描线的垂距 z0）
```
**参数（Table 12，`gla_thesis.txt:2671-2689`）**：

| 参数 | 值 | 符号 |
|---|---|---|
| 激光功率 | **120 W** | `P` |
| 扫描速度 | **400 mm/s** | `V` |
| 层厚 | 50 µm | — |
| 光斑直径 | **70 µm** | — |
| 初始温度 | **473 K** | `T0` |
| 热导率 | **15.75 W/(m·K)** | `k` |
| 热扩散率 | **5.79×10⁻⁶ m²/s** | `α` |
| 吸收率 | **0.85** | `λ` |

**⇒ 可算出的导出量（供自洽检查用）**：
* 激光扫过自身光斑耗时 `≈ 70e-6 / 0.4 = 1.75e-4 s`

## §4 ★★ 两条**自洽性断言**（实现时**必须写成代码里的断言**，不是文档里的愿望）

### 断言 A：**回火动力学自洽** —— 单次再热**不能**把 α′ 分解完
* **实测常数**（`lat_gilmur1996.txt:216-238`，α′ 分解的 Avrami）：`t₅₀%` = **216 / 32.6 / 25.9 / 10.5 min**
  对应 **400 / 500 / 700 / 800 °C**
* **LPBF 单次再热的持续时间**：层内 **0.3 s**、层间 **68.8 s** ⇒ 比 `t₅₀%` **短 10²–10⁴ 倍**
* **⇒ 断言**：若我的 `T(t)` 让某材料点在**某一次**再热里"分解完成" ⇒ **一定错了**（参数或时长写错）
* **旁证（观测）**：`arxiv_2404.txt:914-926` —— 400/500 °C **无可观察变化**（只有回复）；
  `lirias_ku Leuven.txt:669-680` —— 需 **>490 °C** 才开始分解 ✓ 与断言一致

### 断言 B：**冷速自洽**
* `max|dT/dt|` 必须落在 **10⁴–10⁶ K/s**
* 且必须**远大于 410 °C/s**（`lat_ahmed1998.txt:11-16`，否则 α′ **根本不会形成**）
* **⇒ 若算出 < 10³ K/s ⇒ 那是 LMD 量级（`lat_chalmers_subramanian.txt:902-904`），不是 LPBF**
