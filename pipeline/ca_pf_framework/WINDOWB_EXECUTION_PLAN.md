#### ★ D7 **结案**（2026-09-28，用户指示"先找文献；找不到就用文献长厚比反解"）

**实测**：形貌对 `ΔG` 极敏感 —— `df = 0.5/1/2 ×10⁸` ⇒ 长/厚 = **1.165 / 2.207 / 4.170**
（相对散布 **119.5%**，判据门槛 10%）⇒ **CALPHAD 确为阻塞项**，必须去拿数据。

**文献找到了（子代理实读原文，非片段）** —— 取 **D7 选项 (a) + (b) 交叉检查**：

| 文献量 | 值 | 来源 |
|---|---|---|
| **`T0`** | **1145 K（872 °C）** | Ji, Heo, Zhang & Chen (2016), *J. Phase Equilib. Diffus.* **37**(1) 51–64, DOI **10.1007/s11669-015-0436-9**：由 `f^β(X0,T) = f^α(X0,T)` 定出（X_Al=0.1019, X_V=0.036）；f^α/f^β 取自 Zhang et al., *J. Phase Equilib. Diffus.* **28** (2007) 115–120（CompuTherm/Pandat `PanTi`） |
| **`ΔG(M_s)`** | **1200 J/mol** | 同上原文："Assuming Ms = 873 K (600 °C), then this critical driving force can be estimated to be 1200 J/mol by ΔG = f^β(X0,Ms) − f^α(X0,Ms)" |
| **`V_m`** | **1.064e-5 m³/mol** | Boccardo et al. 2024 (arXiv:2404.09806) 附录 A.1，引 Singman (1984) |
| **`M_s`** | **873 K（600 °C）** | 同上（Ji 文**为估 ΔG 而取的名义值**，不是该文测量的 M_s） |

**⇒ 落进模型（`windowB_km.py`）：三个假设量换成「2 个文献值 + 1 个导出值」**

```
DG_CRIT_REF = 1200 J/mol ÷ 1.064e-5 m³/mol = 1.128e8 J/m³        （文献换算）
DS_REF      = DG_CRIT_REF / (T0 − M_s) = 1.128e8 / 272 = 4.147e5 J/(m³·K)   （导出）
自洽断言    : T0_from_Ms(873, 1.128e8, 4.147e5) = 1145.000 K ✅ 与文献 T0 逐位相符
```
`DS_BAND` 由 **4×(1.5e5–6.0e5)** 收窄到 **±20% (3.32e5–4.98e5)**，并有 `T_G_from_calphad()`
在运行期硬断言三者自洽（只改其中一个常数会立刻抛错）。

**工作点反查（自洽性检查）**：`df = 2.0e8 J/m³ ⇔ T = 663 K（390 °C）`
⇒ 旧生产值**没有把 ΔG 设得离谱**（落在层间温度 200–600 °C 的合理区间）；
`df = 3.512e8 ⇔ 298 K（室温）`，即室温驱动力是生产值的 1.76 倍。

⚠ **仍未消除的不确定度（如实记账）**：① `M_s = 873 K` 是 Ji 文为估 ΔG 取的名义值，
本项目旧的 848 K 来自另一条线（差 25 K）；② PanTi 与 Thermo-Calc TCTI 的**库间差**未量化；
③ 用同一个 `V_m` 换算 α′ 与 β。⇒ `DS_BAND` **保留**，A2 交付时**显式报带**。

★ **交叉检查（选项 b）**：`T20_dG_backsolve.py` 用**文献长厚比反解** `ΔG`，
与上面的 CALPHAD 值独立比对。**★ 但本轮实测发现"反解"本身不唯一，必须如实记账**：

| 标定 | 种子 | 长/厚 vs `df` | 斜率 |
|---|---|---|---|
| `T7_verify_dGsens.py`（D17 之前） | 薄核 | 1.165 → 2.207 → 4.170（df 0.5/1/2e8） | **正**（+0.92） |
| `T20_dG_backsolve.py`（本轮，`proj2`） | `R=240 nm, t=100 nm`（AR=4.8） | 6.629 → 5.827 → 5.284（df 0.5/1/1.5e8） | **负**（−0.3） |

**⇒ 两者符号相反**：因为 `长/厚` 不是 `df` 的单值函数 —— 在低驱动下**弹性自能 + 曲率**
使薄板**变厚/缩短**（T20 实测 `df=0.5e8` 时厚度 100→70.7 nm），高驱动下才净长大。
反解必须同时钉住**种子几何**与**物理时间**，否则不唯一。
⇒ **结论：D7 取选项 (a)（CALPHAD 值），反解降级为"带前提的一致性检查"**，
并在 A2 交付里写明该限制。**这正是用户"先找文献"这一指示的价值所在。**

★ **连带需要重算的归档量**（全部依赖 `DS/T0/M_s`）：T6 的 `df(M_s)`、**T8 的 `q*`**
（旧值 `2.4e7 K/s` 是在 `DS=3.0e5` 下算的）、T7 的三档 `df`。已登记为待办。

★ **顺带抓到的一个符号陷阱**（已修）：`windowB_km.T_from_dG` 的入参是 **`dG_chem`**（T<T0 时为负），
不是**驱动力**。把正的驱动传进去会得到 `T > T0` 的反物理结果（实测 1417 K vs 正确 873 K）。
⇒ 新增 `T_from_drive()`（专用、带断言）并写进 docstring。

### ★ D12 决策（2026-09-28，按"**物理正确 + 工程可行**"两条标准定；用户授权）

**背景（实测）**：D12c 的 `r_c` 有**三个候选，物理含义各不相同，而结论随之翻转**：

| `r_c` 候选 | 实测值 | 物理含义 | `L=9.6 µm` 的 core | 判定 |
|---|---|---|---|---|
| 变体标记自相关 1/e | **0.285 µm** | 变体斑块的**最薄维度**（≈ 板条厚 0.25 µm！） | 9.03 µm | ✅ ≥ 8 |
| `χ=(reg>0)` 自相关 1/e | 0.509 µm | 残余母相口袋尺度 | 8.58 µm | ✅ |
| 种子间距 `ρ^{-1/3}` | **1.109 µm** | **周期镜像的弹性相互作用尺度** | 7.38 µm | ❌ < 8 |

**决策（物理正确性优先）**：

1. **D12c 的判据形式作废，改用"不变性判据"（= D12b 的形式）。**
   **理由（物理）**：周期性边界下，**弹性场按构造就是盒周期的**（谱法用周期 Green 函数），
   镜像相互作用是**代数衰减、量级由盒子尺寸本身设定**，不存在一个"不受影响的 core"。
   ⇒ 用 `L − 2r_c` 去界定 core 是**不适定的**（任何 `r_c` 都是拍出来的）。
   唯一**适定且可测**的判据是：**统计量在 `L → 1.5L` 下不变** —— 这正是 D12b，
   且**已实测 PASS**（连续强度量 `f` 7.3%、`Sv` 10.0%、`M6p` p25 **0.45%**）。
2. **`r_c` 保留为上报诊断，取保守（最大）口径**：
   `r_c := max(ρ^{-1/3}, L_block)` —— 因为镜像耦合的**物理载体是弹性场**，
   应按**最大的结构尺度**预留，而不是按板条厚。这条只影响"我们声明多大的核心区可信"，
   不再作为 PASS/FAIL 门槛。
3. **新增 D12d（盒子下限，工程 + 物理双依据）**：**`L ≥ 4·ρ^{-1/3}`**
   * 物理依据【实测】：`L/d = 2.9` 时，单个变体在 **`f = 0.09`** 就沿一个方向**贯通周期盒**
     ⇒ "自由生长"与"碰撞"两个物理**都测不到**（`T13-A` 因此被撤回、改判 INCONCLUSIVE）。
   * 工程依据【实测】：`d = ρ^{-1/3} = 2.068 µm`（`ρ = 0.113 /µm³`）⇒ `L = 9.6 µm` 给
     **`L/d = 4.64`** ✓，而 `N=192 / Δx=50 nm` 实测 **14.7 s/步、6.34 GB**，
     落在 22 GB 预算内 ✓（配置 C 的 `N=256 ⇒ L=12.8 µm, L/d=6.19` 留作 T17 收敛用）。
4. **新增 D12e（采样点）**：**取 `f ≈ 0.10`（"刚碰撞后"），不是 0.35。**
   * 依据【实测】：碰撞体积分数 `f_imp ≈ (π/4)(t/d) = (π/4)(100/2068) ≈ 0.038`；
     要长到 `f = 0.35` 只能靠**增厚**（慢 ~33×）⇒ 那是**晚段**，而晚段已被
     **盒子夹住 + 界面粗化**污染（T16 前置实测界面胞数 601→4232、`p25` 3.5°→18.2°）。
   * 交叉一致性：`d = 2.068 µm` 与 `t ≈ 0.25 µm` 在 `f_imp ≈ 0.1` 处的碰撞间距
     `d = (π/4)(t/f_imp) ≈ 1.96 µm` **相符到 5%** ⇒ 这套 `(ρ, t)` 自洽。
