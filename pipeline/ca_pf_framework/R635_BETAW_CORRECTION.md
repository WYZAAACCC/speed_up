## §4 ★ 教训（新增纪律）

> **R6（新）**：**任何"某机制无效"的结论，动手写结论前必须先做"
> "机制是否被自己的入口参数禁用"的检查。**
> 具体做法：把该机制的关键参数**从 0 扫到设计值**，看判据是否随之变化
> （本案：`β_w` 0 → 2.3 就给 1.000 → 3.536）。
> **若入口参数为 0 而机制又依赖它 ⇒ 判据 FAIL 是"配置的必然结果"，与机制无关。**
> 这与 `P12`（负对照必须在生产参数上做）同源，但**更强**：
> 不只是"负对照要选有分辨力的位置"，还要**确认正的机制没有被入口参数关掉**。
