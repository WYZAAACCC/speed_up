## §2 D5 的结论汇总（**本 goal 里信息量最大的一步**）

### 2.1 文献层（`R665`）
| 发现 | 后果 |
|---|---|
| **文献里没有 α′ 板条的 3D 尺寸**（只有 2D 长:短，值域 **9.0–23.8**） | ⇒ **"厚度"不可观测** |
| 无任何来源**分别**报告 width 与 thickness | ⇒ 模型的 `宽/厚 = e^{β_h−β_w} = 3.32` 是**不可观测的断言** |
| 生产 `β_h = 6.477` ⇒ 长厚比 **647** | ⇒ **远大于一切观测**（9.0–23.8）⇒ **从未被支持** |

| 机制 | 状态 |
|---|---|

| 弹性自协调 | ⚠ 仅注释，**无实现** |
| 板条间钉扎 | ⚠ 是迁移率各向异性，**不是厚度停止** |
| 逐变体各向异性弹性 | ⛔ **路径存在但默认关**（`aniso_elastic=False`），**且 `_bk_exp.py` 无 CLI 入口**（本文件 §3 核实） |

### 2.3 提案层（`R666 §3` + `R668`）
| 提案 | 状态 |
|---|---|

| **(c) 厚度依赖弹性能标度** | ⏸ **需改物理** ⇒ `R629 E3` |

### 2.4 ★ D5 的核心诊断（**三条，按重要性**）
1. **模型缺的不是一个机制，而是"厚度"这一维**：
   **三项独立定标机制全不存在**，`Gibbs–Thomson` 只作用曲率、不定标厚度；
2. **`β_w` 是"高杠杆但无锚"的参数**（`R668 §3.2`）：
   它**强力控制形状**（6.30 vs 3.79），但**靶值不可观测**；
3. **⇒ 唯一有物理依据的方向是 (c)**：
   引入**一个真正的厚度定标机制**（`R646` 的 E3 ❌ 已独立指认缺的就是"**厚度依赖的弹性能标度**"）。
