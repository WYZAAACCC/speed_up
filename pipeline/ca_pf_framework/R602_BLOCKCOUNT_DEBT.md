# R602 —— ★ 记账：**「块数」是规定值，不是物理涌现**（用户 2026-10-05 质疑成立）

> 触发：用户观察「当前的形核是直接设定了有九个块，每个块有 15 个板条吗？这好像并不是物理自然生成与涌现的吧」

## 1. 质疑成立 —— 而且是**代码自己写明的**

引擎的 C-2 口径说明（日志原文）：
```
平行建块（--nuc-block-parallel 1）：前 B 个成功事件各建一个新块，之后才转 stack
  ⇒ 块数 = B（**规定的**），每块最终 ≈ n(T_end) = 23 根
总根数 = B · n(T_end) = 3 × 23 = **69 根**
```
* **「块数 = B（规定的）」** —— 那个词是代码作者自己写的。
* `R502_BLOCKCOUNT.md` 早已记录：**框架里没有「块数」这条律** ⇒ 这是一个**已知缺口**。

## 2. 分清「规定」与「涌现」

| 内容 | 性质 |
|---|---|
| **块数 = B** | ❌ **规定**（非物理涌现） |
| 每块根数 = `n(T) = α_KM(Ms − T)` | ⚠️ **半物理**：Koistinen–Marburger 分数律是无扩散马氏体的标准律、`α_KM` 有文献出处；但"每块根数"这个用法是模型自定 |
| 每根板条的**位置** | ✅ 涌现 |
| 每根板条的**变体取向** | ✅ 涌现（弹性驱动力 `argmax` 选择 ⇒ 自协调的来源） |
| **长成什么形状**（长/厚/长宽比/掐断/阻截） | ✅ 涌现（相场方程决定） |
| **块间排布与块间自协调** | ✅ 涌现 |
| **实际出现几个变体** | ✅ **涌现** —— `n_var_sig` 是**量出来的**（当前 =4，不是设成 4），这是最硬的证据 |

**⇒ 数量被规定；结构、取向、形貌、自协调是涌现的。**

## 4. 物理上「块数」本该由什么决定

真实板条马氏体中，块/群的数量**不是输入**，而是三者共同作用的**结果**：
1. **自催化形核**：已形成的板条的相变应变在邻域产生应力集中 ⇒ **促进**后续形核（autocatalytic nucleation）；
2. **局部应力下的变体选择**：该应力场**偏好**某些变体、**抑制**另一些 ⇒ 决定出现几个变体、如何成组；
3. **碰撞阻截（impingement）**：板条相互阻截限制继续长大 ⇒ 与形核率共同决定最终的块尺度分布。

**⇒ 要让「200+ 根板条」是**涌现**的，需要给框架补一条「块数律」** —— 属**模型扩展**，不是调参能解决的。
