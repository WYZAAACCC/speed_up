# R630 —— ★★ CPU 资源纪律（**用户 2026-10-07 指示，硬约束**）

> **用户原话**：
> 「**每个实验用 4 核即可**，要**留出核供电脑上的其他工作正常运行**。**我还在电脑上写论文**」

---

## §1 规则

| # | 规则 |
|---|---|
| **C1** | **每个实验（每个 `_bk_exp.py` 进程）最多用 4 个逻辑核** —— 用**亲和性**硬约束，不靠"少传 `--nthreads`" |
| **C2** | 多个实验必须分到**不相交**的核（否则它们互相竞争，等于没限） |
| **C3** | 实验进程一律 **`nice = 10`** ⇒ 与用户的前台工作抢同一核时**优先让给用户** |
| **C4** | **至少留 8 个核**（本机 20 核）给用户的日常工作；当前分配：`0–3` / `4–7` 给实验，**`8–19` 留给用户** |
| **C5** | 设完之后**必须实测验证**（`_t11_cpu_audit.py`）—— 设了亲和性 ≠ 真的降下来了 |

---

## §2 ⚠ 关键实现细节（否则限核会**静默失效**）

**只对主进程 `sched_setaffinity` 是不够的。**
引擎是多线程的（实测 `c2Eq0` **37 个线程**、`c2B647` **28 个线程**），
BLAS/OpenMP 的工作线程**已经创建**，它们的亲和性是**创建时**继承的，之后改主线程**不影响它们**
⇒ 必须在 `/proc/<pid>/task/*` 上**逐线程**设置。

**工具**：`_t11_setcpu.py`（逐线程设亲和性 + 设 nice），`_t11_cpu_audit.py`（实测占用与亲和性）。

## §4 后续启动新实验时必须一起做

```bash
# 1) 起实验（--nthreads 仍给 8，真正的上限由亲和性兜住）
nohup python -u _t11_run_one.py <tag> <beta_h> > _w2_<tag>.log 2>&1 & disown
# 2) 立刻限核（在 PLAN 里加一行：tag → 空闲核段）
python _t11_setcpu.py
# 3) 实测验证
python _t11_cpu_audit.py
```

⚠ **`PLAN` 里的核段必须互不重叠**，并且**不得占用核 8–19**（那是用户的）。
