
### 9.7 选项 (a)「标准定量合金 PF」—— 第一步就给出了**判决级**结果（`_chk_ct.py`，SA-1）

**结论：reduced 家族的自由能根本没有公切线 ⇒ 界面没有热力学定义的局部平衡。**

- 仪器自由能（`p1c_ak3.i:68`）：`f(φ,c) = (RT/Vm)[c ln c + (1−c)ln(1−c)] + h(φ)·(A/Vm)·c`
  ⇒ `f_s − f_l = (A/Vm)·c` —— **线性项，但缺常数项**。
- 公切线要求「斜率相等 + 截距相等」。两式合并：
  `f_l(c_s) − f_l(c_l) − f_l'(c_l)(c_s − c_l) = −(A/Vm)·c_s`。
  **左边由 `f_l` 的凸性 ≥ 0，右边对 `A>0` 恒 < 0 ⇒ 方程无解**（除 `c→0` 的退化解）。
- **数值复核（SA-1a FAIL）**：`g(m)` 在 `[5.30e-1, 2.94e8]` 内**处处为正**，**0 个变号**；
  唯一零点在 `m = −2.90e10`（`c→0`）⇒ 退化解 ✓（SA-1b PASS）。
- ⇒ **任何 KR 型抗截留流都不可能修好它**：KR 的全部推导前提就是「界面局部平衡」。
  这**定量解释**了 §7.7 的「所需幅值是 KR 的 ~50 倍」与 §7.3 的「`W→0` 时 `k_eff` 不收敛」。

**最小结构修法（SA-1d PASS）**：把线性项补上常数——

```
f_s − f_l = [ a(1−c) + b·c ] / Vm        （a, b 由合金液相线上的系线定）
```
在 `T = 1911.1 K`、系线取 `(c_s, c_l) = (k_e·c0, c0) = (0.02269, 0.03600)` 时：
`a = −1.9204e7`、`b = 6.4642e8 J/m³`（`b − a = 6.6563e8`，对照 `A/Vm = 6.6567e8`）。
公切线精确落在该系线上，`k = 0.630300` = 目标值 ✓。
⇒ **斜率系数本来是**对的**（差 <0.01%），缺的只是**那个常数项**（约 `A/Vm` 的 2.9%）。

**⚠ 但只补自由能还不够**：常数项只出现在 `f_s − f_l` 里，**`∂f/∂c` 看不见它**
⇒ 对「预设 φ」的仪器，c 方程**完全不变**，界面局部平衡**仍然不被施加**。
⇒ **选项 (a) 必须解 φ（WBM/KKS）**，这正是它与 reduced 家族的**本质**区别。
