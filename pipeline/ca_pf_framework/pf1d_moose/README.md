## 3. 已知的物理坑（本轮实测）

1. **抗截留核的效应严格正比于 `dphi/dt`**（源码级：`AntitrappingCurrent.C` 返回
   `F * v_dot * grad_v * grad_test / |grad_v|`）。若 φ 是 AuxVariable（无 `_u_dot`），
   该核**恒为零**，`ALPHA=0` 与 `ALPHA=2` 会**逐位相同**。这是仓库里"抗截留无效"的根因。
2. `F_at` 的幅值必须跟着界面宽 `W` 走（`F = ALPHA*W*(1-k)*c*(1-phi)`）；
   生成器默认 `W=2e-6` 比 `WGB` 小 2~4 倍，是**第二个** bug。
3. `F_at` 的 `(1-phi)` 权重把电流压到界面的**液相侧**；界面电流的积分 `~W^2`
   （与 Karma-Rappel/Plapp 的标度一致），所以"ALPHA 是纯数"这一点是可以检验的。
4. **本算例的区制**：`V = 0.1 m/s`、`D_L = 9.5e-9`、`l_D = 95 nm`。
   `W = 200 nm` ⇒ `V*W/D_L = 2.1` —— 已经**深入强截留区**（真实物理，也是要校准的对象）。

### 7.1 动机（承接 §4.6 的"需要用户拍板"）

### 7.4 根因候选（记账，两条都指向"仪器与生产脱钩"）

1. ★ **`kappa_c = 0`**（本目录模板）而**生产用 `κ_c = 1e-14`**（`w_c = sqrt(κ_c/f'') = 0.105 µm`，
   见 `stage1_meltpool_c.premerge.i` 的 Gate-1 记录）。`κ_c = 0` ⇒ **c 场没有梯度能**
   ⇒ 这里根本没有"c 的弥散界面"，c 剖面只由 `M(φ)` 的 **19000× 对比** + 线性分配驱动项决定。
   ⇒ 于是测到的"截留"**不是** KR 的薄界面截留，而是"**移动的扩散系数突变区**对溶质的拖曳"，
   它的补偿量 ∝ **c 剖面的宽度**（`l_D`/`w_c ~ 100 nm`），**不 ∝ η 的 `W`** —
   这正好解释 §4.6 的 `ALPHA*·W ≈ 2.9 L_c` ✓，也解释了 `ALPHA*` 为什么随 `W→0` 发散 ✓。
   ⇒ **这是 AGENTS 教训 #24（"同一参数在多处、改一半；验证算例与生产悄悄脱钩"）的第二例**：
   本目录所有 `ALPHA*` 数字都是**在 κ_c = 0 的模型上**得到的，**不能搬生产** ✓（与 §4.6 的
   "不能写论文、不能搬生产"一致，现在给出了机理）。
2. `f_loc` 的分凝项是 `h(φ)·c/Vm` 的**线性**耦合（`h = 3φ²−2φ³`），不是标准合金 PF 的
   双阱 + 分凝形式 ⇒ 局部平衡 `c_s = k c_l` 不是该自由能的**推论**，而只是被"驱动"。

### 7.5 判决实验（已启动）：把电流的宽度因子从 `W` 换成 `w_c`

若 §7.4 的机理成立，则正确形式是 **`F_at ∝ w_c`（c 的界面宽）而非 `∝ W`（η 的界面宽）**，
于是 `ALPHA*` 应回到 **O(1) 且与 `W` 无关**。已生成 `p1c_kcw.i`：
`kappa_c = 1e-14`（= 生产值）、`F_at = ALPHA·1.05e-7·(1−k)c(1−φ)`（字面量 `w_c = 105 nm`），
正在 W = 10 nm 上扫 ALPHA = 0/0.5/1/2/4（`drive_thin.py 10 0,0.5,1,2,4 5 p1c_kcw.i`）。
**判据**：ALPHA* 是否 O(1)（对照 KR/Plapp 的 `1/(2√2) ≈ 0.354`）且与 W 无关。

### 9.7 选项 (a)「标准定量合金 PF」—— 第一步就给出了**判决级**结果（`_chk_ct.py`，SA-1）

**结论：reduced 家族的自由能根本没有公切线 ⇒ 界面没有热力学定义的局部平衡。**

- 仪器自由能（`p1c_ak3.i:68`）：`f(φ,c) = (RT/Vm)[c ln c + (1−c)ln(1−c)] + h(φ)·(A/Vm)·c`
  ⇒ `f_s − f_l = (A/Vm)·c` —— **线性项，但缺常数项**。
- 公切线要求「斜率相等 + 截距相等」。两式合并：
  `f_l(c_s) − f_l(c_l) − f_l'(c_l)(c_s − c_l) = −(A/Vm)·c_s`。
  **左边由 `f_l` 的凸性 ≥ 0，右边对 `A>0` 恒 < 0 ⇒ 方程无解**（除 `c→0` 的退化解）。
- **数值复核（SA-1a FAIL）**：`g(m)` 在 `[5.30e-1, 2.94e8]` 内**处处为正**，**0 个变号**；
  唯一零点在 `m = −2.90e10`（`c→0`）⇒ 退化解 ✓（SA-1b PASS）。
- ⇒ **任何 KR 型抗截留流都不可能修好它**：KR 的全部推导前提就是「界面局部平衡」。
  这**定量解释**了 §7.7 的「所需幅值是 KR 的 ~50 倍」与 §7.3 的「`W→0` 时 `k_eff` 不收敛」。

**最小结构修法（SA-1d PASS）**：把线性项补上常数——

```
f_s − f_l = [ a(1−c) + b·c ] / Vm        （a, b 由合金液相线上的系线定）
```
在 `T = 1911.1 K`、系线取 `(c_s, c_l) = (k_e·c0, c0) = (0.02269, 0.03600)` 时：
`a = −1.9204e7`、`b = 6.4642e8 J/m³`（`b − a = 6.6563e8`，对照 `A/Vm = 6.6567e8`）。
公切线精确落在该系线上，`k = 0.630300` = 目标值 ✓。
⇒ **斜率系数本来是**对的**（差 <0.01%），缺的只是**那个常数项**（约 `A/Vm` 的 2.9%）。

**⚠ 但只补自由能还不够**：常数项只出现在 `f_s − f_l` 里，**`∂f/∂c` 看不见它**
⇒ 对「预设 φ」的仪器，c 方程**完全不变**，界面局部平衡**仍然不被施加**。
⇒ **选项 (a) 必须解 φ（WBM/KKS）**，这正是它与 reduced 家族的**本质**区别。

### 9.8 ★★ 判决：自由能的**符号**必须翻转（k > 1），生产模型现在把 V 分配**搞反了**

**推导（纯物理，不用任何经验值）**

修正后的自由能 `f_s − f_l = [a(1−c) + b·c]/Vm` 里，常数项就是**纯 A 组元的化学势差**：
`a/Vm = μ_A^β − μ_A^liq`（A = Ti）。

`T = 1911.1 K < T_m(Ti) = 1941 K` ⇒ 纯 Ti 此时**液体**稳定 ⇒ 必须有 `a > 0`。

而由公切线代数（`_chk_ct.py` 已数值复核）：`a = RT·ln[(1−c_l)/(1−c_s)]`。
两个式子合起来：`a > 0 ⟺ c_s > c_l ⟺ **k_V(β/liquid) > 1**`。

**也就是说：V 必须富集在固相 β 里。**（与"V 是 β 稳定元素"一致。）

**而生产输入 `pipeline/stage1_meltpool_c.i` 的 `f_loc` 用的是 `A = +7552 J/mol`，对应 `k = 0.6303 < 1`**
—— 即**把 V 当成被固相排出的元素**，方向反了；而且它取 `a = 0`，等价于
**"纯 Ti 没有熔点"**（`μ_Ti^β ≡ μ_Ti^liq`），这是一个**结构性缺陷**，不是参数问题。
