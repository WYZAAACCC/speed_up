**`_pair_normals` 找的是什么？用了什么判据？**【实测】

```
ncmp[k,l] = argmin_n 0.5 · Δε : Λ(C, n) : Δε ,   Δε = ε⁰_k − ε⁰_l        (windowB_surface.py:1177, :1198, :1212)
```
- 它找的是**"两变体的界面放在哪个法向上弹性能最小"的法向**，
  亦即 **rank-1 不变平面（共格界面）法向的微弹性版本**，不是几何不变平面法向。
- 判据的两级：
  1. **经典几何判据（必要条件）**：小应变共格 ⟺ `Δε = sym(a⊗n)` ⟺ 三个特征值中**两个等大反号**。
     在 `tr Δε = 0` 时它**等价于** `det Δε = 0`（即 `λ_mid = 0`）。
     正确实现见 `_r1_pairgeo2.py:21-22`：`g3 = min_{i<j}|λ_i+λ_j| / ‖Δε‖_F`。
  2. **本模型的微弹性判据（有分辨力的那个）**：`E_min = min_n 0.5 Δε:Λ(C,n):Δε`。
- **结论（`R1_PAIR_CRITERION.md:13-19`，逐字）**：
  「经典几何判据在本问题上被『证明』没有分辨力 —— 因为同 packet 的 6 对板条两两之间的
  应变差 Δε 具有『完全相同』的特征值谱 … 而模型自己的各向异性微弹性 `E_min` 对这 6 对
  给出跨 **38.9 倍**的排序。⇒ **排序必须用 `E_min`；几何判据只能当必要条件（一比特筛子）**。」
- **一致性正对照**（`R1_PAIR_CRITERION.md:80-90`）：满足几何判据的 **42 对** `E_min ∈ [4.188e-04, 1.816]`；
  不满足的 **24 对** `E_min = 4.62609e+05`（24 个值只差 5.3e-06 相对）⇒ **两类零重叠、比值 2.5e5**。
  ⇒ 「模型的微弹性判据把经典共格必要条件当成了真正的必要条件」（66 对范围内无反例）。

### 2.1 判据 A —— 宏观形状应变抵消（"Σ f_i ε_i ≈ 0"）

**数学形式**：设变体组 `G`，体积分数 `f_i ≥ 0, Σ_{i∈G} f_i = 1`，宏观转变应变

```
ε̄(G) = Σ_{i∈G} f_i ε⁰_i
```

自协调（在几何线性理论里）⇔ 存在这样的 `f` 使 **`ε̄(G) = 0`**，即
**`0 ∈ conv{ε⁰_i : i ∈ G}`**（凸包条件 / Reuss 下界）。

⚠ **两个必须写进结论的限制**：
1. **迹（体积）部分不可能抵消** —— 本体系里 12 个变体的 `tr ε⁰` **完全相同**
   （`R1_PAIR_CRITERION.md:56-62` 实测极差 1.1e-16）⇒ 判据只能加在**偏量**上：
   `ē = Σ f_i dev ε⁰_i`。**这正是 `_r30_selfac_struct.py:20-24` 写下的口径。**
2. **凸包条件是必要条件，不是充分条件。** 真正的自协调组织必须是**可拼接**的
   （层状/双晶式、界面共格），而不只是"平均应变为零"。Ball & James 的框架里，
   能量极小化序列（fine phase mixtures）给出的才是可达的自协调微结构。
   ⇒ **A 只能当"上界/必要条件"，不能当判据本身。**

**出处**：
【文献·已核实标题+DOI】J. M. Ball, R. D. James, *Fine phase mixtures as minimizers of energy*,
Arch. Rational Mech. Anal. **100**, 13–52 (1987)，DOI [`10.1007/BF00281246`](https://doi.org/10.1007/BF00281246)
（检索到出版方条目；**未读原文**）。
**本仓库对应实现**：`windowB_ti64_variants.py:31,123-126`（C4 自检）、
`_r30_selfac_struct.py:14-36`（群级残差 `r(G)`）。**引擎里没有。**

### 2.2 判据 B —— 配对共格 / 不变平面（Hadamard rank-1）

**数学形式（小应变）**：两变体 `i,j` 之间能存在**无应力共格界面** ⟺

```
∃ a, n :  ε⁰_i − ε⁰_j = sym(a ⊗ n) = ½(a nᵀ + n aᵀ)          （Hadamard / rank-1 跳跃条件）
```

在 `tr(ε⁰_i − ε⁰_j) = 0` 时，它等价于 `det Δε = 0` ⟺ `λ_mid(Δε) = 0` ⟺
**三个特征值中有两个等大反号**（`_r1_pairgeo2.py:21-22` 的 `g3 = 0`）。
⚠ 注意它**不是**"Δε 秩 1"：`a ⊥ n` 时 `sym(a⊗n)` 的特征值是 `(+q, −q, 0)`，**秩 2**。

**数学形式（几何非线性 / 有限应变）**：用转变伸长张量 `U`（`U = √(FᵀF)`），
母相/马氏体界面共格 ⟺ **`λ₂(U) = 1`**（中间主伸长 = 1）；
两变体 `i,j` 的孪晶式共格 ⟺ `λ₂(U_i⁻¹U_j) = 1`。

**"超相容"加强版（cofactor conditions）**【文献·已核实摘要原文，arXiv 页面已抓取】：
Chen, Srivastava, Dabade, James, *Study of the cofactor conditions: conditions of
supercompatibility between phases*, arXiv:[`1307.5930`](https://arxiv.org/abs/1307.5930)，
related DOI [`10.1016/j.jmps.2013.08.004`](https://doi.org/10.1016/j.jmps.2013.08.004)。
摘要逐字给出三条子条件：

```
(i)   λ₂(U) = 1                                     （中间主伸长为 1）
(ii)  a · U cof(U² − I) n = 0                        （a, n 是该孪晶系的特征矢量）
(iii) tr U² + det U² − ¼|a|²|n|² ≥ 2
```
三者合起来是"对**任意**体积分数 `f ∈ [0,1]` 都存在晶体学理论解"的充要条件；
而一般（非 cofactor）材料的晶体学理论对给定孪晶系**最多只有两个** `f*` 与 `1−f*` 有解。
⇒ **这是"自协调能不能连续调体积分数"的严格判据**，比"某一对恰好相容"强得多。

**出处（配对相容判据的教科书级出处）**：
【文献·仅检索到条目，未读原文】K. Bhattacharya, *Microstructure of Martensite:
Why It Forms and How It Gives Rise to the Shape-Memory Effect*, Oxford University Press (2003)；
以及作者公开讲义 Bhattacharya, *Theory of martensitic microstructure and the shape-memory effect*
（Caltech 课程讲义 PDF，`https://www.its.caltech.edu/~me260/class%20notes/Bhattacharya_Unpublished%20notes_1999.pdf`，
我尝试抓取但工具不支持 `application/pdf` ⇒ **未读到正文**）。

**本仓库对应实现**：`windowB_surface.py:1174-1219`（`_pair_normals`，微弹性版）、
`_r1_pairgeo2.py`（几何版）、`R1_PAIR_CRITERION.md`（两者的一致性判决）。
⚠ **本仓库用的是微弹性 `E_min`，不是 `λ₂=1`**；两者在 66 对上零重叠一致，但这只是
**一致性证据**，不是"用了正确的判据"的证明。

### 2.3 判据 C —— 群级共格连通（clique）

把"相容对"当图的边 ⇒ 图 `G`。**全共格团（clique）** = 组内**任意两两**都共格的变体集合，
这是最强的一档自协调（所有界面都是不变平面）。这是 `_r30_selfac_struct.py:33-36` 的 C 条。

⚠ **实现注意**：clique 条件是**充分性过强**的 —— 真实的 block/packet 组织里，

⇒ **判据 C 应读作"最强档的一个子集分类"，不是自协调的必要条件。**

### 2.6 几何非线性理论（Ueda / Inamura 一系）

**该系理论的精神（【推理】，基于标题与摘要性元数据，非读原文）**：
用几何非线性（有限应变）晶体学处理 **habit plane variant (HPV) 集团** ——
即一组惯习面变体能否拼成一个**无缝隙、无长程应变**的自协调集团。
与判据 B 的关系：判据 B 处理"一对"，该理论处理"一个集团"。
**⇒ 对本项目最直接的可用形式是：把判据 A（群级应变残差）与判据 B（配对共格）
在**有限应变**下重做一遍，得到"集团可拼接性"的判据。本仓库现在是**小应变**（`eps0 = sym(F)−I`），
连层级 1 的转动都没有。**

- S. Morito 等, *The morphology and crystallography of lath martensite in alloy steels*,
  Acta Mater. **54**, 5323 (2006)，DOI [`10.1016/j.actamat.2006.07.009`](https://doi.org/10.1016/j.actamat.2006.07.009)（**未读原文**）
- 【文献·仅检索到条目，未读原文】*Variant selection during BCC to HCP phase transformation

  （与 Ti64 最同材料同工艺的一篇；**DOI 未核实**）

**标准量化口径（【推理】+ 本仓库已采用的锚）**：
- **同一 packet 内的 3 个自协调变体对**：Burgers OR 下每个 `{110}_β` 面给出 2 个变体
  （本体系：6 个面 × 2 条 `<111>` = 12 变体，`windowB_ti64_variants.py:16-19`），
  同一 packet 内两变体应变差是**纯剪切**（本仓库实测 `λ = (±1.8378e-02, 0)`，`R1_PAIR_CRITERION.md:96-108`）。
- **block = 同变体反复形核**（`windowB_surface.py:1258-1259` 引 Furuhara 2008，逐字
  "A BLOCK IS FORMED BY **REPEATED NUCLEATION OF THE SAME VARIANT** OF LATHS ADJACENT TO EACH OTHER"）。
- **packet = 同一 `{110}_β` 惯习面族**；本仓库用 `npref` 的等价类近似
  （`T24_verify_grouping.py:29-32`，且记账「这是**本项目自己的**族定义」）。
  ⚠ 而 `R1_PROBLEM_LEDGER.md` 的 D 类明确记着一条**已被实测否决的路**：
  「**`NPF` 当 packet 用** —— 12 个变体各不相同（只有 3 对近简并差 5.28°）⇒ 改用 Burgers c 轴分组」。

**⇒ 可实现的数学形式（综合，给下一步用）**

```
给定 12 个 ε⁰_i（小应变，无迹）：
  A. 群级残差     r(G) = min_{f∈Δ} ‖Σ_{i∈G} f_i dev ε⁰_i‖_F / mean‖dev ε⁰‖_F        （必要条件）
  B. 配对共格     compat(i,j) ⟺ g3(i,j) = min_{p<q}|λ_p+λ_q| / ‖Δε_ij‖_F ≈ 0
                 且用模型自己的 E_min(i,j) = min_n ½Δε:Λ(C,n):Δε 做**排序**
  C. 群级连通     图 G 的 clique（最强档，充分性过强）
  D. 观测富集     Spearman( E_min(k,l) , A_kl ) < 0  且显著
  E. 能量对照     需要"群级下界"，不是"随机散斑对照"
```
**A/B/C 在本仓库已有可跑的代码**（`_r30_selfac_struct.py`、`_r1_pairgeo2.py`、`_pair_normals`），
**D 有代码但从未跑过**，**E 的正确版本不存在**。
