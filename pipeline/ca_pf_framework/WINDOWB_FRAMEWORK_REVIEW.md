## §0 判决（一句话）

**当前 Window B 的表示层（体相场 + Gibbs 零厚度面）是对的，但"物理层"还没有闭合：**

1. **驱动力不来自任何自由能** —— `df` 是一个**手填的常数**（2e8），无温度依赖、无成分依赖；
   代码里没有任何 `f_β(T,c) − f_α′(T,c)`。**【核实】**
2. **动力学语义与马氏体不符** —— 用的是"迁移率 × 驱动力"的**速率型**动力学（`v=M·ΔG`），
   而位移型马氏体是 **athermal**（f 只依赖 T、不依赖 t）。结果**依赖人为的 `M=1e-9`**。**【核实】**
3. **弹性项符号错**（P0-1）—— 使弹性从"阻碍"变成"正反馈"。**【实测】**
4. **B1 的界面被套上了液固分配**（`_stefan` 的 `k_part=0.6303`）—— 位移型变换**不分配溶质**。**【核实】**
5. **界面能各向异性的形式不是立方不变式，且用错了通道**（用 M(n) 代替 γ(n)）；
   而 `M(n)=M0·exp[−β(n·n*)²]` 的 Huygens 渐近形状把长/厚**锁死在 4.36**（β=3.5）。
   **要拿到 10–30 必须改函数形式 + 走 γ(n)/Wulff 通道。**【实测】
6. **没有任何机制定板条厚度** —— 需要补，或者**显式声明厚度是输入**。**【核实】**
7. **离散化不是 dx 无关的**（界面带厚 ∝dx、延拓带宽按**胞**计、面测度 +52% 偏差）⇒
   **不能保证加密收敛**；而"Gibbs 面避开分辨率"这个卖点要求它必须 dx 无关。**【实测/核实】**
8. **形核是输入**（HYBRID §8 item 4）—— 这条必须写死，因为它决定了"block/packet/cluster 能被验证到什么程度"。

**⇒ 结论：不全自洽、也不完备。** 下面 §2 写出应有的完整框架，§3 逐条判决，§5 给补法。

## §2 应有的完整数学框架

### 2.1 状态量

| 层 | 量 | 说明 |
|---|---|---|
| 体 | `c(x,t)`（V、Al） | 守恒；**B1 期间不分配 ⇒ 实际上被冻结** |
| 体 | `ε(x)`、`σ(x)` | 准静态微弹性，`ε⁰(x)` 分段常数（每胞一个变体） |
| 体 | 区域标签 `I(x) ∈ {β, α′₁…α′₁₂}` | 由 level-set 的 `argmin` 给出（每胞唯一） |
| 面 | 面片集合 `Σ = ∂I`，法向 `n`，曲率 `κ`，面积测度 `A` | 3D 中的离散 2D 流形 |
| 面 | **面片身份** `(I⁻, I⁺)` | ← **界面本构必须靠它查表** |
| 外部 | `T(t)` | 由热层/Window A 给定（本轮可先当**时间表**） |

### 2.2 能量泛函（这是"驱动力"的唯一来源）

```
E[I; T] = ∫_V { (1−χ)·f_β(c,T) + χ·f_α′(c,T) } dV          ← 化学（分段常数）
        + E_el[ε⁰(I); σ_ext]                                ← 弹性（谱法，准静态）
        + ∫_Σ γ(n, I⁻, I⁺) dA                               ← 界面能（零厚度面）
        − ∫_V σ_ext : ε⁰(I) dV                              ← 外载功（可选）
```
* `χ(x)=1` 当 `I(x)` 是某个 α′ 变体。
* **化学驱动力**：`Δf_chem(T) = f_β(c,T) − f_α′(c,T) > 0` 表示 α′ 有利。
  由 CALPHAD / `windowB_km.dG_chem` 给出（**符号必须统一到 `df>0 = 变体有利`**）。
* **弹性驱动力**（变分导数，**这是 P0-1 的正确符号**）：
  ```
  δE_el/δI_v = −ε⁰_v : σ      ⇒   界面驱动力 = +ε⁰_v : σ
  ```
* **界面驱动力（Gibbs–Thomson）**：`−γ_eff(n,·)·κ`，`κ` 对**凸的 α′ 体**取正。

### 2.3 演化方程

**(a) 体相成分（守恒）**
```
∂c/∂t = ∇·( Σ_j M^c_{ij} ∇μ_j ),   μ_j = δE/δc_j
```
**B1 特例**：位移型、无扩散 ⇒ 界面扫过时 `c` **不变**；体扩散在建造期可忽略 ⇒ **`c` 冻结**。
（`c` 只在 B2 / 热处理阶段演化。）

**(b) 体相弹性（准静态，每步解一次）**
```
∇·σ = 0,  σ = C : (ε − ε⁰(I)),  ε⁰ = Σ_v χ_v ε⁰_v
```

**(c) 界面推进（面场，PDE 而非胞翻转）**
```
∂φ/∂t + v_n |∇φ| = 0
v_n = M_Σ(n, I⁻, I⁺) · [ Δf_chem(T) + Δf_el(x) − γ_eff(n, I⁻, I⁺)·κ ]
Δf_el(x) = +ε⁰_v : σ(x)          ← 变体的弹性驱动力（正 = 有利）
γ_eff    = γ + γ_θθ              （光滑各向异性）
```

**(d) 面上量（本轮 B1 只需要"几何 + 拓扑"，不需要 Γ）**
`Γ_i` 的守恒式（Stefan + 面储存 + 沿面输运）属 **Window C**，本轮**关掉**。

### 2.4 界面本构（Gibbs 面的"物性"从哪来）

| 量 | 依赖 | 现在的状态 |
|---|---|---|
| `γ` | `n`、面片身份 `(I⁻,I⁺)` | 标量常数 + 单轴 `n` 各向异性 |
| `M_Σ` | `n`、面片身份 | 单轴 `n` 各向异性（`mob_beta`/`mob_beta_w`） |
| `γ_el`（相干界面弹性能） | `[[ε]]`、`n` | **完全没有** |

### 2.5 形核与外边界（**必须显式声明**）

* **形核是输入，不是输出**：模型**不预测** M_s、不预测晶核数密度与取向分布。
  ⇒ **能被验证的只有"给定晶核分布之后的生长与分组"。**
* **体相网格 `dx` 不解析任何界面宽度**（Gibbs 面零厚度）；
  `dx` 只需解析**组织层级**（板条厚、块/群尺度）。

### 2.6 约束与不变量（框架必须满足的）

| # | 约束 | 现状 |
|---|---|---|
| A | 符号统一：`df>0 ⇔ 变体有利`；弹性驱动力与之一致 | ✗ |
| B | 量纲齐次（尤其面量的 mol/m² ↔ mol/胞） | ✓ |
| C | 守恒：B1 期间**无分配** ⇒ `c` 逐位不变 | ✗（`_stefan` 在分配） |
| D | 热力学一致：`γ>0`、光滑时 `γ+γ_θθ>0`；面片为刻面时用 **Wulff 构造** | 部分 |
| E | 立方母相对称性：12 变体由同一 `ε⁰` 集合的群作用生成；`Σ_v dev(ε⁰_v)=0`（自协调） | ✓（实测 3.3e-16） |
| F | **athermal**：`f` 只依赖 `T`，不依赖 `t` | ✗ |
| G | 离散化 **dx 无关**（面测度、带厚、延拓带宽） | ✗ |
| H | 结果对**人为参数**（`M`、`Mob`）不敏感 | ✗ |

## §3 自洽性逐条判决

### C1 符号一致性 —— ✗ **不通过**（2 处）

| 处 | 现状 | 证据 |
|---|---|---|
| **弹性驱动力** | `elastic_driving()` 返回 `ed = −ε⁰_v:σ`，却被当**驱动力**与 `df` 同号相加 ⇒ **反了** | **【实测】** 单变体球有限差分：真实能量释放率 **−1.00e8 J/m³** vs 模型 **+1.66e8 J/m³**（`_audit_edsign2.py`） |
| **化学驱动的两套约定** | `windowB_km.dG_chem(T<T0) < 0`（判据 `_chk_t21b.py` T2.1b-2c 明确要求 `dG(M_s)<0`），而 `LevelSetMulti.df>0` 才是"变体有利" ⇒ 调用点必须**再取一次负号**（`windowB_b1.py:132` 确实写了 `g.df[1:] = -K.dG_chem(...)`） | **【核实】** 两套约定并存 + 一处补偿负号；而 `windowB_pf3d.PF3D` 的 `dG_of_T` 是**直接喂**的（注释还写着"见 `windowB_km.dG_chem`"）⇒ **潜在静默符号错** |

> 本项目已经在"符号"上栽过一次（`WINDOWB_SURFACE_AUDIT §11.5`：化学驱动方向反了 ⇒ 整个 M2 的 `f_trans` 作废）。
> **框架层要求：全套代码只允许一套符号约定，并在每个入口做断言。**

### C2 量纲 —— ✓ 通过

面量按 mol/胞（`Gam_mol`）为权威状态、`ρ_mol` 换算已记账；`_stefan`、`update_Gamma` 都有守恒判据
（M4 **2.015e-16**、W6 5/5 PASS）。**【核实】**

### C3 守恒 —— ✗ 对 B1 不成立（物理错）

`_finish_advance()` 无条件调用 `self._stefan(reg0, reg_adv)`，而 `_stefan` 的默认
`k_part = 0.6303`（**液固分配系数**）⇒ 界面每扫过一胞就把 `c` 改成 `0.6303·c`。
**位移型马氏体不分配溶质** ⇒ 这是把**凝固**的物理搬到了**马氏体**上。
今天它没有动力学后果（`c` 不进任何驱动力），但它
(i) 破坏 MATH §5.5 对 B1 的定义「V 不分配」；
(ii) 在 `prod_boxB*.py` 里 `update_Gamma` 用的 `Gamma_eq(c)` 读到的是**被污染的 c**。**【核实】**

### C4 热力学一致性 —— ✗ 不通过

* `df` 是**手填常数**（`prod_boxB*.py: DF = 2.0e8`），**不来自任何自由能**，**无 T 依赖**。
* level-set 路径里**没有温度这个量**（`LevelSetMulti` 只有 `self.T = 1950.0` 喂给 `Gamma_eq`）。
* `windowB_km.py` 里有完整的 `dG_chem(T)` 与 athermal 形核律，但**只被 `windowB_b1.py` 用**，
  **没有接进板条形貌的那条路径**。**【核实】**

### C5 对称性 —— 部分

* ✅ 12 个 Burgers 变体在立方点群下**精确简并**（AV-1 散布 ~1e-15）；`Σ_v dev(ε⁰_v)=0`（**3.3e-16**）。
* ❌ **界面能形式不是立方不变式**：`herring_stiffness` 用的是 `γ0[1+Λsin²θ]`、θ 相对**单个** `n_pref`。
  对一个**变体**来说"惯习面只有一个"是物理的，但这个函数形式在母相立方群下**不闭合**
  （正确的写法是 `γ(n)` 由 `{hkl}` 族展开或直接给 `γ_{hkl}` 表）。**【核实】**
* ❌ **惯习面本身有矛盾**：PTMC 单变体 IPS 给 `(110)_β`（实测 λ₂=1.00042），
  而代码里弹性最省能法向 `npref` 与 `{334}_β` 的关系**只是"不矛盾"**；
  HX-8b 的无规对照已证明"接近 {334}"**没有证明力**（中位 8.0° 只相当于无规第 89 百分位）。**【核实】**

### C6 时间标度 / athermal —— ✗ 不通过

* `v = M·ΔG`，`M = 1e-9`（**无来源**）。所有形貌结果都是 `M` 的函数 ⇒ **人为参数污染物理结论**。
* 已归档的实测：弹性项比 `df` 大 ~5 倍 ⇒ 实际每步位移 0.6–0.75 dx（超 CFL）⇒
  后来才加 `suggest_dt`。**这说明"速率"这条语义在本问题里一直没被正确定住。**
* **athermal 判据**（f 只依赖 T、不依赖 t）已有（`windowB_km` 的 T2.1b-3 指纹），
  但**跑在 B1 那条独立路径上**；板条形貌路径没有这条判据。**【实测/核实】**

### C7 离散化收敛性 —— ✗ 不通过（**这一条直接动摇"Gibbs 面避开分辨率"这个卖点**）

| 处 | 现状 | 为什么不是 dx 无关 |
|---|---|---|
| 界面带 | `iface = |φ_winner| ≤ iface_band·dx`（`iface_band=2`） | 带宽 ∝ dx；`cell_area_geom` 用 `|∇φ|dx²/3` ⇒ 面积测度依赖带厚 |
| 速度延拓 | `band_cells = 20`（**胞数**） | 物理带宽 = 20·dx ⇒ 随 dx 变 |
| 界面面积 | 格点键测度对球 **+51.9%** 偏差（审计已测） | 斜面/曲面偏差不随 dx 收敛 |
| 重初始化 | `reinit_every=25`（**步数**） | 每步位移 ∝ dx（CFL）⇒ 物理间隔 ∝ dx |
| 阶梯偏差 | `Σ|t_i|` 投影上限类问题 | 见 `AUDIT_2026-09-27` §3.2 |

⇒ **框架要求：Gibbs 面的离散化必须做到"面测度、面本构、推进格式"三者都与 dx 无关**，
并给出 **dx 收敛判据**（同一物理构型、只改 dx，`γ`、`v_n`、`A` 的相对变化 <5%）。
**现在一个都没有。**

### C8 参数来源 —— ✗ 部分

| 参数 | 值 | 来源 |
|---|---|---|
| `Mob` | **1e-9** | **【未核实】无来源、无敏感度** |

## §5 完善方案（逐条给方程与判据）

> 按"先便宜、先判决性"排序。**每一条都先写判据，再改代码。**

### P1 [框架] 把驱动力接回自由能，并统一符号

* **改什么**：`LevelSetMulti` 增加 `dG_of_T` 入口（`PF3D` 已有，照搬）；
  `df` 由 `Δf_chem(T, c) = f_β − f_α′` 给出，不再手填。
* **符号**：**全局统一为 `df > 0 = 变体有利`**；`windowB_km.dG_chem` 改成同号
  （或在 `windowB_km` 内部翻转并**删掉调用点的负号**），并在两个入口加 `assert`。
* **判据 D1**：`dG_chem(T)` 严格单调（T↓ ⇒ 驱动↑）；`dG_chem(M_s) = +|dG_crit|`；
  `LevelSetMulti(df>0)` 使变体长大（复用 T2.1b-7）。

### P2 [框架] 把 athermal 语义写死，`M` 降级为数值松弛率

* **声明**：位移型马氏体的正确描述是**每个 T 上的局部能量极小**，不是速率过程。
  ⇒ `M` **不是物理参数**，只是把系统推向极小的数值速率。
* **判据 D2（关键）**：同一 `T`（同一 `Δf`）下，把 `M` 变 3 档（如 3e-10 / 1e-9 / 3e-9），
  **末态 `f` 与形貌统计（板条厚、变体分组）在 5% 内不变**。
  现在做不到 ⇒ 说明还没跑到极小，是**数值未收敛**而不是物理。
* **判据 D3（athermal 指纹）**：固定 T 跑到平台后 `f` 不随时间变；改 T 则 `f` 变。

### P3 [物理] 补 `γ_el`（相干界面弹性能）

* **方程**：`γ_el = ½ [[ε]] : Λ(n) : [[ε]] · λ_el`，`λ_el` 是界面过渡层厚度 **[A]，必须做敏感度**。
  `Λ(n)` 复用 `windowB_pf3d._lam_full`（已有）。
* **判据 D4**：相容面 `[[ε]] = sym(a⊗n)` ⇒ `γ_el = 0`（机器零）；
  不相容面 ⇒ `γ_el` 有限且与逐 k 闭式一致（沿用 P1a/P1c 的口径）。

### P4 [物理] B1 关掉溶质分配

### P5 [表示] 界面本构按面片身份

* **改什么**：为每个活跃配对 `(I⁻,I⁺)` 存/查 `γ₀`、`M₀`、`n_pref` 表（`ncmp` 已是雏形）；

### P6 [物理] 板条厚度的定标机制（三选一，需用户拍板）

| 选项 | 做法 | 代价 |
|---|---|---|
| (a) 补物理 | `γ_el` + 自协调弹性 + **塑性松弛** ⇒ 厚度成为**输出** | 大；**塑性目前没有模型**，Ti64 α′ 的临界应力/位错密度数据也缺 |
| (b) **尖点的 `M(n)` + Wulff 构造** | 形状 = `v(n)` 极图的 Wulff 形；**尖点**（有限角窗内 `M→0`）⇒ Wulff 形出现**平面刻面**，长/厚可任意大 | 中；**可先解析定标定（秒级）再改代码** |
| (c) 声明为输入 | 形核时给定，做敏感度 | 小；但必须**如实记账**，且论文里不能说"预测" |

> ⚠ **对自己的更正（2026-09-27）**：本文件初稿把 (b) 写成"`γ(n)` 刻面 + Wulff"，**那是错的通道**。
> 形状由 `v(n)` 的 Wulff 构造定，而 `v ≈ M(n)·ΔG` ——
> 实测 `γ_eff·κ / ΔG ≈ 1.4e5 / 2e8 ≈ 7e-4` ⇒ **`γ(n)` 被驱动力淹没，碰不到形状**。
> ⇒ **尖点必须加在 `M(n)` 上，不是 `γ(n)` 上。** `(a)` 里的 `γ_el` 仍要补，
> 但它的作用是"给非惯习面一个代价"，不是定标厚度。

> ✅ **顺带闭环一个悬案**：`AUDIT_2026-09-27` §2.6b 记的"各向异性随时间退化"（r_n 从 0.10 爬到 1.6 nm/步、
> r_a 从 2.8 掉到 0.5）**不是数值 bug，正是走向 Wulff 形**：
> Wulff 预测 `n:w:a = 0.229 : 0.283 : 1`，实测 149 步累计 **0.275 : 0.208 : 1**。
> 早期各面按**瞬时** `Mfac` 走（0.030:0.100:1），包络建立后 n 面被"吃掉"、加速到 `h(n_hab)=0.229·h(a)`。
> ⇒ **同一个 P0-2**。

### 7.3 ★ 一个必须先承认的硬约束

> **板条长 ~5 µm，而"长径比 10–30"要求盒子 ≥ 2.5× 板条长 ≈ 12 µm。**
> `dx = 25 nm` ⇒ `N = 480` ⇒ **~400 GB** ⇒ **不可能。**
>
> ⇒ **在本引擎上，"单根板条的长径比"无法用 3D 周期盒直接量出来。**
> （这正是 `AUDIT_2026-09-27` §3.2 里 9/9 档"长">L 的同一个坑。）

**解法（不是妥协，是换口径）**：
**长径比是"面速度各向异性"的积分结果** ⇒ 只要**逐面测准 `v_n(n)`**，
长径比就是 `∫v_n dt` 的比值，**不需要装下一整根板条**。
`_audit_faces.py` 已经是这个口径（干净盒子里三面速度 n:w:a 实测 1:3.0:28 vs 设计 1:3.31:33）。
⇒ **形貌验收 = 面速度比（射线口径）+ 厚度/宽度分布（盒内统计）**，
**不是**"量一根板条的长/厚"。
