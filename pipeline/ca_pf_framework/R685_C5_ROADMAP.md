## §2 ② 接口清单（**借用 `_r68_facet_op.facet_project_one` 的哪部分**）

### 2.1 ★ 可以直接借用的（**已核实，且已是对的**）
| 部分 | 行号 | 为什么可直接用 |
|---|---|---|
| **`phi_proj = np.max(np.maximum(lo − _pr, _pr − hi), −1)`** | **`:83-84`** | **它对任意 `K` 都成立** ⇒ 推广到 Wulff 面法向**只需换输入**（`lo`/`hi` 从 3 对变成 `K` 对） |
| **体积标定 `s = (tgt/vp)^(1/3)` + 绕中点缩放** | **`:85-92`** | **与面数无关** ⇒ **原样复用** |
| **残差 `rel=(v1−tgt)/tgt`** | **`:96`** | 已被显式算出 ⇒ **`C3-J1`/`W-3` 判据可直接读它** |
| **外扩 `0.5·dx`** | **`:71-72`** | 与面数无关 |
| **`|det U|` 的记账（`R650`）** | `_t11_box_verify2.py` | 体积换算**必须带它** |

### 2.2 ⚠ 必须**替换**的部分
| 部分 | 行号 | 为什么要换 |
|---|---|---|
| **点云来源 = 体内胞 `φ<0`** | **`:33`** | 设计文档要"界面点云"；`R654` 已定量差异（`+8.4…16.1%`（`B40`）/`−49%`（`L0`）） |
| **`lo/hi = quantile(0.005/0.995)`** | **`:64-65`** | `R70` 的**棘轮**来自这里；但换成 `max` 会把棘轮**放大** ⇒ **两难** |
| **三轴循环 `for u in ax`** | **`:60-66`** | 必须改成 `for F_j in facet_normals` |

### 2.3 ⚠ **两难问题的建议处置**（**这是 C5 的一个关键决定**）
| 方案 | 优点 | 缺点 |
|---|---|---|
| (a) 保持 `quantile` | 抗棘轮（`R70` 已实测） | **`C4-J1d`（面数保持）可能 FAIL**（分位数取 3 轴 ⇒ 降级成盒子） |
| **(b) 用 `max` 但对 `h_j` 的**单步增量**设上限** | 保留真刻面 + 限棘轮 | 新引入一个参数（**需登记**） |
| (c) 两个都算、取更稳的 | 最稳 | 复杂度高 |

**⇒ 建议 (b)**：`h_j ← min(h_j^{new}, h_j^{old} + v_j·dt·(1+margin))`
**⚠ `margin` 是**新的自由参数** ⇒ 必须登记并扫描（像 `N_proj` 一样）。**
