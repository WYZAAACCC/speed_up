## §3 ★★ 两臂走了**不同的路径**（这是判据②难判的根源）

| | `pre` | `post` |
|---|---|---|
| `nslab` / `nf3`（step 400） | **3 / 2** | **6 / 5（= M / M−1 满值）** |
| 机制 | **很少形核新板条**，把**少数几根长很大** | **持续形核到满**（6 根）＋每根均匀长 |

| `step` | `pre` `Vt` / `nf3` | `post` `Vt` / `nf3` |
|---:|---|---|
| 150 | 2.3018e-18 / 2 | 2.1094e-18 / **5** |
| 175 | 2.7117e-18 / 1 | 2.8386e-18 / **5** |
| 200 | 3.1533e-18 / 1 | 3.7415e-18 / **5** |
| 275 | 4.5012e-18 / 2 | **8.2200e-18** / **5** |
| 400 | 9.2195e-18 / 2 | **2.1445e-17** / **5** |

**⇒ ⇒ 所以"谁快"取决于量哪个**：
* **按总转变体积 `Vt`** ⇒ **`post` 快**（这是 `B2-D3②` 要量的）；
* **按单根板条的推进** ⇒ 两臂**不可直接比**（`post` 面多、`pre` 面少）。

**⚠ `B2-D3②` 在 step 150–400 落进"形态不同"的区间** ⇒ **该判据在本配置下不干净**（`R695` 已登记此风险）。

## §5 ⚠⚠ 判据② 的**前提问题**（必须说清，否则会误判）

`goal` 写的分母是**"不开投影"**（`q≡0`），而 §2 用的是 `q≡1` 的 `pre`。**两者不是一回事**：

| 情形 | 含义 |
|---|---|

**⇒ 在它跑完之前，§2 的比值不能定案。**
