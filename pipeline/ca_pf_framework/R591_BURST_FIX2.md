## 1. 缺陷（**原代码就带的记账错**）

`_bk_exp.py:2150` 自己写明：

```python
n_ath_ev = 0                 # 由 athermal 律触发的形核次数
n_ath_tgt = 0                # 当前的累计根数（不含预摆的第 1 片）
```

⇒ `n_ath_tgt` 的**定义**是「**盒子里真实存在的板条数**」。
而 `_bk_exp.py:2681`（修前）是：

```python
n_ath_tgt += 1               # ← **无条件**自增
if _ev:  ... 成功分支
else:    ... "被引擎拒" 分支
```

⇒ **被引擎拒（`not _ev`，放不下）时也 +1** ⇒ 把**不存在的板条**记进累计数
⇒ **目标被凭空吃掉**。

### 为什么在 burst 档下才致命（**实测**）

| 档 | 律 | 首档需求 | 实测结果 |
|---|---|---|---|
| 旧（线性） | `floor(α·ΔT)` | 每档 **+1** | 被拒**很稀疏** ⇒ 缺陷几乎不显形 |
| 新（KM 分数） | `round(23·(1−e^(−αΔT)))` | 首档 **45 根**（`B·round(23·0.6327)`） | **尝试 45 → 成功 20、被拒 25** |

实测（`t5BKMo` 与 `t5FIX` 两臂，**逐位相同**——两臂只差 `--ed-eta`，而 η 只影响长大）：

```
t5BKMo: 成功=20 被拒=25  末次打印=累计 21/23
t5FIX : 成功=20 被拒=25  末次打印=累计 21/23
t5ETAo: 成功= 3 被拒= 0  末次打印=累计  3/23   ← 无 burst ⇒ 无缺陷
```

**两个后果**：
1. **25 根此后永不重试** —— KM 律要求的 45 根实际只投放了 20 根（**律被吃掉 56%**）；
2. **量具错** —— 打印「累计 21/23」里有 1 根是**不存在的**
   （用户硬约束：「尤其需要注意量具的正确性」）。

## 2. 修法（`_t5_patch_rejaccount.py`，**只改记账，不改物理律**）

完全由 `--burst-km` 门控：

```python
_burst_on = bool(int(getattr(a, 'burst_km', 0) or 0))
_rej = 0
_rej_cap = 8 if _burst_on else 10 ** 9
while n_ath_tgt < _tgt and n_ath_tgt < nv and _rej < _rej_cap:
    ...
    if _ev or not _burst_on:
        n_ath_tgt += 1
    else:
        _rej += 1
```

* **被拒 ⇒ 不消耗目标**，只累计 `_rej` ⇒ `n_ath_tgt` 回到「真实存在的根数」的原定义 ✓
* **本档放不下的核，下一档（更低温、目标更大）继续重试** ✓
* 每步被拒上限 `_rej_cap = 8`（**局部变量，随本步重置**）⇒ **代价有界**，不会死循环
* 拒绝消息也改成**报口径**的：
  `目标 %d 根、实有 %d 根，本步第 %d/%d 次被拒`
* **惰性**：`--burst-km 0`（默认）⇒ `_rej_cap = 10**9` ⇒ 条件恒真，
  且 `+= 1` 无条件执行 ⇒ **逐位不变** ✓

### 物理含义（**这不是"让它跑起来"的近似**）

`burst` 的需求由 **KM 律**给出（该在 T 温度下有多少根），
而**投放速率受几何容量限制**（引擎的 `stack` 落位检查）。
修后语义 = 「**欠着的核，几何一腾出空间就补上**」，而不是「作废」。
⇒ 这恰好是真实马氏体 burst 的行为：形核需求是瞬时的，实际长大/排布受力学与几何约束。

## 6.2 修法（`_t5_patch_retrygate.py`）—— **物理语义更准，不是"为了快"**

> KM 律给的是「**在温度 T 下应当有多少根**」——
> **它的粒度本来就是"档"，不是"步"**。
> 而 `_tgt` **只在进入新温度档时才增长**（45 → 60 → 66 → 66 → 67 …）。

```python
_tgt_try = int(getattr(g, '_burst_tgt_try', -1))
_do_try  = (_tgt > _tgt_try) if _burst_on else True
if _do_try and _burst_on:
    g._burst_tgt_try = int(_tgt)
    P('   ◆ s292 补投轮：本档目标 %d 根，实有 %d 根' % (_tgt, n_ath_tgt))
while _do_try and n_ath_tgt < _tgt and n_ath_tgt < nv and _rej < _rej_cap:
```

* **每档至多一次补投轮** ⇒ 全跑 **≤ 23 档 × 8 = 184** 次尝试（≈18 min 总代价）；
* **「欠着的核不作废」仍然成立** —— 下一档目标变大时继续补 ✓
* **新增可观测性**：`◆ s292 补投轮` 只在**真的补投**时打印 ⇒ 量具本身可核查；
* **惰性**：`--burst-km 0`（默认）⇒ `_do_try = True` 恒真 ⇒ 逐位不变 ✓
  （旧线性律每步 `_tgt` 都 +1 ⇒ 新档判据**每步都为真** ⇒ 旧路径行为不变）
