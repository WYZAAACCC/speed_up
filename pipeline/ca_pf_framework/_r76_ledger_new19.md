## §111 R76 ★★★ **回归脚本升级**（R152）：加"运行日志三条硬断言" —— **当场抓到我自己新写的一个误报**

### 一、为什么加（`§92` 与 `§108` 的教训）

`§92` 记过：R76 那次 `_blk_verdict` 的 `ValueError` **只出现在终态判决处**，
**CSV 早已写完** ⇒ `_r30_regress.sh` 的**逐位比较照样 PASS**、**量具自检照样 PASS**，
**只有日志里那一行 Traceback 能看出来** —— 而原脚本把运行输出 `tail -4` 掉了。
`§108` 又把"块内界面自检"加进驱动 ⇒ 也必须确认它**真的打了**（否则就是静默失效）。

### 二、改了什么（`_r30_regress.sh`，新增 `①a2` 段）

1. **运行输出完整落盘**：`> _w2_r30_regress_stdout.log 2>&1`（原来是 `| tail -4`）；
2. **三条硬断言**：
   * `Traceback` 行数 **= 0**；
   * 顶层异常行数（`ValueError:` / `TypeError:` / `NameError:` / `KeyError:` /
     `IndexError:` / `RuntimeError:`）**= 0**；
   * **`块内界面自检` 出现次数 ≥ 1**（⇒ `§108` 的接线**真的生效**，不是静默跳过）。

### 三、★ **新断言第一次跑就抓到了东西**

```

  Traceback 行数 = 0（应 0）  ;  顶层异常行数 = 0（应 0）
  '块内界面自检' 出现次数 = 1（应 ≥1 —— §108 的接线**真的生效**）
★★ **块内界面自检（R146 / `§99` 的缺口）**：`cov(t=0)` = **nan**，各对 β 占比 max = **nan**，`n_occ` = **1/6**
   `cov_norm` = nan（基线 `cov_base(L=2400 nm)` = 0.845…）⇒ ❌ **低于 0.95**
```

⇒ **`n_occ = 1/6`**：回归跑的是 `--grow-stack` 路径 ⇒ **t=0 只播 1 片**、其余靠邻位形核。
⇒ `exp_int = tot_broad·(n_occ−1)/n_occ = **0**` ⇒ `cov = nan` ⇒ 我的自检**直接打了 ❌**
「本几何的块内判据没过」。

**⇒ 那是**误报**：1 根板条根本没有"同变体界面"这个东西，判据**不适用**。**

### 四、⇒ 修法（**硬规程④的又一次应用**：判据先问适不适用）

新增适用域分支：

```python
if _nocc < 2:
    P('★★ 块内界面自检（R146）：n_occ = %d/%d ⇒ **判据不适用**'
      '（t=0 只有 %d 根在场 ⇒ 没有"同变体界面"这个东西）')
else:
    ... 真判据 ...
```

【实测】两条对照：

| 算例 | 输出 |
|---|---|
| `--laths 1`（1 根） | `n_occ = 1/1 ⇒ **判据不适用**`（t=0 只有 1 根在场 ⇒ 没有"同变体界面"这个东西） ✅ |
| `--laths 1,1,1`（3 根） | `cov(t=0) = **0.913**`、`maxβ = 0.20`、`n_occ = 3/3`、`cov_norm = 1.242` ⇒ ✅ ≥0.95 ✅ |
