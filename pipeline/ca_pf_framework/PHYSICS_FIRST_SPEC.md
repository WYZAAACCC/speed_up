## 〇之二、★ 路线裁定：**1A 被文献否死，只能走 1B**

* **1A（把 `MOB` 换成真实的 ~1100 m/s）**：
  `dt = cfl·Δx/(M·ΔG_v)` ∝ `1/M`。真实 `M` 比现值大 **~10⁴ 倍**
  ⇒ `dt` 小 10⁴ 倍 ⇒ 覆盖同一段冷却要 **2.75×10⁷ 步**。
  **⇒ 彻底不可行，且不是"再快一点就行"，是数量级问题。**
* **1B（把生长当准静态）**：
  **文献给了直接依据**——生长时间只有冷却时间的 **4×10⁻⁶**
  ⇒ 在每个温度下把界面**弛豫到平衡**，与真实过程**等价**。
  **⇒ 这是唯一与物理和算力都相容的路。**

**⇒ 采用 1B。下面的所有设计都以 1B 为前提。**

## 二、模型为什么被迫在两者之间"选"？（根因）

**根因只有一个：`MOB` 是占位值，而且它的标定是循环的。**

`windowB_closure.params()` 里 `MOB` 那一行的出处**原文**：

> `MOB = 1e-9` 【标】—— "**占位**。C-3 给下界 `MOB_min = α_KM·q·L/ΔG_crit`；上界由'界面不拖后腿'给"

**⇒ 即：`MOB` 是**按 C-3 反解出来**的。**
**⇒ 然后又拿 C-3 当"物理判据"去检验仿真是否物理。⇒ 循环论证。**

**⇒ 后果链**（本会话已实测）：
1. `MOB` 是按**旧** `α_KM = 0.011` 标的；
2. 我们为了多要板条把 `α_KM` 改到 0.0417 ⇒ **C-3 立刻变紧**；
3. 为了"守 C-3"只能把冷速压到 `q_cap` 的 0.8 倍 ⇒ 温度掉得慢；
4. 温度掉得慢 ⇒ `ΔG_v(T)` 起不来 ⇒ **净驱动力为负** ⇒ **播下去的核先溶**（`§203` 实测场 1 缩到 0.09×）；
5. 于是看起来像"必须在 burst 和顺序之间选"。

**⇒ 实际上从头到尾都不是"burst 还是顺序"的问题，而是"迁移率是占位值"。**

## 三、要改什么（**五项**，按优先级；每项都带验证方法）

### 【改 1】★ **1B：把降温时钟与界面弛豫解耦**（准静态 / staggered）

**为什么这是对的**（不再是我拍的，是文献给的）：
生长时间 / 冷却时间 = **4×10⁻⁶** ⇒ 在每个温度上，界面**已经**处于该温度下的平衡
⇒ **把"弛豫"当成时间积分是错的。**

**算法**：
```
重复：
  ① 按物理时钟把 T 降一个 ΔT（ΔT 由冷速与"该温度段的物理停留时间"定）
  ② 激活该温度下应有的核  n(T) = α_KM(M_s − T)          ← R1，已是物理的
  ③ **在 T 固定不变的前提下**做界面弛豫迭代，直到收敛（位移变化 < 阈值）
```
**⇒ 副产品（正是用户要的）**：
* **「顺序形核」自动成立** —— 每个温度段内，所有界面**先弛豫到平衡**，下一段才形核；
* **「burst」自动成立** —— 每个温度段激活 `Δn = α_KM·ΔT` 个核，
  **冷得越快 ⇒ ΔT 越大 ⇒ 一次激活的核越多 ⇒ 就是 burst**；**不需要新造一条律**；
* **C-3 退役** —— 它只是"弛豫够不够快"的伪装。

**验证**：① 同一算例"每段弛豫到收敛"与"弛豫 2× 步数"结果一致（收敛性正对照）；
② 回归逐位不变（新开关默认关）；③ 与旧路径在**同一温度上**的平衡形状一致。

### 【改 2】超临界判据：**只在驱动力撑得住的地方放核**（= 任务(2) 的 P4）

现状：`f_nuc^crit = 4γ/d` 只含界面能；实测弹性罚 `|ed| ≈ 2.5×10⁸` 比界面能项 `2γ/t = 1.2×10⁶`
**大 200 倍** ⇒ 判据恒为真 ⇒ 无效。

**正确判据（本模型自己的量）**：一片厚 `t` 的板条能站住 ⇔ 它的宽面上
```
ΔG_v(T) + ed_face  >  2γ/t
```
⚠ **难点**：核**放下去之前**没有它自己的应变场 ⇒ `ed_face` 未知（放之前是位点上的 `max_k ed_k`，
实测那是 **+1.9e8**，而放下去之后同一根板条的界面 `ed` 变成 **−2.5e8** —— **符号相反**）。

**⇒ 必须用"试放 + 回滚"**：试放 → 算该场自己的 `ed_face` → 不达标就撤销。
**代价**：每次事件多一次 `elastic_driving`（约 0.6 s【实测量级】）。
**验证**：正对照（人为给一个正驱动力 ⇒ 必留）；负对照（`ΔG_v = 0` ⇒ 必撤）。

### 【改 3】burst 的**自催化**部分：**待有依据再加**（⛔ 现状：不造律）

* 【改 1B】已经给出 burst 的**数量**（`Δn = α_KM·ΔT` 一批）；
* 文献给的是**机理**（"应力集中**触发**邻近位点"、"zig-zag 的**互相协调**阵列"）；
* **⇒ 但"触发概率随距离/应力如何衰减"没有可用的定量形式**
  ⇒ **在没有依据之前我不自己造**（本会话已因"自己造判据"踩过 `#54`/`#66`/`#68`）。
* **⇒ 替代**：先做 1B。**若 1B 之后仍看不到"互相协调的阵列"，再去找 burst 的定量律。**

### 【改 4】形核位点：从"预先撒下、用尽即止"改成"**持续可用**"

* 现状：`nuc_init` 撒 N 个位点，用完就没了；且 `nfsv_nofield` 实测被拒 **9 次**。
* 真实：位点是**预先存在的异质位点**（晶界、位错），随温度逐个激活 ⇒ 与 R1 自洽。
* **⇒ 改法**：位点池按**数密度**给出，未激活的位点持续可用到被 `cover` 守卫挡住为止。
* **验证**：事件数应等于 `n(T)`；`nfsv_nofield` 应显著下降。

### 【改 5】收敛判据取代"固定步数"

* 【改 1B】之后，"跑多少步"应由**弛豫收敛**决定，而不是预设。
* **验证**：弛豫步数加倍后结果不变（与【改 1】的验证合并）。

## 6.1 ★★ 生长窗口：板条在什么温度下才站得住（**本轮最重要的新结果**）

速度律是（`windowB_surface.py:3346`，已逐行核对）：

```
dG_cell = (df[karr] − df[larr]) + (ed_k − ed_l) − stk·κ
```

`ed_0 ≡ 0` 已验证（`e0p[0]=zeros(6)`、`sep[0]=0`）。
⇒ 对"板条 k 长进母相 0"这条界面：

```
dG = ΔG_v(T)  +  ed_k  −  stk·κ
```

而 `ed_k = ε⁰_k:σ(x)`，且标准结果给出**弹性能 = `E_el = −½∫ε⁰:σ dV > 0`（是代价）**
⇒ `ed_k < 0`，它在速度律里**抵消**化学驱动力。

**⇒ 存在一个温度门槛：**

```
板条站得住  ⟺  ΔG_v(T)  >  |ed|  +  stk·κ
```

### 定量（`_r470_growthwindow.py`，自检 PASS）

| 量 | 值 | 来源 |
|---|---|---|
| 单根板条弹性能 `E_el` | **2.7869e-11 J** | **`_r439_selfenergy.py` 实测**（`_r439.log` P-3 段，盒 6 µm，半轴 500/250/255 nm） |
| 板条体积 | 1.3352e-19 m³ | 同上半轴 |
| **⇒ 弹性能密度 `\|ed\|`** | **2.087e8 J/m³** | 两者相除 |
| **⇒ 门槛温度 `T*`** | **641.7 K** | `ΔG_v(T*) = \|ed\|` 二分求根，**硬核对相对差 1.4e-16** |

⚠ **口径**：`2.087e8` 是**整根板条的体积平均**密度，不等于界面胞上的**局部** `ed`
（局部值需另测，见 §6.5）。两者量级应一致。
`stk·κ` 是**额外阻力** ⇒ 真实门槛比 `T*` **更低**（更冷）⇒ **641.7 K 是乐观下界**。

### ★ 它一次性解释了三条此前分开记的观测

|---|---|---|
| `dry_saSet2` **12/12 板条都在长**（1.39–4.17×） | `§203` | 它用**常数 `df = 3.5e8` > `\|ed\| = 2.09e8`** ⇒ **全程在窗口内** |

**⇒ 所以「长不起来 / 填不满」的头号嫌疑不是形核律、不是盒长、也不是 `reinit`，
而是【驱动力没有超过弹性自能罚】—— 而这一条又由【冷却没走完】造成（`_r465`）。**

   ⇒ **按原文，abB 的 P2′ 应判 FAIL。** 这个不一致是**我的实现错**，不是数据的问题。

   ⇒ 小核即使 `Λ` 刚过 1 也仍会被曲率缩掉 ⇒ `frac_pos` 要到 `Λ` 稍大于 1 才过半。

   但**精确的转折位置仍受曲率项影响**，`T* = 641.7 K` 应理解为**乐观下界**。

**v1 判据为什么失败（留痕，是我的设计错）**：
* v1 用 `mean(ΔV)` ⇒ **被"新核"这一个事件完全主导**（一个场从 0 变正体积 = 单个巨大正值）；
  v1 的过滤还**放过了** `a[k] ≤ 0 < b[k]` 这种"新核"情形。
  **实测特征**：`[0,0.80)` 桶 `mean = +1.19e-3` 而 `median = −5.62e-3`，**两者符号相反**。
* v1 的负对照**原理上不可判别**：门槛挪 +100 K 后"窗口内"集合只是变大（仍含住真转折点）
  ⇒ 错门槛当然也"看到回升"。
⇒ **两条都是"判据设计错"，不是物理错**；v2 修正了这两点后 P3′ 的判别力也回来了（ρ 从 +0.66 掉到 +0.06）。

## 6.2 ⚠⚠ **更正**：§三【改 1】里"burst 自动成立"那句是**错的**

**原文（本节上方【改 1】的副产品）**：「**burst 自动成立** —— 每个温度段激活 `Δn = α_KM·ΔT` 个核，
**冷得越快 ⇒ ΔT 越大 ⇒ 一次激活的核越多 ⇒ 就是 burst**」。

**为什么错**：它把**温度步长**与**时间步长**混为一谈。
准静态表述里 `ΔT` 是**离散化选择**，不由冷速定。而 athermal 律
`n(T) = α_KM(M_s − T)` 是**状态函数**，不是速率 ⇒ **`dn/dT = α_KM` 是常数 ⇒ 本身不含 burst**。

**物理上正确的说法**（本轮重新推导）：

* 界面弛豫所需时间 `t_relax ≈ L/v_real ≈ 4×10⁻⁶ × t_cool`
  ⇒ 一次弛豫期间温降 `ΔT_relax = q·t_relax = 4×10⁻⁶ × 551 K ≈ **0.0022 K**`
  ⇒ `Δn = α_KM × 0.0022 = **9.2×10⁻⁵ ≪ 1**`
  ⇒ **严格按物理，一个温度档里几乎不可能出现第二根核。**
* **⇒ 【改 1B】给的是「顺序形核」，不是 burst。** burst 需要**自催化项**，
  而该量的**定量形式我们没有依据**（§三【改 3】已经写"不造律"）——
  **这条判断不变，但不能再声称"1B 自动给出 burst"。**
* **★ 但是**：**自协调（C6）不依赖 burst**。
  模型里**已经有了**一条**物理的**（不是编的）自催化通道：
  新核的**位点与变体选择由 `ed` 定**（`--var-rule ed`）⇒
  已有板条的应力场会**偏置**下一个核"在哪、取哪个变体" ⇒
  **这正是"互相协调（mutually accommodating）的板条阵列"的物理机制**（弹性协调）。
  ⇒ **C6 应当从"弹性相互作用 + 逐根顺序形核"里涌现，而不是从一条编出来的自催化率律里。**

**⇒ 框架结论**：
1. **1B 给顺序形核**（数量由 `n(T)` 定，一根一根来）；
2. **burst 的"数量"** 若要有，只能来自**把 `ΔT` 取粗**（一个档放多根）——
   这是一个**建模选择**，必须在文档里明写，**不得说成"物理自动给出"**；
3. **C6（自协调）走弹性通道**，可验证、无需新律。

## 6.3 准静态时钟的数学表述

**现在的语义（对照）**：对 `∂φ_k/∂t + v_n|∇φ_k| = 0` 积分，`v_n = M·dG(φ; T(t))`，
`T(t)` 由 `linear_cool` 给。`dt` 由 CFL 定。

**准静态语义**：**不对 `t` 积分，而是对 `T` 求不动点。**

```
对每个温度档 m（T_0 > T_1 > … > T_M = T_end）：
   ① 放下该温度下应有的核（n(T_m) − n(T_{m−1}) 根），位置/变体由 ed 定；
   ② 固定 T = T_m，把界面**弛豫到不动点**：φ ← 松弛(φ; T_m)，直到 max|v_n|·Δx/ΔG < ε；
   ③ 记录 `med|∇φ|`（SDF 健康）；然后降 T。
```

**★ 关键断言（必须验证，是 1B 的立足点）**：
**不动点 `Φ*(T)` 与 `M` 无关。**
证明思路：不动点由 `v_n = 0` 逐胞定义 ⇒ `dG(Φ*, T) = 0` ⇒ **`M` 不出现在方程里**。
⚠ **成立的前提**：速度律对 `M` 是**线性**的（`v = M·dG`，现在就是）。
**若将来加了非线性迁移率，这条必须重证。**

**★ 判据（写代码前登记，`M`-收敛检验）**：
同一个小算例（`N=48`、单根板条、固定 T），把 `M` 依次取 `1×, 10×, 100×`，
**弛豫到各自的不动点** ⇒ **末态几何必须收敛到同一个值**（判据：`V` 的相对差 ≤ 2%）。
* **正对照**：`M×100` 与 `M×10` 的差 应当 **小于** `M×10` 与 `M×1` 的差（收敛趋势）；
* **负对照（必须能失败）**：把速度律人为改成 `v = M²·dG`（非线性）⇒ 末态**必须**随 `M` 变
  ⇒ 若不变，说明判据没在测它该测的东西。

## 6.4 ⚠ 前提核验：`ed` 里含不含板条**自身**的弹性能？—— 含；**但它几乎不随厚度变**

**这是 1B 成败的关键前提。**
* 不动点方程 `ΔG_v(T) = stk·κ − ed_k` 里，**必须**有一项**随板条长大而增长**，
  否则板条会一直长下去（没有有限厚度）。
* 那个"增长项"只能是**板条自己的弹性能**（曲率项随厚度增长是**反向**的：κ ∝ 1/t 减小）。

**（a）结构：含自能 ✓**（`windowB_surface.py:2983-2995`）
`ed_v(x) = Σ_p e0v[v,p]·σ_p(x) + sext_e0[v]`，`σ = self.pf.sigma_tensor(reg)`
—— σ 由整个 `reg` 场（**含 x 点自身的本征应变**）经 FFT 解出 ⇒ 含自能。
（`sep = sext_e0` 是**外加载荷**项，不是自能修正。）

**（b）定量：`ed` 对厚度的依赖** —— **`_r474` / `_r475` 实测**

| 检验 | 结果 | 判据 |
|---|---|---|
| **T1 球，扫半径 `R = 6→14 Δx`** | `E/V` 的 `max/min = **1.0131**` | ≤1.05 ✅（Eshelby 尺寸无关，正对照） |
| **T3 板条自相似缩放 `×0.5→×2.0`** | `max/min = **1.0250**` | ≤1.05 ✅（形状不变 ⇒ 尺寸无关） |
| **A2 离散收敛**（固定物理尺寸，`Δx` 减半两次） | 最细两档相对差 **0.0010** | ≤0.03 ✅ **读数已收敛** |
| **A1 绝对标定**（各向同性 Eshelby 闭式） | 求解器/解析 = **1.063** | ∈[0.5,2] ✅（Zener 比 = **3.0** 强各向异性下已属良好） |
| **A3 形状敏感性**（固定 t，平面内长宽比 1→4） | `max/min = 1.1351` | — |
| **★ T2 固定 L/W、扫厚度 `t = 125→510 nm`（4 倍）** | **`max/min = 1.0578**` | ≥1.20 才算"显著" ⇒ **实测只有 ~5.8% ⇒ 弱依赖** |

**⇒ ★★ 结论：单一孤立板条的弹性能密度几乎不随厚度变（~6%）。**
把 `ed(t) ≈ const` 代回不动点方程：

```
dG(t) = (ΔG_v + ed) − 2·stk/t
  · 若 (ΔG_v + ed) > 0 ⇒ 对**所有** t 都 dG > 0 ⇒ **一直长**（直到碰撞/出盒）
  · 若 (ΔG_v + ed) < 0 ⇒ t 越大 dG 越负 ⇒ **溶解**
⇒ **只有"一直长"与"溶掉"两种结局，孤立板条没有有限厚度。**
```

**⇒ 对成功判据的影响（必须记账）：**

| 判据 | 影响 |
|---|---|
| **C5「块填满整个盒子」** | ✅ **反而更容易达到** —— 正因为没有单根尺寸上限，板条会长到**互相碰撞**为止 |
| **C2「单根板条的三维几何量、长宽比符合物理」** | ⚠ **孤立单根**的厚度/长宽比会被**盒子与碰撞**定住，**不是物理定住的** ⇒ **不能拿孤立单根去核 C2** |
| **C6「涌现自协调」** | ✅ **靠集体弹性**：σ 含全部场 ⇒ 装配体的 mean-field 应力会（i）**限制总转变量**、（ii）**选择互相协调的变体** |

**⇒ 定尺寸机制的正确落点是【集体弹性 + 碰撞】，不是单根自能。**
真实板条厚度的另一个来源是**塑性协调/缺陷拖曳**（属 S13 未表示的范畴）——
**在没有文献依据之前不得自己编**（§改 3 的纪律）。
**⇒ 因此 C2 的检验必须改成"在装配体里量厚度/长宽比"**，并在看到不物理的值时
把"缺塑性协调"作为**首要候选解释**记账，而不是去调参。

**（c）遗留：内部交叉核对 `E_el/(−½∫ε⁰:σ)` 给出 1.19–1.21（应等于 1）。**
⚠ 这一条**本轮未解决**。但 **A1 的绝对标定（1.063）比它更强** ——
它直接拿求解器的 `E/V` 与 Eshelby 闭式比。⇒ 判定：**该内部比值是"那条诊断口径"的问题，
不构成对 `E_el` 读数的否定**；登记为开放项，**不阻塞 1B**。

## 6.6 温度档 `ΔT` 怎么定（**必须拍板，不得自己造律**）

| 选项 | 含义 | 物理依据 | 风险 |
|---|---|---|---|
| **A：`ΔT = 1/α_KM = 23.96 K`** | 每档恰好放 **1 根**核，共 `n(T_end)` 根 | 直接由 athermal 律定义（`T_k = M_s − k/α_KM`，**复现 C-2**） | 无 burst |
| **B：`ΔT` = 冷速 × 某个物理时间** | 需要"界面弛豫时间"作尺度，而准静态假设说它 →0 | ❌ 与准静态假设**自相矛盾** | 不成立 |
| **C：用户给一个 `ΔT`（或"每档放几根"）** | 把 burst 强度当**输入** | 无（明写为建模选择） | 必须显式标注 |
