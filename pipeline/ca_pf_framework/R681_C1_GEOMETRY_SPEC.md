## §0 ★ 先定一件根本的事：**"面法向集"从哪来？**（**不是假设，是算出来的**）

### 0.1 仓库已有权威机制（`windowB_wulff.py:1-18`，逐字）
> `φ_t + v(n)|∇φ| = 0` 的渐近形状 = Wulff 形 `W = {x : x·n ≤ v(n) ∀n}`。
> `v` 非凸时，`W` 的支撑函数是 `v` 的**凸包络 `v**`**，它在缺失取向上是平的
> ⇒ **平面刻面**。
> `v**(n)` 不必每步求凸包：它**只依赖 `M(n)` 的角函数形式**（与场状态无关）
> ⇒ **预计算一次查找表**，运行时插值。

### 0.2 仓库已有的三个可复用件（**逐条核实**）
| 件 | 位置 | 作用 |

## §1 ① 算法：从 `M(n)` 到**面法向集**（完整伪码）

### 1.1 数学（**Wulff 构造的"极集凸包 → 取极"形式**）
设 `M(n) = Mfac(n)`（引擎的迁移率角函数，见 §3）。
定义**生长速度极图**（取 `Δf` 各向同性、`Δf = 1` 归一）：
```
P = { M(n) · n  :  |n| = 1 }              # (在 R³ 中的曲面)
```
其**凸包** `H = conv(P)`。**Wulff 形的支撑函数**：
```
h(d) = max_{x ∈ H} ( x · d )              # = v**(d)
```
**Wulff 形** `W = { x : x·d ≤ h(d) ∀d }`。
**★ 面法向集 = `H` 的**顶点**所对应的方向**（每个顶点 ↔ `W` 的一个平直面）。

### 1.2 伪码（**可直接实现，复用仓库已有件**）
```python
# ---------- 一次性预计算（与场状态无关）----------
def build_facet_normals(nh, a, w, beta_h, beta_w, dip_c,
                        nsamp=20000, tol_hull=1e-9):
    """返回 (面法向集 F, 面距集 hF)。F: (K,3) 单位向量；hF: (K,)。"""

    # 1) 球面采样
    N = fib_sphere(nsamp)                          # windowB_wulff.fib_sphere
    # 2) 迁移率角函数（★ 复用仓库实现，含 dip）
    M = mrel(N, a, w, nh, beta_h, beta_w, dip_c)   # :35-48
    # 3) 极集点云 P = {M(n)·n}
    P = M[:, None] * N
    # 4) 凸包 H（仓库做法：不调 ConvexHull，直接在采样点上取 max；
    #    ⇒ 若要**顶点集**，需真凸包 ⇒ 用 scipy.spatial.ConvexHull（见 §6 风险）
    from scipy.spatial import ConvexHull
    H = ConvexHull(P)                              # 顶点索引 H.vertices
    V = P[H.vertices]                              # (K,3) 凸包顶点
    # 5) ★ 面法向集 = 顶点方向；面距 = 顶点模
    hF = np.linalg.norm(V, axis=1)
    F = V / hF[:, None]
    return F, hF
```

## §2 ★★ 真刻面数的**稳健提取**（C1 的核心贡献）

### 2.1 判据：**真刻面 ↔ 凸包的"大面片"**
`H` 的每个**面**（`H.simplices` 的一个三角形）对应 `W` 的一个**顶点**；
而 `W` 的**平直面**对应 `H` 的**顶点**。
**⇒ 采样密度有限时**，一个真刻面会表现为**一簇相邻的、几乎共面的凸包顶点**。
**⇒ 提取算法：把 `V`（凸包顶点）按"方向聚簇"合并。**

### 2.2 伪码（**建议实现**）
```python
def extract_true_facets(V, hF, ang_tol_deg=2.0):
    """把凸包顶点按方向聚簇 ⇒ 真刻面。返回 (法向, 面距, 簇大小)。"""
    F = V / np.linalg.norm(V, axis=1)[:, None]
    # 贪心聚簇：方向夹角 < ang_tol ⇒ 同一刻面
    used = np.zeros(len(F), bool); clusters = []
    for i in range(len(F)):
        if used[i]: continue
        m = (~used) & (F @ F[i] > np.cos(np.radians(ang_tol_deg)))
        used |= m
        clusters.append((F[m].mean(0) / np.linalg.norm(F[m].mean(0)),
                         hF[m].mean(), int(m.sum())))
    return clusters                              # 真刻面候选
```

## §3 ④ 坐标系约定（**含 `a·n* = −0.127` 问题**）

### 3.1 三轴的**精确定义**（**逐条核实**）
| 轴 | 定义 | 出处 | 正交性 |
|---|---|---|---|
| **`n*`** | **惯习面法向**（弹性最省能法向） | `npref[k]`；`windowB_wulff.py:22` 的 `A_DOT_N_DEF = -0.127` | — |
| **`a`** | **rank-1 分解的位移方向**（= **长轴**） | `windowB_surface.py:1389-1393`（`_rank1_axes`） | ⚠ **`\|n*·a\| = 0.127107`** |

### 3.2 ★ **`a` 与 `n*` 不正交 —— 这是物理，不是 bug**（**仓库已核实**）
`windowB_surface.py:1817-1823`（**逐字**）：
> ⚠ 一条对我自己早先假设的更正
> 我此前说"应当断言 `along · nrm ≈ 0`（长轴落在惯习面内）"—— **那是错的**：
> 实测 `a` 与 `n*` 差 **82.7°**，并不落在惯习面内。若照原假设写断言，
> 会把**正确的物理**判成 FAIL。⇒ 断言改成 `|n*·a| <= TOL_AXN`。
> ⇒ **`a` 是 rank-1 分解的**位移方向**，本来就是长轴；
> 它与 `n*` 不垂直是**不变线**的几何后果，不是 bug。**

**⇒ ⇒ C1 的坐标系**不得假设正交**：
* ✅ **允许**：把 `(n*, a, w)` 当**斜基**用（`w` 与两者都正交，`a` 与 `n*` 差 7.3°）；
* ✅ **引擎既有做法**：`facet_project_one` 直接用斜基的分位数定盒子（`_r68_facet_op.py:60-72`）
  ⇒ **`|det U| = 0.9919`**（我实测）⇒ 体积换算**必须带它**（`R650` 的记账）；
* ⛔ **禁止**：对 `a` 与 `n*` 做正交化（那会**改变物理**：把长轴移出不变线）。

## §5 ② 顶点/棱/面的数据结构（建议）

### 5.1 建议的表示（**半边/面表**，够用且简单）
```python
# 一个场（变体 k）的多面体
PolyK = {
  'nh': (3,),            # n*（惯习面法向）
  'a':  (3,),            # 长轴（rank-1 位移方向）
  'w':  (3,),            # w = n* × a
  'F':  (K,3),           # ★ 面法向集（来自 Wulff 构造，§1–2）
  'h':  (K,),            # ★ 各面的支撑距离（= 到原点的距离）
  'V':  (M,3),           # 顶点（由相邻三面求交得出）
  'E':  (P,2),           # 棱（顶点对）
  'facet_of_vert': (M,K),# 顶点属于哪些面（稀疏）
}
```
### 5.2 ★ 三点设计理由（**都有仓库依据**）
| # | 理由 |
|---|---|
| **① 只存 `(F, h)` 而不存 `V`** | `φ = max_j(x·F_j − h_j)` **直接给出 SDF**（`_r68_facet_op.py:88-92` 的现写法）⇒ **不需要显式求顶点** ⇒ **避免"求交 + 拓扑维护"** |
