### 1.1 12 个变体的特征应变 ε⁰（[推导]，`windowB_ti64_variants.py`）

构造（**不是指派**）：把 bcc {110} 面的中心矩形 2D 点阵 (√2a_β, a_β) 映到 hcp (0001) 面的
中心矩形 (√3a_α, a_α)；面内取向由 OR 的 `<11-20>∥<111>` 条件唯一确定；法向 a_β[110] → c_α。

| 判据 | 结果 |
|---|---|
| C1 变体数 = 12 | **PASS** |
| C2 `det(F)-1` 与**每原子体积**比一致 | **−2.677% vs −2.677%，相对差 8e−15** ✅ |
| C3 主应变 ∈ 0.08–0.12 量级 | **[−0.1129, +0.0874]** ✅（框架 §5.4 期望 0.08–0.12） |
| C4 Σ_v dev(ε⁰_v) = 0（自协调） | **3.3e−16** ✅ |
| C5 F 把母相点阵映到同一 hcp 点阵（整数坐标残差） | **2.2e−16** ✅ |
| C6 OR 精确性（F(d)∥d、夹角 60°） | **2.2e−16** ✅ |

**必须记账的两条**：

1. **小应变约定**：`ε⁰ = sym(F) − I`。因为应变 ~10%，`trace(ε⁰) = −1.68%` **不等于**
   真实体积变化 `det(F)−1 = −2.677%`。**体积变化一律用每原子体积核对**，不用迹。
2. **shuffle 未表示**：bcc→hcp 需要原子 shuffling（体心原子不映到点阵点），
   本 PF 只保留形变部分（与文献 PF 做法一致）。⇒ 12 个"取向变体"在 ε⁰ 层面成对简并的
   可能性必须由 `windowB_bench3d.py` 的 P1（rank-1 相容性）来检验，而不是假定。

| 量 | 值 | 依据 |
|---|---|---|

## 4. 动力学与驱动（含 [占位]）

| 量 | 值 | 状态 |
|---|---|---|
| `dG`（β→α′ 化学驱动，单位体积） | **默认 5×10⁷ J/m³** | **[占位]**：由 ΔG≈−1000…−2000 J/mol ÷ V_m(1.1e−5 m³/mol) 得 1e8–2e8；CALPHAD 待给（见 `CALPHAD_REQUEST.md`）。⇒ §5-S4 |
| ↳ **但数值上必须按 `dG = dg_ratio · W` 取** | **默认 `dg_ratio = 0.05`** | **[推导/数值]** 真实界面 ~1 nm ⇒ `W ≈ 2×10⁹`，而 `Δf ≈ 1×10⁸` ⇒ `Δf/W ≈ 0.05`。若数值上 `Δf > W`，界面**失稳**、区域会变成"多变体混合"（本轮实测：`φ_max` 从 0.9 掉到 0.5，无一个纯胞）。⇒ 保比值才能让弥散界面代表锐界面。由 S4 扫 `dg_ratio` |
| 变体间 dG 差异 | **0（12 个 α′ 变体成分相同）** | **[推导]** |
| 界面迁移率 `L` | 由目标速度反解：`v ≈ 50–100 m/s` | **[数值]** 见下 |
| 非热动力学（B1） | `f_α′ = 1 − exp[−α_KM(M_s − T)]`，`α_KM = 0.011 K⁻¹` | **[占位]**（K–M 系数出自钢，Ti64 无可靠值）⇒ §5-S5 |

**为什么 L 的不确定性不影响本轮结论（重要）**：
板条宽 0.3 µm、`v = 50 m/s` ⇒ 填满一条板条 **6×10⁻⁹ s**；而 LPBF 单次热循环 ~10⁻³ s。
⇒ 只要 `v > 1 m/s`（差 2 个数量级都行），马氏体在冷却过程中**瞬间完成**，
**末态构型由能量（弹性能 + 界面能）决定，不由迁移率决定**。
所以本轮按"能量主导"跑，并把这条写成显式记账；要预测**形核/生长序列**时才需要真实 L。

**k=0 约定（[数值]，必须记账）**：`Λ(0) := C` ⇒ **clamped**（RVE 平均应变固定在 0）。
换成"自由弛豫"（k=0 项置零）会改变自协调行为。**Clamped 的物理依据**：RVE 埋在
同材料母相中，周围介质同样在相变/自协调，故 RVE 不能自由膨胀。**必须做 §5-S6 对照**。
