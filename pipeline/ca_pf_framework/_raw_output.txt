RULE 项 (设计禁令):
  - W4 [RULE] 横向截断不是指数衰减 :: 横向溶质场由 Laplace 型(代数 1/r)控制 => 该判据只在生长方向严格; 横向窗口必须靠 domain-size convergence 数值定
  - K3 [RULE] 线性闭式 vs 隐式解 :: 3 / 5 个驱动下有稳态解; 有解处最大偏差 98%; 无解处线性闭式凭空给出速度
  - K5 [RULE] 拖曳的正确书写形式 :: 必须解隐式方程 v = M_GB [dG - P_drag(v)]; 线性闭式既给不出负拖曳也刻画不了脱钉
  - G3 [RULE] 单个 Gamma_i 是规范相关的 :: 论文里给 Gamma_i 必须同时声明分界面定义(等摩尔面/零溶剂吸附面), 否则不可复现
  - G4 [RULE] bulk+surface 守恒 :: d/dt[int c dV + int Gamma dA] = 外部通量; 面-体交换项必须成对出现且符号相反
  - P3 [RULE] 反例: above-beta-transus 退火 600 s :: dd = 1.296e-03 m = 1296.16 um => 骨架会动, 必须退回 REACTIVATE_GRAIN
  - L4 [RULE] 投影算子 Pi 的守恒要求 :: Pi: c_cell -> c(x) 必须逐胞精确守恒 int(c dV) = c_cell V_cell; 直接插值会把凝固偏析抹平(仓库已实测过这个错误)
  - L5 [RULE] 一致性判据: PF 必须复现 CA 的 V(dT) :: 薄界面极限(W->0, W/V 固定, Karma-Rappel)下 PF 的解必须收敛到 LKT 的 V(dT); 这是两级之间唯一的可检验接口条件
