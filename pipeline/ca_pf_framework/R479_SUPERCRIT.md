## §0 一句话

**只在"放下去站得住"的位点放核**：判据 `ΔG_v(T) + ed_face > 2γ/t`，
用**真放 + 精确回滚**实现（`--nuc-supercrit 1`）。

## §1 为什么必须有它（不是可选优化）

`R477_QS_CLOCK.md §6.1` 的逐档记账（准静态钟，`T_end = 600 K`）实测：

* `T > T* = 641.7 K` 的档（`PHYSICS_FIRST_SPEC §6.1` 的生长窗口）里
  `Σ|ΔV|/V` 停在 **0.03–0.30 不衰减**，每档都撞 400 步上限 —— **场在持续溶解，没有不动点**；
* 场溶光之后的档**一步就"收敛"**（没有东西可动）。

**⇒ 在"撑不住"的位点/温度放核，那些核只会溶掉**：既浪费弛豫步数，
又让盒子在温度真正够冷时**已经是空的**。

## §2 判据为什么不能用旧的 `use_fcrit`

仓库已有的 `--nuc-fcrit`（`windowB_surface.py:1589`）判的是
`(df + max_k ed_k) > 4γ/t`，其中 `ed_k` 取**位点上、放核前**的值。

**它恒为真**（`R2_PARAM_VERDICTS.md` 已记）：`4γ/t = 2.4e6` 远小于 `df + max_k ed_k ≳ 1.2e8`（51 倍余量）。

**根因（本轮读代码确认）**：`ed` 在**放核前后不是同一个量**：

| | 物理含义 | 实测值 |
|---|---|---|
| **放核前**（位点上的 `max_k ed_k`） | 只是**与已有板条的相互作用**，可正可负 | **+1.9e8** |
| **放核后**（该盘自己的 `ed`） | 含**自身弹性能** | **−3.17e8**（本轮实测） |

**⇒ 符号都不同** ⇒ 用放核前的值判"放下去站不站得住"**原理上无效**。

## §3 ⚠⚠ 我的第一版实现被**它自己的预登记判据否决了**（留痕，不抹掉）

### 3.1 第一版：不写场的"试放 `region`"

**想法**：`windowB_pf3d.sigma_tensor(idx)` 的**唯一**输入是 `idx`（已核对 `:2985` 的调用点）
⇒ 弹性求解**只认 `region`、不认 `phi`** ⇒ 造一个"假如把 `cover` 划给 `kk`"的试放 `region`
就能拿到 σ，**不用备份 9.2 GB 的 `phi`，也不用回滚**。

**预登记判据 T1**：试放 `med_ed` 与真放 `med_ed` 的相对差 **≤ 0.15**。

**实测 ⇒ FAIL**：

```
试放：med_ed = −4.073672e+08
真放：med_ed = −3.172046e+08
相对差 = 0.2842   （判据 ≤ 0.15）
```

**根因（读 `seed_plate` 找到）**：`seed_plate` 除了写 `phi[k] = min(phi[k], sdf)`，
还会把**其它每一个场**写成 `phi[j] = max(phi[j], −sdf)`，而这两条都是**全场**操作
⇒ 它们会改**盘外**的 `region` ⇒ 改**近场** σ ⇒ 改这张盘**自己的自能**。
⇒ 试放 `region` 与真 `region` **不是同一个东西**，近似不成立。

**⇒ 处理**：按纪律**不放宽判据**，而是**改实现**（见 §4）。

### 3.2 为什么不能"备份整个 `phi` 再回滚"

`phi` 是 `(nv+1, N³)·8 B`。生产尺寸（N=160、nv=300）下一次备份是 **9.2 GB** ⇒ **不可接受**。

**但真正被改变的胞只是** `sdf < phi[k]` / `−sdf > phi[j]` 的那些
（其余位置 `minimum`/`maximum` 是恒等）
⇒ **只记"变了的胞"的旧值**即可（`np.flatnonzero` + 花式索引，与一次 `region()` 同量级）。

## §4 现在的实现：**真放 + 精确回滚**

```
_supercrit_probe(kk, cc, nrm, R, t, cover, df, gamma):
    bak = []
    seed_plate(kk, cc, nrm, R, t, undo=bak)   # 记账：只记真正改变的胞
    ed  = elastic_driving()                   # 全场 FFT（_r439 实测 N=96 量级 ~0.6 s）
    med = median(ed[kk][cover])               # 该盘自己的 ed（含自能）
    _seed_undo_apply(bak)                     # ★ finally 里无条件还原
    return (df + med > 2γ/t), med, 2γ/t, n_cover
```

**配套改动（全部纯附加）**：
* `seed_plate(..., undo=None)`：**默认 `None` ⇒ 立即返回 ⇒ 归档路径逐位不变**；
* `_seed_undo_note` / `_seed_undo_apply`：记账与还原；
* `nuc_cfg(supercrit=False)` + `c.get('supercrit')`；
* CLI `--nuc-supercrit {0,1}`；
* 在 `fresh` 通道**决定放不放之前**插入探针；拒绝时 `continue`（试下一个候选位置）
  —— **因为净效果为零，所以"拒绝"不需要撤销任何东西**。

⚠ **范围缺口（必须随结论一起给）**：与 `--nuc-fcrit` 相同，本判据**只覆盖 `fresh` 通道**，
**`stack`（sympathetic）通道没有加**。**不得**说成"两条通道都过了超临界判据"。

## §6 ★★ 物理读数（本轮最值钱的一条）

**翻转点 `df* = 3.1818e8 J/m³`** —— 即"这个位点站得住所需的最小化学驱动力"。

拆开看：

| 项 | 值 | 占比 |
|---|---|---|
| 判据阈值 `2γ/t` | **9.8039e5** | **0.3%** |
| 该盘的弹性罚 `\|med_ed\|` | **3.172e8** | **99.7%** |

**⇒ 界面能项在超临界判据里几乎不起作用（差 320 倍）—— 判据实质上是"付不付得起弹性罚"。**
（与 `PHYSICS_FIRST_SPEC §三【改 2】` 记的"弹性罚比界面能项大 200 倍"一致。）

**⇒ 折算成温度：该位点需要 `T ≲ 377.7 K`**（用 `ΔG_v(T) = 4.147e5·(1145−T)`）。
对照 `ΔG_v(298 K) = 3.5125e8` ⇒ 比值 **1.104×**
⇒ **该位点在 298 K 够格，但只在冷却的最后一段**（378→298 K 只占全程 551 K 的 **14.5%**）。

**⇒ 与 `_r470` 的生长窗口（`T* = 641.7 K`）的差别是有原因的**：
`_r470` 用的是**光滑椭球**板条（弹性能密度 2.087e8），
而 `seed_plate` 播的是**带尖边的圆盘**（`sdf = max(|d|−t/2, rperp−R)`）⇒ **罚更大**（3.17e8）。
⇒ **两者都对，各自对各自的形状**；引用时必须带上形状口径。

**⇒ 可用的物理杠杆**（供任务(5) 定参数）：罚由**核的形状与尺寸**主导，不由 `γ` 主导
⇒ 更大/更光滑的核 ⇒ 门槛更低。`R_nuc`/`t_nuc`/形状是**有物理依据**的旋钮，
但**不得为了"让它形核"而随意调** —— 它们同时决定 C2（单根几何）。
