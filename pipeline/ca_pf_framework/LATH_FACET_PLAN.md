## 1 主因重定位（★ 本条更正了此前"要把各向异性搬到面上"的说法）

**先纠正一个事实**：`windowB_surface.py:118 herring_stiffness` 与
`windowB_surface.py:386 LevelSetSurface.advance` 的写法是
@@v_n = M[df - gamma_eff(n)·kappa]@@，其中 @@kappa@@ 就是 **level-set 零等值线（零厚度面）的曲率**。
⇒ 各向异性**本来就作用在面上**，不是"没进面"。真正的缺口是下面四条：

### 主因 ①-a（实现缺口，可修且便宜）：**变体-变体界面用错了参考取向**

- 现状：`advance()` 里 @@stiff[k] = herring_stiffness((n·npref[k])**2, ...)@@，
  其中 @@npref[k]@@ = **变体 k 对母相**的弹性最省能法向（= 对母相的惯习面）。
  随后 @@stk = take_along_axis(stiff, karr)@@ ⇒ 任何界面（含变体-变体）都用 **winner 对母相**的法向。
- 物理上应分两类：@@(k,0)@@ 类界面用 @@npref[k]@@；@@(k,l)@@ 两个变体之间**必须用两变体的
  不变平面法向** @@ncomp(k,l) = argmin_n 0.5*dEps0:Lam(C,n):dEps0@@（@@dEps0 = eps0_k - eps0_l@@）。
- **量级**：`prod_boxB` 末态 @@f=0.9001@@ ⇒ 母相只占 9.99% 面积 ⇒ **绝大多数界面是变体-变体**，
  即**当前几乎全用错了参考取向**。这正是 M6 完全随机的第一嫌疑。
- 代价：预计算 66 个配对法向（秒级）+ `advance` 加一条按配对取法向的分支（~30 行）。

### 主因 ①-b（表示缺口，工作量中等）：**凸各向异性在数学上给不出刻面**

- @@gamma(theta)=gamma0(1+Lam sin^2 theta)@@ 的 Herring 刚度
  @@gamma + gamma_tt = gamma0(1 + 2*Lam - 3*Lam sin^2 theta)@@（已逐项核对，**代码正确**），
  凸性要求最坏处 @@gamma0(1-Lam) > 0@@ ⇒ **Lam < 1**。当前 @@Lam=0.4@@。
- 而"平直板条面 + 板条间的尖角"（faceted / missing orientations）要求 @@gamma(n)@@ **近奇异（尖点）**，
  等价于极图**非凸** ⇒ 必须走 **Wulff 凸化（Legendre 二次共轭 / 极图内凸包）**，用凸化后的
  @@gamma_tilde(n)@@ 与 @@gamma_tilde + gamma_tilde_tt@@ 求 @@v_n@@。
  **凸 @@gamma@@ 无论 @@Lam@@ 取多大（<1）都不会产生刻面。**
- 代价：预计算 @@gamma_tilde@@ 的支撑函数表（凸包，一次）+ `advance` 里查表（~40 行）。

### 主因 ②（尺度问题，需先诊断再定）：**界面能通道被驱动力压掉 ~4 个量级**

- @@gamma*kappa@@ ≈ @@0.15 * (2/4um)@@ ≈ **7.5e4**（Pa 量级）；@@df = 2e8@@；
  **弹性项中位 4.9e8**（= df 的 ~5 倍，代码已记账）。比值 ⇒ 界面项 **~1e-4**。
- ⇒ 即使 ①-a/①-b 修好，"择优是否够强"仍取决于这个比值。**必须先用隔离实验判定**（D4），
  再决定是否需要（i）缩小 df、（ii）放大 gamma、（iii）接受"择优弱、靠界面本身陡度"。

### 主因 ③（真物理缺口）：**板条厚度没有定标机制**

- 12 个核全取弹性最省能法向 ⇒ 与母相近 rank-1 相容 ⇒ 自身弹性能≈0、**无背应力**（§11.12）
  ⇒ 板片厚只由"核数密度 + 生长时间"定 ⇒ 得到 4.7 µm（集束尺度）。
- 真实板条厚 0.25–0.9 µm 由「孪晶/层错尺度 × 板条间弹性自协调」竞合定。
  ⇒ 需要 (i) **板条级配置**（小盒子 + 高分辨率，见 §2 的"便宜"论证）、(ii) 开逐变体各向异性弹性。

### 主因 ④（区制缺口，已定路线）：**athermal 快生长区制进不去**

- @@t_g ≈ 1.4e-5 s@@ vs @@t_cool = 3e-7 s@@ ⇒ 生长比冷却慢 ~50 倍（§11.12）。
- 真实板条长大是**无扩散、声速量级**。⇒ 已定 **KM-as-input**：@@f(T)@@ 作输入，
  PF/level-set 只负责"给定分数下的形貌"。⇒ **本规划不试图解决 ④**，但形貌判据要在
  "固定 f 下"读，避免被 ④ 污染。

## 7.2 df 的物理标定（自查，结论：**原来的 df 没标错**）

{BT}windowB_km.py{BT}：DS_REF = 3.0e5 J/(m^3 K)（由纯 Ti 同素异构 dS~3.5 J/(mol K) x rho_mol 1.0129e5 交叉验证），
T0 = M_s + dG_crit/DS = 848 + 333 = 1181 K =>
**dG_chem(M_s=848 K) = -3e5 x 333 = -1.0e8 J/m^3**；室温 298 K 时 -2.65e8。
=> P0.3 用的 df=1e8 **正好是 M_s 时刻的真实驱动力**；生产的 2e8 对应约 600 K。**两者都在物理范围内。**

=> 于是 P0.3 的结论是**真物理**，不是标定错误：
**在真实驱动力（1e8 量级）下，"界面能 vs 驱动力"的幅度竞争根本不成立**（γκ/ΔG ~ 1e-4）。
W1 的 Wulff 正对照之所以 PASS，是因为它用 **df=0**（无驱动力）—— 与本结论自洽。

## 7.3 D8 正对照：**界面迁移率各向异性**（`_chk_m8_mobpin.py`）

机制：M(n) = M0 * [1 - a (1-(n.mref)^2)]（本组为"沿 mref 长得快"的形式）。
配置：N=64, dx=2 nm, R0=12 nm, **df=+1e8（真实驱动力）**, 300 步。

| a | V/V0 | 长径比 | **主轴 vs mref** |
|---|---|---|---|
| 0.00 | 29.27 | 1.00 | 25.2 deg |
| 0.50 | 11.67 | 1.33 | **0.0 deg** |
| 0.90 | 3.40 | 1.88 | **0.0 deg** |
| 1.00 | 2.18 | 2.15 | **0.0 deg** |

**判决：机制有效** —— 长径比单调（1.00 -> 2.15）、**主轴精确对齐（0.0 deg）**，而同样的 df 下
gamma(n) 通道完全无效。**原因**：M(n) 是**动力学**量，**没有热力学凸性约束**（不需要 gamma+gamma_tt>0）
=> 各向异性强度可任意大，不会被 Delta G 淹没。

**★ 口径记账（我第一版把判据写错了）**：该实验里 mref = **快生长方向** => 形状沿 mref 拉长
=> **侧面法向必然垂直于 mref** => "界面法向 vs mref" 的中位从 60 deg **升到** 78 deg（**这是对的**，
不是失败）。**正确口径是"主轴 vs mref"与长径比**。第一版的"法向中位 <20 deg"门槛是错的。

# 9 ★ (1)(2) 决策：M(n) 的**物理标定**（2026-09-26）

## 9.1 为什么择优必须走 M(n) 而不是 gamma(n)（物理 + 实测）

* **实测**（见 8.3）：gamma(n) 从 0 调到 0.9（凸界极限）对界面取向**零效果**；
  而 M(n) 从 0 到 1.0 让 M6p 从 35.8 deg 降到 11.2 deg。
* **为什么**：gamma(n) 要与 Delta G 做**幅度竞争**（gamma*kappa/DeltaG ~ 1e-4），
  且受**热力学凸性**约束（gamma+gamma_tt > 0 => Lam < 1），不可能靠幅度取胜；
  M(n) 是**动力学**量，**没有凸性约束**。
* **物理上这不是权宜之计**：位移型（马氏体）相变的界面迁移本就**不是**界面能驱动的
  曲率流，而是**界面位错（interface dislocation）的保守滑移**（Olson & Cohen 的
  phenomenological theory；Christian 的 displacive 图像）。位错只能在其**滑移面**内滑移，
  而该滑移面正是**惯习面 / 不变平面**（MATH_FRAMEWORK 5.6 的 lam2(U)=1）。
  => **面内迁移（侧向长大）容易、法向迁移（增厚）必须容纳失配**
  => **M(n) 必须在 n 平行 n_hab 时最小**。这正是 pin_min=True 的物理含义。

## 9.2 形式与物理公式

    M(n) = M0 * exp[ -beta * (n . n_hab)^2 ],    beta = dG_misfit / (k_B T)

* 因子 (n.n_hab)^2 的几何来源：界面法向偏离不变平面时，**必须由界面位错容纳的失配量**
  随法向分量增长（一阶几何投影）=> 额外激活能正比于其平方。
* 用 exp(-beta) 而不是线性 1-a：(a) 指数形式**本身有物理**（热激活跨越失配势垒，
  Arrhenius）；(b) 数值上安全 —— beta=3.5 时 M_min = 3% M0，**界面不会被冻结**；
  而 a->1 的线性形式会让 M->0（界面停住），那才是"为了跑通加的坏参数"。
* 线性形式 1-a 保留为 **beta 的一阶展开对照**（小 beta 下 1-a 约等于 exp(-beta) 的展开）。

## 9.3 beta 的**两条独立**推导（不猜、不调）

**(i) 失配位错环形成能（理论推导）**
界面法向推进一段距离需要面积 A 内新增失配 => 位错线长度 L = A*eps/b（eps = 相变切应变）。
单位面积额外能 e_misfit = eps*mu*b/(4*pi*(1-nu)) * ln(R/r0)。
Ti-64：mu = 40 GPa, b = 0.29 nm, eps 约 0.1, nu = 0.34, ln(R/r0) 约 3
=> e_misfit 约 0.42 J/m^2。
再除以"每个界面原子位置的等效 kT 面积"（kT/rho_surface 约 (1.1e-20 J)/(1e-19 m^2) = 0.11 J/m^2）
=> **beta 约 3.8**。

**(ii) 观测板条纵横比反推（半经验）**
板条侧向/法向生长速率比约等于长径比（观测 10-30）
=> v_side/v_norm = M_max/M_min = exp(beta) 约 10-30 => **beta 约 2.3-3.4**，中心 **3.0**。

（0.815 -> 0.575），**宽/厚 3.98 -> 2.80**，向观测值 2.5 靠拢 ✓。
但 **长/厚 卡在 ~4.2**，远低于理论 e^{beta_h} ~ 33。

**=> 新的核心问题：长/厚 饱和在 ~4-5，不随 beta 增大而改善。**
待判：是**时间不够**（长时程 L1200 跑 1200 步在测）还是**内在饱和**
（怀疑是 10.1 说的"边缘斜面"效应，需要**尖点/近奇异**的 M(n) 而非平滑 exp 形式）。

## 10.5 记账

1. 双轴只作用于**变体-母相**界面；变体-变体界面保持单轴（那里 ncmp 已是不变平面）。
2. beta_w 与 beta_h 都由**同一组观测量**（长/宽/厚比）反推，且相互校验自洽 => 不是两个自由参数。
3. D11 的 aspect 定义（面内均值/法向）在"面内有短轴"时会**低估**长条程度 =>
   报告长条必须**同时报"长/厚"与"宽/厚"两个数**（见 10.4 的表）。
4. 单核实验的"面内 extent"是**包围盒**口径（对 4 胞厚的形状有 O(dx) 误差），
   待用惯性张量口径交叉验证。

# 12 ★ 反常的**真正原因**：统计量口径（2026-09-26）

## 12.1 结论先行

** 双轴钉扎的实现与生效都是正确的。** 11.1/11.3 记的"三方向增长次序与预测相反"
**全部是统计量口径造成的假象**：所有出问题的口径都用了**在重尾分布上不鲁棒的量**
（均值、包围盒 extent、体积差）。改用**中位数 / 逐胞反推**后，实测与设计**逐项吻合**。

## 12.2 三条独立判据（都用鲁棒口径）

**(a) 逐胞反推 **（_DBG_VNK，关重初始化、关弹性）
   从 "phi 的实际变化 / (dt*|grad phi|)" 反推作用在界面上的速度，与 `M*df*Mfac` 比：

| axis | 比值（**中位数**）| 比值（均值）|
|---|---|---|
| n | **1.161** | 5.59 |

| a | **0.938** | 1.48 |

**(b) 平界面速度比**（_DBG_PLANE_MED，关弹性、**中位数**口径）

## 12.4 记账：一条新的通用教训（与本仓库教训 20/26 同族）

> **重尾分布上不能用均值/极值类统计量判物理**。
>
> 本轮的  /  在界面上是**重尾**的（少数胞的 |dG| 是均值的 ~10 倍，
> 因为它们落在弹性奇异区）。于是：
>   *  被尾部主导 => 看起来"速度几乎相同"（0.5-1.0）而真值比是 0.03:0.10:1；
>   * 包围盒 extent 会被单根"尖刺/失稳"主导；
>   *  换算位移在**斜平面**上面积因子错（每档不同）。
> **规则**：判"界面速度/形状演化"用
>   (i) 逐胞反推 + **中位数**，或 (ii) 零等值面的**几何位置中位数**；
> 不要用 mean、extent、`dV/A`。
> 本仓库此前的教训 20（守恒量做差）、26（守恒量逐位不变）是同一类错误的两个前例。

## 13.3 判决

## 13.4 为什么长/宽 只有 1.39（诊断）

面内两方向的迁移率比应为 Mfac_a : Mfac_w = 1.0 : 0.100 => 长/宽 应趋于 ~10。
实测 1.39 => 差异被两条机制抹平：
1. **块合并/互相挤压**：24 个核在 1.6 um 盒内（平均间距 ~0.7 um，而核直径 0.6 um）
   => 块一长大就碰到邻居 => 形状由"邻居包围盒"决定，不由自身各向异性生长决定；
2. **曲率/Gibbs-Thomson 的等轴化**（与 11 节同源，但那里是被统计量假象掩盖的）。

=> **正确的下一步**：**孤立单核自由生长**（无邻居）才能量出真实的长/厚 上限 ——
   见 _RUN_FREE（L=1.6 um, dx=20 nm, 单核 R=0.3 um, 厚 0.2 um, 2000 步, 有/无钉扎对照）。
