## §119 R76 ★★★ **`§118` 的普适性检验 → 结论要改强**：`r` **散得没有规律**（不是"高估 N 倍"）

### 一、为什么做（`§118` 第五节自己列的局限）

`§118` 的结论（`r` 差 **9.10×** 而 `E_el/Vt` 只差 **1.12×**，比值 **8.09**）
只有 **2 个变体集、1 个几何** ⇒ **普适性未验**。

### 二、做法（`_r162_univ.py`，**控制两个混杂**）

1. 全库所有同时有 `r_selfac` / `E_el_J` / `Vt` 的臂的**末行**；
2. 只在**同一 `(N, Δx)`** 内比（跨分辨率不可比）；
3. 再筛 **`|ΔVt|/Vt < 10%`** 的成对臂（`E_el/Vt` 强烈依赖转变体积）。

### 三、【实测】**196 对**可比对

**⚠ 第一版统计量设计错了**：我拿 `(Δr/r)/(ΔE/E)` 的**中位数**当判据，得 **0.108** ⇒
按那个数会说"普适性不成立"。**但那 0.108 是被"`r` 根本没差的那些对"拉下来的**
（同一变体集、只改几何 ⇒ `Δr ≈ 0` ⇒ 比值 ≈ 0）—— **那些对不是证据**（`r` 不动就无从谈"代理"）。

**⇒ 修：只在 `Δr/r > 0.2`（`r` 真的差了）的对里问"能量差多少"。**

| 统计量 | 值 |
|---|---|
| **全部**对的比值中位 | 0.108（Q1/Q3 = 0.000 / 1.636） |
| **`Δr/r > 0.2` 的对** | **82 / 172** |
| **这些对的比值中位** | **1.73**（**最小 0.22、最大 66.2**） |
| 其中比值 > 3 的 | **36 / 82 = 44%** |

### 四、⇒ 结论要**改强**（**不是"高估 8 倍"，而是"散得没有规律"**）

`§118` 原来写的是"`r` 把能量差异**放大约 8 倍**"。**那是**一对**的读数，不能普遍化。**

**正确的表述**：

> **`r_selfac` 与 `E_el/Vt` 之间没有可用的定量对应关系 ——**
> 在 82 对"`r` 真的差了、同分辨率、`Vt` 差 <10%" 的可比对里，
> 比值 `(Δr/r)/(ΔE/E)` **从 0.22 散到 66（跨 2.5 个数量级，中位 1.73）**。
>
> * **有时 `r` 高估 60 倍**（例：`saOddG/saSet2` 那对，比值 8.4）；
> * **有时 `r` 反而**低估**（比值 0.22 ⇒ 能量差得比 `r` 还多）。
>
> ⇒ **`r` 不能当弹性能的代理** —— 不是"有系统偏差"，而是"**散得没有规律**"。

### 五、⇒ 对"框架是否完善"的回答（**这一条是给用户条件(2)的**）

`BLOCK_SELFAC.md §3.1` 把 `r(G)` 定为**自协调的唯一判据**（P-SA-1 的主判据量）。
本节 + `§118` 合起来说明：

> **这个判据在"能不能当能量的代理"这件事上，既没有系统偏差、也没有稳定关系**
> ⇒ 它**可以**作为"**运动学必要条件**"（它本来就是：`Σf_i dev ε⁰_i` 的模），
> 但**不能**用来判"组织自不自协调"或"能量低不低"。

⇒ **框架的完善方向（具体）**：
1. **`r` 保留为运动学量**，但**任何"自协调"结论都必须同时报 `E_el/Vt`**；
2. **`P-SA-1` 的判据量要换**（历史结论用 `r` 量的，`§118` 已记"量级要下调"）；
3. 更根本的：需要一条**与能量挂钩的、空间分辨的**自协调判据
   （`BLOCK_SELFAC` 的 **L-2/L-4** 早就预警了这一点）。

### 六、⚠ 仍然**不能**说的

* **不能**说"`r` 无用" —— 它是**运动学必要条件**（这一点 `§3.1` 的定义本身是对的）；
  本节否掉的是"**它能当能量代理**"这个**未明说的假设**。
* **不能**说"组织不自协调" —— `E_el/Vt` 在两臂里都随体积共模上升，
  要判"能量意义上的自协调"需要**同 `Vt` 的臂内**分析（`§118` 已给 `Vt` 列，可再做）。
* ⚠ 本检验仍受**同一批臂**的局限（多数是同一引擎、同一批几何）。
