物理理由：`ed` 存的是"弹性能**变化**"，而 `:1149` 用 `argmax_k ed` 选"弹性能变化**最小**"的变体
⇒ **`ed` 越大越有利** ⇒ 驱动力 = `df + max_k ed_k`，与 `argmax` 选法自洽。

**★ 必须做成"默认关闭的开关"，否则会改数**：

1. `nuc_cfg(..., use_fcrit=False)` 新增开关（默认 `False` ⇒ **逐位向后兼容**，归档可复现）；
2. `nucleate()` 签名加 `df=0.0`；
3. 开关打开时，在 `fresh` 通道的 **NaN 守卫之后、变体选择之前**插入：

##### ★ `W1-6 doublet` 补丁规格（**已定稿，等解冻即可落地**；用户决策 D-2）

**目标**：新增 `var_rule='doublet'` = Salama 2024 的配方「**每个形核点随机抽 2 个 K-S 变体**」。

**改动点（一处，`nucleate()` 的 `fresh` 通道）**：
现写法（`:1228`）：
```python
kk = (int(rng.integers(1, nv + 1)) if c.get('var_rule') == 'random'
      else int(np.argmax(drv)) + 1)
```
⇒ 改为**先定"要抽几个变体"**，再逐个落位：
```python
_rule = c.get('var_rule', 'ed')
if _rule == 'random':
    _ks = [int(rng.integers(1, nv + 1))]
elif _rule == 'doublet':
    # Salama 2024：每形核点**随机抽 2 个** K-S 变体（不重复）
    _ks = list(rng.choice(np.arange(1, nv + 1), size=2, replace=False))
else:                                    # 'ed'（默认）⇒ 逐位向后兼容
    _ks = [int(np.argmax(drv)) + 1]
```
随后**对 `_ks` 里每一个变体各落一片核**（复用现成的 `cover` 守卫与 `seed_plate` 调用），
每个成功事件 `out.append(...)` 一次。`max_per_step`（`cap`）仍然生效。

**⚠ 三点必须遵守**：
1. **默认 `'ed'` 的路径必须逐位不变** —— `_ks = [argmax(drv)+1]` 与原式逐字等价，
   且**不得**改变 RNG 的调用次数（原式在 `'ed'` 下**不消耗** `rng`）⇒ `doublet`/`random` 才调 `rng`。
2. `n_fresh` 的语义：原实现对 `n_fresh` 计数的是**事件数**；`doublet` 下一个"形核点"产生 2 个事件
   ⇒ **必须明确**：`n_fresh` 限的是**事件数**还是**位点数**？⇒ **取事件数**（与现有一致），
   并在 docstring 写明「`doublet` 下每个位点占 2 个 `n_fresh` 名额」。
3. `cap`（`max_per_step`）仍按事件数截断；若剩余名额只有 1，`doublet` 只落 1 片（**不报错、但要计入 `dbg`**）。

**补丁（三处，**最小且默认逐位向后兼容**）**：

1. **加参数**：`def sussman_reinit(phi, dx, iters=40, dtau=None, grad='upwind2', guard=True, band_cells=None)`

   if band_cells is not None:
       _sel = np.abs(phi0) <= float(band_cells) * dx
       if not _sel.any():
           _sel = None                      # 空带 ⇒ 退回全域，绝不静默变成"全体 False"
   _med = (lambda a: float(np.median(a))) if _sel is None else (lambda a: float(np.median(a[_sel])))

   ⚠ **必须用 `if _sel is None` 分支而不是 `a[_sel]` 配全 True 掩模** —— 后者会**多一次拷贝**，
