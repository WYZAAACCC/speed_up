## 1. 用户的三个子问题，逐条回答

### 1.1 「有多少个板条构成一个块」——能不能推出来？

**能，而且不需要新常数。** 推导三步（记作 **C-2**）：

1. **引擎几何本身就是一条恒等式**：`stack` 通道的每一次形核事件播一整片，
   而 `attach` + `align_inplane` 让新片**占满整个面内足迹** `A_f = L·W`
   ⇒ "一个核最终占的面积" `A_0 ≡ A_f`。**这是几何，不是选择。**
2. **面密度的 athermal 位置饱和律**（`windowB_km.Nv_of_T` 的三维律在形核面上的类比）：
   `N_A(T) = α_KM·(M_s − T)/A_0`  [1/m²]。
3. **板条数 = 面上的核数**：
   `n = N_A·A_f = α_KM·(M_s − T_f)·A_f/A_0 = α_KM·(M_s − T_f)`。

> ★ **必须写清楚的边界**：第 2 步是**三维律的二维类比（一个假设）**，
> 不是从自由能独立推出的。它的物理内容是：
> **`α_KM` = 单位过冷度下、每个"核体积"里可用的有效核位数。**
> 它的函数形式与仓库里早已登记的 `windowB_km.Nv_of_T` **完全相同**，
> 因此**没有引入新的自由常数**。
>
> 这条**只对"堆叠型块"成立**（每片占满同一足迹）。面内并列的多个 block
> 需要在面内做 Voronoi 分割，**本轮不做**（见 §7）。

**数值**：`α_KM = 1.1e-2 /K`、`M_s = 873 K`、冷却到室温 `T_f = 298 K`
⇒ `n = 6.325` ⇒ **`n = 6`**。

**它给出的可证伪预言（这是闭环的价值所在）**：

| 预言 | 数值 | 怎么证伪 |
|---|---|---|
| 第 k 根板条的形核温度 `T_k = M_s − k/α_KM` | `782 / 691 / 600 / 509 / 418 / 328 K` | 中断淬火数板条，或原位 XRD 测 `f(T)` 的拐点 |
| 冷到 600 K 停止 ⇒ 只有 **3** 根 | `floor(0.011×273) = 3` | 同上；这是**工艺可调**的预言 |
| block 沿堆叠方向的尺寸 `W_block = n·t` | `6 × 0.51–0.88 µm = 3.1–5.3 µm` | **这一条最硬**：直接量 block 宽度，除以板条厚 |
| `α_KM` 的敏感度带 `(5e-3, 1.1e-2, 2e-2)` ⇒ `n = 2 / 6 / 11` | — | 用户文献复核建议的"扫 2/4/6/10/15/20"现在有了**物理参数化** |

### 1.2 「能否用形核率让模型合理运转」—— 能，前提是**先把形核机制分诊清楚**（**C-1**）

#### C-1a｜**匀相**形核在本体系里热力学上不可能

```
ΔG* = 16πγ³/(3ΔG_v²)                      （球形匀相形核势垒，教科书式）
ΔG_v(T) = ΔS·(T0 − T)                     （windowB_km；ΔG_v(M_s) = 1.128e8 J/m³）
γ ∈ [0.201, 0.337] J/m²                   （Murzinova 2017 的 975 °C 带）

⇒ ΔG*/k_B T ：T = M_s 处           = 887 … 4181      （γ 取带的两端）
              放开 T 到 298 K 的全矩形 = **258 … 4182**
              ★ 最小值在 **T = T0/3 ≈ 382 K**（解析：`ΔG*/kT ∝ γ³/[(T0−T)²·T]`，
                对 T 求极值 ⇒ `T = T0/3`；数值 384 K ✓）
```

要有一个**可测**的形核速率，通常需要 `ΔG*/kT ≲ 60`（`e^{−60} ≈ 1e−26`）。于是：

| 说法 | 数值 | 说明 |
|---|---|---|
| 势垒比是门槛的**倍数** | **4.3 … 69.7 ×** | 无量纲比值 |
| **速率**慢的**数量级** | **86 … 1790** | `(ΔG*/kT − 60)/ln10` |

> ⚠ **这两个数不是一回事**（相差 26 倍以上）。本文档第一版把前者写成了"9–42 个数量级"，
> 那是**量纲错**；同时第一版给的区间 `516…2500` 也把 **`T = M_s` 处**的值与
> **`T = 298 K` 处**的值拼成了一个区间 ⇒ 两处都已在 `windowB_closure.selftest`
> 的 `C-1c.1…C-1c.5` 上钉住（含一条解析钉点 `T = T0/3`）。

反过来问：**要多低的 γ 才能把匀相势垒压到 60？**

```
γ_max = [3·60·k_B T·ΔG_v²/(16π)]^{1/3} = 0.0819 J/m²     （在 T = M_s 处）
```

**这比文献最低端（0.201）还低 2.5 倍** ⇒ **匀相形核在任何文献 γ 下都慢到不可测。**

#### C-1b｜**异相**形核只在"高效位点"上才可行（★ 这条是阶段回顾时补的，纠正了我自己论证过头的地方）

> **第一版我写的是"匀相不可能 ⇒ athermal 是唯一可能的机制"。前半句对，后半句不成立。**

异相形核把势垒乘上接触角因子 `f(θ) = (2 − 3cosθ + cos³θ)/4`（`f(0)=0`、`f(90°)=0.5`、
随 θ 单调增）。本体系需要

```
f(θ) ≤ 60/1707 = 0.035      ⇒      θ_max ≈ 39.2°
```

**所以正确的结论是三条，不是一条**：

| # | 结论 | 依据 |
|---|---|---|
| ① | **匀相形核不可能** | `ΔG*/kT = 1707 ≫ 60`（且 γ 低到 0.08 都不行） |
| ② | **异相形核只有在接触角 ≲ 39° 的高效位点上才热激活可行** | `f(θ_max) = 0.035` |
| ③ | 马氏体的胚芽是**预存**的层错型缺陷（Olson–Cohen），其**有效界面能远低于宏观 γ** ⇒ 正落在 ② 的高效位点一侧 ⇒ **athermal 位置饱和与 `ΔG*` 估算一致** | ② + Olson–Cohen 图像 |

⇒ **`athermal` 是"与估算一致的机制"，不是"由 ΔG* 推出的唯一机制"。** 措辞红线。
⇒ 顺带把 C-2 的地位也说清楚：**位置饱和律是本文采用的本构假设，C-1 只为它提供
"与热力学估算不矛盾"的支持，不为它提供唯一性证明。**

> **另外顺带解释了长期挂账的一件事**：**`f_nuc^crit = 4γ/d` 判据为什么"接上也拦不住"**
> （**C-7**）：`ΔG_v/(4γ/t) = 57.5`（在 `t = 510 nm, γ = 0.25` 上），
> 与 `_bk_fcrit.py` 独立测得的 73–583 同量级。
> **它不是"没接线"，而是在本体系的参数区间里结构性惰性。**

### 1.3 「让模型在现有框架上合理运转」——闭环算力下界（**C-3**）

athermal 律要跑进仿真，就必须知道**时钟走多快**。这里有一条**不含任何自由参数**的推导：

```
步长     dt = cfl·Δx/(M·ΔG_v(T))          （CFL，引擎的 dt 定义）
驱动力   ΔG_v(T) = ΔS·(T0 − T)            （windowB_km，已登记）
时钟     T(t) = T_start − q·t
有序性   Δt_grow = L_lath/v ≤ Δt_nuc = 1/(α_KM·q)   ⇒ q ≤ M·ΔG_v(T_start)/(α_KM·L_lath)
```

消掉 `M` 与 `q`（两者都在分子分母里成对出现）⇒

```
N_steps ≥ ΔT·[(T0 − T_start) + ΔT/2]·α_KM·L_lath / (cfl·Δx·(T0 − T_start))
```

**= 2173 步**（`ΔT = 484 K`、`Δx = 125 nm`、`L_lath = 4.59 µm`）。

> ⇒ **这是一个物理下界，不是调参结果**：想按物理次序把 6 根板条长出来，
> 就算力而言至少要这么多步，**调 `MOB` 或 `q` 都省不掉**。
> 省算力的唯一途径是放大 `Δx`、缩短 `L_lath`、或减小冷却区间。

它还给出了**"顺序 vs 突发"的判据**：`q ≤ q_cap = 2.98e6 K/s`。
闭环配置取 `q = 0.8·q_cap = 2.38e6 K/s`（安全系数 1.25），
落在 LPBF 文献冷速区间 `1e4–1e8 K/s` 内。

### 1.4 还有两条把"数值选择"变成"推导量"的闭合

**C-4b｜播种厚 ≠ 物理厚（记账偏移，不是可调参数）。**
这是 R29 跑到一半时由 `_bk_thick.py` 抓出来的一条**实现错**，现在写成闭式：

```
共享界面（attach）把重叠区 o 从**两片各吃 o/2**  ⇒
    内部片（两张界面）播种  t_seed = t_phys + o
    末片（一张界面）  播种  t_seed = t_phys + o/2      （t_last_reduce = o/2）
```

**判据的靶必须是 `t_phys`（`--plate-t-physical`），不是 `t_seed`。**
不补的实测代价（`dry_cl1`，`t_seed = t_phys = 510`、`o = 125`，跑到 step 1000）：

| 场 | 原始包围（`ths`） | **剔孤儿** | 与 510 比 |
|---|---:|---:|---:|
| 1（被咬两次） | 619.9 nm | **391.8 nm** | **−23.2%** |
| 2（尚未被咬） | 638.8 nm | 503.5 nm | −1.3% |
| 3（尚未被咬） | 640.1 nm | 508.0 nm | −0.4% |

⇒ `510 − 2×62.5 = 385` 与 391.8 吻合 ⇒ **不是孤儿污染，是播种厚少补了**。
若等 2853 步跑完，V-8b 与 A-8 都会 FAIL，而原因是**配置错**、不是物理。

⚠⚠ **但本条只闭合了一半（Round 5 的实测把它推翻了）**：
`dry_cln2`（`α_KM=5e-3` ⇒ 导出 `n=2`、**只有一张界面**）的末态是

| 场 | 播种 | 末态（剔孤儿） | 相对播种 |
|---|---:|---:|---:|
| 1（种子片） | 635 nm | **670.7 nm** | **+35.7** ⇒ **根本没被咬** |
| 2（末片） | 572.5 nm | 566.2 nm | −6.3 ⇒ 减薄逻辑对 |

⇒ 整块等效厚度 **618 nm/lath**，比物理靶 510 厚 **+21%** ⇒ **`V-8b` FAIL**。
而**不补偿**的 `dry_cl1`（n=6、两张界面）种子片是 **391.8 nm**（−23%）。

⇒ **"被咬量"不是常数 `o/2`**：n=6 两张界面时接近 `o`，n=2 一张界面时接近 **0**。
**C-4b 的"形式"（`t_seed = t_phys + 被咬量`）对，但"被咬量"这个取值没有闭合。**
⇒ 现状必须如实写成：**`t_seed` 是 [标]**（开关 `--seed-comp-frac` 供扫描），
**不是 [推]**。这是本轮唯一一条被判 FAIL 的实质物理判据。

**C-4｜几何容纳上限**（把"Δx 该取多少"从习惯变成推导）：

```
(n·t/2)|n̂_i| + (L/2)|â_i| + (W/2)|ŵ_i| ≤ L_box/2    对 i = x,y,z   （AABB 精确判据）
```

实测：`N=96/Δx=62.5 nm` 的盒子里，`t = 0.51 µm` 时 `n_cap` **恰好 6**（零余量），
`t = 0.68 µm` 时 `n_cap = 3`，`t = 0.88 µm` 时 `n_cap = 0`。
⇒ **归档几何（Δx=62.5）与"文献板条厚 + 6 根板条"不相容**，必须放大到 `Δx = 125 nm`
（`N=96 ⇒ L_box = 12 µm`，`t/Δx = 4.08`，同时满足本仓库自己 `t/Δx ≥ 4` 的分辨率目标）。
**这不是"为了让结果好看"，而是让离散化合法。**

**C-5｜`β_h` 的下界由"跑多少步"导出**：```
M(n̂) = M0·e^{−β_h}  ⇒  N_steps 步累积法向位移 ≤ cfl·N_steps·Δx·e^{−β_h} ≤ δ_max·t
⇒ β_h ≥ ln(cfl·N_steps·Δx/(δ_max·t))
```

* 归档配置（200 步 / Δx=62.5 / t=250 nm）⇒ `β_h ≥ 3.22`。**归档的 3.5 刚好过**
  （它预测增厚 57 nm，而实测末态 236–325 nm 即最多 +30% = 75 nm ✓ 量级相符）。
* 闭环配置（2853 步 / Δx=125 / t=510 nm）⇒ `β_h ≥ 5.86`。**3.5 远远不够。**
* **物理修法**（不是调参）：`β_h` 的内核是 `dG_misfit/(k_B T)`
  （`LATH_FACET_PLAN §9` 已登记），⇒ **随降温变大**：`β_h(T) = 3.5·M_s/T`。
  按运行时间表加权平均（权重 `dt ∝ ΔG_v`）给 **6.48**。
  **两条完全独立的路线（物理的 `1/T` 律 6.48，与算力下界 5.86）落在同一个数上** ——
  这是本轮最漂亮的一条自洽性检查。

### 1.5 ★ 回答目标里那一句「**两者判谁限速**」（**C-8**）

「几何 `n = W_block/t_lath`」与「athermal 形核率供给」是两条**独立**的上限，
`n = min(两者)`：

| | 值 | 由什么给 |
|---|---:|---|
| **供给** `n_kin = α_KM(M_s − T_f)` | **6.3** | C-2 |
| **几何** `n_geo_cap` | **21** | C-4 的 AABB 判据 |
| **谁限速** | **供给（形核）** | 6.3 < 21 |
| 「几何开始咬人」的温度 `T_bind = M_s − n_cap/α_KM` | **−1036 K** | 不物理 ⇒ 几何**永远**不咬人 |
| α 取敏感带上端 2e-2 | `n_kin = 11.5` | **仍是供给限速** |

★ **负对照**：缩回归档几何（Δx=62.5 nm）并取 `t = 0.68 µm` ⇒ `n_cap = 3 < 6`
⇒ **变成几何限速**。这既证明了判据有分辨力，也说明
**归档配置其实一直是几何受限的**（一个此前没被指认出来的隐性缺陷，
正是 C-4 逼着把 Δx 放大到 125 nm 的原因）。

⇒ **可证伪的推论**：`n` 与 `T_end` **成线性**（斜率 `−α_KM`）⇒
**冷得越深、板条越多、块越厚**（`W_block = n·t`）。**这是工艺可调的**，
也是本模型给实验的一条最直接的接口：同一台机器上改冷却终温，数块里几根板条。

### 5.3 本轮自己抓到的七个错误（**如实记账**）

> 本项目的硬规矩是"**结论先问怎么证伪它**"。四条**全部**是新写的判据/量具自己抓出来的：

**(a) 判据只写了一边。** `_bk_athermal.py` 的 A-3 第一版只查

**(b) 我自己的律用错了时钟起点（错位一根）。**
`n(T) = α_KM(M_s − T)` 在 `T = M_s` 处是 **0** —— 一根板条都还没有。

## 7. 局限（**不得省略**）

1. **C-2 只对"堆叠型块"成立**（每片占满同一足迹）。面内并列的多个 block
   需要在面内做分割，本轮不做。
2. **`α_KM` 仍是 [标]**：定义清楚、可测，但本轮**没有 Ti-64 的实测值**。
   ⇒ `n = 6` 是"**在 α_KM 的文献量级下的自洽值**"，**不是实验确认的 6**。
3. **`block` 沿堆叠方向的尺寸仍未检索到** ⇒ C-4 只能给"装得下/装不下"，
   **不能反过来独立定 `n`**。`W_block = n·t = 3.1–5.3 µm` 是**本模型的预言**，
   它可被直接证伪 —— 这是本文最有价值的一条待检验预言。
4. **`γ_α′β` 借的是扩散型 α/β 平衡界面能**（Murzinova），不是位移型 α′/β 的值。
   C-6 的结论建立在这个借用上；**翻转阈值 0.1385 J/m² 是它的证伪条件**。
5. **`F2`（异变体界面）在全部归档块算例里面积为 0**（6 个场同变体）
   ⇒ **它的面能从未被检验过**。多变体 packet 之前不得引用任何 F2 结论。
6. **`β_h` 的指数形式本身是唯象的**。长跑把它暴露出来（C-5）：200 步的 3.5
   在 2853 步上远远不够 ⇒ 必须用 `β_h(T)`。
7. **`Γ_i ≡ 0`（无溶质通道）、`shuffle` 未表示、小应变近似** —— 见 `WINDOWB_PARAMS §6`。
8. **本轮没有与实验的定量对照**。全部证据是**内部一致性**（回到用户的
   "先闭环"要求），不是"模型对了"。
9. **机时**：闭环配置一次 2853 步约 **1.5–2 h**（N=96，实测 1.6→3.6 s/步，
   随板条数上升；不是先前估的 1.3 s/步）。
   `n = 11`（α_KM = 2e-2）的敏感度情景需要 **6124 步**（≈4 h），**本轮未跑**；
   `n = 2`（α_KM = 5e-3）只需 **842 步**（≈40 min），**已跑**（`cln2`）：A-1..A-8 全过。
10. ★★ **C-4b 只闭合了一半（本轮唯一一条被判 FAIL 的实质物理判据）**：
   **"共享界面咬掉的量"不是常数** —— `n=2`（一张界面）时种子片**根本没被咬**
   （播种 635 → 670.7 nm），而 `n=6`（两张界面）时被咬掉 ≈`o`（→391.8 nm，
   比物理靶 510 薄 23%）。⇒ `t_seed` 必须读作 **[标]** 而不是 [推]。
   实测后果：闭环配置的 **`V-8b`（末态厚度保真）FAIL**（618 nm/lath vs 510，**+21%**）。
11. **"块内板条的面内尺寸"不是文献值**：只有惯习法向被 `β_h` 钉住，
   面内 α′/β 界面继续往母相里长 ⇒ 实测 `Vt` 是种子几何的 **1.66 倍**。
   `L_lath = 4.59 µm`（Wang 2026 的 9:1）只是**种子**尺寸。
