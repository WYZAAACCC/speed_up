## §1 ① 逐面速度公式（**从引擎的逐胞律推导**）

### 1.1 引擎的**逐胞**速度律（**逐字核实**）
`windowB_surface.py:4857-4859` + `:5128`：
```python
dG_cell = ((self.df[karr] - self.df[larr])           # 化学驱动 Δf_k − Δf_l
           + ed_eta * (edk - edl)                    # 弹性驱动 η·Δed（η = ed_eta）
           - stk * kap_cell)                         # 界面能项  γ_eff·κ
v_cell = self.M * dG_cell                            # :5128
```
⇒ **`v = M · [ Δf + η·Δed − γ_eff·κ ]`**

**参数取值**（本任务配置）：`η = ed_eta = 0.253`（`_t11_facet_arm.py:97`）、`γ_eff` 由 `_stiff_of`（`:3889`）给出。

### 1.2 ⇒ **逐面速度公式**（把 §1.1 按"面"重写）
对多面体的第 `j` 个面（法向 `n_j`、面积 `A_j`、质心 `c_j`）：
```
v_j = M(n_j) · [ Δf(c_j) + η·Δed(c_j) − γ_eff(n_j)·κ_j ]
```
| 量 | 逐面如何取 | **从哪来** |
|---|---|---|
| **`M(n_j)`** | 按**该面的法向**查 `Mfac` | `windowB_wulff.mrel(N, a, w, nh, β_h, β_w, dip_c)`（`:35-48`）**或**引擎已用的 `fast_support_factory`（`windowB_surface.py:5185`） |
| **`Δf(c_j)`** | 面质心处的化学驱动 | `self.df[·]`（按变体号索引） |
| **`Δed(c_j)`** | 面质心处的**弹性驱动差** | `elastic_driving()`（`:4043`）⇒ **网格场上的量，需在 `c_j` 处插值** |
| **`γ_eff(n_j)`** | **该面的** Herring 刚度 | `_stiff_of(k, g, gn, npref, aniso, γ0, herring, facet_lam, facet_eps, nref_cell)`（`:3889-3921`） |
| **`κ_j`** | ⚠ **平面 ⇒ `κ_j = 0`** | 见 §1.3 |
| **`A_j`** | 该面的面积 | 几何（由 `(F, h)` 算出，见 `C1 §5`） |

### 1.3 ★★ **一个决定性的简化**：**平直面的曲率恒为 0**
多面体的每个面**是平面** ⇒ **`κ_j ≡ 0`** ⇒
```
v_j = M(n_j) · [ Δf(c_j) + η·Δed(c_j) ]
```
**⇒ ⇒ 界面能项 `γ_eff·κ` 在**面上**消失，只在**棱/角点**处非零（奇异）。

**⚠ 这与现引擎的差别很大**：
现引擎里**每个界面胞都带 `−γ_eff·κ`**（`κ` 是 level-set 等值面曲率，非零）
⇒ 那正是 `R659` 测到的"**形状拿不到各向异性速度**"的原因之一
（曲率帽 ⇒ `v_tip` 被 Gibbs–Thomson 惩罚钉住）。

**⇒ ⇒ 这是阶段 C 的**最核心的物理收益**：**
**用多面体表示 ⇒ 面是平面 ⇒ 曲率惩罚只在棱上 ⇒ 面上的速度**完全**由 `M(n)·Δf` 决定
⇒ 尖端能拿到它该有的速度。**

### 1.4 ⚠ 但**面不是孤立的** —— 必须记账的耦合
| # | 耦合 | 说明 |
|---|---|---|
| **①** | **`Δed` 依赖整个形状** | `elastic_driving()` 是**全局 FFT 解** ⇒ `Δed(c_j)` 依赖**所有场**的当前构型 ⇒ **不能把面独立推进** |
| **②** | **`Δf` 依赖输运/温度** | `self.df` 是**状态量**，若走 KM-as-input 则随 `f(T)` 变 |
| **③** | **体积守恒** | 各面独立移动会**改变体积** ⇒ 必须**显式标定**（见 `C3`） |

**⇒ ⇒ 逐面速度公式**可用**，但**每步必须**：先解弹性（全局）⇒ 再取各面质心处的 `Δed` ⇒ 再推面。**

## §2 ② 棱/角点如何运动（**含选择依据**）

### 2.1 ★ 三种候选方案（**必须选一个，依据要给**）

| 方案 | 棱的运动 | 优点 | 缺点 | 依据 |
|---|---|---|---|---|
| **(a) 相邻面的交线**（推荐） | 棱 = 面 `i` 与 `j` 的交线，**随两面移动自动更新** | ✅ **无自由参数**；✅ 与"面独立推进"自洽；✅ 数学上就是 Wulff 形的棱 | 棱**可能消失**（需拓扑处理） | **Huygens/支撑函数**的标准性质【推理】 |
| **(b) 最小二乘 / 加权平均** | 棱点速度 = 相邻两面速度的**加权平均** | 简单 | ⚠ **引入权重（自由参数）** | 无依据 ⇒ **不建议** |
| **(c) 角点独立速度** | 给角点自己的速度律 | 最灵活 | ⚠ **角点速度在数学上是**欠定**的** | **不建议** |

### 2.2 ⇒ **推荐 (a)**，理由（**与本项目已有做法一致**）
* `_r68_facet_op.py:88-92` 用的是 `phi = max_j(x·F_j − h_j)`
  ⇒ **这正是 (a) 的实现**：棱自动出现在**两个 `max` 支的切换处**；
* 且 `BLOCK_SELFAC §9.1` 的建模前提**允许面与面之间是奇异的** ⇒ **棱可以是不光滑的**。

### 2.3 ⚠ (a) 的**已知代价**（必须记账）
`R70`（`_r68_facet_op.py:52-58`）：
> min/max **对长指敏感** ⇒ 只要某次推进在某个方向甩出一根指头，`hi_j` 就被顶大；
> 再经**统一体积缩放**，宽度方向被压得更小 ⇒ **每投影一次，长径比就被"棘轮"抬高一档**。
> 【实测】`facet_proj=10` 给 `d(a)=3.818`，而面推进只有约 0.86 nm/步（`d(a)` 应 ≈1.7）
> ⇒ 多出来的那一倍**就是棘轮加的**。

**⇒ ⇒ (a) 的**棘轮**风险继承自现实现** ⇒ **`C4` 的判据必须包含"棘轮检测"**
（见 `R675` 的 `facet_proj` 频率扫描：`N=1` 唯一有效，`N≥3` 收益消失）。

## §3 ③ 拓扑变化（面消失/合并/掐断）—— 判定与算法

### 3.1 **面消失**（★ 最容易处理，因为表示是 `(F, h)`）
| 步 | 判据 | 算法 |
|---|---|---|
| 1 | **面 `j` 的支撑距离 `h_j` 是否降到 0 以下** | 若 `h_j ≤ 0` ⇒ **该面已消失** ⇒ **删除** |
| 2 | **面 `j` 是否被相邻面完全"遮蔽"** | 若 `∀x: x·F_j − h_j < max_{i≠j}(x·F_i − h_i)` ⇒ 删 |

**⇒ 因为表示是 `(F, h)` 的 `max`，删一个面**不需要拓扑重建**（只是少一个 `max` 支）
⇒ **这是 `C1 §5.2` 选 `(F,h)` 表示的**直接好处**。**

### 3.2 **两个多面体合并**（板条对撞）
| 判据 | 算法 |
|---|---|
| **两场的 `φ` 同时 <0 的胞数 > 阈值**（如 ≥50 胞） | **与现引擎的 `_pair` 逻辑对比** ⇒ 见 §3.4 |

### 3.3 **一个多面体被掐断**（分裂）
| 判据 | 算法 |
|---|---|
| **`region == k` 的连通分量数 > 1** | **拆成两个多面体**（各取自己的 `(F, h)`） |

**⚠ 记账**：现引擎**已有**连通分量工具（`_t11_perfield_lam.py` 用的 `ncomp`）
⇒ **可复用**。

### 3.4 ⚠ **重要：现引擎**已有**配对/碰撞逻辑**（不必重造）
| 件 | 位置 |
|---|---|
| `elastic_driving_pair(karr, larr)` | **`windowB_surface.py:4265`** |
| `_pair_normals` / `ncomp(k,l)`（两变体的不变平面法向） | `:1199-1211`（`de=0` 守卫）、`LATH_FACET_PLAN:35` |
| 绕盒/撞盒检测 | `box_touch`（CSV 列）、`_t11_touchstep.py` |

### 4.2 ⇒ **多面体表示对 CFL 的影响（三点，定性）**
| # | 影响 | 方向 |
|---|---|---|
| **①** | **面的推进不受 `|∇φ|` 限制** | 现 CFL 来自 level-set 平流（`dt ≤ dx/max|v|`）⇒ 多面体**同样**需要它 |
| **②** | **曲率项消失 ⇒ `v` 变大** | 现引擎的 `−γ_eff·κ` 项**减小** `v`（当 `κ>0`）⇒ 去掉它 ⇒ **`v` 变大** ⇒ **`dt` 需更小** |
| **③** | **棱处的速度可能无界** | 若角点速度为两速度之和（Huygens），在**尖锐**处可能超界 ⇒ **需监视** |

```
dt_new = min( dt_CFL , dx / max_j |v_j| )       # 面速度也必须满足
```
**⚠ 这条是我提的**（依据 `①`/`②` 的定性推理）⇒ 标【推理，未核实】。**

### 4.3 ★ 一条**已实测**的相关事实（`windowB_surface.py:4365-4368`，逐字）
> `band_len`（米）给定时**按物理长度**定延拓带宽…为什么必须：`band_cells` 是**胞数**
> ⇒ 物理带宽 `band_cells·dx` 随 Δx 变 ⇒ 界面速度会**依赖分辨率**
> （**实测 `v/(MΔf)` 在 Δx=40/50/62.5 nm 上分别为 0.923/0.843/0.818**）

**⇒ ★ 现引擎的速度**兑现率**：`Δx=62.5 nm`（本任务）⇒ **0.818**（**18% 的损耗**）。
**⇒ ⇒ C2 的"逐面速度公式"若用 `M(n)·Δf` 直接推，会**高估 22%**
（除非把该兑现率算进去）。**

**⚠ 这是本文件**最有用的定量输入** —— 且它是**仓库实测的**，不是我估的。**
