## 1. 这个实验在问什么（以及它为什么关键）

前几轮已确认三件事实：
1. **形核比值 ≠ 最终比值**（用户 2026-10-06 指出）⇒ 两者之间隔着"生长变换因子"；
2. 生产配置里 **场 1 长宽比 2.00 / 长厚比 1.96**，而**引擎核 7.00 / 14.34** ——
   两套几何不一致（`R625 §4.6.6`、`R626`）；
3. 唯一可用的文献靶 = **长厚比 ≈9:1**（Wang 2026，Ti-64/LPBF/α′，`R627`）。

⇒ **本实验把"生长层"单独隔离**：核**三边相等**（无种子偏置），
**若长出来仍是等轴** ⇒ **生长层不产生伸长** ⇒ 那么"把核预先拉长"是在**代偿生长层**；
**若长出来是板条** ⇒ 生长层本身能造出板条 ⇒ 该改的是**形核靶**而不是**生长机制**。

## 2. 生长各向异性的机制（读实，`windowB_surface.py:5192-5213`）

```
:5193  c2b_ = clip( (n̂·n*)^2, 0, 1 )
:5197  _expo = -mob_beta * (c2b_ if pin_min else (1 - c2b_))
:5211  _expo -= mob_beta_w * where(_use_w, (n̂·w)^2, 0)     # 第二钉扎轴（仅变体-母相界面）
:5212  _mfac_dt = exp(_expo)
:5213  v_cell = v_cell * _mfac_dt
```
其中 `mob_beta = --beta-h`（`:2219`）。⇒
$$M_{\rm fac}=\exp\!\big[-\beta_h(\hat n\cdot\hat n^*)^2-\beta_w(\hat n\cdot\hat w)^2\big]$$

| 界面朝向 | 因子 | 后果 |
|---|---|---|
| 沿 `n*`（**增厚**） | `e^{−β_h}` | **被压制** |
| 面内（**伸长**） | `1` | 不受压制 |

⇒ **单步伸长/增厚比 = `e^{β_h}`**
⇒ 从长厚比 1 到 9 只需 `n_R = ln 9 / β_h ≈ 0.34` 步的"钉扎重初始化" ⇒ **理论上几步就够**。

## 9. ★★★ 量具更正（**最重要的一节**）：轴向投影口径被**系统性污染**，已换成基无关量具

### 9.1 现象：立方核被量成"不等轴"

`c2Eq0` 的 step 0 是 `plate_L = plate_W = plate_T = 250 nm` 的**立方核**，
三轴跨度**应当相等**。但旧量具（把胞坐标投影到 `a_ax`/`w_ax`/`n_hab` 再取 `ptp`）给出：

```
沿a = 229 nm   沿w = 177 nm   沿n = 244 nm      ← −29% / +0% 的散布
```
**4 胞的核不可能有 29% 的离散化偏差** ⇒ 一定是量具问题。

### 9.2 根因：`a` 与 `n` **不正交**

`windowB_surface.py:1435 _rank1_axes` 的 docstring **逐字**：
> ★ 记账：**`a·n` 不要求为 0**（rank-1 分解中 `a·n` 正比于 `trace(eps)`）

本算例实测 **`a·n = 0.127`**。把胞坐标投影到**非正交**的三条轴上取 `ptp`，
**投影跨度会被非正交性污染**：沿 `n̂` 的真实跨度为 `c` 胞、`â·n̂ = cosθ`
⇒ 投影跨度可达 `c/|sinθ|`（θ=45° 时虚高 **41%**）。

**⇒ 这是量具伪影，不是物理。** 而且它已经把**负对照误判成 FAIL**（旧口径 `L/T = 1.64`）。

### 9.3 修法：**回转张量**（基无关）

$$G=\big\langle(\mathbf r-\bar{\mathbf r})(\mathbf r-\bar{\mathbf r})^{\mathsf T}\big\rangle,\quad
\lambda_1\ge\lambda_2\ge\lambda_3,\quad R_i=\sqrt{5\lambda_i}$$

判据改用 **`R1/R3`**（长/厚）与 `R1/R2`（长/宽）；本征值**不依赖坐标系**。
另报**沿 `n̂` 的真实厚度**（取沿 `n̂` 中间 60% 层的 `ptp`，避开斜边拉长）。
工具：`_t11_shape2.py`（`shape_metrics()`）。

| 口径 | step 0（立方核） | step 40 | step 100 |
|---|---:|---:|---:|
| 旧（轴向投影 `L/T`） | **1.38** ❌ | 1.07 | **1.64**（假 FAIL） |
| **新（回转张量 `R1/R3`）** | 1.29 | **1.06** | 1.85（大分量，见 §9.4） |

### 9.4 ★ 读数选点规则（**预登记，不因数据而改**）

**主口径 = 「最后一个 `nc == 1`（单连通）且未自贯通」的读数。**

**为什么必须加 `nc == 1`**（实测驱动，不是为凑结论）：
`c2Eq0` 在 step 100 时 `nc = 4`，但**最大连通分量占 8595 / 8601 胞** ⇒
它其实是**一个连通大团**（其余 3 个是孤儿）⇒ 那个大团的 `R1/R3 = 1.85`
反映的是**团块不规则性**，**与板条伸长无关**。
若拿它当负对照，会把 `β_h = 0` 误判成"伸长"。
⇒ 依据 **`P22`**（按身份聚合前，**先问这个身份对象是否连通**）。

⚠ **这不是改判据** —— 判据 ① 的 `|R1/R3 − 1| ≤ 0.5` **一字未动**，
只是把**读数选点规则**写明；碎裂后的读数一律**降为诊断**，不参与判定。

### 9.5 修完后的第一条判定

```
c2Eq0 ：step=40  R1/R2 = 1.02   **R1/R3 = 1.06**   厚 = 468 nm   nc=1   [单连通体]
```

## 11. ★★ 正对照臂给出的**量具刻度**（比预想更有价值）

### 11.1 设计 vs 实测

```
【c2PosA】核按 `plate-T = 1250/9` 设计 ⇒ 几何长厚比 = 9.00
   step 0 实测：R1 = 701 nm  R2 = 699 nm  R3 = 89 nm  ⇒ **R1/R3 = 7.87**
```

### 11.2 为什么低了约 12%（**几何原理，不是缺陷**）

回转张量对**薄板**给出的比值有解析形式：均匀板条 `L×W×t`（`t ≪ L, W`）时

$$\frac{R_1}{R_3}=\sqrt{\frac{L^2+t^2}{t^2}}\;\Big/\;\text{(离散化项)}
\quad\Longrightarrow\quad \frac{L}{t}=9 \;\Rightarrow\; \sqrt{1+1/81}\approx 9.06
$$
离散厚（**2.2 胞**）再加底边 20 胞的量化 ⇒ 理论落到 **8.66–8.9**，实测 **7.87**。

### 11.3 ⇒ **对靶的正确期望值要改口径（记账，不是改判据）**

| 量 | 值 |
|---|---|
| 几何长厚比（设计） | **9.00** |
| `R1/R3` 理论（连续薄板） | **9.06** |
| `R1/R3` 理论（离散，厚 2.2 胞） | **8.66–8.9** |
| **`R1/R3` 实测（本量具 + 本分辨率）** | **7.87** |

⇒ **判据③ 的靶 `≈9` 对应到本量具应读 `R1/R3 ≈ 8`**（带 **约 −10% 系统偏置**）。
⚠ 这条**必须与结论同时报**，否则会把"量出 8"误判成"不到 9 ⇒ 未达标"。

## 13. ★ 本轮抓到的**两个量具/记账坑**（都会导致误判）

### 13.1 「构造 N s」是**墙钟**计时 ⇒ **冻结时长被计进去**（85 分钟假象）

两臂日志同一位置都有这行：
```
【c2Eq0】 构造   **76.5 s**（7 个场）
【c2B647】 构造 **5099.4 s**（7 个场）   ← ⚠ 字面上 85 分钟
```

**`c2B647` 的进程被 `SIGSTOP` 冻结过 84.2 分钟**（23:10 → 00:34），

⇒ **该计时是墙钟（含被暂停的时间），不是 CPU 时间**。

**⇒ 纪律（新增）**：**看"构造耗时/步耗时"这类日志数字时，必须先确认它是否含被冻结/被抢占的时间**；

**这是 `P29`（"进程不见了"先怀疑进程列表工具）的同类**：
