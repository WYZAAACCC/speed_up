## 1. 这个实验在问什么（以及它为什么关键）

前几轮已确认三件事实：
1. **形核比值 ≠ 最终比值**（用户 2026-10-06 指出）⇒ 两者之间隔着"生长变换因子"；
2. 生产配置里 **场 1 长宽比 2.00 / 长厚比 1.96**，而**引擎核 7.00 / 14.34** ——
   两套几何不一致（`R625 §4.6.6`、`R626`）；
3. 唯一可用的文献靶 = **长厚比 ≈9:1**（Wang 2026，Ti-64/LPBF/α′，`R627`）。

⇒ **本实验把"生长层"单独隔离**：核**三边相等**（无种子偏置），
**若长出来仍是等轴** ⇒ **生长层不产生伸长** ⇒ 那么"把核预先拉长"是在**代偿生长层**；
**若长出来是板条** ⇒ 生长层本身能造出板条 ⇒ 该改的是**形核靶**而不是**生长机制**。

## 2. 生长各向异性的机制（读实，`windowB_surface.py:5192-5213`）

```
:5193  c2b_ = clip( (n̂·n*)^2, 0, 1 )
:5197  _expo = -mob_beta * (c2b_ if pin_min else (1 - c2b_))
:5211  _expo -= mob_beta_w * where(_use_w, (n̂·w)^2, 0)     # 第二钉扎轴（仅变体-母相界面）
:5212  _mfac_dt = exp(_expo)
:5213  v_cell = v_cell * _mfac_dt
```
其中 `mob_beta = --beta-h`（`:2219`）。⇒
$$M_{\rm fac}=\exp\!\big[-\beta_h(\hat n\cdot\hat n^*)^2-\beta_w(\hat n\cdot\hat w)^2\big]$$

| 界面朝向 | 因子 | 后果 |
|---|---|---|
| 沿 `n*`（**增厚**） | `e^{−β_h}` | **被压制** |
| 面内（**伸长**） | `1` | 不受压制 |

⇒ **单步伸长/增厚比 = `e^{β_h}`**
⇒ 从长厚比 1 到 9 只需 `n_R = ln 9 / β_h ≈ 0.34` 步的"钉扎重初始化" ⇒ **理论上几步就够**。

## 3. 配置（为什么这样选）

| 项 | 值 | 理由 |
|---|---|---|
| 盒 | **`N=64`、`Δx=62.5 nm` ⇒ 4.00 µm** | `Δx` 与生产**逐字相同**（分辨率口径可比）；内存约 0.2 GB（**可安全并存**） |
| 核 | **`plate_L=plate_W=plate_T=500 nm`** ⇒ **立方** | 用户要求"长宽高相同" |
| 形核通道 | **全关**：`--nuc-init 0`（无 fresh 位点）+ `--nuc-law cadence` + `--nuc-every 0` + 不传 `--grow-stack` | **只留 t=0 那一片** ⇒ 纯生长 |
| 步数 | 600 | 够看到趋势 |
| 各向异性 | 3 臂扫 `--beta-h` | 见下表 |

⚠ **记账（不得含糊）**：**立方核在晶体学上不是真实核形状**（真实 α′ 是 `{334}` 薄片）；
本实验是**诊断探针**（立方暴露全部界面法向，看哪个方向长得快），**不是"真实形核"的复现**。

## 4. 三个臂与**预登记判据**

| 臂 | `--beta-h` | 角色 |
|---|---|---|
| **`cubeEq0`** | **0.0** | ★ **负对照**：无各向异性 |
| **`cubeB647`** | **6.477** | **生产值** |
| **`cubeB15`** | **15.0** | ≈ 由 Wang 2026 的 9:1 反推值（14.90，`R627 §4`） |

**判据（可 FAIL，先写死）**
1. ★ **负对照闸**：`cubeEq0` 的终态长厚比必须 **≈ 1**
   （若 ≠ 1 ⇒ 量具有偏或驱动自带各向异性 ⇒ **整批作废**）；
2. **主判据**：`cubeB647` / `cubeB15` 的终态**长厚比**是否 **> `cubeEq0`**
   （⇒ 生长层是否真的造出伸长）；
3. **靶**：长厚比 **≈9**（Wang 2026，`R627`）；
4. **副判据**：`cubeB15` 的伸长是否 **> `cubeB647`**（剂量-响应单调 ⇒ 机制在起作用）。

**量具**：`_t11_lath_shape_when.py` 同口径 —— 逐场沿 `a_ax`/`w_ax`/`n_hab` 的三轴跨度，
长轴取三轴最大者（**立方核无先验长轴**）。
