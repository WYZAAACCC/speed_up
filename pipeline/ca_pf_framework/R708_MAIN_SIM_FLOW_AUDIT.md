## 1. 问 (0)：板条的**表示**正确吗？

### 1.1 代码事实

| 事实 | 位置 |
|---|---|
| 每个变体/板条一个**有符号距离场** `φ_k`，形状 `(nreg, N, N, N)` | `windowB_surface.py:1128` |
| 相 = **`region = argmin_k φ_k`**（VDF / 多区域 level-set） | `:1564 region()` |
| 界面 = **差分场 `d = φ_k − φ_l` 的零等值面** | `:4793-4814` |
| 核形状 = `sdf = max(\|d\|−t/2, rperp−R)`（**尖边圆柱**）或椭球 | `:3334` / `:3355` |
| 界面刚度 = `γ_eff(n)`（Herring 项） | `:488-496 herring_stiffness` |
| 尖点界面能（近奇异）函数**存在**，但**生产关闭** | `:461 herring_stiffness_cusp`；生产 `--facet-lam 0.0` |
| **唯一的"面片/多面体"设施** = `facet_project()`，把场**覆盖**成 `K=3`（6 法向）轴对齐盒 | `:3928`；算子 `_r68_facet_op.py:17` |
| 全仓**没有**任何多面体/面片/棱边数据结构 | `grep 多面体\|polyhedr\|GibbsLath` 在 `windowB_surface.py` 只命中 **1 处注释**（`:3350`） |

### 1.2 判定

**（a）"当前用的是等值面表示"—— 属实，有代码证据。**
`φ_k` 是**处处光滑的标量场**；`region = argmin φ_k` 是一个**隐式**表示；
文档里称它为"Gibbs 面"，但**数学对象是 level set 的零等值面**，不是分片平面集合。

**（b）"Gibbs 面应该有的、可以相互奇异的多面体"—— 未实现。**
- `grep` 全仓：没有 `K_k = {x : x·n_j ≤ h_j}` 这类多面体对象；
- 唯一的 `K=3` 盒在 `_r68_facet_op.py:83-92`，是**投影算子**（覆盖 φ），不是**表示**；
- 棱边/顶点的物理（Gibbs 面在三面交汇处可以奇异的能量项）**没有任何承载**。

**（c）★ 一个比"表示不一致"更硬的缺陷：`−γ_eff·κ` 这一项在奇异面上没有连续极限。**

下面 §5 的【实测】给出：
- 在算子输出的盒子上，**平面上的离散曲率中位 ≡ 0.000**（正确）；
- **棱上的 `max|κ|·Δx ≡ 1.789` 在 Δx = 125 / 93.8 / 62.5 / 46.9 nm 四档上逐位不变**。

⇒ 即 `κ ~ 1/Δx` **不收敛**。而速度律是
`v = M(n)·[Δf + Δed − γ_eff·κ]`（`windowB_surface.py:4873-4875`）——
**被罚的恰好是"面与面之间的奇异处"**，而罚的强度**由网格决定**。

**⇒ 判定：(0) 成立，而且比"表示选错了"更严重 —— 当前框架里"棱"既没有被正确表示，
也被一个不收敛的曲率项主动惩罚。** 这解释了上游文档反复记录的现象
（"平坦面在数值扩散下消失"、"冲销发生在平流环节"）。

**（d）【推理】正确的做法（未实施）**：把界面换成**显式面片集合**
（每个面族一组平面 + 棱/顶点拓扑），面上 `κ ≡ 0`、棱上按 Read–Shockley 型
奇异能量处理；`φ` 只留作体相的辅助量。这与本仓 `R681_R1_GEOMETRY_SPEC.md` /
`R682_C2_MOTION_LAW.md` 的方案一致 —— 但那两份**只有规格，没有实现**。
**⚠ 我没有实施它，也不建议在没跟您确认前实施**（这是表示层的改动，会改全部归档读数）。

## 2. 问 (1)：形核物理正确吗？（burst 与顺序形核）

### 2.1 代码里到底有哪几条形核通道

| 通道 | 代码 | 语义 |
|---|---|---|
| `fresh` | `:2127-2331` | 独立形核：均匀位点，变体取 `argmax_k ed[k]` |
| `stack` | `:2365-2900` | sympathetic：在已有场的**外缘**、沿 `n*` 平移一片，**同变体** |
| `attach` | `:2568-2740` | `stack` 的一个 regime：新片**与源板条共用一张界面** |
| `nuc_iface_nucleation` | `:1695-1709` | 允许落在**异变体**已有场的界面上（R623 G2，**默认关**） |
| athermal/burst 调度 | `_bk_exp.py:2878-3300` | **档目标量**由 KM 分数律给出 |

### 2.2 burst

**（a）实现了**：`_bk_exp.py:2906-2912`
```
_burst_km=1 ⇒ _N_end = floor(α(M_s − T_end))            # = 23（单块的板条数）
              _f_km  = 1 − exp(−α(M_s − T_now))          # KM 分数律
              _n_blk = round(_N_end · _f_km)
```
⇒ 首档 `f(ΔT=1/α)=0.632` ⇒ 目标跳到 **63%**，后续档 23%/8.5%/3.1%…
与 `windowB_km.py:232 koistinen()`（文献式）一致。

**（b）★ 但它不是"自催化律"，是一个**配额**。** 代码自己写死了这一点：
> `_bk_exp.py:2956-2958`（R623 §0.3(g) 引）：
> "**R-B 给的是判据，不是率律**…**没有给** `dN/dt` 形式的形核率"

并且 `p_auto`（自催化增益）**生产恒为 0**（`_bk_exp.py:2044 p_auto=0.0`），
其函数形式本身也没有一手文献依据（`windowB_surface.py:1877-1891` 自陈）。

**（c）★ 物理上更要紧的一条：`T(t)` 是**线性占位**。**
`windowB_km.py:138 linear_cool` 的 docstring **自称占位**；
而"形核事件温度 `T_k = M_s − k/α_KM`"**完全由这条曲线决定**
⇒ 最终板条数、burst 档位划分全部依赖一个占位曲线。
生产确实走了这条：`--nuc-law athermal --cool-rate 2.3524e6 --therm-hist linear`。

**⇒ burst 判定：算式在（KM 分数律），时间表不在（线性占位），自催化项不在（`p_auto=0`）。**

### 2.3 顺序形核

**（a）"在已有板条上继续形核"—— 有**：** `stack`（同变体）+ `attach`（共用界面），
且 `nfsv=True` 让同变体的核进入**新的空场**而不是加厚同一片
（`windowB_surface.py:2461-2538`；文献锚 Furuhara 2008 "repeated nucleation of the same variant"）。

**（b）"上一代接了下一代"的**判据**—— 没有。** 文献给的机制是
`E_int(r,p) = −σ_ij^{V1}(r)·ε_ij^{Vp}` 的**符号**决定"能不能在 r 处形核、哪个变体抢到位点"。
代码里的现状：
- **没有** `σ·ε` 张量缩并接到形核路径上（引擎**有** σ，但形核只看 `ed = ε⁰:σ` 的 `argmax`）；
- **没有**"共用位点时更负者抢占"；
- **没有**钝化（saturation）机制 —— 上游用"位点距离 ≈ `plate_T`"（`evloc_dup=0`）
  间接取证，但**没有算 `E_int` 来关闭饱和面**。

**（c）★ 阶段③（母相硬化 ⇒ 换变体）在生产里**不可达**：**
`harden_f=1.0`（`_bk_exp.py:2044`）而判据是 `hardened = f_now >= 1.0`
（`windowB_surface.py:2392`）⇒ 需要母相胞数**恰好为 0**。
⇒ 三阶段规则（Morito 2022）里的第 ③ 阶段**没有在跑**。

**（d）★ 顺序形核与"块"的关系被一个常量切断了：**
`sym_gap_cells = 0`（`_bk_exp.py:2044`）。
引擎默认的 sympathetic 语义是"新核与已有板条之间**留一层残余母相**"
（文献锚 Chen 1979，`windowB_surface.py:1640-1642`）；
生产把它设成 0 ⇒ 走的是 `attach` 的"干晶界"语义（`:1726-1746` 记为**模型选择**，
不是从自由能推出来的）。这是**一个开关定了一种物理**，必须在结论里带着。

**⇒ 顺序形核判定：位置通道在（`attach`/`stack`/`nfsv`），物理判据不在
（无 `E_int`、无抢占、无钝化、阶段③不可达），速率不在（配额 + 线性 T(t)）。**

## 3. 问 (2)：生长物理正确吗？`facet_proj` 一定是错的吗？

### 3.1 速度律本体（代码原文）

`windowB_surface.py:4873-4875`
```python
dG_cell = ((self.df[karr] - self.df[larr])
           + ed_eta * (edk - edl)
           - stk * kap_cell)
...
v_cell = self.M * dG_cell            # :5144
v_cell = v_cell * _mfac_dt           # :5211/5250/…（M(n) 各向异性）
```
这是标准 Gibbs–Thomson：`v = M(n)[Δf + Δed − γ_eff(n)κ]`。
**对光滑面是对的**，且 `κ` 的取法（差分场、按编号定向）经过两轮修正
（`:4786-4814`，含"丢掉 winner 定向因子"的自查）。

### 3.2 ★ 用户断言"`facet_proj` 一定是错的"—— **成立，五条独立理由**

算子：`_r68_facet_op.py:17 facet_project_one`，被 `windowB_surface.py:3928 facet_project` 调用。
它做的事：**取体内胞 → 在 `(n*, a, w)` 三轴上取 0.5%/99.5% 分位 → 外扩 `0.5Δx` →
建一个轴对齐盒 → 按体素数统一定标体积 → **用盒子的 SDF 覆盖 φ_k**。

| # | 错在哪 | 代码位置 | 我的【实测】（§5） |
|---|---|---|---|
| **E1** | **它不是"表示层重整"，它改变几何** —— 算子自称保体积，实测**不是** | `_r68_facet_op.py:86-96` | 圆盘 ΔV **+4.32%**；非凸月牙 **−12.32%**；算子自报 `rel` +4.3e-2 / +1.1e-1 |
| **E2** | **它把场的凸包填成盒子** ⇒ 非凸/凹形**表示不了**（`K=3`，恒凸） | `:83-92` | 月牙形的体积被删 12.32% —— 就是凹区被填/被削 |
| **E3** | **它重新居中到"跨度中点"** ⇒ 非对称体的**质心被搬走** | `:88-90 mid = 0.5*(lo+hi)` | 月牙形质心漂移 **154.1 nm = 2.47 Δx**（圆盘 0，因为对称 —— 这正是 v1 量具无分辨力的教训） |
| **E4** | **它造出 12 条尖棱，而 `−γ_eff·κ` 在棱上不收敛** | 输出 `max_j(...)`，`:83/91` | `max\|κ\|·Δx ≡ 1.789` 在 Δx=125/93.8/62.5/46.9 nm **四档上完全相同** ⇒ `κ ~ 1/Δx`；**平面中位 κ ≡ 0.000** |
| **E5** | **它每步覆盖整个场**（`--facet-proj 1` 时 `_fp_cnt % 1 == 0` 恒真）⇒ 上一节"表示层重整"的说法在**动力学上不成立**：`Vt` 变 1.45×、形核事件 5→13（上游 `R707 §5.1` 实测） | `windowB_surface.py:4350-4355` | 本次未跑仿真验证，**引用上游实测** |

**⇒ 判定：`facet_proj` 不是"把 Gibbs 面该有的平面还回来"，而是**用一个 6 面的凸盒子
替换掉物理演化出来的形状**。它同时改了三件事：(i) 体积，(ii) 质心/内部几何，
(iii) 棱上的曲率罚。前两件是**新增的、未记账的几何操作**，第三件**不可收敛**。**

### 3.3 ★ 还有一条比 `facet_proj` 更根本的（这才是"生长物理"的真问题）

`M(n)` 是**唯一的动力学各向异性通道**，而它的输入是**离散法向**
`ndir_ = ∇(φ_k − φ_l)/|∇(…)|`（`:4697-4699`）。
- 代码自己记录了：带内 `|∇d|` 中位只有 **0.70–0.93**（应 ≈1）⇒ 法向有散布（`:4674-4684`）；
- 上游定量判决：`β_w^eff/β_w = 0.50`、`β_h^eff/β_h = 0.70`
  ⇒ **有效各向异性只有设计值的一半**；`oblique`（斜法向）胞占比 **52–60%**，
  与角函数形式（凸化/凹陷/椭圆）**无关**。

**⇒ 生长物理的病灶排序**：
1. **界面法向估计被污染**（`M(n)` 的输入 ~ 50–70% 强度）—— **未修**；
2. **表示层不能承载平面**（问 (0)）—— **未修**；
3. **`facet_proj` 是"用几何硬掰代替物理通道"** —— 它能把 `v_a/v_w` 的**读数**做上去，
   但那是**盒子的几何必然**，不是模型涌现的各向异性；
4. `--facet-lam`（尖点界面能，把惯习面同时做成**低能面 + 刚性面**的**物理**通道）
   **函数已实现、生产关闭**。

**⇒ 判定：生长物理不正确。而且"错"的地方不是 `facet_proj` 一个算子 ——
它是被用来**掩盖** (1)(2)(4) 三条未修的物理缺口。**

| **自协调（self-accommodation）**：`grep 自协调` 在引擎三文件里**只出现在注释** | 上游 `R30_AUDIT_S4_SELFAC.md §0①` |

### 4.2 判定

**（a）"同取向成块"—— 机制在，但规模是**规定**的。**
- ✅ 机制：`attach` + `nfsv` 让同变体板条一个接一个贴在块外缘，**界面是共用的一张**；
- ❌ **块内有几根 = 您命令行写了几个同变体的场**。
  没有任何动力学能改变它（引擎里**没有**板条分裂/合并）。
  `BLOCK_DERIVATION.md §6.8` 的自欺表把这一条自己标为"**规定，不是涌现**"。
- ⚠ 旁证（上游实测）：`t10B9` 的 `累计 fresh=9 stack=32` ⇒ `fresh` **全落在一开头**
  ⇒ "首档爆发"被摊成"先建 9 个块"；块数由 `--nuc-block-target 9` 规定。

**（b）"不同取向但可自协调成块"—— 没有这个物理。**
- 自协调要求"这一组变体的**形状应变互相抵消**"。引擎里：
  - **没有**任何"组级应变残差"驱动力；
  - **变体选择与相容性完全脱钩**：`fresh` 用 `argmax ed`、`stack` 从已有场**均匀随机**抽、
    阶段③ 从 12 变体**均匀随机**抽；
  - `ncmp`（配对不变平面）只被当作**界面迁移率的参考轴**，**从不参与"选哪个变体"**；
  - F2 界面能表**未填** ⇒ 占 90.4% 面积的变体-变体界面共用一个未检验的常数。
- ⇒ 即便模型跑出多块，那些块之间的**取向搭配是输入决定的，不是物理选出来的**。
- ⚠ **一条必须同时报的边界**：自协调在数学上需要 **≥3 个变体**（本仓的判据给
  `k* = 6`，且"两个块不可能自协调"）⇒ 历史上用 2 变体盒子去测自协调是**假阴性**设计。

**⇒ 判定：(3) 部分正确。"同取向成块"的**几何机制**是对的（这是真进展）；
但"块内的根数/块数/变体配比"是**输入**，而"自协调成块"**完全没有实现**。
⇒ 按 `RESEARCH_INTENT §2.2` 的原文（板条"**自发**按 Burgers 分组"），
**这一条现在不满足**。**

## 5. 问 (4)：块与块之间的相互影响，物理正确吗？

### 5.1 代码事实 —— 耦合通道是**弹性的**，而且是**全盒谱法**的

| 事实 | 位置 |
|---|---|
| 每胞的弹性驱动 `ed_k(x) = +ε⁰_k : σ(x)` | `windowB_surface.py:4043-4142 elastic_driving` |
| 速度律里的配对项 `Δed = ed_{karr} − ed_{larr}` | `:4638 elastic_driving_pair` → `:4873` |
| `σ(x)` 由**整个 region 场**（所有块）谱法解出 | `windowB_pf3d.PF3D.sigma_tensor` |
| **自协调判据 `E_int = −σ_ij ε_ij^{Vp}` 未接到形核路径** | `R623 §8.6` 残留差距 ①② |
| F2（异变体）界面能通道：`--f2-pair-gamma 0` ⇒ **常数** | `_bk_exp.py:4737` |

### 5.2 判定

**（a）块间"相互影响"在物理上是**存在**的，而且通道是正确的。**
`ed_k(x) = ε⁰_k:σ(x)`，而 `σ` 是**全盒**的（谱法、周期边界）⇒ 块 A 的存在**改变 σ**，
从而改变块 B 界面上的 `Δed`。这是**长程弹性耦合**，不是人为加的。
⇒ **这一条（"块与块相互影响"）物理上成立。**

**（b）但"相互影响"的**具体内容**缺两块：**
- ❌ **界面能通道**：异变体界面共用一个未检验的常数（F2 表空）
  ⇒ 60–90% 的块间界面上，"相容性"没有进入能量；
- ❌ **形核通道**：文献的 `E_int(r,p) < 0 ⇒ 促进、> 0 ⇒ 抑制`、以及
  "共用位点时 `E_int` 更负者抢占" —— **都没有接到形核上**。
  现状是用 `ed` 的 `argmax` 近似"促进"，相当于**取 `E_int = −ε⁰:σ = −ed` 且丢了变体间竞争**。

**（c）★ 一条必须报的量的边界：`impingement`（硬碰撞）在本预算内**到不了**。**
上游实测：采样区间在 `f ≈ 0.02`，而 `f_imp ≈ 0.076–0.098`；
`62 block / 64 晶核 ≈ 1 block 每晶核` ⇒ **没有碰撞导致的合并/分组**。
⇒ 现在能谈的是 **pre-impingement 的"远场弹性影响"**，
**不能**谈"块撞在一起之后怎么相互调整"。

**⇒ 判定：(4) 部分正确。弹性长程耦合的**装置**是对的、也在跑；
但 (i) 界面能通道缺失，(ii) 形核的 `E_int` 判据缺失，
(iii) 当前的运行区间**还没进到真正"块与块相遇"的阶段**。
⇒ "块间自协调"这一条**目前无法判定**（不是"弱"，是"没到那个区间且判据没接"）。**
