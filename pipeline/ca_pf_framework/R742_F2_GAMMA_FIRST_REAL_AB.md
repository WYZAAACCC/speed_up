## §3 ⛔ **`W-1` 这条判据本身是错的**（我登记错了）

我照抄 `_t11_f2_ab.py` 的判据 1：「λ>0 的两臂**必须打印** `§122` 那段（含 `Δe_ref` 与 `n_f2`）」。
**读码核实（`windowB_lath.py:288-329`）：那段代码里根本没有 `print`。**
```
:295   self.f2_lam = float(f2_lam)
:296   self.n_f2 = 0
:297   if self.f2_lam > 0.0:
:302       self.de_ref = max(...)
:312           self.gtab[i+1, j+1] = self.gamma0 * (...)   ← 只写 `gtab`
:315           self.n_f2 += 1
:318   else: self.de_ref = float('nan')
```
⇒ **`n_f2` / `de_ref` 只是属性，从不打印。**
⇒ **`W-1` 是一个基于"不存在的输出"的判据** ⇒ 它的 FAIL **不构成任何证据**。

### 3.1 ⇒ `W-1` 的正解（**这才是"开关是否生效"的有效判据**）
`γ_F2` 只在 `gtab[i+1, j+1]` 上生效，而 `gtab` **只被异变体对读到**。
⇒ 有效的三层证据（**已在手**）：
1. **三臂 `series.csv` 签名互不相同**（`W-2`）⇒ **λ 确实进入了数值**；
2. **三臂在 `step 0` 完全相同**（21 558）而与边界相关的初始场尚未生成
   ⇒ **λ 不改变初始条件**（正确）；
3. **三臂从 `step 25` 起分叉** ⇒ **一旦出现异变体界面，λ 就起作用**。

⇒ ⇒ **结论：`λ` 确实生效了**（`W-1` 的名义 FAIL 是判据设计错，不是开关无效）。

## §4 ⇒ 物理结论（**诚实版**）

### 4.1 `λ` 的效应**极小**：`nf2` 的终值差只有 **±0.5%**
```
λ=0.5 : +161 / 31050 = **+0.52%**
λ=1.0 :  −70 / 31050 = **−0.23%**
```
且**非单调**：**λ=0.5 > λ=0 > λ=1**。

### 4.2 ⚠ 与码内注释的**预测**对照
`windowB_lath.py:288-289` 预测：
> **λ = 1 ⇒ 最共格的对拿到 `γ_lo = 0` ⇒ **packet 形成会被促进****

**实测：λ=1 的 `nf2` 反而比 λ=0 **低** 0.23%（`31 050 → 30 980`）。**
⇒ **没有观察到"packet 促进"**（在 `nf2` 这个量上）。

### 4.3 ⚠ 为什么不能就此说"注释错了"（三条限定）
| # | 限定 |
|---|---|
| **1** | **`nf2` 只是"异变体界面格面数"**，不是"packet 程度" ⇒ **它测不到 packet 是否形成**。要判 packet 需要**同惯习面变体的聚集度**（本实验**没有测**） |
| **2** | 本配置的 `n_var_sig = 2`（**只有 2 个变体**）⇒ packet 是"**同惯习面多个变体**"的现象，**2 个变体构不成 packet** ⇒ **本实验的选择性不足** |
| **3** | ⚠ 码内注释**自己就警告过**（`:291-294`）："促进 packet"与"六变体自协调"是**两个不同的物理目标**，**在面内聚集可能反而远离 `r = 0`** ⇒ **不预设哪个对**。本实验**不能分辨**这两个目标 |

### 4.4 ⇒ 所以本实验的结论是
> **`γ_F2` 的机制是**活的**（λ 确实进入数值、且在出现异变体界面后开始分叉），
> 但在这个配置（2 变体、200 步）上，`nf2` 对 λ 的响应只有 ±0.5% 且非单调。**
> **要判 `windowB_lath.py:288-289` 的"packet 促进"预测，必须换配置：**
> **多惯习面变体 + 测"同惯习面变体的聚集度"而不是 `nf2`。**
