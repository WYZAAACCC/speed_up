### 一、裁定与设计

用户裁定 **C：两条都跑，作受控对照**（不预设哪条判据对）。

**对照设计（只差一个因素）**：

| 臂 | `--rank1-swap` | 其余 |
|---|---|---|
| **`dry_mb2fp10`**（**已有**，R75） | **`none`**（`n* = NPF = argmin_normal(C,ε)`） | N=96 / Δx=62.5 / 6 µm / `--laths 1,1,1,3,3,3` / `--multi-block --block-gap-nm 2500` / L=1600 W=700 T=635 / `--facet-proj 10` / 600 步 / `--pair-every 20` |
| **`dry_swapinv`**（R132，新） | **`invariant`** | **逐项相同** |

⇒ **R75 的两个块正是 `V1`（块0）与 `V3`（块1）⇒ 两块都被对调**（整构型一致改变）。

### 二、实现（`_bk_exp.py`，**默认关 ⇒ 归档逐位不变**）

```python
ap.add_argument('--rank1-swap', choices=['none', 'invariant'], default='none', ...)
```

* `none`（默认）⇒ 现行行为，**逐位不变**（由 `_r30_regress.sh` 把关）；
* `invariant` ⇒ 按判据 `rB(u) = ‖(F−I)B_u‖₂`（平面 ⟂u 内向量不动）**算出**该换哪些变体，
  然后对这些变体把 `n*` 与 `a` **对调**。

**两条纪律都落进去了**：
1. **受影响集合是算出来的，不是写死的** —— 由判据现场决定；
2. **判据自带正对照**：先在一个**合成 IPS**（`F = I + 0.2·d pᵀ`）上验证判据会选中 `p`，
   不通过就 `SystemExit` **拒绝运行**（`_r89`/`_r92` 的教训：判据不验就跑 = 白干）。
