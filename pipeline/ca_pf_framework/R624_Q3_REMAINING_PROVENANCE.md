## 2. ★ `β_h`/`β_w`：为什么判定为「不可锚定」（三条独立理由）

### 2.1 `β_h` 的"位错环形成能锚"**存在，但标定公式是错的**
* **物理输入（Ti-64，材料对得上）**：`mu = 40 GPa`、`b = 0.29 nm`、`eps ≈ 0.1`、`nu = 0.34`
  ⇒ 位错环形成能路径给 **`β ≈ 3.8`**（`MEASUREMENT_SPEC.md:500`）。
* ⚠ **但 `LATH_FACET_PLAN §9.3` 把它与"观测长径比"互校时用的公式 `长/厚 = e^{β_h}` 是错的**
  —— 漏了 **Wulff 凸化**（`AUDIT_2026-09-27_INDEPENDENT_REVIEW.md:22`）。
  正确闭式（对 `v(n)=C·exp[−β_h(n·n*)²−β_w(n·w)²]`）：
  ```
  h(a) = 1,  h(ŵ) = e^{−1/2}/√(2β_w),  h(n_hab) = e^{−1/2}/√(2β_h)
  ⇒ 长/厚 = √(2β_h)·e^{1/2} = 2.3316·√β_h      （不是 e^{β_h}）
  ```
  （`WINDOWB_P0_REGISTER.md:109`、`AUDIT_2026-09-27:153`）
* **⇒ 后果**：`β_h = 3.5` 的上限是 **4.36**（不是 `e^{3.5}=33`），
  而**实测长/厚 4.17–4.87 与之吻合** ⇒ **已经长到模型极限**
  （`AUDIT_2026-09-27:170-174`）。
  ⇒ **"两条独立路径互校自洽"不成立**：位错环给 3.8，而用**正确**公式反推
  文献长径比 10–30 需要 **β ≈ 18–165**（`WINDOWB_P0_REGISTER.md:136`）。

### 2.2 `β_w` **无同工艺锚点**（检索已穷尽）
* **3D 长:宽 查不到**（`MEASUREMENT_SPEC.md:532`）；
* **2D 截面无法分离"宽"与"厚"** ⇒ 模型有**两个**参数（`β_w`、`β_h`），
  而数据只能约束**一个**指数 ⇒ **退化**（`:545-565`）；
* ⇒ 现有 2D 数据里 `β_h=3.5` 隐含长:短 = **33**，而**任何 2D 实测都不超过 24**
  ⇒ **超出文献范围**（`:565`）；
* `β_h − β_w = 1.2` ⇒ 隐含截面各向异性 `e^{1.2} = 3.32:1` ⇒ **无任何出处**（`:566`）。
* ⚠ 且 `ΔW:ΔT = 3.6` 这个"独立交叉核对"**部分循环** ——
  它来自 `e^{β_h−β_w}`，而 `β_h−β_w` 正是那个无出处的假设（`:602-603`）。

### 2.3 位移型 vs 扩散型（跨机制）
* **位移型 α′ 的增厚是界面控制的** ⇒ 扩散型 α 析出的数值**不能**作为本项目 `β_h` 的锚
  （`R621_VARIANT_SELECTION_PAPER.md:63`）。
* 我的外部检索（本轮 3 条 query）**未命中**任何独立的
  「位移型 α′/β 界面能」或「Ti-64 位错环形成能」文献值 ——
  返回的多是学位论文/无关综述，**质量层级不足**，不予采纳。

> **`β_h` 与 `β_w` 应作为「一个受约束的参数 + 一个显式退化」处理，
> 不得声称两者各有独立的同工艺锚点。**
> 这是仓库里**已有的推荐**（`ALPHA_PRIME_LATH_WIDTH_PROVENANCE.md:295-297`：
> 「do not re-calibrate `β_w` to a single literature number. Either (i) run the …

## 6. ★★★ ③-5「块的几何口径」：**已判定 —— `block` 是堆叠型，块厚 = `n·t`**

### 6.1 ⚠ 先更正 goal 里的一处**误读**
goal 把 ③-5 写成「`R507 §5` 两列（**堆叠 6.3 vs 面内 2.48**）」，
暗示这是「block 是堆叠型还是面内并列型」的**两种候选口径**。
**实测（读 `R507_SHAPE_CLOSURE.md:18-45/96-110` 全文）**：**6.3 与 2.48 不是两种口径，
而是两个不同的量**：

| 列 | 算式 | 含义 |
|---|---|---|
| **6.3** | `α_KM · **575**` | **C-2 预言**的每块根数 `n`（`575 ≈ M_s − T_end − 0.2`） |
| **块厚 `n·t`** | `6.3 × 0.51 = **3.23 µm**` | 块沿 `n*` 的厚度 ⇒ 判据是落在 `W_BLOCK_BAND_UM = (1.0, 6.0)` 内 ✅ |
| **2.48** | `α_KM · **225.8**` | **几何容量**：「**每块放得下**几根」 |

### 6.2 ★ 判定：**堆叠型**（三条独立证据）

1. **§5 明写「块厚 = `n·t`」** —— 块沿 `n*` 由 `n` 根**堆叠**而成，`t` 是单根厚度。
2. **[L] 文献侧**：板条按 Burgers 取向分组，**同一变体 = block/colony**；
   同一惯习面族的不同变体 = packet（`AGENTS.md §1.1`，与 `RESEARCH_INTENT` 一致）。
   同一变体的板条**共面** ⇒ 只能**沿法向堆叠**，不可能面内并列（面内并列会互相穿插）。
3. **代码侧**：`--nuc-shape ellipsoid` 是**唯一**使五约束交集非空的形状（`§2`），
   而椭球的半轴是 `320/320/255 nm` ⇒ **核本身就是"扁饼"** ⇒ 堆叠是几何必然。

**⇒ 结论**：`block` **是堆叠型**，**块厚 `W_block = n·t`**，`n` = 该块内的板条数。
⇒ 「块的几何口径」**不需要再检索文献**（它是模型与晶体学的推论，不是可查的观测量）。

### 6.3 ★★ 但这个判定暴露了一条**真正重要的张力**（直接关系 ⑧ 的「两百多根」）

**`R507 §1` 的算式**（`:18`）：
```
每块放得下的核数 = n(T_end) − n(T_阈) = α_KM · (T_阈 − T_end)
T_阈 取决于核的形状（因为判据里的弹性罚 |ed| 取决于形状）
```
**引擎同一路径（`_supercrit_probe`）、同一核几何（R=320 nm、t=510 nm）实测**（`:24-27`）：

| 核形状 | `\|med_ed\|` | `T_阈` | **每块放得下** |
|---|---:|---:|---|
| **带尖边圆盘**（`sdf = max(\|d\|−t/2, rperp−R)`，**现默认**） | **3.1720e8** | 380.1 K | `α_KM × **82.1**` |
| **光滑椭球**（`--nuc-shape ellipsoid`） | **2.5760e8** | 523.8 K | `α_KM × **225.8**` |

⇒ **椭球的弹性罚比圆盘低 18.8%** ⇒ 形核窗口从 **82 K 放宽到 226 K（2.75 倍）**。

**生产配置（`α_KM = 0.041739`、**归档用圆盘**）下的三个数**：
| 量 | 值 | 与文献带比较 |
|---|---|---|
| C-2 **预言**每块根数 | `0.041739 × 575 = ` **24.0** | 块厚 `24×0.25 = 6.0 µm` ⇒ **正好压在带上界** |
| **几何容量**（圆盘） | `0.041739 × 82.1 = ` **3.43** | 块厚 `0.86 µm` ⇒ **略低于带下界 1.0** |
| **几何容量**（椭球） | `0.041739 × 225.8 = ` **9.42** | 块厚 `2.36 µm` ⇒ ✅ **落在带内** |

**⇒ 这就是"块厚对但根数不够"的机理**：
* 基线实测**最大块 = 10 根**（`R623 §14`）—— 与**椭球容量 9.42 吻合**；

## 7. ⚠⚠ 生产跑的一处**严重配置错误**：`--out` 没被传递 ⇒ 写错目录（已修）

3. `__main__` 里 `over.setdefault('out', '_exp/_bk_t5')`。
**验证**（`_t11_check_cmd.py`）：
