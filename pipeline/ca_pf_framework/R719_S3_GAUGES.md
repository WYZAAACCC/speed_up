## §1 ★★ 量具 ① `test_effective_anisotropy` —— **给出了基线，且与上游结论方向相反**

### 1.1 口径（**与引擎逐字同式**，不另立公式）`[码]`

`windowB_surface.py:5251-5272`：
```
c2b   = clip((n · n*_ref)^2, 0, 1)
c2w   = clip((n · w)^2, 0, 1)        # **只对变体-母相界面施加**（:5268-5269）
M(n)/M0 = exp(−β_h·c2b − β_w·c2w)
```
本量具对**快照实测法向** `n`（`np.gradient(φ, edge_order=2)`，与引擎 `:3792` 同口径）
逐胞算 `M(n)/M0`，在 `|φ| ≤ 0.5Δx` 的**界面胞**上取均值（网格均匀 ⇒ 面积加权 = 计数加权）。

**配置自证**（`R690` 的坑）：快照**有** `n_hab` / `w_ax` / `a_ax` / `band_cells`
⇒ **`n*` 与 `w` 来自快照本身**（`n_hab` ／ `w_ax`），**不需要硬编码回退** ✅
⚠ **但 `β_h`/`β_w` 只能硬编码回退**（6.477 / 2.300）—— 快照与 `meta.json` **都不落盘 β**
⇒ 与 `R690 §5` 的同类缺陷（**配置不能自证**）**仍然存在**。
