## §1 ② 是不是"Gibbs 面场 + 体相场"？—— ✅ **设计上是，代码 docstring 逐字如此**

`windowB_surface.py:3`（**模块第一行**）：
> `windowB_surface.py --- **Gibbs 面场（level-set）+ 体相场** 的混合实现`

**两套场分别是什么**（读代码确认）：

| 场 | 是什么 | 证据 |
|---|---|---|
| **体相场** | 各变体的相场 `φ_k`（`self.phi`，形状 `(nreg, N, N, N)`）；`φ_k<0` = 变体 k 的体内；`region() = argmin_k φ_k` | `:1128`、`:1585-1588` |
| **Gibbs 面场** | **界面自身的本构量**存在"面上"：`γ(n)`、`M(n)`、**面上溶质过剩 `Γ`**（`self.Gam`/`Gam_mol`）、**面上薄膜序参量 `ψ`** | `:3396`「面上场 Γ（溶质过剩）：Gibbs 面的"面"」、`:1202`/`:4511`（ψ）、`:3801`（`γ(n)`/`M(n)` 是面自己的性质） |

### ⚠ 但**实现上界面是弥散的，不是零厚度**

| 事实 | 数值/证据 |
|---|---|
| `φ` 是有符号距离场（SDF），用窄带存储 | 快照 `band_val` 范围 **±3.75e-07 m = ±6 个胞** |
| **Sussman 重初始化**维持 `\|∇φ\|=1` | `sussman_reinit`（解 `φ_τ + S(φ₀)(\|∇φ\|−1)=0`） |
| 弹性求解器读的是**弥散**的 `h`（`pf.phi`），仓库自陈有 Gibbs 振荡 | `:1243`「硬 `region` 指示场喂进 FFT 谱法弹性求解器会产生 **Gibbs 振荡**」 |
| **仓库自己写明"设计是零厚度，实现不是"** | `:1250`「设计是**零厚度 Gibbs 面** ⇒ 若将来要走严格锐界面，正确做法是换**锐界面弹性求解器**」 |

**⇒ 结论（②）**：**设计意图 = "零厚度 Gibbs 面 + 体相场"；实现 = 用弥散 level-set 近似那个零厚度面。**
⇒ **`facet_project` 正是为了把这个偏差拉回来**（把被数值扩散抹圆的弥散剖面重整回平面）。

## §2 ① 所有场是否都变成盒子了？—— **代码上：所有"有实体"的场都会被换掉**

`windowB_surface.facet_project` 的主循环（`:3980-4008`，逐字读）：

```python
for k in sorted(n_tab):                 # 对**每个变体**
    k = int(k)
    if k <= 0 or k >= self.nreg: continue
    ...
    ph, info = _FP.facet_project_one(self.phi[k], self.dx, (nh, av, wv), excl=excl)
    if info.get('ok'):
        self.phi[k] = ph                # ★ **替换整个场**
        n_done += 1
return n_done
```

* `facet_project_one` 内部：**体内胞**（`φ_k<0`，≥50 个）沿 `(n*,a,w)` 三轴取分位数定上下界，
  外扩 `0.5Δx`，按体积标定缩放，返回**盒子的 SDF**（`:83-92`）；
* 体内胞 < 50 ⇒ `ok=False` ⇒ **不投影**（`return phi_k` 原样）；
* 场 0（母相）**不在循环里**（`k<=0` 跳过）；
* `excl`（`facet_excl`）**默认 0** ⇒ 不构造排除掩码（见 §3）。

**⇒ 所以：**凡是有实体（`φ_k<0` 的胞 ≥50）的场，其 `φ_k` 都会在每次投影时被替换为盒子。**
⇒ **`B40@700` 的 4 个场（都是实体）在投影发生的时刻**都是盒子**。**

### ⚠ 两个必须并列说明的限定

1. **投影是"周期性"的**（`facet_proj=N` ⇒ **每 N 步一次**），
   而**两次投影之间** `φ_k` 仍按正常物理推进（平流 + 重初始化）
   ⇒ **任意时刻的场不是严格盒子，而是"被盒子周期性重置的场"。**
2. **每次重置后 `φ_k` 是盒子；下一次投影前它已偏离盒子。**
   ⇒ 我在快照里看到的（step 700 恰是投影步吗？**未核实**）是"重置瞬间"还是"演化中"，
   **决定了它像不像盒子**。
