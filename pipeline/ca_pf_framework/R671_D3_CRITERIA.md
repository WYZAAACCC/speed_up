## §2 D3 要新增的判据（**六条，按"是否需界面离散"分层**）

### 2.1 ★ 核心：**一维层状算例**（有精确解析解，且是"锐界面"的最小模型）

**算例**：两相层状介质（相 A / 相 B），界面为平面 `x=0`，各相内 `ε⁰` 为常数。
**这是"锐界面弹性"的**最小可判问题**，且有**闭式解**（Eshelby 型 / 一维弹性力学）。

| # | 判据 | 解析答案 | 阈值（**可 FAIL**） |
|---|---|---|---|
| **D3-J1** | **法向位移连续** `[u_n] = 0` | 精确 0 | `\|[u_n]\| / (u 的尺度) ≤ 1e-10` |
| **D3-J2** | **面力连续** `[σ·n] = 0` | 精确 0 | `\|[σ·n]\| / \|σ\| ≤ 1e-8` |
| **D3-J3** | **应变跳变** `[ε] = f(ε⁰,C)` | 一维闭式解 | 相对差 `≤ 1%` |
| **D3-J4** | **界面处的 Gibbs 振荡** | 相内 `σ` 应为**常数** | `std(σ) / \|σ\|` 在相内 **≤ 1e-3**（**这是 ③ 的量化**） |

**⇒ `D3-J4` 就是 goal 第 ③ 项要的"Gibbs 振荡直接量化"**，而且给了一个**可 FAIL 的数**。

### 2.2 ② **与 `soft=True` 的同算例对照**（必须先量"现状有多差"）

**做法**：在 §2.1 的同一层状算例上，跑 **`soft=True`（现状）** 与 **锐界面（待实现）**，比：

| # | 判据 | 期望 |
|---|---|---|
| **D3-J5** | `soft=True` 的 `std(σ)/\|σ\|`（相内） | 应**显著大于** `1e-3`（否则 §2.1 的分辨力不足） |
| **D3-J6** | 两者的 `[σ·n]` 与 `[ε]` 误差比 | 锐界面应**至少好 1 个量级** |

**⇒ ⚠ 关键**：**必须先证明 `soft=True` 在这条判据上"确实差"** ——
否则整个 D1 的价值主张（"换求解器能改善弹性精度"）**不成立**。
**这正对应 `P24`（负对照要有分辨力）与 `P26`（判据要有"无法判定"支）。**

### 2.4 扩展 A0 的四条（**保持原有，加"界面版"**）

| 原判据 | 扩展 | 为什么 |
|---|---|---|
| A0a 均匀 `ε⁰` | **两相各自均匀 `ε⁰`**（即 §2.1 的退化情形） | 检验"相内正确" |

## §3 ★ 阈值从哪来（**不能凭感觉定**）

| 判据类 | 阈值来源 |
|---|---|
| **连续性类**（`[u_n]=0`、`[σ·n]=0`） | **精确 0**（物理定律）⇒ 阈值 = **数值零**（取 `≤1e-8 ~ 1e-10`，按双精度与量级定） |
| **跳变类**（`[ε]`） | **闭式解** ⇒ 阈值按**离散化误差**定（`≤1%`） |
| **振荡类**（`D3-J4`） | ⚠ **无解析参考** ⇒ 只能**相对定标**：以"界面与网格对齐时的振荡"为下界，以"`soft=True` 的振荡"为上界 |
| **守恒类** | **精确 0** 或**闭式** ⇒ 同上 |

**⚠ 诚实标注**：**`D3-J4` 的绝对阈值（`1e-3`）我给不出文献依据** ⇒
**它应先用 `soft=True` 与"界面严格对齐网格"两个极限定出标尺**，再定阈值。
**标为【待定标】。**
